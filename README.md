# 2026-2 기계학습 팀 프로젝트 — 차선 인지 실패 예측과 실패 유형 발견

인하대 스마트모빌리티공학과 · 기계학습(SME3006-001) · 담당 장준우 교수 · 2026학년도 2학기
팀: 안승현, 손재호, 장원태 (+4인째 미정)

## 주제 `[확정]`

> **"우리 차는 자기 차선 인식이 언제, 어떤 식으로 틀리는지 알 수 있을까"**

MORAI 시뮬레이터(K-City)에서 직접 수집한 데이터로, 미리 학습해 둔 카메라 차선 인지 모델(TwinLiteNet+)이
**실패하는 프레임을 GT 없이 예측**하고, **실패 유형을 라벨 없이 찾아낸다.**
인지 모델은 고정된 블랙박스로 두고 고전 ML(분류·회귀·군집·불확실성)만 쓴다.
→ [구현 계획](./docs/05_구현계획/A1_구현계획.md)

## 레포 구조

```text
2026-2-ML/
├── docs/                   과목 정보, 주제 후보, 팀 운영, 일정, 구현 계획
├── config/
│   └── local.env.example   각자 PC의 경로·이미지 설정 예시 (local.env는 Git 제외)
├── scripts/
│   └── run_container.sh    인지 모델 학습 이미지에서 이 레포 코드를 실행
└── src/
    ├── common/             외부 인지 코드·대상 모델 연결부
    └── visualization/      추론 결과 시각화 (카메라별·BEV)
```

인지 모델 코드는 이 레포에 복사하지 않는다. 각자 가진 인지 코드 레포 클론을 읽기 전용으로 마운트해 import한다.

## 빠른 시작 — 추론 결과 시각화

```bash
cp config/local.env.example config/local.env    # 처음 한 번, 자기 PC 경로로 채운다
scripts/run_container.sh python3 -m visualization.visualize_inference --split val --name v5b_val
```

결과는 레포 밖 `<워크스페이스>/outputs/inference_vis/<name>/`에 생기고, 그 안의 `README.md`·`index.html`로 찾아본다.
요구 사항과 설정은 [개발 환경](./docs/05_구현계획/개발환경.md)을 본다.

## 데이터 원칙

- **원본 데이터와 그 파생물(영상, 마스크, 시각화 이미지, feature), 체크포인트는 Git에 올리지 않는다.** `.gitignore`가 막고 있지만 커밋 전에 한 번 더 확인한다.
- 결과물은 레포 밖 `outputs/`에 둔다. 발표 자료에 쓸 이미지는 팀 공유 드라이브로 주고받는다.
- 개인 PC 경로와 이미지 이름은 `config/local.env`에만 적는다.
