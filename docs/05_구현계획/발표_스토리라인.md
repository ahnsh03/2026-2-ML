# 발표 스토리라인 — 왜 필요한가부터 결과까지

> 기준일: 2026-09-26 · 근거: [A1 구현 계획 §0](./A1_구현계획.md#01-왜-필요한가--동기와-의의) · 교수님 평가 기준: [프로젝트 요구사항](../01_강의정보/교수님_프로젝트_요구사항.md)
> proposal(9/30), milestone(11/4), 최종(12/9) 슬라이드를 만들 때 이 순서를 뼈대로 쓴다.

## 한 문장

> **"라벨이 없는 대량의 주행 데이터에서 사람이 봐야 할 실패 frame만 골라내는 방법을 만들고, 그 방법이 어떤 실패는 잡고 어떤 실패는 놓치는지까지 밝힌다."**

## 교수님 스토리라인 6단계에 맞춘 흐름

| 단계 | 슬라이드 | 핵심 메시지 | 근거·그림 |
|---|---|---|---|
| ① 재밌는 일 | **문제** | 시뮬레이터에는 정답이 있지만 실제 차에는 없다. 인지 결과를 고치려면 사람이 라벨을 달아야 하는데, 데이터가 너무 많다 | 카메라 3대 × 20 Hz → **한 시간에 약 21만 6천 장**. 그중 실패는 front 기준 **19%** → 무작위 라벨링은 노력의 80%를 이미 맞은 frame에 쓴다 |
| ① | **질문** | "GT 없이 틀린 frame을 골라낼 수 있을까? 어디서·언제 틀리고, 어떤 실패는 모델도 모르고 지나가나?" | Q1·Q2·Q3 ([계획 §1](./A1_구현계획.md#1-세-가지-질문--결과를-미리-알-수-없는-것만)) |
| ② 데이터 | **직접 수집한 데이터** | MORAI K-City에서 같은 2.2 km 경로를 날씨·시각만 바꿔 반복 주행했다. frame마다 GT가 있어 **"GT 없는 예측기"를 공정하게 채점**할 수 있다 | 8조건 × 반복 + 처음 보는 날씨(cloudy). 교란 문제(val은 조건마다 다른 구간) → 같은 경로 반복 설계 |
| ③ 알고리즘 | **문제에 맞춘 기법 선택** | 질문마다 필요한 것만 고른다: 장소·조건 분해 = 선형회귀, 위험 곡선 = 1차원 GP, 경보기 = 로지스틱 → boosting, 실패 유형 = PCA + GMM, 튜닝 = random search | [계획 §1.5](./A1_구현계획.md#15-기법-선정--쓰는-것-6개와-빼는-것). 강의 주차와 1:1 대응 |
| ④ 구현 | **파이프라인** | 인지 모델은 블랙박스로 고정. 출력에서 GT 없는 신호 14개(자기 확신·재질문·영상 상태)를 뽑아 경보기에 넣는다. GT는 학습할 때 채점용으로만 쓴다 | [계획 §0.2](./A1_구현계획.md#02-무엇을-학습하고-gt는-언제-쓰나)의 학습/사용 그림, 추론 시각화(카메라별·BEV) |
| ⑤ 성능을 높였다 | **경보기 계단** | 기준선(확신 임계값) → 로지스틱 → boosting → +재질문·영상 → +위험 지도. 단계마다 PR-AUC가 얼마나 오르나 | PR 곡선, 튜닝 곡선(random vs grid) |
| ⑤ | **라벨링 효율 (대표 수치)** | "신뢰도 낮은 10%만 보면 실패의 몇 %를 찾나" — 무작위 10% 대비 몇 배 (이론 최대 약 53%) | 라벨링 효율 곡선 |
| ⑥ 완성 | **발견** | 어디서·언제 틀리나(위험 지도), 어떤 실패가 조용한가(유형별 탐지율), 사전 예측과 무엇이 달랐나 | 위험 지도, 조용한 실패 갤러리, 사전 예측 vs 결과 표 |
| ⑥ | **한계와 다음 단계** | 같은 경로·시뮬레이터에서의 검증이다. 다음은 실제 주행 데이터 선별에 적용하는 것 | 조용한 실패 → "무작위 감사 샘플을 함께 돌려야 한다"는 처방 |

## 예상 질문과 답

| 질문 | 답 |
|---|---|
| GT가 있으면 얼마나 틀렸는지 다 나오는데 왜 머신러닝인가? | GT는 시뮬레이터에만 있다. 우리가 만드는 것은 **GT 없이** 틀린 frame을 고르는 예측기이고, GT는 그 예측기를 학습·채점하는 데만 쓴다 |
| 시뮬레이터에서 되면 실차에서도 되나? | 보장하지 않는다. 다만 GT 없는 예측기의 성능은 GT가 있는 곳에서만 잴 수 있으므로 시뮬레이터 검증이 첫 단계다. 실차 적용은 다음 단계로 명시한다 |
| 딥러닝 모델을 새로 학습하나? | 하지 않는다. 인지 모델은 고정된 블랙박스이고, 그 출력 위에서 고전 ML로 "언제 틀리나"를 푼다 |
| 조용한 실패가 많으면 실패한 연구 아닌가? | 아니다. "신뢰도 기반 선별로는 이 유형을 못 잡는다"는 것이 발견이고, 그 유형만 따로 모으는 처방으로 이어진다 |
| 왜 같은 경로만 달렸나? | 장소 효과와 날씨·시각 효과를 분리하려는 실험 설계다. 새 장소로의 일반화는 범위 밖임을 한계로 둔다 |
| 베이스라인은? | 확신 임계값 하나(단계 0a)와, 영상 없이 장소·조건만 쓰는 사전확률(단계 0b)이다 |
