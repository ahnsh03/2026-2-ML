# B2. Image-goal 도달 판정기

> 계열 B (ERC) · 순위 6
>
> **9/23 판정:** 정지 격자 촬영으로 GT를 만들면 ERC 단독 주제 중 상위권. MORAI 프로젝트 도움 없음 → 문서 하단 [9/23 구체화](#923-구체화--어떤-ml을-하나) 참고.

## 한 줄 정의

> **"이 장면이 목표 지점인가"**
> 목표 이미지와 현재 시점 이미지를 비교해 미션 완료 여부를 판정하는 모델을 만든다.

## 동기 — 주최측도 아직 정하지 않은 기준

ERC Indoor(Track 02)·Off-road(Track 03) 트랙은 **목표 이미지와 일치하는 시점에 도달하면 미션 완료**다.
그런데 대회 문서 기준으로 **"Image-goal 성공의 정량 판정 기준(위치/각도/이미지 유사도 임계값)"은
`[미확정]`** 상태다.

> "주최측이 아직 정하지 않은 판정 기준을 우리가 직접 만들어 본다"

이 스토리는 교수님의 ①단계("재밌을 것 같은 일")를 강하게 만족한다.

## 데이터·라벨

| 항목 | 내용 |
|---|---|
| 프레임 | FrodoBots 계열 ride의 front/rear 카메라 프레임 |
| 양성 쌍 | 같은 ride에서 시간적으로 가까운(또는 GPS상 가까운) 프레임 쌍 |
| 음성 쌍 | 같은 ride의 먼 구간, 다른 ride의 프레임 |
| 난이도 축 | 조명 변화, 시점 각도 차, 반복 텍스처 구간 |

## 알고리즘 — 6주차 PCA를 정면으로 사용

| 단계 | 방법 | 주차 |
|---|---|---|
| 0 | 픽셀 차이 / 히스토그램 유사도 (베이스라인) | — |
| 1 | **PCA 임베딩 + 유사도** | 6 |
| 2 | **kernel PCA 비교** | 6·7 |
| 3 | SVM으로 "도달/미도달" 이진 분류 | 7 |
| 4 | 앙상블 + random search 튜닝 | 11·14 |
| 분석 | 실패 사례 군집 (유리벽·반복 텍스처) | 13 |

작년 예시 `PCA vs. kPCA: A Comparative Analysis for Low-Resolution Face Recognition`과
구조가 같지만, **로봇 내비게이션이라는 실제 미해결 문제**에 붙어 있다.

## 강점

- 6주차 PCA/차원축소를 프로젝트의 중심에 놓을 수 있다 (다른 후보들은 PCA가 보조 역할).
- ERC 규정의 미확정 항목을 다룬다는 서사가 강하다.
- 이미지 데이터라 발표 슬라이드가 직관적이다.

## 약점

- **라벨 구성이 임의적이다.** "시간적으로 가까우면 같은 장소"라는 가정이 회전 구간에서 깨진다.
  GPS를 쓰면 Indoor 트랙(GPS 없음)의 취지와 어긋난다.
- **딥러닝 임베딩 없이 고전 기법만으로 성능이 얼마나 나올지 불확실하다.**
  다만 "고전 기법의 한계를 정량화했다"는 것도 결론이 될 수 있다.
- ERC 트랙 중 Indoor/Off-road는 우리 팀 우선순위가 Urban보다 낮을 수 있다 (확인 필요) `[미확정]`

## 9/23 구체화 — 어떤 ML을 하나

ERC 규정상 **판정 기준(위치·각도·유사도 임계값)이 `[미확정]`** 이고, 팀 Indoor 아키텍처 문서도
"stop head 별도 필요, 다양한 threshold 실험"을 남은 과제로 적고 있다.

**문제**: 목표 이미지 G와 현재 프레임 I가 주어졌을 때 "도착했나?"를 판정하고, 그 확신도도 낸다.

| feature 그룹 | 내용 |
|---|---|
| 외관 | HSV 히스토그램 거리, HOG 거리, 축소 영상의 PCA/kPCA 임베딩 거리 |
| 기하 | ORB 매칭 수, **RANSAC 인라이어 비율**, 호모그래피 스케일·회전, 매칭점 시차 — 같은 *시점*인지를 잡는다 |
| 조건 | 밝기·대비 차, 텍스처 반복도 |
| (선택) | 사전학습 descriptor(MegaLoc 등) 코사인 유사도를 **고정 feature로만** — 고전 feature의 한계를 재는 기준 |

| 단계 | 모델 | 주차 |
|---|---|---|
| 0 | 유사도 하나에 임계값 (주최측이 쓸 법한 방식) | — |
| 1 | Logistic regression | 3 |
| 2 | PCA vs kPCA | 6 |
| 3 | SVM linear vs RBF | 7 |
| 4 | RF/GBM + importance (외관 vs 기하) | 11 |
| 5 | GP — 도착 확률 + 불확실성, "확신할 때만 정지" | 12 |
| 분석 | GMM 실패 군집 (유리벽·반복 텍스처·조명) | 13 |

**GT — 정지 격자 촬영이 해법**: 실내 목표 지점 주변에 테이프 격자(예: 0.25 m, 헤딩 15° 간격)를 깔고 로버를 세워 찍으면
모든 사진의 상대 위치·각도가 실측값이 된다. 장소 5곳 × 약 100장. 조명 변화로 도메인 시프트 테스트셋도 만든다.
FrodoBots·Mini-4K의 시간·GPS 근접 쌍은 약라벨 규모 확보용이며 평가에는 쓰지 않는다.
허용 오차(0.5/1/2 m)를 실험 변수로 두면 "주최측이 정하지 않은 기준을 정량화했다"가 결론이 된다.

**판정 (9/23)**: 격자 촬영을 전제로 하면 ERC 단독 주제 중 B1과 비슷하거나 약간 위. 다만 **MORAI 프로젝트 도움이 없고**
ERC 본선(9/30–10/1) 이후라 다음 시즌용이다. ERC 집중으로 방향을 바꿀 때 먼저 검토할 후보.
