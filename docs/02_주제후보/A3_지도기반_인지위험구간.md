# A3. 지도 기반 인지 위험 구간 예측

> 계열 A (MORAI) · 순위 4 · 주 담당 적합: **장원태**
>
> **9/23 판정:** 단독 주제로 쓰지 않고 A1의 분석 축(실패 유형이 K-City 어디에서 나는가)으로 흡수 → [A1 구현 계획 §6](../05_구현계획/A1_구현계획.md#6-실패-유형-발견--고유-오류맵-군집)

## 한 줄 정의

> **"K-City의 어느 구간이 인지에 위험한가"**
> MGeo 지도의 구간(link) 속성으로 그 구간의 **인지 실패율**을 예측하고, 지도 위 히트맵으로 그린다.

## 데이터·라벨

| 항목 | 내용 |
|---|---|
| 지도 | `R_KR_PG_K-city_2025` — `link_set.json`(~8.7 MB), `node_set.json`, `global_info.json` |
| 부가 | 전역경로 4,429점, 체크포인트 pose 15개, KATRI 주행가능영역 자료 |
| 주행 로그 | capture_runs / datasets — 각 프레임의 위치를 링크에 매칭 |
| **라벨** | 링크별(또는 링크×조건별) 평균 인지 실패율 — A1과 동일하게 GT 마스크에서 산출 |

## Feature

곡률, 링크 길이, 차로 수, 교차로 여부, 정지선 유무·밀도, 경로 유형, 인접 링크 수,
전역경로상 위치, 그리고 조건(날씨·시간대).

## 알고리즘

| 단계 | 모델 | 주차 |
|---|---|---|
| 0 | 전체 평균 실패율 (베이스라인) | — |
| 1 | Linear / Logistic Regression | 3 |
| 2 | **Gradient Boosting / XGBoost** | 11 |
| 3 | GP 회귀 — 데이터가 적은 링크의 신뢰구간 | 12 |
| 분석 | PCA(지도 속성 구조), K-means(구간 유형 군집) | 6·9 |

## 강점

- **정합 문제가 A2보다 훨씬 단순하다.** 프레임 단위가 아니라 링크 단위 집계라 타임스탬프 정밀도 부담이 없다.
- **발표 비주얼이 가장 강하다.** K-City 지도 위 위험도 히트맵.
- 작년 예시 `Accident-Prone Segment identification via XGBoost from GEOLife`와 구조가 같되,
  공개 데이터가 아니라 **자체 데이터 + 자체 라벨**이다.
- 장원태가 이미 MGeo bake를 담당하고 있어 진입 비용이 낮다.

## 약점

- **샘플 수 부족 위험.** K-City 링크 수가 많지 않으면 학습 데이터가 수백 건에 그친다.
  → 링크 × 조건(날씨 2 × 시간대 4 = 8) 조합으로 확장해야 한다. 그래도 부족하면 링크를 고정 길이로 재분할.
- **GP·불확실성을 넣을 자리가 A1/A2보다 약하다.** (다만 "데이터가 적은 링크의 예측 불확실성"이라는
  각도로는 오히려 자연스럽다.)
- 안승현의 기여가 라벨 제공에 그쳐 역할이 작아진다.

## 활용 방안

**A2의 하위 모듈로 흡수 가능하다.** A2의 "지도 정합 feature" 파트를 장원태가 맡을 때,
이 주제의 분석(구간별 위험도 히트맵)을 발표의 한 섹션으로 넣으면 A2가 더 풍부해진다.
