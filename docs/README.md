# 팀 문서 시작점

목표는 **기계학습 기반 인지 품질 추정을 통한 딥러닝 인지모델 개선 데이터 플라이휠 구축**이다. 전방 RGB와 TwinLiteNet+ Medium v6의 출력에서 전체 차선 IoU를 추정하고, 같은 검수 예산으로 취약 장면을 찾아 재학습 효과와 기존 성능 유지를 검증한다.

**내부 완료일은 12월 4일**이다. 11월 24일 ROI 결정 → 27일 특징·알고리즘 첫 결합 → 30일 오프라인 판정 → 12월 4일 시연·영어 발표·공개 페이지를 완성한다. 공식 영어 8분 발표는 12월 9일, 페이지 제출 마감은 12월 13일이다. [상세 일정과 인계](guides/일정과_역할.md)

## 현재 확인한 상태

- **9영역에서 RF·GP 공통 24열을 선정했다.** 환경 쪽은 날씨 80개·시각 160개 히스토그램 성분과 e-means RGB54를 별도로 인계한다. 새 8위치 480장의 관측 MAE는 RF 0.0616, GP 0.0673이다. 정상 오경보·환경별 검수 기준의 보정은 다음 결합 과제다. [특징 선정 결과](experiments/ROI_9영역_특징선정_20261124.md) · [실행 가이드](guides/ROI와_특징추출.md)
- 11월 23일 저녁의 후보 576장 중 위험순 116장은 모두 실제 IoU < 0.7이었다. 조건부 갱신 후보는 과거 회로 273장에서 차선 IoU 0.4026→0.5293, 기존 1,613장에서 0.8011→0.7991을 보였다. 해당 결과는 과거 모델·자료의 관측이다. 기본 모델은 v6이며 후보의 미사용 도로 검증이 남아 있다. [모집단·통제 조건·품질 MAE](experiments/오프라인_검수와_동일예산_재학습_20261123.md)
- 보관 연구 8개 세션 3,233장을 원본·해시·지연 GT 목록으로 검증했다. 기존 스트림·ROS 수신 부품과 관찰 실험이 있고, 채택한 새 특징·모델·정책의 26R1 통합 검증은 오프라인 판정 후 진행한다.

## 근거와 문서 관리

[실험 결과 목차](experiments/README.md)에는 날짜별 결과와 한계, [이력과 원문 대응표](archive/README.md)에는 이전 설계·실행 문서와 보존 해시가 있다. [논문·코드 출처](baselines/참고논문_베이스라인.md), [v6 근거](baselines/medium_v6_baseline_evidence.json), [X56 실행 스키마](contracts/quality_xy_v2.json), [입출력 정의](contracts/품질추정_입출력규약.md)를 함께 사용한다.
