# 팀 문서 시작점

목표는 **기계학습 기반 인지 품질 추정을 통한 딥러닝 인지모델 개선 데이터 플라이휠 구축**이다. 전방 RGB와 TwinLiteNet+ Medium v6의 출력에서 전체 차선 IoU를 추정하고, 같은 검수 예산으로 취약 장면을 찾아 재학습 효과와 기존 성능 유지를 검증한다.

**내부 완료일은 12월 4일**이다. 11월 24일 ROI 결정 → 27일 특징·알고리즘 첫 결합 → 30일 오프라인 판정 → 12월 4일 시연·영어 발표·공개 페이지를 완성한다. 공식 영어 8분 발표는 12월 9일, 페이지 제출 마감은 12월 13일이다. [상세 일정과 인계](guides/일정과_역할.md)

## 최신 완료 상태와 우선순위

[11월28일 전체 원본 재생·환경 검증 결과](experiments/환경검증_전체원본재생_20261128.md)와 [공개 표·16개 그림](baselines/environment_cycle_20261128/README.md)이 현재 정본이다.8회 재학습, f1용 X/y·GP/RF 재적합, 환경별 기준·동점·구간 비교,26R1 새 확인618장, RGB→검수→GT 연결과 standalone 재생을 완료했다.

**온라인 이행·f1/g1 통합 교체는 보류한다.** 후보 GP52열은 새 확인 MAE0.03653, RF52열은0.03047이었다. GP의 Dev 우세가 모든 조건에 유지되지는 않았다. 낮은 IoU precision95.16%와 달리 도로별 recall은 무작위 미만이고 근거리 결함114장 중 회수0장이다. 무표시·원거리 전용 장면과 검수 가치를 구분하지 못했다. [지원량 감사](baselines/environment_cycle_20261128/reports/fresh_support_audit.json)

원본26,001장 전체 재생은 유지한다. 다음은 **타깃 가용성·근거리 FP/FN 라벨과 장면 표현 보완→새벽/장면 층화 Dev→새 독립 확인**이다. 그 전에는 임계 BO나GP를 더 조정해 이번 실패 확인의 점수를 맞추지 않는다. 오프라인 기준 통과 후 ROS shadow와 누적f2로 넘어간다.

승현은 데이터 역할·유효 표시 구간과 무표시 음성 구간의 등록·종합 판정을 맡는다. 재호는 RGB 장면/표시 가용성·07시 특징과 사례 검수, 원태는 검수 가치·GP/RF·불확실성·BO의 독립 재현을 맡는다. 영어 프로젝트 페이지는 현행 결과·한계·정확한 그림부터 병행한다. [구체적 인계](guides/일정과_역할.md)

[27일 부분 재생](experiments/군집_검수_동일예산_재학습_20261127.md)과 [26일 저속 주행](experiments/ROI9_저속주행과_검수보정_20261126.md)은 당시 자료·버전·결과로 보존한다.
