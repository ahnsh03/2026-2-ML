# 팀 문서 시작점

목표는 **기계학습 기반 인지 품질 추정을 통한 딥러닝 인지모델 개선 데이터 플라이휠 구축**이다. 전방 RGB와 TwinLiteNet+ Medium v6의 출력에서 전체 차선 IoU를 추정하고, 같은 검수 예산으로 취약 장면을 찾아 재학습 효과와 기존 성능 유지를 검증한다.

**내부 완료일은 12월 4일**이다. 11월 24일 ROI 결정 → 27일 특징·알고리즘 첫 결합 → 30일 오프라인 판정 → 12월 4일 시연·영어 발표·공개 페이지를 완성한다. 공식 영어 8분 발표는 12월 9일, 페이지 제출 마감은 12월 13일이다. [상세 일정과 인계](guides/일정과_역할.md)

## 현재 확인한 상태

- **최신 인계는 [군집·검수·동일 예산 재학습 통합 결과](experiments/군집_검수_동일예산_재학습_20261127.md)**와 [공개 근거·그림](baselines/selection_cycle_20261127/README.md)다.9영역·품질28열·환경RGB27열/e-means K8, GP/RF·BO·검수·인지 재학습·새 품질 재적합을 연결했다.
- 신규3,072장+공통replay4,096장으로 Random/QualityRank/ClusterBO 각2시드와 신규0장 대조2회, 총8학습을 마쳤다. 각24,000업데이트·약68분이다. 추가24개는 gradient학습 없이 만든 보간 가중치다. 원본 복사나 새 수집은 하지 않았다.
- 개발에서 고른 QualityRank alpha0.5는 주 확인IoU0.57891→0.64997, 기존lane 손실0.00294였다. 두 시드의 인지 기준은 통과했지만 품질·군집 선별이 무작위보다 재학습 효과가 크지는 않았다.
- **f1/g1 통합 교체는 보류하고 f0/g0 기본값을 유지한다.** 새GP MAE0.07979(RFQ0.08382)는 사전 품질 유지 기준을 실패했다. 낮 장면의 과신과 도로별 편향을 공개했다. 검수 후보 정책은 공통Q0.7확률+감사 fallback이며 군집강제할당·σ혼합·환경하향임계는 미채택이다.
- RGB96장→검수12장→GT연결과 예약 역할 보존을 확인했다. 같은 배치의 특징 차이는0,40CPU/50GPU IoU예측 차이는0.00001132다. portable RF·버전 혼입 거부도 통과했다. 실제40GPU·liveROS·누적f2는 별도다.
- 원래 train26,001/val1,404장과 등록28,971장의 디코딩RGB 중복은0이다. quality-fit과 인지 추가학습은 ID/픽셀은 다르지만 위치가 가까운 경우가 많다. 확인3도로는 같은 지도에서 이미 열린 f0의 paired 진단이며 처음 보는 최종 시험이 아니다.

다음은 **g1 품질 유지성 보완→새 동결 구간 확인→다음 수천장 주기→ROS shadow 연결**이다. 재호는 사례/특징·영문 페이지, 원태는 새 버전의 GP/확률/검수 독립 재현, 승현은 자료 역할·버전 쌍·최종 판정을 맡는다. [상세 분담](guides/일정과_역할.md)

이전의 [저속26R1 수집·f0 보정](experiments/ROI9_저속주행과_검수보정_20261126.md), [조건부 GP 라벨 획득](experiments/GP_조건부_라벨획득_20261126.md), [초기 f1/g1 기능 연결](experiments/9영역_인지버전쌍_연결검증_20261126.md)은 당시 자료·버전·성적을 보존한다. 새 장시간 재학습 결과와 합산하지 않는다.
