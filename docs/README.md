# 팀 문서 시작점

목표는 **기계학습 기반 인지 품질 추정을 통한 딥러닝 인지모델 개선 데이터 플라이휠 구축**이다. 전방 RGB와 TwinLiteNet+ Medium v6의 출력에서 전체 차선 IoU를 추정하고, 같은 검수 예산으로 취약 장면을 찾아 재학습 효과와 기존 성능 유지를 검증한다.

**내부 완료일은 12월 4일**이다. 11월 24일 ROI 결정 → 27일 특징·알고리즘 첫 결합 → 30일 오프라인 판정 → 12월 4일 시연·영어 발표·공개 페이지를 완성한다. 공식 영어 8분 발표는 12월 9일, 페이지 제출 마감은 12월 13일이다. [상세 일정과 인계](guides/일정과_역할.md)

## 현재 확인한 상태

- **주 품질 입력은 9영역·28열 GP로 유지한다.** 저속 주행 개발 자료에서 보닛·거리 관계·추가 RGB/확률 후보를 비교했다. 원거리31열은 새 확인의 MAE 이득이 사전 기준보다 작아 기본 대체로 채택하지 않았다. [저속 주행 결과와 판정](experiments/ROI9_저속주행과_검수보정_20261126.md) · [현재 실행 구성](baselines/roi9_drive_20261126/runtime_manifest.json)
- 26R1 새 구간의 정규 수집237회·5,541장, 기록 이동 합7.266km를 확보했다. 목표4km/h·최대5.648km/h·최대 횡오차0.166m다. 날씨/시각별 반복은 새 구간의 통제 대조이며 도로 수를 늘려 세지 않는다. 원본4채널·372후보·전체/3m 간격 목록을 보존했다.
- 새 확인3구간·366후보의 전체IoU MAE는 GP0.04982·RF0.05769였다. 한 구간은 GP0.11522로 오판이 남았고, 낮 장면Q0.428을0.763으로 예측한 사례도 공개했다. 같은 지도3도로 결과로 보편적 정확도를 주장하지 않는다.
- **검수는 공통IoU0.7의 저품질 확률순이다.** 별도28+31 진단 보정v2는 근/원거리90% 포함률98.4%/91.8%였으나 구간이 넓어졌고 원시 분포보다 Brier가 조금 나빴다. 근거리recall 유지가 정상인지를 보장하지 않아 사후GT에precision·FP수를 추가했다. 환경별 하향 임계·공간 예산 혼합·자동 학습 승인은 채택하지 않았다.
- GT없는 RGB366장 → 검수45장 → 원본 해시 확인·사후GT 연결을 확인했다. 40·50이미지 CPU 테스트 각226개, 40CPU/5070Ti RGB8장 호환이 통과했다. 실제40GPU·liveROS·새 인지모델 재학습/유지성 채택은 별도다. 원래 위치·Keyboard/Park·Sunny13으로 복원 후 실험 relay/컨테이너를 종료했다.
- 현행 전역 등록은103팩·28,971고유ID/디코딩RGB다. 보정용으로 전환한 후속 도로와 이미 열어본 확인 도로의 역할 원장을 따로 보존해 이후 미사용 평가로 섞이지 않게 했다. [공개 집계·그림](baselines/roi9_drive_20261126/README.md)
