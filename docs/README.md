# 팀 문서 시작점

목표는 **기계학습 기반 인지 품질 추정을 통한 딥러닝 인지모델 개선 데이터 플라이휠 구축**이다. 기계학습·캡스톤은 같은 개발 결과를 공유한다. 내부 완료일 **12월4일**, 공식 영어8분 발표 **12월9일**, 영어 프로젝트 페이지 제출 **12월13일**이다.

## 현재 채택 상태

**[GP 대비·새벽 QA·ROS shadow](experiments/대비특징_검수와_shadow_20261129.md)를 검증했다.** GP 정규화 선별·GP57 입력은 새534장 확인에서 제외했고 r2·9영역을 유지한다. [배포 모델](../models/README.md) · [단순 shadow 명령](guides/shadow_실행.md). RF/GP는 둘 다 유지하고 최종 패밀리 선택을 대용량 선별·재학습 비교 뒤로 미룬다.

**11월28일 새96조건 확인과 오프라인 인계를 완료했다.** 현재 인지는 `m-v6-r2-20261128`, 품질은GP52, 검수는RF74, 환경은RGB400과photo12/e-means20pass/K16이다. [정확한 결과와 한계](experiments/표시가용성_누적갱신_20261128.md) · [최종 표·그림·검증 영수증](baselines/scene_cycle_20261128/confirmation/README.md) · [인지 등록부](../config/perception_releases.json)

590장 새 확인의 표시3구간 IoU는 v6/r1/r2가0.58353/0.76453/0.78415다.59장 검수로 근거리 오류107장 중53장을 회수했다. 동결 GP 품질 MAE0.03136보다 RF 대조0.02421이 작았으며 GP의 일관된 우세를 주장하지 않는다.05시18/50·07시0/4, 같은 지도·원래 인지학습 위치 근접·한 학습 시드의 제한도 보고한다.

오프라인 RGB→선별→GT 연결과 standalone을 통과했고,26R1 ROS 약20Hz·실제 저속88.45m·293장 상주 추론/같은 배치 재생도 확인했다. [최신 표·그림](baselines/shadow_cycle_20261129/README.md). CPU353검사는 두 이미지에서 통과했다. 실제40GPU·긴 연속 주행/재연결·대용량 선별/재학습·자동 편입은 남아 있다. 이미 개봉한590/534장을 다음 독립 시험으로 재사용하지 않는다.

## 근거와 보존

[실험 목차](experiments/README.md)는 날짜별 질문·결과·한계, [archive](archive/README.md)는 이전 설계·원문 대응표다. [오전 가이드8개 보존본](archive/guides_20261128_early/README.md)은 상대 링크만 조정하고 원본/보존 해시를 기록했다. [논문·코드](baselines/참고논문_베이스라인.md), [원래v6 근거](baselines/medium_v6_baseline_evidence.json), [현재 번들 규약](contracts/support_aware_review_bundle_v1.md)을 함께 확인한다.

새 결과는 dated experiment, 현행 사용법은 guide에 반영한다. 원본·전체 학습 원장·세부 로그·개인 절대경로는 실험 볼륨/로컬 문서에 둔다. 검증한 배포 가중치·추론 번들은 사용자 요청에 따라 버전/해시를 고정해 [models](../models/README.md)에 포함한다. 공개 근거는 집계·실제 GT가 검증된 사례 그림·실행/게시 해시를 담고 전체 원본 데이터·optimizer를 포함하지 않는다.
