# 팀 문서 시작점

목표는 **기계학습 기반 인지 품질 추정을 통한 딥러닝 인지모델 개선 데이터 플라이휠 구축**이다. 전방 RGB와 TwinLiteNet+ Medium v6의 출력에서 전체 차선 IoU를 추정하고, 같은 검수 예산으로 취약 장면을 찾아 재학습 효과와 기존 성능 유지를 검증한다.

**내부 완료일은 12월 4일**이다. 11월 24일 ROI 결정 → 27일 특징·알고리즘 첫 결합 → 30일 오프라인 판정 → 12월 4일 시연·영어 발표·공개 페이지를 완성한다. 공식 영어 8분 발표는 12월 9일, 페이지 제출 마감은 12월 13일이다. [상세 일정과 인계](guides/일정과_역할.md)

## 현재 확인한 상태

- **27일 결합 기준선은 9영역·28열·GP다.** 재호의 원본 확률 후보를 대조해 상위 엔트로피 하나와 근−원거리 관계3개를 남겼다. 확대 품질 학습은 RF·GP 동일2,480장이다. [26일 특징·GP·26R1 결과](experiments/ROI9_GP와_26R1_검증_20261126.md) · [v3 명세](../config/region_feature_recipe_v3.json)
- 새26R1 품질 학습 미사용4링크96장 MAE는 GP0.0645·RF0.0712, 보관 반복주행7,339장은 GP0.0562·RF0.0595다. 다른 보관 링크에서는 RF가 좋다. 새 도로4곳의 작은 표본으로 일반적 우위를 주장하지 않는다. **원거리 recall 구간 포함률39.6%로 과신이 남아 공간 확률은 진단용**이다.
- 26R1 신규336장(기존 학습 장면 재생성144·별도 보정96·품질 학습 미사용 링크96)을4전방채널·상태·해시와 보존했다. GPU변경 뒤 기존14,955장의 IoU0.7 전환0건, GT없는RGB 재생과 사후GT 연결도 검증했다. [데이터·해시 근거](baselines/roi9_gp_20261126/README.md)
- 40/50 GPU 프로파일을 분리했고26R1 payload27/전체59바이트·송신 조향 반전을 반영했다. 실제ROS 메시지·저속 좌우 회전 인수는 남아 있다. 26일에는 인지모델 가중치를 바꾸지 않았다. 과거 재학습 효과는 [23일 결과](experiments/오프라인_검수와_동일예산_재학습_20261123.md)의 당시 버전이며 현재28열 파이프라인 채택 결과가 아니다.
- [9영역 인지 버전 쌍 연결](experiments/9영역_인지버전쌍_연결검증_20261126.md)도 기능 검증했다. 보관 f1에서384장 특징/정답을 다시 만들고 g1·RGB96장·검수12장·GT를 연결했다. 기존 f0/g0는 유지하고 새 인지 재학습 성과와 구분한다. 40·50 공통 RF 추론은 [NPZ 호환 번들](baselines/roi9_gp_20261126/portable/README.md)을 사용한다.
- [실제 라벨 획득·GP 조건부 갱신](experiments/GP_조건부_라벨획득_20261126.md)은 별도9방법×3예산을 동결한 뒤 새96장에 평가했다. 이득은 작고 부모/무작위 대비 불확실하므로 주28열·정책을 바꾸지 않는다. 신규26R1은624장, 전역85팩·23,430고유ID/픽셀이다. 인지 재학습 결과와 구분한다.

**26일 원거리 후속:** 보정96장과 다른4링크 평가96장을 더 수집했다. 원거리 전용31열 GP는 새 평가의 recall MAE0.0546(RF0.0591), 보강 보정의90% 포함률91.7%였으나 이전 도로와 결합 확률에는 한계가 남았다. 이 단계의 신규26R1 누계는528장이며, 이후 라벨 획득 평가96장을 더해 **현재 누계는624장**이다. 환경 RGB432장에서는 날씨95.1%·시각80.6%였지만 군집별 검수 기준을 정할 정상 지원이 부족했다. [후속 결과와 구분](experiments/ROI9_원거리보조와_환경전이_20261126.md)

팀원에게 모델과 실행 예제를 전달할 때는 [독립 추론 묶음 안내](guides/개발환경.md#팀원에게-독립-추론-묶음-전달)를 따른다. 원래 데이터 경로 없이 RGB8장으로40이미지CPU·5070Ti 재생을 확인했다.
