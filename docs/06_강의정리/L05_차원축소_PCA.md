## 한눈에

- 고차원 데이터(영상 픽셀, 단어 one-hot)를 적은 차원으로 옮기는 이유와 그 대가(정보 손실, 해석성 저하, 처리 단계 추가)를 정리한다.
- 선형 차원 축소 `z = Wᵀx`를 사영·재구성으로 보고, **PCA = 재구성 오차 최소화 = 사영 분산 최대화**임을 유도한다. 해는 공분산 행렬의 고유벡터다.
- PCA 알고리즘(중심화 → 공분산 → 고유분해 → 상위 k개 고유벡터)과 응용 **eigenface**(주성분을 이미지로 보기, 성분 수별 재구성, best/worst 재구성)를 다룬다.
- 선형 PCA가 못 잡는 비선형 구조에는 **kernel PCA**(커널 트릭, 커널 행렬 중심화)를 쓴다. 대신 해석과 재구성이 어렵고 n×n 행렬을 저장해야 한다.
- 매니폴드 학습(MDS, Isomap, LLE, LTSA, Laplacian eigenmaps)과 시각화 전용인 t-SNE/UMAP의 성격을 소개한다.
- 우리 프로젝트의 **고유 오류맵**(24×40 FN/FP 오류맵의 PCA, 구현 계획 §6)은 이 강의의 eigenface를 그대로 옮긴 것이다.

## 핵심 내용

### 1. 왜 차원 축소인가 (p.2–4)

- 예: 1080p 영상은 1920×1080×3 ≈ 622만 차원이다(원본 약 6 MB, PNG 1~3 MB, JPEG 0.1~0.5 MB). 단어 one-hot은 사전 크기만큼의 차원이다(옥스퍼드 영어사전 50~60만, 표준국어대사전 40~50만).
- 장점: 메모리·계산 효율, 의미 있는 정보만 뽑아 성능 향상, **차원의 저주 회피**, 일반화(과적합 방지), 2D·3D 시각화.
- 단점: 중요한 정보를 잃을 수 있다, 해석성이 떨어질 수 있다, 데이터 처리 단계가 늘어난다.
- 응용: 통신, 로봇 제어·자율주행, 생물정보학.

### 2. Feature 추출과 auto-encoder (p.5–7)

- 32×32×3 = 3,072차원의 공 영상도 실제로는 위치 `(x, y)`, 반지름 `r`, 색이라는 몇 개 값(latent vector, 예: `[14, 18, 5]`)으로 설명된다. auto-encoder는 이 값으로 압축(embedding)했다가 영상으로 되돌린다(reconstruction).
- feature는 과제(예: 분류)에 따라 달라지는 "측정 가능한 성질"이다(자동차: 바퀴·창문·문·전조등, 개: 다리·꼬리·털 질감). 뒤집히거나 찌그러진 차 그림으로 "그래도 차인가?"를 묻는다.
- auto-encoder 목적식 `min_θ ‖x − g(f(x))‖²`. 라벨이 없는 **비지도 학습**이고, 데이터의 본질적 구조를 보존하는 저차원 표현을 배운다. 흐름: 차원 축소 → feature 추출 → 표현 학습.

### 3. 선형 차원 축소 (p.8–12)

- `z = Wᵀx`, `W ∈ R^{D×d}`, `d < D`. `W`를 projection matrix라 한다.
- 선형대수의 사영: 부분공간의 기저 `Q = [u1 … uk]`에 대해 `v∥ = Q(QᵀQ)⁻¹Qᵀv`, 남는 부분이 `v⊥`.
- 2D 점 5개를 pc1 방향에 사영하면 점이 넓게 퍼지고 재구성이 원본에 가깝다. pc2 방향에 사영하면 점이 한곳에 뭉치고 재구성이 한 점 근처로 무너진다(p.9–11). 2차원 모두에 사영하면 원본이 그대로 복원된다.
- "하나만 고르라면 어느 벡터인가?" → 퍼짐이 큰 쪽이다.
- **PCA 정의**: d차원 데이터를 k차원으로 선형 사영하되 정보를 최대한 보존한다. 즉 **재구성 오차가 최소인 사영을 고른다.**

### 4. PCA 유도 (p.13–16)

| 단계 | 내용 |
|---|---|
| 1) 전처리 | 모든 변수의 평균이 0이 되게 **중심화** `x_i ← x_i − μ`. 분산 1 **정규화는 선택**이다: "보통은 하지 않는다(분산 자체가 의미 있을 수 있다)", "측정 단위가 서로 다르면 한다" |
| 공분산 | `Var(X) = Σ(X_i − X̄)²/N`, `Cov(X,Y) = Σ(X_i − X̄)(Y_i − Ȳ)/N`. 중심화 후 행렬로 `v = xᵀx / n` |
| 2) 1차원 사영 | 원점을 지나는 단위벡터 `w` 방향 사영 `(x_i·w)w`, 잔차 `‖x_i − (x_i·w)w‖² = x_i·x_i − (x_i·w)²` |
| 잔차의 합 | `MSE(w) = 1/n Σ‖x_i‖² − (1/n Σ x_i·w)² − Var[x_i·w]`. 중심화했으므로 가운데 항이 0 → `MSE(w) = 1/n Σ‖x_i‖² − Var[x_i·w]` |
| 결론 | **잔차 제곱합 최소화 = 사영의 분산 최대화.** 여러 성분은 서로 직교하는 단위벡터 `w1, …, wk` |
| 3) 분산 최대화 | `x ∈ R^{n×p}`, `σ_w² = 1/n Σ(x_i·w)² = 1/n wᵀxᵀxw = wᵀvw` |
| 고유분해 | `v`는 대칭·PSD라 `v = QΛQᵀ`, `Q`는 고유벡터로 된 직교행렬, `Λ = diag(λ1, …, λp)`, `λ1 ≥ λ2 ≥ … ≥ λp` |
| 해 | 아무 벡터나 고유벡터 기저로 `w = Qa`, `‖w‖ = 1 → ‖a‖ = 1`. `wᵀvw = aᵀΛa`를 최대화하면 `a = [1, 0, …, 0]ᵀ` → **`w = q1`(최대 고유값의 정규화된 고유벡터)** |

- p.13 그림: 공분산이 `[[5,4],[4,6]]`, `[[5,−4],[−4,6]]`이면 산점도가 기울고, `[[5,0],[0,1]]`, `[[1,0],[0,5]]`이면 축에 정렬된다. 공분산 행렬이 퍼짐의 방향과 크기를 담는다.

### 5. PCA 알고리즘과 예시 (p.17–22)

1. 재중심화: `x_i ← x_i − μ`
2. 공분산: `v = (1/n) xᵀx`
3. `v`의 고유벡터 `q_i`와 고유값 `λ_i`를 구한다
4. 고유값이 가장 큰 k개 고유벡터가 주성분이다. 슬라이드 표기 `x̂_i = Σ_{j=1..k} (q_j·x_i) q_j = x_iᵀQ_k`

- (보충 정리) 점수(좌표) `z_i = Q_kᵀ(x_i − μ)`(k차원), 재구성 `x̂_i = μ + Q_k z_i`, 재구성 오차 `‖x_i − x̂_i‖²`. 학습 데이터의 평균 재구성 오차는 버린 성분의 고유값 합 `Σ_{j>k} λ_j`와 같다. 그래서 "설명 분산 비율" `Σ_{j≤k} λ_j / Σ_j λ_j`로 성분 수를 고른다.
- 3D 예(p.18): 축을 주성분으로 돌리면 퍼짐이 pc1·pc2에 몰리고 pc3는 거의 0이다 → 2차원이면 충분하다.
- **eigenface**(p.19–21)
  - 얼굴 영상 ≈ `w1·PC1 + w2·PC2 + w3·PC3 + …`. 주성분을 얼굴 크기 이미지로 그리면 조명 방향, 윤곽 같은 전역 패턴이 보인다.
  - 성분 10 / 50 / 100 / 500개로 재구성하면 흐릿한 평균 얼굴에서 점점 본인 얼굴로 선명해진다.
  - **재구성이 가장 나쁜 얼굴**은 안경·모자·특이한 표정처럼 소수만 가진 특징이 있는 영상이다. "reconstruction error occurs when we have minor features."
- 잘 되는 예(p.22): `λ1 = 0.0938, λ2 = 0.0007`, `λ1 = 0.1260, λ2 = 0.0054`처럼 첫 고유값이 대부분이면 실질 차원은 1이다.
- 어려운 예: 원 위의 점은 `λ1 = 0.0884, λ2 = 0.0725`로 두 고유값이 비슷하지만 **진짜 차원은 1**(극좌표의 각도)이다. 선형 PCA로는 이 구조를 못 잡는다.

### 6. Kernel PCA (p.23–27)

- 입력 `x_i` 대신 다른 feature 공간 `φ(x_i)`에서 PCA를 한다(예: 직교좌표 대신 극좌표). 공분산 `v = (1/n) Σ φ(x_i)φ(x_i)ᵀ = (1/n) φ(x)ᵀφ(x)`.
- 커널 `K(x_i, x_j) = φ(x_i)ᵀφ(x_j)`. `φ`는 몰라도 되고 `K`만 있으면 된다. **내적만으로 쓰이는 알고리즘은 이 커널 트릭으로 비선형 버전을 만들 수 있다.**
- 유도(p.24): `φ`가 (무한 차원) 기저를 가지므로 `w = φ(x)ᵀa`로 둔다. `‖w‖² = 1 → aᵀKa = 1`, `wᵀv_φw ∝ aᵀK²a`. 정리하면 고유문제 `Ka = nλa`가 되고, 가장 큰 고유값의 고유벡터 `a`를 `aᵀKa = 1`이 되게 정규화한다.
- 대표 커널: 다항 `(x_iᵀx_j + c)^d`, RBF `exp(−‖x_i − x_j‖² / 2σ²)`, sigmoid `tanh(α x_iᵀx_j + c)`, 그 밖에 Fisher, neural tangent, Laplacian, Bessel.
- feature 공간 중심화: `φ̃(x_i) = φ(x_i) − (1/n) Σ_k φ(x_k)`, `K̃(x_i, x_j) = φ̃(x_i)ᵀφ̃(x_j)`. 슬라이드 식 `K̃ = K − 2·1_{1/n}K + 1_{1/n}K1_{1/n}`(`1_{1/n}`은 모든 원소가 1/n인 행렬).
  - (보충) 정확히는 `K̃ = K − 1_{1/n}K − K1_{1/n} + 1_{1/n}K1_{1/n}`이다. 가운데 두 항은 서로 전치 관계라 슬라이드는 이를 `2·1_{1/n}K`로 줄여 적었다.
- 알고리즘: 1) 커널 선택 → 2) 중심화된 커널 행렬 `K̃` → 3) `K̃`의 고유벡터·고유값 → 4) 상위 k개 고유벡터로 `ẑ_i(x) = Σ_{j=1..n} q_ij K(x_j, x)`.

| 기본 PCA 대비 장점 | 단점 |
|---|---|
| 복잡한 비선형 구조를 잡는다 | 계산이 비싸다 |
| **군집·시각화에 잘 맞는다** | **n×n 커널 행렬 전체를 저장**해야 한다 |
| | **성분을 해석하기 어렵다** |
| | **원본 데이터로 재구성하기 쉽지 않다** |

- p.27: 동심원 데이터는 선형 PCA로는 섞인 채로 남고 kernel PCA로 두 원이 분리된다. circle·moons·swiss roll·iris에 linear/rbf/poly/sigmoid 커널을 적용하면 결과가 크게 달라진다 → **커널과 그 파라미터 선택이 결과를 좌우한다.**

### 7. 비선형 차원 축소·매니폴드 학습 (p.28–36)

- 가정: 데이터가 매끄러운 저차원 기하 객체(매니폴드) 위에 있고, 그 매니폴드는 국소적으로 유클리드 공간처럼 보인다. 매니폴드를 "펴면" 분석이 쉬워진다(예: swiss roll, torus).
- **MDS**: 점 사이 거리를 보존하는 저차원 표현을 찾는다. 거리는 유클리드가 아니어도 되며, 매니폴드를 따라가는 **측지(geodesic) 거리**를 보존하고 싶다(지구 위 두 도시, swiss roll 위 두 점).
- 측지 거리 근사: 점을 꼭짓점으로 하는 그래프를 만든다. 방법 1은 반경 안의 점 연결, 방법 2는 k-최근접 이웃 연결.
- **Isomap**: 유사도 그래프 구성 → 그래프 최단 경로로 측지 거리 → 측지 거리 행렬 → MDS.
- LLE: 각 점을 이웃의 선형결합으로 표현하고, 그 국소 관계를 보존하는 저차원 임베딩을 고유분해로 찾는다. LTSA: 점마다 PCA로 접공간을 추정한 뒤 접공간이 정렬되게 임베딩한다. Laplacian eigenmaps: 그래프 라플라시안의 고유문제를 푼다.
- 장단점(p.34): Isomap은 구멍 없는 평평한 매니폴드·작은 데이터에 적합, LLE는 단순하고 빠름, LTSA는 경계에서 정확, LE는 국소 매끄러움은 좋지만 위상만 보존한다.
- **t-SNE, UMAP, LargeVis**는 차원 축소와 시각화의 경계를 흐린다. **축이 입력 공간의 어떤 의미에도 대응하지 않고, 새 데이터를 변환하지 못하는 경우가 많다.** t-SNE는 perplexity(2, 5, 30, 50)에 따라 같은 데이터가 전혀 다르게 보인다(distill.pub "How to use t-SNE effectively").
- MNIST 2D 시각화: PCA는 숫자들이 겹쳐 있고, t-SNE·UMAP은 숫자별 덩어리가 뚜렷이 분리된다.

## 교수님이 강조한 것 (작년 영상)

> 작년 Lecture 5는 영상이 올라오지 않았다(녹화본 없음). 아래는 **다른 강의 영상의 자동 자막**에서 PCA·차원 축소·feature를 언급한 대목을 모은 것이다. 출처 강의를 괄호로 적는다.

1. **작년에도 PCA 수업은 했고, kernel PCA는 못 했다** (L06 SVM) — "저번 시간에 … 디멘션 리덕션을 하면서 PCA를 하고 … 리니어 PCA만 했는데 PCA의 확장형으로 커널 PCA까지 들어가서 … 배웠어야 되는데 배우지를 못했는데". → 녹화본만 빠진 것이다(기존 분석 문서의 "다뤄지지 않았을 가능성"은 정정된다). 선형 PCA(~p.22)까지는 수업했고 kernel PCA(p.23–27)는 건너뛰었다. 매니폴드 학습(p.28–36)을 다뤘는지는 알 수 없다.
2. **커널은 여러 알고리즘에 쓰는 도구, 그리고 시험 언급** (L06 SVM) — "이 커널이라는 스킬은 다양한 머신러닝 알고리즘에서 사용이 될 수 있는 스킬이에요." 바로 뒤에 시험 이야기가 나오지만 자막이 깨져("시험 배놓는 거니까") 시험에 **넣는다**는 뜻인지 **뺀다**는 뜻인지 알 수 없다. → kernel PCA·SVM·GP가 같은 커널 트릭으로 이어진다. 시험 범위는 올해 공지로 확인해야 한다.
3. **차원 축소 → feature 벡터 → 거리 → 군집** (L07 Clustering) — "텍스트나 이미지 데이터 … 저번에 했었던 디멘션 리덕션 알고리즘으로 뭔가 조금 더 다른 피처 벡터로 만들어내고 그 피처 벡터를 기반으로 … 유클리디언 디스턴스나 … 코사인 시밀러리티를 만들어서 그 데이터의 … 근접함을 나타냅니다." → 구현 계획 §6의 "PCA 점수 위에서 GMM·K-means"가 교수님이 설명한 파이프라인 그대로다.
4. **영상은 펼쳐서 벡터로 본다, 단 스케일 전제가 있다** (L07 Clustering) — "20×20 × RGB 3 … 1200개의 벡터 플랫하게 만들면은 1200개 디멘션의 벡터 … 그 벡터끼리의 계산을 이렇게 해도 되는 거겠죠?", 이어서 유클리드 거리에는 각 축(x·y 방향)의 스케일이 같다는 가정이 있다고 덧붙인다(자막 일부가 깨져 요지만 옮김). → 24×40 FN·FP 맵을 1,920차원으로 펴는 것과 같은 조작이다. 셀 간 스케일이 비슷한지 먼저 확인한다.
5. **공분산으로 방향별 퍼짐을 맞추는 거리(마할라노비스)** (L07 Clustering) — "이쪽으로는 많이 퍼져 있고 이쪽으로는 적게 퍼져 있어요 … 코베리언스 공분산을 구해 줘서 … 적게 퍼진 만큼 넓게 퍼진 만큼의 디스턴스를 통일시켜 주는 거예요." → (보충) PCA whitening 뒤의 유클리드 거리가 곧 마할라노비스 거리다. K-means 기준선에 whitening을 할지 판단하는 근거가 된다.
6. **차원의 저주와 단순한 모델** (L02-1 ML basics) — "스페이스가 커지면 커질수록 데이터는 굉장히 스파스해질 거고 그런 측면에서 피처를 적절히 적게 좋은 피처들만 선택을 해서 데이터를 만들어야 학습이 잘 될 수가 있어요." 이어서 오컴의 면도날: "심플한 모델일수록 제너럴라이제이션이 잘 돼요." → 1,920차원을 그대로 GMM에 넣지 않고 PCA로 줄이는 이유다.
7. **차원 축소는 전처리 파이프라인의 한 단계** (L02-1 ML basics) — "프리프로세싱을 하는데 노멀라이제이션이나 피처 익스트랙션을 여기서 뭐 한 번 더 할 수가 있거나 디멘셔널리티 리덕션 같은 여러 가지 알고리즘들을 이용해서 프로세싱을 합니다." 그 뒤 하이퍼파라미터 튜닝 루프로 이어진다. → 성분 수 d도 튜닝 대상이다.
8. **one-hot을 저차원 임베딩으로** (L02-2 ML basics) — "몇십만 개의 디멘션이 필요해요 … 적은 디멘션으로 차원을 축소해 줘야 돼. 디멘션 리덕션 이런 데서 이런 알고리즘을 씁니다."(word2vec 예) → 슬라이드 p.2의 단어 one-hot 예와 같은 문제의식이다.
9. **스케일이 다르면 정규화** (L02-2 ML basics) — "하나는 데이터가 0부터 1인데 하나는 데이터가 0부터 10의 50승 … y축을 노멀라이제이션을 해서 … 웨이트가 비슷해지겠죠." → 슬라이드 p.13의 "단위가 다르면 분산 1로 정규화"와 같은 원칙이다. 오류맵(같은 단위)과 feature 표(다른 단위)에서 결론이 갈린다.

## 우리 프로젝트(A1)에서 쓰는 곳

[구현 계획](../05_구현계획/A1_구현계획.md) §6 "실패 유형 발견 — 고유 오류맵 군집"이 이 강의의 직접 응용이다. 일정상 첫 고유 오류맵은 8주차, 첫 군집 갤러리는 10주차 milestone, 확정은 13주차다(§10). 담당은 실패 유형 발견 역할이다(§11).

| 강의 내용 | A1에서 쓰는 곳(계획 §) | 구현 메모(scikit-learn 클래스·하이퍼파라미터·주의점) |
|---|---|---|
| 영상 → 벡터 펼치기, 선형 사영 `z = Wᵀx` | §6 단계 2 | 뷰별 valid 영역을 24×40으로 area pooling한 FN·FP를 이어 붙여 `X ∈ R^{n×1920}`(FN 960 + FP 960). **뷰별로 따로** 적합(front 따로). left/right를 합칠 때는 right 맵을 좌우 반전한 뒤 펼친다(§6 확장). 열 순서(FN 먼저, row-major)를 `error_maps.npz` 메타에 고정 |
| 중심화, 평균 μ | §6 단계 3·5 | `PCA`가 자동으로 평균을 뺀다. `pca.mean_.reshape(2, 24, 40)`이 **평균 오류맵**이며 갤러리 첫 장으로 쓴다 |
| 정규화는 선택, 단위가 같으면 보통 안 함 | §6 단계 2–3 | 셀 값이 모두 같은 단위(비율)이므로 **StandardScaler를 쓰지 않는다.** 표준화하면 오류가 거의 없는 셀(valid 경계, 차선이 드문 위쪽 행)의 잡음이 커진다. 다만 원거리 행은 차선이 가늘어 값이 작으므로 "원거리 소실"이 묻히는지 행별 분산 그림으로 확인하고, 필요하면 √ 변환(보충)과 비교 |
| 분산 최대화, 고유값 λ, 설명 분산 | §6 단계 3–4 | `explained_variance_ratio_` 누적 곡선(scree)을 그린다. 이미지로 볼 성분은 상위 8~10개. GMM 입력 차원은 누적 80~90% 지점 또는 d ∈ {5, 10, 20}을 비교해 BIC 최적 K와 bootstrap ARI가 안정한 값으로 고른다 |
| eigenface = 주성분을 이미지로 | §6 단계 3 **고유 오류맵** | `pca.components_[j].reshape(2, 24, 40)` → FN·FP 두 패널. 고유벡터 부호는 임의이므로 0 중심 diverging colormap을 쓰고 절댓값 최대 셀이 양수가 되게 부호를 고정한다. (보충) `μ ± 2√λ_j q_j` 두 장을 나란히 그리면 "이 성분 점수가 크면 어디 오류가 늘어나는가"가 바로 읽힌다 |
| 재구성 오차, best/worst 재구성 | §6 단계 5–6 갤러리·검증 | `X_hat = pca.inverse_transform(pca.transform(X))`, 행별 `((X − X_hat)**2).sum(1)`. 잔차 상위 sample은 PCA가 못 담는 **드문 실패 유형 후보**로 갤러리에 따로 싣는다. F 묶음으로 적합한 PCA에 O 묶음(cloudy)을 넣어 잔차가 커지는지 보면 H5의 오류 공간 버전이 된다 |
| λ1이 지배하는 예(p.22) | §6 단계 3 해석 | 오류맵은 sample마다 총 오류량 차이가 커서 **PC1이 심각도(≈ 1 − IoU) 성분**이 되기 쉽다(eigenface에서 조명이 앞 성분을 차지하는 것과 비슷, 보충). PC1 점수와 `lane_iou`의 Spearman을 기록한다. "모양"만 보려면 (a) 실패 sample(`lane_iou < τ`)만으로 PCA, (b) 맵을 합이 1이 되게 정규화한 뒤 PCA를 비교한다 |
| whitening(보충) + L07 마할라노비스 | §6 단계 4 K-means 기준선 | `PCA(whiten=True)`는 점수를 `√λ`로 나눠 성분별 분산을 1로 만든다. K-means(구형·유클리드)는 whitening 여부로 결과가 달라지므로 둘 다 보고한다. full 공분산 GMM은 선형 변환에 거의 불변이라 영향이 적다. 이미지는 항상 whitening 전 `components_`로 그린다 |
| 차원의 저주 | §6 단계 4 GMM | full 공분산 파라미터는 `K·d(d+1)/2`개다(d = 20, K = 12면 공분산만 2,520개). 표본이 적을 때는 d를 줄이고 `covariance_type='diag'`와 비교한다 |
| 표본 수 < 차원(eigenface와 같은 상황) | §10 5–8주 export v0 | 기존 val은 1,404 sample, front만 보면 468 < 1,920이다. 성분은 최대 n−1개이고 뒤쪽 성분은 잡음이다. v0에서는 앞 성분만 해석하고 F 묶음 수집 뒤 다시 적합한다 |
| kernel PCA | §6 확장 비교 | `KernelPCA(kernel='rbf', gamma=…)`. n×n 행렬이라 2~3k 층화 서브샘플로 한다. 성분을 오류맵 이미지로 그릴 수 없으므로 **주 방법은 선형 PCA**로 두고, kernel PCA는 "사람 분류와의 NMI·ARI가 나아지는가"만 비교한다 |
| t-SNE/UMAP은 시각화 전용 | §6 단계 5 갤러리 | PCA 점수(예: 20차원) → `TSNE(perplexity=30)` 2D 산점도, 색 = 군집·날씨·시각·뷰. 새 데이터를 변환하지 못하므로 군집 입력으로 쓰지 않는다. perplexity를 2~3개 바꿔 모양이 유지되는지 확인 |
| 단위가 다르면 표준화 | §6 확장 "입력 공간 군집" | feature A+B(밝기, 엔트로피, 면적 …)는 단위가 달라 `make_pipeline(StandardScaler(), PCA())` 순서로 한다. 오류맵 PCA와 반대 결론인 이유를 발표에서 한 줄로 설명한다 |

**누수 주의**: 오류맵은 GT로 만든 값이다. PCA 점수·재구성 오차·군집 id는 **분석과 타깃 용도**이며, GT 없이 돌아가야 하는 예측기(§5, §7)의 입력 feature로 넣으면 누수다. §6 "쓸모"의 다중분류는 군집 id를 타깃으로 두고 §5 feature로 맞히는 방향으로 한다. PCA·GMM 적합에는 L 묶음(12월 전용, §3.3)을 넣지 않는다.

## 구현 체크리스트

- [ ] `error_maps.npz`의 벡터 순서(FN/FP, row-major, 뷰별 valid crop)를 메타에 적었고, `reshape(2, 24, 40)` 왕복이 원래 맵과 일치하는지 테스트했다
- [ ] StandardScaler 없이 PCA를 적합했고 그 이유(같은 단위, 분산이 정보)를 주석에 남겼다. 원거리 행이 묻히는지 행별 분산 그림으로 확인했다
- [ ] 평균 오류맵과 상위 성분을 0 중심 diverging colormap·고정 부호로 그렸고, 성분마다 설명 분산 비율을 제목에 적었다
- [ ] scree 곡선을 그리고 GMM 입력 차원 d를 근거와 함께 기록했다(d를 바꿔도 BIC 최적 K와 ARI가 유지되는지 확인)
- [ ] PC1과 `lane_iou`의 상관을 확인하고, "모양" 분석(실패 sample만 / 합 정규화) 중 무엇을 주 결과로 쓸지 정했다
- [ ] sample별 재구성 오차를 저장하고 best/worst 재구성 갤러리를 만들었다
- [ ] PCA·GMM을 L 묶음 없이 적합했고, 오류맵 파생값을 GT-free 예측기 입력에 넣지 않았다
- [ ] kernel PCA와 t-SNE는 서브샘플에서 비교·시각화 용도로만 썼다

## 올해 강의와 다를 수 있는 점

- 이 노트는 **2025 작년 노트**다. 올해는 6주차(구현 계획 §10 일정상 10월 초)에 다룬다. **올해 노트가 올라오면 수식과 범위를 대조해 갱신한다.**
- 작년 영상이 없어 교수님의 강조점을 이 강의에서 직접 확인하지 못했다. 작년 L06 발언으로 보면 작년 수업은 **선형 PCA까지만** 했고 kernel PCA(p.23–27)는 건너뛰었다. 올해는 kernel PCA와 매니폴드 학습(p.28–36)이 실제 수업·시험 범위에 들어가는지 확인한다.
- 작년에는 커널 트릭이 SVM 시간에 처음 설명됐다. 올해 kernel PCA를 다루면 커널 개념이 6주차로 당겨지고, 7주차 SVM은 그 위에 쌓이게 된다.
- 올해는 8주차가 중간고사라 6주차 내용이 시험 범위에 들어갈 가능성이 높다(추정).
