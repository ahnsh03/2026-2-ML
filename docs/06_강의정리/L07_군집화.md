# L07. 군집화 — K-means와 그 밖의 방법

> 강의노트: `Lecture Note/Lecture 7 - clustering.pdf` (2025 작년 노트, 37쪽) · 올해 9주차(온라인)
> 작년 강의영상: "Lecture 7 - Clustering and K-means" (`scKkOHQ8y4E`) — 자동 자막 기반 · 기준일 2026-09-25

## 한눈에

- 군집화는 레이블 없이 비슷한 샘플끼리 묶는 비지도 학습이다. **"올바른 묶음"이 하나로 정해지지 않아서** 군집의 품질을 재는 것부터 어렵다.
- 무엇을 "비슷하다"고 볼지는 거리·유사도(L2, L1, 코사인, 마할라노비스, 해밍·자카드)를 무엇으로 고르느냐가 정한다.
- K-means는 **할당 단계와 재적합(평균 이동) 단계를 번갈아** 비용 `J`를 단조 감소시키는 휴리스틱이다. 결과가 초기값에 따라 달라지고 국소해에 빠질 수 있다.
- 확장: K-means++(초기화), mini-batch(속도), K-medoids(이상치), **K 선택(elbow, silhouette, X-means/BIC, G-means)**.
- K-means의 한계(선형 경계, 구형·같은 크기 가정, 불안정한 hard assignment) 때문에 DBSCAN(밀도 기반)과 계층 군집(덴드로그램·linkage)을 대안으로 본다.
- GMM·EM은 이 강의에서 다루지 않고 13주차(노트 `Lecture 12 - EM and GMM.pdf`)에서 다룬다. 프로젝트의 GMM+BIC는 두 강의를 함께 봐야 한다.

## 핵심 내용

### 1. 비지도 학습과 군집화 (p.3–7)

- 지도 학습은 입력과 타깃으로 학습한다. 비지도 학습은 입력만 쓰고(레이블 달기가 비싸서) **입력의 숨은 구조**를 찾는 데 집중한다.
- 군집 레이블은 "서로 다른 그룹"이라는 것만 나타낸다. 0·1·2 같은 번호나 색에는 의미가 없다.
- 실제 데이터에서는 군집이 몇 개인지 모르는 경우가 많다.
- "무엇이 올바른 묶음인가?": 원숭이와 더 관련 있는 것이 판다인지 바나나인지 묻는 예, 이모지를 고양이/사람으로도 행복/불행으로도 나눌 수 있는 예. **두 분류가 모두 합리적이라서 군집 알고리즘의 품질을 측정하기가 어렵다.**

### 2. 거리와 유사도 (p.8–10)

| 척도 | 식 | 특징 |
|---|---|---|
| 유클리드(L2) | `d(x,y) = sqrt(Σ_i (x_i − y_i)^2)` | 연속 feature 공간의 직선거리. **모든 feature가 같은 스케일이고 서로 상관이 없다고 가정한다** |
| 맨해튼(L1) | `d(x,y) = Σ_i |x_i − y_i|` | 이상치에 덜 민감하다. 대각선으로 갈 수 없는 격자 도시(뉴욕 맨해튼)의 거리. 슬라이드에는 `|Σ_i (x_i − y_i)|`로 적혀 있지만 절댓값이 합 안에 있어야 맞다(보충: 오기) |
| 코사인 유사도 | `sim(x,y) = x·y / (‖x‖ ‖y‖)` | 두 벡터의 **각도만** 보고 크기는 무시한다. 고차원·희소 데이터에 효과적이다 |
| 마할라노비스 | `d(x,y) = sqrt((x − y)^T Σ^{-1} (x − y))` | 공분산 행렬로 feature 간 상관과 스케일 차이를 반영한다(타원 위 `d1 = d2 = d3`). 슬라이드에는 `Σ`로 적혀 있지만 교수님이 영상에서 역행렬이어야 한다고 정정했다. `Σ = I`이면 L2와 같다 |
| 해밍 | 불일치 개수 | 범주형 데이터(혈액형, 머리색) |
| 자카드 | `sim(A,B) = |A∩B| / |A∪B|` | 집합의 교집합 크기 |

- 텍스트·이미지는 실무에서 **차원 축소(임베딩)로 벡터를 만든 뒤 feature 공간에서 기하 거리를 계산한다.**

### 3. K-means (p.11–16)

- 가정: 데이터가 유클리드 공간에 있고, K개 클래스에 속하며, 같은 클래스 점끼리는 유클리드 거리가 가깝다.
- **닭과 달걀 문제**: 할당을 알면 평균을 쉽게 구하고, 평균을 알면 할당을 쉽게 구한다. 최적해를 구하는 문제는 NP-hard라서 무작위로 시작해 둘을 번갈아 푸는 휴리스틱을 쓴다.
- 절차
  1. 초기화: 군집 중심 K개를 무작위로 둔다.
  2. 할당(assignment): 각 점을 가장 가까운 중심의 군집에 넣는다.
  3. 재적합(refitting): 각 중심을 할당된 점들의 무게중심(평균)으로 옮긴다.
  4. 할당이 바뀌지 않을 때까지 2–3을 반복한다.
- 목적함수: `J = Σ_{i=1..k} Σ_{x∈C_i} ‖x − μ_i‖^2` (`C_i`: 군집 i에 할당된 점들)
- **`J`는 증가하지 않는다.** 할당 단계에서는 점마다 거리가 줄고, 재적합 단계에서는 군집이 고정됐을 때 최적 중심이 평균이다. 따라서 수렴하지만 전역 최적은 보장되지 않는다.
- 국소해: 비볼록 문제라서 초기값에 따라 결과가 달라진다(p.16 그림: 한 덩어리를 둘로 쪼개고 두 덩어리를 하나로 합친 해).
  - 대응 ① **무작위 시작점을 여러 번** 돌려 `J`가 가장 작은 해를 고른다.
  - 대응 ② split-and-merge: 가까운 두 군집을 합치는 동시에 큰 군집 하나를 둘로 나눈다.

### 4. K-means 확장 (p.17–22)

| 문제 | 확장 | 방법 |
|---|---|---|
| 초기화에 민감 | **K-means++** | 첫 중심은 데이터 점 중에서 균등하게 뽑는다. 다음 중심은 **이미 뽑은 중심 중 가장 가까운 것까지의 거리 제곱에 비례하는 확률**로 뽑는다. 중심을 다 뽑으면 K-means를 돌린다. 실제로 더 정확하고 빠르다 |
| 계산·메모리 | **mini-batch K-means** | 미니배치를 무작위로 뽑아 그 데이터만으로 중심을 갱신하고 다시 뽑는다(GD → SGD와 같은 관계) |
| 이상치 | **K-medoids** | 평균 대신 중앙의 실제 데이터 점(medoid)을 중심으로 쓴다. 다른 비유사도(범주형 등)도 쓸 수 있다. `X = {1,2,3,4,100}`이면 mean 22, medoid 3 |

**K를 정하는 방법**

- **Elbow**: K마다 비용 `J`를 계산해 `J`–K 그래프에서 꺾이는 점을 고른다. `J`는 K에 대해 단조 감소한다(왜? 군집을 하나 더 두면 이전 해에서 출발해도 비용을 줄이는 방향밖에 없다 — 영상 설명). 그래서 "`J`가 최소인 K"를 고르면 안 된다.
- **Silhouette**: `S_i = (b_i − a_i) / max(a_i, b_i)`
  - `a_i`: 같은 군집의 다른 점들까지의 평균 거리, `b_i`: 가장 가까운 다른 군집의 점들까지의 평균 거리.
  - 군집이 잘 분리되면 `b_i ≫ a_i`여서 `S_i`가 1에 가깝다. 슬라이드 예에서는 K=4가 적절하다. K=3(0+2 병합)이나 K=5(3을 3-1·3-2로 분할)로 바꾸면 일부 군집의 실루엣이 떨어진다.
- **X-means**: 군집 하나를 둘로 나눴을 때 모델이 좋아지면 나눈다. 판단 기준은 **BIC(Bayesian information criterion)**다.
- **G-means**: 군집 안의 데이터가 가우시안처럼 보이지 않으면 나눈다(참 군집은 가우시안을 따른다고 가정).
- X-means와 G-means는 모두 군집 1~2개에서 시작한다.

### 5. 응용 (p.23–24)

- 벡터 양자화: 각 픽셀을 가장 가까운 대표색(군집 중심)으로 바꾼다. K=2, 3, 10으로 늘리면 K=10만으로도 원본에 가깝다. 즉 데이터를 크게 줄이는 방법이다.
- 이미지 분할: 픽셀을 군집해 영역으로 나누는 기초적인 분할이다.

### 6. K-means 정리와 한계 (p.25–26)

| 이슈 | 대응 |
|---|---|
| 제곱 유클리드 목적함수가 제한적 | K-medoids |
| 비볼록 최적화 | K-means++ |
| 실행 시간 | mini-batch K-means |
| K를 정해야 함 | elbow, silhouette, X-means, G-means |

추가 이슈(p.25 "More issues"):

- **hard assignment는 데이터가 조금만 흔들려도 불안정하다.**
- 모든 좌표와 모든 군집에 같은 가중치를 준다.
- **K가 바뀌면 군집이 임의로 바뀐다.**
- 비볼록·비구형 군집에 약하다.
- 군집마다 밀도·크기가 다르면 약하다.
- 군집 사이 경계가 선형이다(p.26: 보로노이 분할). 초승달 두 개나 비스듬히 늘어진 군집을 제대로 못 나눈다.

### 7. DBSCAN (p.27–30)

- 아이디어: 군집은 feature 공간의 밀집 영역이다. 군집 수를 지정하지 않아도 되고, 어느 군집에도 속하지 않는 점(잡음)을 가려내며, 복잡한 모양의 군집도 잡는다.
- 절차: 무작위로 점 선택 → 코어 점인지 확인(거리 `d` 안에 점이 `n`개 이상) → 코어면 색(레이블)을 주고 이웃 전체에 퍼뜨림 → 이웃 중 코어가 있으면 계속 퍼뜨림 → 더 퍼뜨릴 코어가 없으면 아직 색이 없는 새 점을 고른다.
- 장점: 임의의 모양을 학습하고 이상치를 찾는다.
- 단점: **새 샘플에 대해 예측할 수 없다.** 직관적이지 않은 하이퍼파라미터 두 개(`n`, `d`)를 튜닝해야 한다. 밀도가 서로 다른 군집에 약하다(p.30: K-means는 나누는 데이터를 DBSCAN은 희소한 군집을 잘게 쪼갠다).

### 8. 계층 군집 (p.31–36)

- 분할형(divisive, 전체에서 시작해 나눔)과 병합형(agglomerative, 점 하나하나에서 시작해 합침)이 있고 대부분 병합형을 쓴다.
- **덴드로그램**: 군집이 합쳐지는/나뉘는 과정을 나타낸 트리다. 원하는 높이에서 자르면 군집을 얻는다(p.32: 두 군집·세 군집).
- 병합형은 가장 가까운 두 점을 먼저 합친다. 그다음부터는 "군집–점", "군집–군집" 거리가 필요하고, 이 거리를 **linkage**라고 한다.

| linkage | 정의 |
|---|---|
| single | 두 군집에서 가장 가까운 점 사이 거리 |
| complete | 가장 먼 점 사이 거리 |
| average | 모든 점 쌍 거리의 평균 |
| Ward | 합쳤을 때 **군집 내 분산의 증가량** |

- 같은 6개 점도 linkage에 따라 병합 순서가 달라진다(p.35).
- 장점: 군집 수를 가정하지 않고, 덴드로그램만 보고 K를 정할 수 있으며, 의미 있는 분류 체계(taxonomy)와 대응할 수 있다.
- 단점: 한 번 합치면 되돌릴 수 없다. 직접 최소화하는 목적함수가 없다. 데이터가 많으면 안 된다. linkage마다 잡음·이상치에 민감하거나, 큰 군집을 쪼개거나, 크기·모양이 다른 군집을 다루기 어려운 문제가 있다.
- 스펙트럴 군집은 개요에만 있고 다루지 않았다.

### 9. K 선택과 군집 평가 — 슬라이드에 있는 것과 없는 것

| 질문 | 슬라이드가 주는 것 | 슬라이드에 없는 것 (보충) |
|---|---|---|
| K를 어떻게 정하나 | elbow(`J`–K), silhouette, X-means(BIC로 분할 판단), G-means(가우시안성 검사), 덴드로그램 절단 | GMM의 BIC 곡선을 K마다 직접 비교하는 방법은 13주차 EM·GMM |
| 군집이 좋은가 | "정답 묶음이 없어 품질을 재기 어렵다"(p.7), silhouette(내부 지표) | 외부 레이블과 비교하는 NMI·ARI, 사람 간 일치도 Cohen's κ |
| 군집이 안정한가 | "hard assignment는 작은 섭동에 불안정", "K가 바뀌면 군집이 임의로 바뀜"(p.25) | bootstrap 재표본 ARI로 정량화 |

## 슬라이드의 코드·라이브러리

슬라이드에 파이썬 코드는 없다. 그림 제목에 scikit-learn 매개변수 이름(`n_clusters`, `eps`, `min_samples`)이 보인다. 아래는 대응하는 API다(보충).

| 개념 | API | 메모 |
|---|---|---|
| K-means / K-means++ | `sklearn.cluster.KMeans(n_clusters, init='k-means++', n_init, random_state)` | `inertia_` = `J`. 1.4부터 `n_init='auto'`가 기본이라 k-means++ 초기화에서는 **한 번만** 돈다 |
| mini-batch | `sklearn.cluster.MiniBatchKMeans(n_clusters, batch_size)` | |
| K-medoids | `sklearn_extra.cluster.KMedoids` | scikit-learn 본체에는 없다(scikit-learn-extra) |
| silhouette | `sklearn.metrics.silhouette_score(X, labels, sample_size)`, `silhouette_samples` | 거리 행렬이 `O(n^2)`이므로 표본이 크면 `sample_size` |
| DBSCAN | `sklearn.cluster.DBSCAN(eps, min_samples)` | 잡음은 레이블 `-1`. `predict`가 없다(`fit_predict`만) |
| 계층 군집 | `sklearn.cluster.AgglomerativeClustering(n_clusters, linkage='ward')`, `scipy.cluster.hierarchy.linkage`·`dendrogram` | 덴드로그램 그림은 scipy |
| 거리 | `sklearn.metrics.pairwise_distances(metric=...)`, `cosine_similarity`, `scipy.spatial.distance.mahalanobis(u, v, VI)` | scipy의 `VI`는 **공분산의 역행렬**을 받는다 → `Σ^{-1}`이 맞다는 확인 |

## 교수님이 강조한 것 (작년 영상)

1. **군집에는 정답이 없다.** 원숭이–판다–바나나를 손들기로 물은 뒤 "그 정답이 있는 문제가 아니잖아요", "클러스터링 알고리즘을 … 잘됐냐 안 됐냐를 측정하기가 조금 어려운 경향이 있습니다". 그래도 "잘하는 것을 판단하기 위해서" 수학적으로 재야 한다고 했다.
   → 군집 결과는 우리가 정한 수치 기준으로 설득해야 한다는 뜻이다.
2. **군집 레이블은 이름이 아니다.** "빨간색 초록색 파란색이라는 답이 정해져 있는게 아니고 … 단순히 얘네들이 다른 그룹이다라는 것을 알려 주기 위해서".
   → 군집 번호는 임의로 붙는다. 비교할 때는 번호가 바뀌어도 값이 같은(순열 불변) 지표를 써야 한다.
3. **한쪽으로 쏠린 분할은 좋은 군집이 아니다.** "데이터 한 개와 데이터 나머지 전체다. 이런 식의 분류가 아니라면 적절하게 밸런스가 맞는 …".
   → 군집 크기 분포를 반드시 본다.
4. **마할라노비스 식 정정.** "코베리언스가 아니라 코베리언스의 인버스 매트릭스가 돼야 될 거 같은", "나중에 확률 분포 … 모델링을 해야 된다라고 했을 때 마할라노비스 디스턴스를 많이 보게 될 거예요".
   → 슬라이드 식의 `Σ`는 `Σ^{-1}`로 읽는다. 13주차 GMM의 공분산과 이어진다.
5. **코사인은 크기를 버린다.** "스케일이 좀 중요한 의미를 가지고 있는 상황에서는 이러한 형태를 쓰면 안 되고요".
   → 크기가 의미를 갖는지 먼저 따지고 척도를 고른다.
6. **이미지·텍스트는 차원 축소 후 거리를 잰다.** "디멘션 리덕션 알고리즘으로 … 다른 피처 벡터로 만들어내고 그 피처 벡터를 기반으로 지오메트릭 디스턴스".
   → 고유 오류맵(PCA) 뒤에 군집하는 우리 파이프라인과 구조가 같다.
7. **국소해는 여러 번 시작해서 피한다.** "그냥 많은 스타팅 포인트를 시작하면 됩니다". K-means++는 "프랙티컬하게 조금 더 정확하고 빠르게".
   → 구현할 때 `n_init`을 명시한다.
8. **개선의 흐름을 이해하라.** "항상 머신 러닝 알고리즘들이 어떠한 문제가 생기면은 … 개선이 되는데 개선되는 흐름을 이해를 조금 해 보면 좋을 것 같아요".
   → p.25의 이슈→확장 대응표가 이 강의의 핵심 정리다.
9. **시험·과제.** 작년에는 중간고사 전 주라 "시험 기간인만큼 적당히 하고 넘어가도록 할게요", "이번 주는 숙제를 안 낼게요"라고 했다. 덴드로그램이나 지난 시간의 RKHS 같은 생소한 용어는 시험 문제로 내지 않을 테니 "이건 좀 어렵다 싶으면 넘기세요"라고 했고, 스펙트럴 군집은 "(이) 주제 하나만으로도 또 하나의 렉처가 되더라고요"라며 건너뛰었다.
   → 공부할 때는 알고리즘 절차와 장단점 비교에 집중하면 된다.

## 우리 프로젝트(A1)에서 쓰는 곳

| 강의 내용 | A1에서 쓰는 곳(계획 §) | 구현 메모 |
|---|---|---|
| 차원 축소 후 기하 거리(p.10) | §6 단계 2–4: 오류맵 1,920차원 → PCA 점수 → 군집 | 성분 수는 6주차(PCA) 기준(누적 설명분산)으로 정한다. 군집은 **PCA 점수 공간**에서 하고, 군집 중심은 역변환해 24×40 평균 오류맵으로 그린다 |
| 유클리드는 "같은 스케일" 가정(p.8) | §6 단계 4 | PCA 점수를 그대로 쓰면 원 공간의 유클리드 거리가 보존된다(분산이 큰 성분이 지배). 점수를 `StandardScaler`로 표준화하면(whitening) 분산이 작은 잡음 성분까지 같은 무게가 된다 → **기본은 표준화하지 않고**, whitening은 비교 실험으로만 한다(보충) |
| 코사인은 크기를 무시(p.9, 강조 5) | §6 단계 2–4 | 오류맵 벡터에는 오류의 **양(심각도)**과 **공간 패턴**이 섞여 있다. 패턴만으로 묶으려면 PCA 전에 행을 L2 정규화하는 변형(코사인과 같은 효과)을 비교한다. 심각도는 `lane_iou`로 따로 설명한다(보충) |
| K-means, K-means++, 다중 시작(p.12–17) | §6 단계 4: K-means 기준선 | `KMeans(n_clusters=k, init='k-means++', n_init=10, random_state=0)`. 기본값 `n_init='auto'`는 1회뿐이라 명시한다. 표본이 약 2만 × 수십 차원이므로 mini-batch는 필요 없다 |
| elbow·silhouette(p.20–21) | §6 단계 4, §8.2 군집 지표 | K=2~12에서 `inertia_`와 `silhouette_score(X, labels, sample_size=5000, random_state=0)`를 그린다. silhouette은 볼록·구형 군집에 유리하므로 GMM 해의 평가는 BIC를 주 기준으로 한다 |
| X-means의 BIC 아이디어(p.22) | §6 단계 4: GMM, BIC로 2~12 탐색, full vs diag | `GaussianMixture(n_components=k, covariance_type='full'|'diag', n_init=5, random_state=0).bic(X)`. 자세한 내용은 13주차 노트에서 보강한다 |
| K-means의 한계: 구형·같은 크기·선형 경계(p.25–26) | §6 단계 4: "K-means 기준선 vs GMM"의 근거 | 발표에서 "왜 GMM인가"의 근거로 이 슬라이드를 인용한다. full 공분산 GMM은 군집마다 마할라노비스 거리를 쓰는 셈이다 |
| 정답 없음·레이블 임의성(p.5–7, 강조 1–2) | §6 검증 "사람 분류와의 일치" | `normalized_mutual_info_score`, `adjusted_rand_score`는 순열 불변이다. 사람 분류도 여러 합리적 묶음 중 하나이므로 **먼저 `cohen_kappa_score`로 사람끼리의 일치도를 보고**, 군집–사람 NMI·ARI를 그 기준에 비춰 해석한다. 교차표는 `scipy.optimize.linear_sum_assignment`로 군집↔유형을 짝지은 뒤 그린다 |
| hard assignment 불안정, K마다 군집이 바뀜(p.25) | §6 검증 "안정성", §8.2 bootstrap ARI | 재표본에 다시 적합 → 원 데이터 전체에 `predict` → 전체 적합 결과와 ARI를 구한다. K마다 반복해 "안정한 K" 곡선을 만든다. GMM은 `predict_proba`도 저장해 경계 샘플을 표시한다 |
| 균형 잡힌 군집(강조 3) | §6 단계 5 갤러리 | 갤러리 맨 위에 군집 크기 표를 둔다. 전체의 1% 미만인 군집은 병합 후보나 이상치로 표시한다 |

- 계획에 없는 DBSCAN은 `predict`가 없어 O·L 묶음에 적용할 수 없으므로 쓰지 않는다. 계층 군집(Ward)은 "실패 유형의 분류 체계"를 보여 주는 덴드로그램 보조 그림으로만 고려한다(선택).

## 구현 체크리스트

- [ ] 군집 입력이 뷰별 PCA 점수이고, 점수 표준화 여부를 설정 파일에 기록했다(기본: 표준화 안 함)
- [ ] `KMeans`에 `init='k-means++'`, `n_init≥10`, `random_state`를 명시했다
- [ ] K=2~12에서 inertia(elbow)·silhouette(표본)·GMM BIC를 한 그림에 그렸고, 기준마다 가리키는 K가 다르면 모두 보고한다
- [ ] 군집 비교는 ARI·NMI(순열 불변)로 하고, 교차표는 군집↔유형을 짝지은 뒤 그린다
- [ ] 사람 분류 150개의 Cohen's κ를 군집–사람 NMI·ARI보다 먼저 계산했다
- [ ] bootstrap ARI(50~100회)로 K별 안정성을 보고한다
- [ ] 군집 크기 분포를 확인하고 극소 군집을 표시했다
- [ ] 군집 id를 실패 예측 feature로 쓸 때(§6 "쓸모")는 PCA와 군집을 **fold 안에서** 적합해 누수를 막는다. O·L 묶음에는 `predict`만 한다

## 올해 강의와 다를 수 있는 점

- 2025 작년 노트 기준이다. 올해는 9주차 **온라인** 강의라 작년 영상이 재사용될 수도 있다. 올해 노트가 올라오면 이 문서를 갱신한다.
- 작년에는 중간고사 직전 주에 했고 과제가 없었다. 올해는 중간고사(8주차) 다음이라 시험 범위·과제 여부가 다를 수 있다.
- 작년 노트 개요에는 스펙트럴 군집이 괄호로 들어 있었지만 강의에서는 건너뛰었다. 올해 추가되는지 확인한다.
- 슬라이드 오기(마할라노비스의 `Σ` → `Σ^{-1}`, 맨해튼 식의 절댓값 위치)가 올해 노트에서 고쳐졌는지 확인한다.
- 올해 9주차는 계획 §10에서 팀 작업을 멈추는 주(10/30 다른 일정)다. 군집 코드는 10주차 milestone용 첫 갤러리와 13주차 GMM 확정 때 이 노트를 다시 본다.
