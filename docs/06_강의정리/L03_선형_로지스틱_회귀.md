## 한눈에

- 지도학습의 기본형을 다룬다. 타깃이 연속이면 회귀, 이산이면 분류이고, 데이터로 가설 `h: X → Y`를 학습한다.
- 선형 회귀를 최소제곱 비용 `J(θ)`로 정의하고 두 가지로 푼다. 하나는 닫힌 해(정규방정식)이고, 다른 하나는 반복 해(경사하강법의 batch / SGD / mini-batch)다.
- 오차가 i.i.d. 가우시안이라고 가정하면 최소제곱은 최대우도추정(MLE)과 같아진다. 이것이 제곱 비용의 확률적 근거다.
- 로지스틱 회귀는 선형식에 시그모이드를 씌워 `P(y=1|x)`를 출력하고, 베르누이 로그우도를 경사상승이나 뉴턴법으로 최대화한다. 갱신식은 선형 회귀와 모양이 같다.
- 일반화 선형 모델(GLM)은 지수족 분포와 링크 함수로 두 회귀를 한 틀에 묶는다. 기울기는 언제나 `(잔차) × (입력)` 꼴이다.
- numpy로 정규방정식·GD·SGD를 구현하고, 직접 만든 `LogisticRegressionGD` 클래스로 iris 두 클래스를 분류한다.

## 핵심 내용

(자막)은 작년 영상의 구두 설명이고, (보충)은 정리자가 덧붙인 설명이다.

### 1. 지도학습과 회귀 문제 (p.2–4)

- 예제로 집 크기(sq ft)에서 가격을 예측한다. 특징(방 개수 등)이 늘면 가설은 `h_θ(x) = θ0 + θ1 x1 + θ2 x2`가 된다.
- 학습 절차는 training set → learning algorithm → h 순서다. h를 predictor 또는 hypothesis라고 부른다.
- 타깃이 연속값이면 regression이고, 적은 수의 이산값이면 classification이다.

### 2. 선형 회귀와 비용 함수, 정규방정식 (p.5–7)

- 일반형은 `h_θ(x) = Σ_{i=0..d} θ_i x_i = θᵀx`이고, 절편을 넣으려고 `x0 = 1`로 둔다.
- 비용 함수(최소제곱)는 `J(θ) = 1/2 Σ_{i=1..n} (h_θ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²`다. 입력이 1차원이면 회귀선을, 2차원이면 회귀 평면을 맞춘다.
- 행렬형은 설계행렬 X(n×(d+1), i번째 행이 x⁽ⁱ⁾ᵀ)와 벡터 y로 `J(θ) = 1/2 ‖Xθ − y‖² = 1/2 (Xθ − y)ᵀ(Xθ − y)`로 쓴다.
- 미분하면 `∇J = XᵀXθ − Xᵀy = Xᵀ(Xθ − y) = 0`이다.
- 정규방정식은 `XᵀXθ = Xᵀy`이고, 해는 `θ = (XᵀX)⁻¹Xᵀy`다(pseudo-inverse, Moore–Penrose 역행렬).
- (자막) 제곱 비용은 볼록(convex) 이차함수라서 최솟값이 하나뿐이고, 그 점이 곧 전역 최솟값이다. 파라미터 수보다 데이터가 적으면 해가 여러 개 생긴다.

### 3. 경사하강법 (p.8–13)

- 초기 추정값에서 출발해 `θ_j ← θ_j − α ∂J/∂θ_j`를 반복한다. α가 learning rate다.
- 샘플 하나에 대한 기울기는 `∂J/∂θ_j = (h_θ(x) − y) x_j`다.
- j = 0..d 전부를 **동시에** 갱신한다. 2D에서는 각 축 기울기를 합친 벡터 방향으로 움직이는 셈이다.
- 경사하강법은 일반적으로 local minimum에 빠질 수 있다. 다만 이차 비용은 볼록이므로 학습률이 너무 크지 않으면 항상 전역 최솟값에 수렴한다.

| 방식 | 갱신 | 특징 |
|---|---|---|
| Batch GD | `θ ← θ + α Σ_{i=1..n} (y⁽ⁱ⁾ − h_θ(x⁽ⁱ⁾)) x⁽ⁱ⁾` | 스텝마다 전체 데이터를 훑는다. 참 기울기를 따라가므로 안정적으로 수렴한다 |
| SGD | i = 1..n마다 `θ ← θ + α (y⁽ⁱ⁾ − h_θ(x⁽ⁱ⁾)) x⁽ⁱ⁾` | 곧바로 진행을 시작해 빠르다. 대신 최솟값 근처에서 계속 진동하고 정확히 수렴하지 않을 수 있다 |
| Mini-batch GD | 샘플 일부를 묶어 갱신 | 둘의 절충이며 실무 기본이다. (자막) 이것을 SGD라고 부르기도 한다 |

- (자막) SGD의 진동은 학습률을 시간에 따라 줄이는 스케줄링으로 누그러뜨린다. 스케줄 자체도 튜닝해야 하는 하이퍼파라미터다.
- (자막) epoch는 전체 데이터를 한 번 다 쓰는 단위다. 슬라이드 코드처럼 `randint`로 복원추출하기보다 epoch마다 섞어서 샘플을 한 번씩 쓰는 편이 낫다.

### 4. 확률적 해석: 왜 최소제곱인가 (p.18–21)

- 가정은 `y⁽ⁱ⁾ = θᵀx⁽ⁱ⁾ + ε⁽ⁱ⁾`이다. ε은 모델에 담기지 않은 효과나 잡음이고, `ε⁽ⁱ⁾ ~ N(0, σ²)` i.i.d.로 둔다.
- 가우시안을 쓰는 이유는 세 가지다. 중심극한정리가 있고, 다루기 쉬우며(선형결합·조건부·주변분포가 모두 가우시안), 최대 엔트로피 분포다.
- 우도는 `p(y⁽ⁱ⁾|x⁽ⁱ⁾;θ) = 1/(σ√(2π)) exp(−(y⁽ⁱ⁾ − θᵀx⁽ⁱ⁾)²/(2σ²))`이다. 샘플이 독립이므로 `L(θ) = Π_i p(y⁽ⁱ⁾|x⁽ⁱ⁾;θ)`가 된다.
- 최대우도 원리는 데이터가 나올 확률을 가장 크게 만드는 θ를 고르라는 것이다. 계산이 쉬워지도록 로그우도를 최대화한다.
- `l(θ) = n log(1/(σ√(2π))) − 1/(2σ²) Σ (y⁽ⁱ⁾ − θᵀx⁽ⁱ⁾)²`에서 첫 항은 상수이고 둘째 항이 최소제곱이다. 따라서 **l(θ)를 최대화하는 것은 LS 비용을 최소화하는 것과 같고**, 결과는 σ 값과 무관하다.

### 5. 로지스틱 회귀 (p.22–26)

- 선형 회귀로 y ∈ {0,1}을 예측하면 0보다 작거나 1보다 큰 값이 나온다. 그래서 가설의 형태를 바꾼다.
- 새 가설은 `h_θ(x) = g(θᵀx) = 1/(1 + e^(−θᵀx))`이고, g를 logistic(sigmoid) 함수라고 한다. z→∞이면 1로, z→−∞이면 0으로 간다.
- 출력이 threshold(보통 0.5) 이상이면 positive class, 미만이면 negative class로 분류한다.
- 도함수는 `g'(z) = g(z)(1 − g(z))`다. 슬라이드 마지막 줄의 `g(z)g(1−z)`는 표기 오류로 보인다. 도함수를 원래 함수값으로 쓸 수 있어 계산이 편하다.
- 확률 모델은 `p(y=1|x;θ) = h_θ(x)`, `p(y=0|x;θ) = 1 − h_θ(x)`이고, 합치면 `p(y|x;θ) = h^y (1−h)^(1−y)`(베르누이)다.
- 로그우도는 `l(θ) = Σ_i [ y⁽ⁱ⁾ log h_θ(x⁽ⁱ⁾) + (1 − y⁽ⁱ⁾) log(1 − h_θ(x⁽ⁱ⁾)) ]`다. (보충) 부호를 바꾸면 binary cross-entropy, 곧 log-loss가 된다.
- 기울기는 `∂l/∂θ_j = (y − h_θ(x)) x_j`이고, 경사**상승** `θ_j ← θ_j + α (y⁽ⁱ⁾ − h_θ(x⁽ⁱ⁾)) x_j⁽ⁱ⁾`으로 갱신한다.
- LS 갱신식과 모양은 같지만 h_θ가 비선형 함수이므로 같은 알고리즘은 아니다.

### 6. 뉴턴법 (p.27–28)

- 뉴턴법은 원래 `f(x) = 0`의 근을 찾는 방법이다. 접선으로 선형 근사해 그 근으로 이동하는 `x ← x − f(x)/f'(x)`를 반복한다.
- 로그우도의 최대점은 `l'(θ) = 0`인 점이므로 `θ ← θ − l'(θ)/l''(θ)`로 찾는다. 다차원에서는 `θ ← θ − H⁻¹ ∇_θ l(θ)`이고, H는 헤시안 `H_ij = ∂²l/∂θ_i∂θ_j`다.
- 보통 GD보다 수렴이 빠르다. 한 번의 반복은 더 비싸지만 전체로 보면 대개 훨씬 빠르다.
- 로지스틱 회귀의 로그우도를 뉴턴법으로 최대화하는 방법을 **Fisher scoring**이라고 한다.
- (자막) 헤시안(곡률)이 스텝 크기를 정해 주므로 학습률을 따로 튜닝할 필요가 없는 셈이다. 그러나 파라미터가 아주 많은 신경망에서는 역행렬 계산 부담이 커서 맞지 않는다. 이 내용은 L04로 이어진다.

### 7. 일반화 선형 모델 GLM (p.29–35)

- 선형 회귀는 `p(y|X) ~ N(θᵀX, σ²)`로 쓸 수 있고, 세 가지를 가정한다. 분산이 일정하고, 평균이 특징의 선형결합이며, 분포가 가우시안이다. 이 가정을 하나씩 풀면 GLM이 된다.

| 질문 | GLM의 답 |
|---|---|
| 분포가 정규분포가 아니면? | 지수족(exponential family)의 다른 분포로 바꾼다. 가우시안, 베르누이, 이항, 다항, 지수, 포아송 등 |
| X와 평균의 관계가 더 복잡하면? | 비선형 링크 함수 g를 둔다: `g(μ(x)) = Σ_j θ_j x_j` |
| 분산이 X에 따라 변하면? | `var(y) = φ V(μ)`(φ는 상수)로 두고, 분산함수는 분포가 정한다. 가우시안 `V(μ)=1`, 이항(로지스틱 회귀) `V(μ)=μ(1−μ)`, 포아송 `V(μ)=μ` |

- 지수족의 형태는 `p(y;η) = b(y) exp(ηᵀT(y) − a(η))`이고, `η = θᵀx`로 둔다. 각 기호의 뜻은 다음과 같다.
  - η는 natural(canonical) parameter다.
  - T(y)는 충분통계량이며 대개 `T(y) = y`다.
  - a(η)는 log partition function으로, 사실상 정규화 상수다.
  - b(y)는 base measure다.
  - 정규·감마·베타·베르누이·포아송·지수·카이제곱·디리클레·범주형 분포가 모두 여기에 속한다.
- 로그우도 기울기는 `∇_θ l(θ) = Σ_i (T(y⁽ⁱ⁾) − a'(η⁽ⁱ⁾)) x⁽ⁱ⁾`, 즉 **(잔차) × (입력)**이다. 가우시안이면 `a'(η) = θᵀx`(선형 회귀)이고 베르누이면 `a'(η) = g(θᵀx)`(로지스틱 회귀)다. 두 갱신식의 모양이 같은 이유가 여기에 있다.
- (자막) count 데이터(예: 시간대별 빵집 손님 수)는 포아송 GLM으로 회귀한다. 교수님은 "데이터가 어떤 분포 특성을 가졌는지 파악해 GLM에 맞추는 것"이 핵심이라고 했다.

## 교수님이 강조한 것 (작년 영상)

1. **학습률 튜닝.** 코드 데모에서 학습률을 0.02→0.1→0.4→0.8→1로 키우며 "0.8에서는 이렇게 왔다 갔다 해서 찾았고 1에서는 … 아예 발산"하는 것을 보여 주고 "러닝 레이트를 이런 형태로 튜닝을 하면서 찾아야 된다"고 했다.
   → 학습률은 결과를 바꾸는 하이퍼파라미터이고, 값 몇 개를 비교해 보는 것이 기본이다.
2. **볼록이면 전역 최적.** "유니크한 미니멈 포인트밖에 있지 않아서 하나라도 미니멈 포인트를 찾으면은 그게 글로벌한 미니멈 포인트라서 … 옵티마이즈가 완벽하게 된다."
   → 선형 회귀는 초기값과 상관없이 같은 해에 닿는다. 다음 주 볼록 최적화 강의의 예고다.
3. **SGD는 진동하고, 스케줄도 튜닝 대상.** SGD는 "미니멈 포인트에 절대 수렴을 할 순 없지만" 효율적이라고 했다. 진동은 학습률 스케줄링으로 줄이되 "러닝 레이트 스케줄링을 잘해야 되는 것도 우리가 조절해야 되는 튜닝 파라미터"라고 했다.
   → 실무 표준은 mini-batch에 스케줄을 더한 방식이다.
4. **seed 습관.** "재현 가능하기 때문에 시드를 해 주는 습관이 있으면 좋고."
   → 모든 실험에서 random_state를 고정한다.
5. **왜 제곱 오차인가.** 유도가 어렵다면 "결론만 알아도 돼요. … 가우시안 디스트리뷰션을 가정했기 때문에 그렇게 된다."
   → 비용 함수를 고르는 일은 곧 잡음 분포를 가정하는 일이다. 개념 문제로 나오기 좋다.
6. **과제: 왜 시그모이드인가.** "시그모이드도 뭔가 이유가 있으니까 시그모이드를 썼을 거 아니에요. 그게 여러분 숙제예요." 어려우면 렉처노트 2·3장을 읽으라고 했다. 작년 홈워크 1의 1번이 "explain why the logistic function …"이었다.
   → 답은 GLM과 지수족에 있다(베르누이 분포의 canonical link). 올해 과제도 비슷할 수 있다.
7. **과제 코드는 GPT를 써도 된다.** "여러분 숙제도 그냥 GPT한테 짜 달라고 하세요 … 이해할 수 있고 그것에 문제가 생겼을 때 고칠 수 있는 능력이 더 중요한 거지." 대신 결과를 내고 보고서에서 분석은 직접 해야 한다고 했다.
   → 평가 대상은 코드보다 결과 해석이다.
8. **GLM은 어려우니 책을 보라.** "저도 이걸 공부하는데 한 3, 4일은 걸렸어요 … 어려우면 어쨌든 책을 봐라." 끝에는 CS229 노트를 가리키며 "이거가 제일 중요하니까 이거를 많이 읽어 보세요"라고 했다.
   → 이 주차의 사실상 교재는 CS229 노트 1–3장이다.
9. **기말 프로젝트는 데이터 분포를 보고 모델을 고른다.** "기말고사는 파이널 프로젝트로 뭔가의 데이터셋을 여러분이 직접 가지고 와서 … 재밌는 데이터 디스트리뷰션이 있고 … 새로운 형태의 디스트리뷰션으로 나타내는게 적합하다 해서 모델링을 하면은 그 예측 모델을 만들어 낼 수가 있을 겁니다."
   → 직접 가져온 데이터와 타깃 분포에 맞춘 모델 선택이 요구 사항이다.

## 우리 프로젝트(A1)에서 쓰는 곳

A1의 주 타깃 `y_fail = lane_iou < τ`는 이진 분류이고, 모델 계단의 첫 학습 모델이 이 강의의 로지스틱 회귀다.
MORAI 시뮬레이터 데이터에서 export한 feature CSV를 입력으로 쓴다.

| 강의 내용 | A1에서 쓰는 곳(계획 §) | 구현 메모 |
|---|---|---|
| 로지스틱 회귀 (시그모이드 + 베르누이 로그우도) | §7 단계 1. 선형 모델의 한계를 확인한다 | `LogisticRegression(penalty="l2", C=1.0, class_weight="balanced", max_iter=1000)`. C는 CV에서 로그 스케일(1e-3~1e2)로 탐색한다. L2와 C는 슬라이드에 없는 내용이다(보충) |
| 로지스틱 회귀로 go/no-go 판정 | §13. 기존 val 1,404 sample에서 leave-one-run-out ROC-AUC ≥ 0.7이면 진행한다 | `LeaveOneGroupOut()`에 `groups=run_id`를 준다. 같은 frame의 3뷰는 같은 fold에 들어가야 한다 |
| threshold 0.5로 클래스 결정 | §8.2 "선택 임계값에서 F1·재현율" | 실패율이 10.4%(front 19%)라 0.5는 최적이 아니다. 임계값은 train fold의 PR 곡선에서 정해 test fold에 그대로 쓴다. PR-AUC·ROC-AUC 같은 순위 지표는 임계값과 무관하다 |
| 출력 `h_θ(x) = P(y=1\|x)`의 확률 해석 | §7 공통 calibration (reliability diagram, ECE, Brier) | (보충) log-loss로 학습하므로 기본 보정은 괜찮은 편이다. 다만 `class_weight="balanced"`는 우도 항에 가중치를 주어 예측 확률을 위로 민다. 가중치 없는 LR이나 `CalibratedClassifierCV`와 함께 보고한다 |
| 로그우도 = 샘플 항의 합 | §4 라벨의 클래스 불균형 | `class_weight`나 `sample_weight`는 `Σ w_i [y log h + (1−y) log(1−h)]`의 w_i다. 뷰별 실패율이 다르므로 뷰 one-hot(D 그룹)을 넣은 모델과 뷰별 모델을 비교한다 |
| 표준화 후 학습 (p.39: `StandardScaler`를 train에만 fit) | §5 feature 전체, §8.1 GroupKFold | `Pipeline([("sc", StandardScaler()), ("lr", LogisticRegression(...))])`을 CV 안에 넣어 fold마다 train으로만 fit한다. 표준화된 계수로 feature 영향을 비교할 수 있지만, 상관된 feature의 계수는 불안정하므로 §7 단계 3의 permutation importance와 교차 확인한다 |
| `train_test_split(stratify=y)` | §8.1. run 단위 분할로 대체한다 | 프레임을 무작위로 나누면 인접 프레임이 누수된다. `GroupKFold`나 `StratifiedGroupKFold`에 `groups=run_id`를 준다 |
| 뉴턴법, Fisher scoring | §7 단계 1 solver 선택 | scikit-learn 기본 `solver="lbfgs"`는 준뉴턴법이다. 표본이 많고 특징이 적으면 `"newton-cholesky"`도 쓸 수 있다. `ConvergenceWarning`이 나면 표준화부터 확인하고 그다음에 `max_iter`를 늘린다 |
| 가우시안 잡음 가정과 최소제곱(MLE) | §7 단계 5 GP 회귀 (`lane_iou` 타깃) | GP도 가우시안 우도를 가정하고, `WhiteKernel`의 잡음 분산이 이 강의의 σ²(aleatoric)에 해당한다. `lane_iou`는 [0,1]에 묶여 있고 1 근처에 몰려 가우시안 가정과 어긋난다. 예측 클리핑과 logit 변환 후 회귀를 비교한다(보충) |
| GLM: 타깃 분포에 맞춘 모델 | §4 라벨 설계, 발표 | 이진 `y_fail`에는 베르누이(로지스틱)를, 연속 `lane_iou`에는 회귀(GP)를 쓴다. "분포를 보고 모델을 고른다"를 라벨·모델 선택의 근거로 발표에 넣는다 |
| seed 고정 | 전체 (§9 재현성) | CV splitter, 모델, GP용 서브샘플링에 모두 `random_state`를 고정하고, export 메타처럼 실험 설정도 기록한다 |

> 선형 회귀, 정규방정식, 직접 구현한 GD는 A1 코드에서 직접 쓰지 않는다. 다만 L04의 학습률 논의와 GBM `learning_rate` 해석의 바탕이 된다.

## 구현 체크리스트

- [ ] LR을 `Pipeline(StandardScaler → LogisticRegression)`으로 묶어 CV 안에서 fold마다 fit했다(표준화 누수 없음)
- [ ] run 단위(`LeaveOneGroupOut`/`GroupKFold`)로 분할했고, 같은 frame의 front/left/right가 한 fold에 있다
- [ ] go/no-go 수치(ROC-AUC)와 함께 주 지표 PR-AUC, 그리고 기준선(실패율 = 무작위 분류기의 PR-AUC)을 보고했다
- [ ] 분류 임계값을 0.5로 두지 않고 train fold에서 정해 test fold에 적용했다
- [ ] `class_weight="balanced"`를 썼다면 확률 보정(ECE·Brier)을 가중치 없는 모델이나 보정 후 모델과 비교했다
- [ ] `ConvergenceWarning`이 없다. 있었다면 스케일과 `max_iter`를 조정해 없앴다
- [ ] 표준화 계수의 부호와 크기를 표로 남겨 feature 그룹(A/B/C/D) 해석에 썼다
- [ ] 모든 무작위 요소에 `random_state`를 고정했다

## 올해 강의와 다를 수 있는 점

- 올해 노트(2026)와 작년 영상은 흐름이 같다. 선형 회귀 → GD/SGD → 확률적 해석 → 로지스틱 회귀 → 뉴턴법 → GLM → 코드 순서다.
- 작년 영상은 SGD 코드를 설명하며 `t0/(t1 + t)` 꼴의 학습률 스케줄을 다뤘다. 올해 p.17의 SGD 코드는 고정 학습률(0.02)뿐이다.
- 작년에는 로지스틱 회귀 코드에서 loss만 정의하고 미분은 라이브러리에 맡겼다고 설명하면서 "갱신식으로 직접 짜는 것도 좋다"고 했다. 올해 p.38은 `X.T@errors`로 직접 갱신한다(자막 기준 추정).
- 포아송 GLM 예(빵집 손님 수)는 작년에 말로만 설명했다. 올해 슬라이드에는 분산함수와 참고 링크로만 나온다.
- 슬라이드 표기를 확인할 곳이 있다.
  - p.24 `g'(z)`의 마지막 줄은 `g(z)(1−g(z))`가 맞다. 작년 영상에서도 이 유도 중에 표기를 되짚었다.
  - p.19 베이즈 식의 라벨은 표준형 `p(θ|D) ∝ p(D|θ)p(θ)`와 다르다.
  - p.6 행렬의 `x_30`은 `x_n0`이어야 하고, θ 첨자도 확인이 필요하다.
  - p.38 loss 줄의 괄호 위치를 확인해야 한다.
- 과제 번호(작년 홈워크 1의 1번)는 올해 달라질 수 있다. 올해 과제가 공지되면 과제 관련 부분을 갱신한다.
