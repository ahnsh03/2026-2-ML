## 한눈에

- ML 학습은 제약 아래에서 목적함수 J(x)를 최소화하는 최적화 문제다. 선형·로지스틱 회귀, MLE, K-means가 모두 같은 틀에 들어간다.
- 그래디언트(기울기)와 헤시안(곡률)으로 최적성 조건(필요조건·충분조건)을 세운다. 제약이 있으면 KKT 조건이 필요한데, 대학원 수준이라 개념만 다룬다.
- 볼록 집합, 볼록 함수, 볼록 최적화를 정의한다. 볼록 문제에서는 국소 최솟값이 곧 전역 최솟값이며, LP와 QP가 대표 예다.
- 경사하강법은 1차 테일러 근사를 최소화하는 방법이다. 문제는 세 가지다: 학습률 선택, 모든 파라미터에 같은 학습률, 좁은 골짜기에서 비효율적인 방향.
- 수렴 속도는 조건수 κ = L/μ(최대 곡률 / 최소 곡률)에 좌우된다. Nesterov momentum은 κ 의존을 √κ로 줄인다.
- 2차 방법(뉴턴법)은 헤시안 역행렬로 스텝을 정하지만 고차원에서는 비싸다. 그래서 기울기 통계로 곡률을 흉내 내는 준2차(quasi-2nd) 옵티마이저인 Adagrad, RMSProp, Adam을 쓴다.

## 핵심 내용

(자막)은 작년 영상의 구두 설명이고, (보충)은 정리자가 덧붙인 설명이다.

### 1. 최적화 문제 (p.3–4)

- 표준형은 `minimize_x J(x)  s.t.  f_i(x) ≤ 0 (i=1..k),  h_j(x) = 0 (j=1..l)`이다. J는 objective function이고, f_i와 h_j는 constraints다.
- ML의 예는 다음과 같다.

| 문제 | 목적함수 |
|---|---|
| 선형 회귀 | `min_w ‖Xw − y‖²` |
| 분류(로지스틱 회귀, y ∈ {−1,+1}) | `min_w Σ_i log(1 + exp(−y_i x_iᵀ w))` |
| 최대우도추정 | `max_θ Σ_i log p_θ(x_i)` |
| K-means | `min J(μ) = Σ_{j=1..k} Σ_i ‖x_i − μ_j‖²` |

- (자막) 이 로지스틱 손실은 레이블이 ±1인 경우의 식이라 L03의 0/1 레이블 식과 모양이 다르다.
- 제약은 feasible set(허용 영역)을 정한다. 경우는 셋이다: 제약이 없거나, 등식 제약으로 해가 곡선 위로 제한되거나, 부등식 제약으로 해가 영역 안으로 제한된다.

### 2. 그래디언트와 헤시안 (p.5–6)

- `f: ℝⁿ → ℝ`의 그래디언트는 `∇f = [∂f/∂x_1, …, ∂f/∂x_n]ᵀ`이다. 점 (x*, f(x*))에서의 접평면은 `y = f(x*) + ∇f(x*)ᵀ(x − x*)`다.
- `∇f(x*) = 0`이면 x*는 극대점, 극소점, 또는 안장점이다. (자막) 이 조건은 미분 가능할 때만 쓸 수 있다. 예를 들어 |x|는 0에서 미분할 수 없다.
- 헤시안 `∇²f(x)`는 2계 편미분을 모은 n×n 행렬이고 국소 곡률을 나타낸다. `∇²f ≻ 0`이면 양의 곡률(아래로 볼록), `≺ 0`이면 음의 곡률, `= 0`이면 평평하다.
- (자막) 1차원 예로 `y = x²`, `10x²`, `0.1x²`의 2계 미분은 각각 2, 20, 0.2다. 이 값이 포물선이 얼마나 가파른지를 알려 준다.

### 3. 최적성 조건 (p.7–11)

- 제약 없는 최소화 `min f(x)`의 조건은 다음과 같다.
  - 필요조건 `∇f(x*) = 0`, `∇²f(x*) ⪰ 0`: 모든 국소 최솟값이 만족하지만, 안장점 같은 가짜도 함께 걸린다.
  - 충분조건 `∇f(x*) = 0`, `∇²f(x*) ≻ 0`: 만족하면 반드시 국소 최솟값이지만, 바닥이 평평한 최솟값은 놓칠 수 있다.
  - 절차: `∇f(x) = 0`의 근을 찾고, 그중 `∇²f(x*) ≻ 0`인 점을 국소(또는 전역) 최솟값으로 본다.
- 제약이 있으면 위 조건이 그대로 성립하지 않고 KKT(Karush-Kuhn-Tucker) 필요조건으로 넘어간다(대학원 수준). (자막) 경계에서 먼저 해를 찾고, 경계가 아니면 내부의 국소 최솟값을 본다.
- 제약이 없어도 찾은 최솟값이 국소인지 전역인지는 알 수 없다. 비볼록 문제는 국소 최솟값이 여러 개이고 초기점에 민감하다. 볼록 문제는 최솟값이 하나뿐이다(국소 = 전역).

### 4. 볼록 집합과 볼록 함수 (p.12–16)

- 볼록 집합: `C ⊆ ℝⁿ`의 모든 x, y ∈ C와 α ∈ [0,1]에 대해 `αx + (1−α)y ∈ C`이다. 두 점을 잇는 선분이 집합 안에 있다는 뜻이다.
- 볼록 집합의 예로는 norm ball `{x: ‖x‖ ≤ r}`, 초평면 `{x: aᵀx = b}`, 반공간 `{x: aᵀx ≤ b}`, affine 공간 `{x: Ax = b}`, 다면체 `{x: Ax ≤ b}`가 있다. 볼록 집합의 임의 교집합도 볼록이며, 다면체가 볼록인 이유가 이것이다.
- 볼록 함수: `f(αx + (1−α)y) ≤ αf(x) + (1−α)f(y)`이다. 두 점을 잇는 현이 그래프 위에 있다는 뜻이다.
- 1차 조건(미분 가능할 때): f가 볼록 ⇔ 모든 x, y에서 `f(y) ≥ f(x) + ∇f(x)ᵀ(y − x)`. 접선이 항상 그래프 아래에 있다.
- 2차 조건(두 번 미분 가능할 때): f가 볼록 ⇔ 모든 x에서 `∇²f(x) ⪰ 0`.
- epigraph는 `epi f = {(x,t): f(x) ≤ t}`이고, epi f가 볼록 ⇔ f가 볼록이다. 함수의 볼록성과 집합의 볼록성을 잇는 개념이다. 볼록 f의 sublevel set `{x: f(x) ≤ a}`도 볼록이다.

### 5. 볼록 최적화 (p.17–20)

- 볼록 최적화의 조건은 세 가지다. 목적함수가 볼록이고, 부등식 제약 f_i가 볼록이며(허용 영역이 볼록 집합이 된다), 등식 제약 h_j가 affine(`h_j(x) = bᵀx + c`)이다.
- x*가 볼록 최적화 문제의 국소 최솟값이면 전역 최솟값이다. 또 `∇f(x) = 0` ⇔ x가 f의 전역 최솟값이다.
- 증명은 두 경우로 나눈다.
  - `∇f(x) = 0`이면 1차 조건에서 `f(y) ≥ f(x) + ∇f(x)ᵀ(y − x) = f(x)`가 모든 y에 대해 성립한다.
  - `∇f(x) ≠ 0`이면 내려갈 방향이 있으므로 최솟값이 아니다.
- 대표 부류는 다음과 같다.

| 부류 | 형태 |
|---|---|
| LP | `min cᵀx  s.t. x ≥ 0, Ax = b` |
| QP | `min 1/2 xᵀP₀x + q₀ᵀx + c₀  s.t. Ax = b, x ≥ 0`. (자막) P₀가 양의 준정부호일 때 볼록이다 |
| 기타 | SOCP, SDP, cone program 등 |

### 6. 경사하강법 (p.21–23)

- 갱신식은 `x_{t+1} = x_t − α_t ∇f(x_t)`이고, α_t는 step size(learning rate)다.
- 경사하강법은 최급강하법이다. `−∇f`가 x의 단위 변화당 f를 가장 많이 줄이는 방향이고, 학습률은 그 방향으로 얼마나 갈지를 정한다. (자막) 1차원에서는 방향이 두 개뿐이지만, 고차원일수록 방향 정보가 의미를 갖는다.
- 1차 테일러 근사는 `f(x + d) ≈ f(x) + ∇f(x)ᵀd`다. 반지름 r인 구 안에서 이 근사를 최소화한 것이 GD 스텝이다: `−α_t∇f(x_t) = argmin_{d: ‖d‖≤r} f(x) + ∇f(x)ᵀd`.
- f가 충분히 매끄럽고 학습률이 작으면, 기울기는 그 영역에서 계속 내리막을 가리킨다. 매끄럽지 않으면 근사가 맞는 영역이 좁아지므로 학습률도 줄여야 한다.

### 7. 경사하강법의 어려움 (p.24–30)

| 문제 | 내용 | 대응(슬라이드) |
|---|---|---|
| 학습률 선택 | 작으면 느리고 국소 최솟값에 갇힐 수 있다. 크면 수렴을 방해하거나 발산한다 | 학습률 스케줄 `α_t = α₀βᵗ, β ∈ [0,1]` (step, exponential, cosine, polynomial 등). 단, 미리 정해야 하므로 데이터셋에 적응하지 못한다 |
| 모든 파라미터에 같은 학습률 | 희소 데이터나 빈도가 크게 다른 특징에서는 드문 특징을 더 크게 갱신하고 싶다 | 파라미터별 학습률 `xⁱ ← xⁱ − αⁱ∇f(xⁱ)` (이후 Adagrad 등) |
| 기울기 방향이 최적이 아님 | 좁은 골짜기(narrow valley)에서는 최급강하 방향이 최솟값으로 가는 효율적인 길이 아니다. 큰 학습률은 튕기고, 작은 학습률은 지그재그로 느리다 | momentum, 2차 방법 |

- GD가 암묵적으로 최소화하는 2차 근사는 `f(θ + d) ≈ f(θ) + ∇f(θ)ᵀd + 1/2 dᵀF(θ)d ≈ f(θ) + ∇f(θ)ᵀd + L/2 ‖d‖²`이고, 최소점은 `d = −(1/L)∇f(θ)`다.
- 즉 GD는 모든 방향의 곡률을 똑같이 가장 큰 값 L로 보는 보수적인 근사다. 그래서 방향마다 곡률이 크게 다른 문제에서 고전한다.
- 곡률에는 위아래 경계를 둘 수 있다.
  - smooth(상한): `f(y) ≤ f(x) + ∇f(x)ᵀ(y − x) + L/2‖x − y‖²`
  - strongly convex(하한): `f(y) ≥ f(x) + ∇f(x)ᵀ(y − x) + μ/2‖x − y‖²`

### 8. 수렴 이론 (p.31, p.37)

- 가정은 두 가지다. Lipschitz smooth `‖∇f(x) − ∇f(x')‖ ≤ L‖x − x'‖`(곡률 상한)와 strongly convex(곡률 하한 μ, 최솟값 근처에서만 성립해도 된다)다.
- `α = 2/(L+μ)`로 두면 `f(x_t) − f(x*) ≤ L/2 · ((κ−1)/(κ+1))^{2t} · ‖x₀ − x*‖²`이다. 여기서 `κ = L/μ`가 조건수다.
- `f(x_t) − f(x*) ≤ ε`에 이르는 반복 수는 `t ∈ O(κ log(1/ε))`다.
- 1차 방법은 갱신이 지금까지 관측한 기울기들의 선형결합인 방법(GD, momentum, conjugate gradient)이다. 반복 수 경계는 다음과 같다.

| 방법 | 반복 수 |
|---|---|
| 1차 방법의 최악 하한 | `Ω(√κ log(1/ε))` |
| GD 상한 | `O(κ log(1/ε))` |
| Nesterov momentum GD 상한 | `O(√κ log(1/ε))` (하한과 같은 차수) |

### 9. Momentum과 Nesterov (p.32–36)

- 동기: 학습률이 크면 스텝마다 기울기가 앞뒤로 뒤집힌다. 그래서 여러 스텝 동안 일관되게 내리막인 방향으로 가속한다.
- Momentum의 갱신식은 `v_{t+1} = γv_t − ∇f(x_t)`, `x_{t+1} = x_t + α_t v_{t+1}`, `v₀ = 0`이다. γ는 momentum 상수이고 보통 0.9다.
- (자막) v는 과거 기울기의 지수 가중합이다. γ, γ², … 가 곱해지면서 오래된 기울기는 잊힌다. 관성 덕분에 작은 국소 최솟값을 넘어갈 수도 있다.
- Nesterov(NAG)는 "뛰기 전에 먼저 보라"는 발상이다. `v_{t+1} = γv_t − ∇f(x_t + α_tγv_t)`로, momentum으로 먼저 이동한 위치에서 기울기를 계산한다.
- 예시 `f(x,y) = x² + 10y²`의 결과는 다음과 같다.
  - SGD는 학습률을 0.08→0.09→0.10으로 키울수록 y 방향 진동이 커진다.
  - momentum 0.9는 크게 흔들린다.
  - NAG가 가장 곧게 수렴한다(0.7과 0.9 비교).
  - (자막) γ가 크면 과거 속도를 많이 써서 너무 멀리 간다.

### 10. 2차 방법과 뉴턴법 (p.38–43)

- 1차 방법의 반복 수는 조건수 κ(최대 곡률 / 최소 곡률)에 따라 늘어난다. 2차 방법은 이 의존을 줄인다.
- 2차 테일러 근사 `f(x + d) ≈ f(x) + ∇f(x)ᵀd + 1/2 dᵀH(x)d`를 최소화하면 `d = −H(x)⁻¹∇f(x)`이고, 갱신식은 `x_{t+1} = x_t − H(x_t)⁻¹∇f(x_t)`다.
- 뉴턴법은 L03과 같다. `f(x) = 0`을 풀 때는 `x ← x − f(x)/f'(x)`, 최대화할 때는 `l'(θ) = 0`을 풀어 `θ ← θ − H⁻¹∇_θ l(θ)`다.
- GD와 비교하면 다음과 같다.
  - GD가 발산하지 않으려면 `α ≤ 1/L`이어야 한다(L = 최대 곡률, Lipschitz 상수).
  - GD는 `H(x)`를 `LI`로 바꾼 나쁜 2차 근사를 최소화하는 셈이다. 모든 방향을 최대 곡률로 취급한다.
  - (자막) 교수님은 이를 "러닝 레이트가 헤시안의 인버스"라고 표현했다.
- 2차 근사는 현재 점 근처에서만 믿을 수 있다. 대응은 두 가지다. 스텝을 trust region R 안으로 제한하거나, 더 나은 곡률 행렬(Generalized Gauss-Newton, Fisher information matrix)을 쓴다.
- 단점은 규모다. 신경망은 파라미터가 수백만~수십억 개라 n×n 행렬을 계산·저장·역산할 수 없다. 그래서 대각 성분만 쓰거나 대각 블록만 쓰도록 근사한다.

### 11. 준2차 옵티마이저 (p.44–50)

- 준2차(quasi-2nd) 방법은 기울기(1차 정보)만 쓰면서 평균 등을 통해 곡률 정보를 암묵적으로 반영한다. 현대 딥러닝 옵티마이저 대부분(Adagrad, Adadelta, RMSProp, Adam, AdamW, Nadam, AMSGrad)이 여기에 속한다.

| 옵티마이저 | 갱신 | 핵심 |
|---|---|---|
| Adagrad | `g_{t,i} = ∇J(x_{t,i})`, `x_{t+1,i} = x_{t,i} − α/√(G_{t,ii} + ε) · g_{t,i}` | G_t는 과거 기울기 제곱 합을 담은 대각 행렬이다. 자주 나온 특징은 작게, 드문 특징은 크게 갱신하므로 희소 데이터에 맞다. 약점은 G_t가 계속 쌓여 학습률이 계속 줄어든다는 점이다 |
| RMSProp | `E[g²]_t = γE[g²]_{t−1} + (1−γ)g_t²`, `x_{t+1,i} = x_{t,i} − α/√(E[g²]_t + ε) · g_{t,i}` | 제곱 기울기를 지수이동평균으로 바꿔 Adagrad의 학습률 소멸을 해결한다. Hinton은 γ = 0.9, α = 0.001을 권했다 |
| Adam | `E[g²]_t = γ₁E[g²]_{t−1} + (1−γ₁)g_t²`, `m_t = γ₂m_{t−1} + (1−γ₂)g_t`, `m̂_t = m_t/(1−γ₂ᵗ)`, `Ê[g²]_t = E[g²]_t/(1−γ₁ᵗ)`, `x_{t+1,i} = x_{t,i} − α/√(Ê[g²]_t + ε) · m̂_t` | RMSProp에 momentum을 더한 방법이다. 초기에 0 쪽으로 치우친 추정을 편향 보정한다. 기본값은 `(γ₁, γ₂) = (0.999, 0.9)` |

- (보충) 슬라이드의 γ₁(제곱 기울기)과 γ₂(기울기)는 원 논문의 β₂ = 0.999, β₁ = 0.9와 이름이 반대다. 값은 같다.
- 계보(p.48)는 다음과 같다.
  - 출발점은 GD와 SGD다.
  - 방향을 개선한 갈래: Momentum → NAG.
  - 스텝 크기를 개선한 갈래: Adagrad → RMSProp, AdaDelta.
  - 두 갈래를 합친 것: Adam(RMSProp + Momentum) → Nadam(Adam + NAG).
- 무엇을 쓸지(p.50)는 다음과 같다.
  - Adam/AdamW가 기본 선택이다.
  - Adam보다 나은 경우는 주로 RMSProp이나 NAG였다.
  - LLM에는 Adafactor, Lion, Signum이 유망하다.
  - SGD(+momentum)는 비전 과제에 좋지만 세심하게 튜닝해야 한다.

## 슬라이드의 코드·라이브러리

없음. 코드 대신 참고 링크가 있다: 옵티마이저 개관(`ruder.io/optimizing-gradient-descent`), 수렴 애니메이션 예시(`tiddler.github.io/optimizers`), 이론 노트(Simon Weissmann, Bernd Gärtner & Martin Jaggi).
scikit-learn에서 이 개념이 드러나는 인자는 아래 A1 표에 정리했다.

## 교수님이 강조한 것 (작년 영상)

1. **모든 공학 문제는 최적화다.** "대부분의 문제에서는 모든 것들이 결론적으로는 최적화 문제입니다." 동역학이든 제어든 결국 비용 J를 정하고 최소화한다는 뜻이다.
   → 모델마다 "무엇을 최소화하는가"부터 적는 습관을 들인다.
2. **KKT는 개념만.** "대학원 수준의 레벨이라서 깊게 얘기하진 않겠지만"이라며, 제약 최적화는 경계부터 본다는 개념만 설명했다.
   → KKT 유도까지 요구할 가능성은 낮아 보인다(추정).
3. **볼록 최적화를 좋아하는 이유.** "어떤 상황에서의 이니셜라이제이션을 하더라도 … 글로벌한 미니멈 포인트가 하나밖에 없기 때문에 … 그래서 우리는 이 컨벡스 옵티마이제이션 프로블럼을 좋아하고."
   → 볼록이면 초기값을 걱정할 필요가 없다. 비볼록이면 초기값과 재시작이 중요하다.
4. **과제: QP가 왜 볼록 최적화인가.** QP가 왜 볼록 최적화인지 "정의를 이용해서" 설명하는 문제가 과제(작년 숙제 2번)에 있다고 했다.
   → 볼록 최적화의 3조건(목적함수 볼록, 부등식 제약 볼록, 등식 제약 affine)을 정확히 알아 둔다.
5. **학습률 조절이 곧 최적화.** "러닝 레이트를 잘 조절하는게 결국 우리가 옵티마이제이션 프로블럼을 잘 해결하는 문제"라고 했다. 스케줄러도 "매뉴얼하게 튜닝을 하긴 해야 됩니다"라며 데이터셋마다 다르다고 했다.
   → 학습률은 자동으로 정해지지 않는 핵심 하이퍼파라미터다.
6. **GD는 만능이 아니다.** "그레디언트 디센트가 최종적으로 항상 좋은 거는 아니에요. 적절한 정보량만 제공해 줄 뿐이지." 좁은 골짜기 예를 들었다.
   → 조건수가 나쁘면(특징 스케일이 제각각이면) 수렴이 느리다.
7. **헤시안은 곡률이자 스텝 크기.** "러닝 레이트가 헤시안의 인버스이다." 하지만 파라미터가 10⁶개면 헤시안은 10⁶×10⁶이라 계산도 메모리도 감당할 수 없어서 대각 근사나 준2차 방법을 쓴다고 했다.
   → 1차(방향)와 2차(크기) 정보를 얼마나 싸게 쓰느냐가 옵티마이저 설계의 핵심이다.
8. **Adam은 학습률에 둔감하다.** Adam은 "러닝레이트에 그렇게 민감하지가 않습니다"라며, 10⁻⁴~10⁻³ 정도로 고정해 두고 쓰면 스케줄러 없이도 학습이 잘 된다고 했다.
   → 딥러닝 실무의 기본값이다.
9. **유도보다 동기.** 마무리하며 "이걸 다 이해할 필요는 없고 얘네들이 어떻게 데리베이션이 됐는지 뭐 이런 것을 다 이해할 필요는 없지만 그래도 한번 다시 읽어 보고 옵티마이저가 이런 거였구나"라고 했다.
   → 유도 과정보다 각 방법의 동기와 장단점을 이해하는 것이 목표다(시험 대비 방향 추정).

## 우리 프로젝트(A1)에서 쓰는 곳

A1은 신경망을 새로 학습하지 않는다(대상 모델(TwinLiteNet+)은 고정). 따라서 Adam 같은 딥러닝 옵티마이저를 직접 고를 일은 없다.
대신 scikit-learn 모델 안에서 돌아가는 최적화의 성질이 설정과 결과 해석에 영향을 준다.

| 강의 내용 | A1에서 쓰는 곳(계획 §) | 구현 메모 |
|---|---|---|
| 볼록 최적화: 국소 = 전역 | §7 단계 1 LR, §13 go/no-go | L2 로지스틱 손실은 볼록이라 solver나 초기값과 상관없이 같은 해가 나온다. 베이스라인 수치가 재현 가능하다는 근거가 되고, 결과 차이를 feature·분할의 차이로 해석할 수 있다 |
| 조건수 κ, 좁은 골짜기 | §5 feature 전처리 | feature 단위가 제각각이다(예: 예측 면적은 수천 픽셀, 비율 feature는 0~1). 표준화하지 않으면 κ가 커져 lbfgs 수렴이 느려지고 `ConvergenceWarning`이 난다. LR·SVM·GP 앞에 `StandardScaler`를 둔다 |
| 뉴턴법·준뉴턴(곡률 이용) | §7 단계 1 solver | 기본 `solver="lbfgs"`를 쓴다. 수렴에 실패하면 `max_iter`를 늘리기 전에 스케일부터 확인한다 |
| QP(볼록, 부등식 제약) | §7 단계 2 SVM (7주차) | `SVC` 학습은 제약이 있는 QP라서 전역 해가 나온다. 반면 `C`와 `gamma`는 QP 밖의 하이퍼파라미터이므로 CV로 찾는다 |
| 학습률 트레이드오프(작으면 느리고, 크면 불안정) | §7 단계 3 HistGradientBoosting, §7 단계 6 튜닝 | (보충) gradient boosting은 함수 공간에서 하는 경사하강이다. `learning_rate`를 낮추면 `max_iter`를 늘려야 하므로 둘을 함께 튜닝한다. 내장 `early_stopping`은 검증 분할을 무작위로 떼어 같은 run의 인접 프레임이 섞인다. `early_stopping=False`로 두고 `max_iter`를 run 단위 CV로 정하는 쪽이 안전하다 |
| 비볼록이면 초기값에 민감 | §7 단계 5 GP 커널 하이퍼파라미터 | `GaussianProcessRegressor`는 로그 주변우도를 L-BFGS-B로 최대화하는데, 이 문제는 비볼록이다. `n_restarts_optimizer`를 5~10으로 두고 커널의 `length_scale_bounds`를 정한다. fold마다 학습된 `kernel_`(WhiteKernel 잡음 포함)을 기록해 안정성을 확인한다 |
| 비볼록이면 여러 초기값 | §6 단계 4 GMM·K-means 군집 | EM과 K-means는 국소 최적에 머문다. `GaussianMixture(n_init=5~10, random_state=…)`, `KMeans(n_init=10)`으로 여러 번 돌린 최선값으로 BIC를 비교하고, §6의 bootstrap ARI 안정성과 함께 해석한다 |
| MLE도 최적화 문제 (p.3) | §7 단계 1·5, §6 | LR(베르누이 우도), GP(주변우도), GMM(혼합 우도)은 모두 우도 최대화다. 발표에서 모델 계단을 "무엇을 최적화하는가"로 한 줄씩 정리할 수 있다 |
| 기울기를 쓸 수 없는 목적 | §7 단계 6 random vs grid search | CV 점수는 하이퍼파라미터에 대해 미분할 수 없고 잡음도 있어 경사법을 쓸 수 없다. 이 지점이 14주차 gradient-free 최적화(random search)로 이어진다 |

## 구현 체크리스트

- [ ] 모델마다 "무엇을 최소화/최대화하는가"(log-loss, SVM 목적함수, 주변우도, 혼합 우도)를 코드 주석이나 문서에 한 줄로 적었다
- [ ] LR·SVM·GP 입력을 표준화했고, 로그에서 `ConvergenceWarning`을 확인했다
- [ ] GP의 `n_restarts_optimizer`를 1 이상으로 두고, 학습된 커널 하이퍼파라미터를 fold별로 기록했다
- [ ] GMM·K-means의 `n_init`을 5 이상으로 두고 `random_state`를 고정했다
- [ ] HistGradientBoosting의 `learning_rate`와 `max_iter`를 함께 튜닝했고, early stopping이 run 단위 분할을 깨지 않는지 확인했다
- [ ] 튜닝 공간에서 학습률·C·gamma·length_scale 같은 스케일 파라미터는 로그 스케일로 샘플링했다

## 올해 강의와 다를 수 있는 점

- 올해 노트(2026)와 작년 영상은 순서와 내용이 거의 같다. 최적화 문제 → 그래디언트·헤시안 → 최적성 조건·KKT → 볼록 → LP/QP → GD와 그 어려움 → 수렴 이론 → momentum·NAG → 2차 방법 → Adagrad·RMSProp·Adam → 옵티마이저 선택 순서다.
- 개요(p.2)에 "stochastic optimization"이 있지만 별도 절은 없다. SGD와 mini-batch는 L03에서 다뤘고, 작년 영상에서도 "저번 시간에 이야기했다"며 넘어갔다.
- 슬라이드 표기에 주의할 곳이 있다. Adam의 γ₁/γ₂ 이름이 원 논문과 반대이고(값은 같다), p.29는 f, h, F를 섞어 쓴다. 답안에서는 슬라이드 표기를 따르되 의미를 함께 적는다.
- 과제(QP의 볼록성 설명)는 올해 번호나 내용이 다를 수 있다. 올해 과제가 공지되면 갱신한다.
