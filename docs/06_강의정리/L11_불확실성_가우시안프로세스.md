> 강의노트: `Lecture Note/Lecture 11 - UQ and GP.pdf` (2025 작년 노트, 37쪽) · 올해 12주차
> 작년 강의영상: "Lecture 11 - Uncertainty quantification and Gaussian process" (`QvilZ4bCgHA`) — 자동 자막 기반 · 기준일 2026-09-25

## 한눈에

- 불확실성 정량화(UQ)는 모델 출력을 **결과를 보기 전에** 얼마나 믿을 수 있는지 수치로 내는 일이다. 교수님은 자율주행처럼 안전과 관련된 모델이면 반드시 들어가야 한다고 본다.
- 불확실성은 **aleatoric**(데이터에 원래 있는 잡음이라 데이터를 더 모아도 줄지 않음)과 **epistemic**(지식이 부족해서 생기며 데이터를 더 모으거나 모델을 바꾸면 줄어듦)으로 나뉜다.
- 베이즈 규칙에서 **Bayesian linear regression(BLR)** 으로 넘어간다. 가중치를 분포로 두면 예측분산이 `σ² + x*ᵀΣx*`(aleatoric + epistemic)로 저절로 나뉜다.
- BLR에 feature map ψ(x)를 넣고 커널 트릭을 쓰면 **Gaussian process(GP)** 가 된다. 커널이 함수 prior를 정하고, 하이퍼파라미터는 marginal likelihood를 최대화해 맞춘다. 계산량은 O(n³)이다.
- GP가 아닌 기존 모델은 **앙상블 모델끼리 예측이 얼마나 갈리는지(disagreement)** 로 불확실성을 잰다.
- 불확실성은 active learning, **Bayesian optimization**(acquisition = 예측 평균 + 불확실성), calibration·OOD·selective prediction에 쓰인다.

## 핵심 내용

### 1. 왜 불확실성인가 (p.3–5)

- 회귀에는 노이즈·외란·무지(ignorance) 때문에 더는 줄일 수 없는 오차 하한이 있다. 모델을 복잡하게 만들면 평균 오차는 줄지만 일반화가 나빠진다(underfit / good fit / overfit 그림).
- 오차는 결과를 관측한 **뒤에야** 계산할 수 있다. 불확실성은 관측하기 **전에** 예측해야 한다. 주식 예측, 자율주행, 그 밖의 실용·안전 관련 모델이 모두 그렇다.
- 불확실성은 확률로 잰다. 연속 변수(강수량 1 mm? 1.1 mm? 1–1.1 mm?)는 한 점의 확률이 아니라 **확률밀도(PDF)** 를 예측해야 한다.

### 2. 바람직한 예측과 불확실성의 두 종류 (p.6–9)

- 예측은 underconfident / overconfident / **well calibrated** 중 하나다. 목표는 well calibrated다. (보충) 예를 들어 90% 구간을 냈다면 실제 값의 약 90%가 그 구간 안에 들어가야 한다.

| | Aleatoric | Epistemic |
|---|---|---|
| 원인 | 데이터에 원래 있는 랜덤 잡음 | 학습 데이터가 유한함. 데이터를 설명하는 모델이 여럿이라 어느 파라미터를 쓸지 불확실함 |
| 영상에서 쓴 다른 이름 | data uncertainty | model uncertainty |
| 데이터를 더 모으면 | 줄지 않는다(데이터가 무한해도 남는다) | 줄어든다 |
| p.6 그림에서 | 데이터가 있는 구간에서 굵어졌다 가늘어지는 띠 | 데이터가 없는 구간에서 부푸는 띠 |
| 선형회귀 예 (p.7–8) | `y = βᵀx + ε, ε ~ N(0, σε²)`. σε²는 학습 residual의 분산으로 추정한다 | 같은 데이터에 맞는 여러 직선·곡선 |

- 목표가 계속 바뀌는 non-stationary 환경에서는 epistemic 불확실성이 늘 남는다.
- p.9에는 전체 불확실성 요인 질문이 나열되어 있다. 교수님이 영상에서 분류한 결과는 아래와 같다.

| 질문 | 분류 | 교수님 근거 |
|---|---|---|
| 측정한 feature로 정확히 예측하기에 충분한가 | aleatoric | feature를 정한 뒤에는 데이터를 늘려도 줄지 않는다 |
| feature에 selection bias가 있는가 | aleatoric | 같은 이유 |
| 모델 class가 참 결정경계를 근사할 수 있는가 | epistemic | 모델을 바꾸면 좋아질 수 있다 |
| feature에 측정 잡음이 있는가 | aleatoric | 데이터를 늘려도 잡음은 그대로다 |
| 학습 데이터가 충분한가 | epistemic | 데이터를 더 얻으면 좋아진다 |
| 라벨 잡음, 결측, 학습 알고리즘의 한계, 시간에 따른 변화(data shift) | (영상에서 다루지 않음) | 아래 판별 규칙을 적용한다 (보충) |

- 판별 규칙(영상): **"데이터를 더 얻거나 모델을 바꿨을 때 좋아지면 epistemic, 안 좋아지면 aleatoric."**

### 3. 확률적 모델링과 베이즈 규칙 (p.10–14)

- `p(h|D) = p(D|h) p(h) / p(D)`에서 posterior = likelihood × prior / marginal likelihood(evidence)이다. 데이터를 만든 underlying process(분포)를 명시적으로 두고 그것을 찾는 것이 Bayesian 모델링이다.
- xkcd의 "태양이 폭발했나" 예에서 검출기는 1/36 확률로 거짓말을 한다. frequentist는 p < 0.05이므로 "폭발했다"고 결론짓는다. Bayesian은 prior `p(exploded) ≈ 10⁻¹⁰`을 넣는다. 그러면 `p(exploded|yes) ≈ (35/36·10⁻¹⁰) / (1/36) ≈ 35×10⁻¹⁰`이 되어 폭발하지 않았다고 결론짓는다. prior가 결론을 바꾸는 사례다.
- 가우시안 밀도 추정 예: σ = 1을 안다고 하고, 관측한 5개 점을 μ ∈ {−2, −1, 0, 1, 2} 중 어느 후보가 만들었는지 따진다.
  prior는 균등, likelihood는 `Π N(xn|μ, 1)`, marginal likelihood는 다섯 후보 likelihood의 합이다. marginal likelihood는 정규화 상수라 보통 무시하므로 posterior ∝ prior × likelihood가 된다.

### 4. Bayesian linear regression (p.15–20)

- 선형회귀 복습: `ŷ = wᵀx`, `L = ½ Σ(yᵢ − ŷᵢ)²`. 해석해는 `w = (XᵀX)⁻¹Xᵀy`이다. GD 식은 슬라이드에 `w ← (1−α)w − αXᵀ(y−ŷ)`로 적혀 있다. (보충) 이 손실의 기울기는 `−Xᵀ(y−ŷ)`이므로 갱신항의 부호는 `+αXᵀ(y−ŷ)`가 맞다.
- Full Bayesian inference: `p(w|D) ∝ p(w) p(D|w)`, 예측은 `p(y|x,D) = ∫ p(w|D) p(y|x,w) dw`이다. 그럴듯한 설명 전부에 대해 평균을 내므로 모델 불확실성이 정량화된다. 그림에서는 관측이 0 → 1 → 2개로 늘면서 가능한 직선의 폭이 좁아진다.
- 가정: σ²는 고정되어 있고 알려져 있다. `y = Xw + ε, ε ~ N(0, σ²I)`이므로 likelihood는 `N(Xw, σ²I)`이다. prior는 `p(w) = N(0, σw² I)`로 둔다.
- **Posterior**(가우시안 × 가우시안 = 가우시안)
  - `Σ = (σw⁻² I + σ⁻² XᵀX)⁻¹`, `μ = σ⁻² Σ Xᵀy`
  - 유도: 지수부를 w에 대한 2차식으로 모으면 `A = σ⁻²XᵀX + σw⁻²I`, `b = σ⁻²Xᵀy`가 되고, 식은 `∝ exp(−½ (w − A⁻¹b)ᵀ A (w − A⁻¹b))` 꼴이 된다. 따라서 `Σ = A⁻¹`, `μ = A⁻¹b`이다.
  - (보충) μ는 `(XᵀX + (σ²/σw²) I)⁻¹Xᵀy`, 즉 ridge 해와 같다. 가우시안 prior가 L2 정규화 역할을 한다.
- **Posterior predictive**: `p(y*|x*, X, y, σ²) = N(μᵀx*, σ² + x*ᵀΣx*)`. 여기서 `σ²`는 **aleatoric**, `x*ᵀΣx*`는 **epistemic**이다.
- 교수님 설명: `XᵀX = Σ xᵢxᵢᵀ`는 데이터가 쌓일수록 커지고, 그 역행렬이 들어간 Σ는 작아진다. 그래서 데이터를 더 모으면 epistemic은 줄고 σ²는 그대로 남는다.
- p.20 그림: likelihood × prior로 posterior가 한 점씩 좁아지고(순차 Bayesian 갱신), 데이터 공간에 그린 직선 샘플들도 한 방향으로 모인다.

### 5. Gaussian process (p.21–29)

- BLR의 prior `y = wᵀx + ε`는 직선만 만든다. 이를 general prior `y = wᵀψ(x) + ε, w ~ N(0, σw² I)`로 넓힌다. ψ는 feature map, 곧 feature 공간의 basis function이다.
- posterior는 `Σ = (σw⁻² I + σ⁻² ΨᵀΨ)⁻¹`, `μ = σ⁻² Σ Ψᵀy`이고, 예측은 `N(ψ(x*)ᵀμ, σ² + ψ(x*)ᵀΣψ(x*))`이다. 식을 더 전개하면("with some math") 예측분포가 **커널만으로** 표현된다.
- 커널은 `K(xᵢ, xⱼ) = ψ(xᵢ)ᵀψ(xⱼ)`이다. ψ를 몰라도 K만 계산하면 된다.
  RBF `exp(−‖xᵢ−xⱼ‖² / (2σ²))`는 무한차원 ψ에 해당한다. 1차원이면 `ψ(x) = exp(−x²/2σ²)·[1, x/(σ√1!), x²/(σ²√2!), x³/(σ³√3!), …]ᵀ`이고, 이렇게 전개한 값을 실제로 쓰지는 않는다.
- 커널 종류 (p.24)

| 커널 | 식 | prior 함수의 구조 |
|---|---|---|
| Squared-exp (SE, RBF) | `σf² exp(−(x−x')² / (2ℓ²))` | 국소 변동(local variation) |
| Periodic | `σf² exp(−(2/ℓ²) sin²(π(x−x')/p))` | 반복 구조 |
| Linear | `σf² (x−c)(x'−c)` | 직선. BLR과 같아지므로 GP는 BLR을 포함한다 |

- 하이퍼파라미터 효과 (p.25, 영상): length scale이 작으면(0.25) 함수가 들쭉날쭉하고, 크면(4) 매끈하다. 앞에 붙는 계수(100)는 y의 스케일을 키운다. `xᵀx'`는 직선만, Matern 3/2 `(1+|x−x'|)exp(−|x−x'|)`는 거친 함수를 만든다.
- 커널 조합 (p.26): 커널끼리 더하거나 곱해도 커널이다. Lin+Per(증가하면서 주기), SE+Lin, SE(long)+SE(short), Lin×Lin(2차), SE×Per(국소 주기), Lin×Per(진폭이 커지는 주기) 등이 있다. 교수님은 **예측하려는 함수의 경향을 보고 거기에 맞는 커널을 골라야 한다**고 했다.
- 정의 (p.27–28): GP는 확률변수(함수값)의 모음이고, 그중 유한 개를 뽑으면 언제나 결합 가우시안을 이룬다. 커널은 함수값 사이의 공분산을 정한다.
  이론상으로는 모든 x에 대한 함수 prior, 곧 무한차원 가우시안이다. 실제로는 유한한 입력 집합에서 다변량 가우시안으로 계산한다.
  데이터가 많은 곳에서는 함수 후보들이 한데 모여 불확실성이 작고, 데이터가 없는 곳에서는 후보들이 퍼져 불확실성이 크다.
- (보충) **예측식**: 슬라이드는 이 부분을 "with some math"로 생략했다. 아래는 Rasmussen & Williams의 표준식이다.
  학습 입력 X(n개), 타깃 y, `K = K(X,X)`, `k* = K(X, x*)`, 잡음 분산 σn²로 둔다.
  - 사후평균 `μ(x*) = k*ᵀ (K + σn² I)⁻¹ y`
  - 잠재함수 f의 사후분산 `σf²(x*) = k(x*,x*) − k*ᵀ (K + σn² I)⁻¹ k*` ← **epistemic**
  - 관측값 y*의 예측분산 `σf²(x*) + σn²` ← 여기에 **aleatoric**이 더해진다. BLR의 `x*ᵀΣx* + σ²`와 구조가 같고, linear 커널이면 BLR과 똑같다.
  - x*가 학습점에서 멀어지면 `k* → 0`이므로 `σf² → k(x*,x*)`(prior 분산)로 돌아간다. 학습 분포 밖(OOD)에서 분산이 커지는 이유다.
- **하이퍼파라미터 튜닝** (p.29): f를 적분해 없앤 y의 log-likelihood, 곧 marginal likelihood를 최대화한다.
  - 슬라이드 식: `log p(y|X,w,σ²) = log ∫ p(y|f,σ²) p(f|X,w) df = log N(0, K(X,X))`
  - 슬라이드 공분산에는 잡음항이 빠져 있다. 잡음을 넣으면 공분산은 `K + σ²I`가 된다.
  - 이 식은 미분 가능하므로 gradient로 최적화하기 편하다. 교수님도 GP 하이퍼파라미터는 튜닝이 쉬운 편이라고 했다.
  - (보충) 전개하면 `−½ yᵀ(K+σn²I)⁻¹y − ½ log|K+σn²I| − (n/2) log 2π`이다. 앞은 데이터 적합항, 가운데는 복잡도 벌점이라 과적합이 저절로 억제된다. 함수가 non-convex이므로 초기값을 바꿔 여러 번 재시작한다.
- 단점 (p.29)
  - 커널 행렬 역행렬에 O(n³)이 든다. 요즘은 GPyTorch 같은 병렬 계산 도구를 쓴다.
  - 커널 설계에 품이 든다.
  - 주로 회귀에 쓰인다.
  - 이미지 같은 고차원 입력에서는 일부 커널이 제대로 동작하지 않는다.

### 6. 앙상블로 불확실성 재기 (p.30–31)

- PCA, SVM, 군집, 트리 같은 기존 모델은 불확실성을 직접 주지 않는다. 대신 모델을 여러 개 학습해 **예측이 얼마나 갈리는지(disagreement)** 를 잰다. 많이 갈릴수록 epistemic이 크다고 본다. 데이터가 무한하면 학습 알고리즘이 하나의 답으로 수렴한다는 가정에 기댄다.
- bagging 방식: D에서 n개씩 복원추출해 데이터셋 m개를 만들고, 각 데이터셋으로 학습한 모델들의 **예측 분산**을 불확실성으로 쓴다. 모델 자체가 확률적(stochastic)이면 이 분산에 aleatoric도 섞인다.

### 7. Bayesian optimization·active learning (p.32–35)

- Bayesian optimization(BO)은 평가 비용이 큰 black-box 함수에서 **다음에 평가할 점**을 고르는 방법이다. active learning은 정보가 가장 많은 샘플을 골라 효율적으로 학습하는 방법이다.
- 불확실성은 보상이 있을 법한 영역을 드러낸다. 여기에 함수값(cost)도 함께 본다. 그래서 **acquisition function = 불확실성 + cost**다.

| acquisition | 식 (p.34 표기, 최소화 문제) | 성격 |
|---|---|---|
| Expected improvement | `α_EI(x) = ∫ max(0, y_best − y) p(y|x,θ,D) dy` | 현재 최고값보다 얼마나 나아질지의 기대값 |
| Confidence bound (LCB) | `α_LCB(x) = −μ(x) + β_t σ(x)` | 평균과 불확실성을 β로 절충 |
| Thompson sampling | `g(x) ~ GP(μ(x), k(x,x'))`에서 함수 하나를 뽑아 그 최소점을 고른다 | 확률적 선택 (다른 둘은 결정적) |

- 절차 (p.35): GP 적합 → acquisition이 최대인 점 평가 → 데이터 추가 → GP 갱신을 반복하면 참 함수의 최소점으로 다가간다.
- 교수님 관점: epistemic은 데이터를 모을수록 줄어든다. 그래서 불확실성이 높은 곳을 공략하는 것이 BO·active learning의 핵심이다.

### 8. 더 볼 주제 (p.36)

- 응용: selective prediction, active learning, system integration, uncertainty-aware learning
- 연구 주제: uncertainty calibration, propagation, OOD detection, anomaly detection, conformal prediction

| SE / Periodic / Linear / Matern / 합·곱 커널 | — | `kernels.RBF`, `ExpSineSquared`, `DotProduct`, `Matern(nu=1.5)`, `ConstantKernel`, `WhiteKernel`, 연산자 `+`, `*` |

## 구현 체크리스트

- [ ] GP 입력 feature를 train fold 기준으로 `StandardScaler` 표준화하고, `normalize_y=True`로 둬서 IoU 평균을 prior 평균으로 쓴다.
- [ ] 커널에 `WhiteKernel`을 넣고 total / aleatoric(noise) / epistemic 분산을 따로 저장한다. normalize_y의 단위 환산(ystd²)을 확인한다.
- [ ] fold마다 `gpr.kernel_`(length scale, noise_level)과 `log_marginal_likelihood_value_`를 기록한다. length scale이 bounds 끝에 붙으면(ConvergenceWarning) bounds를 조정한다.
- [ ] 서브샘플은 GroupKFold의 train fold 안에서만 run·view·IoU 구간으로 층화해 뽑고 seed를 고정한다(누수 방지).
- [ ] 90% 구간 포함률과 coverage 곡선을 in-distribution fold와 OOD(O 묶음)에서 따로 보고한다.
- [ ] OOD에서 epistemic 분산이 커지는지(H5)를 분포 그림과 수치로 보인다.
- [ ] IoU는 [0, 1] 범위인데 가우시안 예측 구간은 이 범위를 넘을 수 있다. 구간을 [0, 1]로 자르는 방법과 logit(IoU)로 변환해 적합하는 방법을 비교한다 (보충).
- [ ] `Φ((τ−μ)/σ)`로 실패확률을 만들어 분류 모델들과 같은 PR-AUC·ECE·risk–coverage 표에 넣는다.
