# 품질모델과 GP 불확실성

품질모델은 **정확한 인지 가중치·9영역·열 순서·정답·보정·정책**과 짝지어 관리한다. 현재 비교의 기준 입력은28열이며 추가6열과 near F1 보조 목표도 개발 자료에서 확인한다. 실제 채택 열과 GP 설정은 번들의 `ordered_features`, `target_names`, 모델 메타데이터를 따른다. [통합 결과](../experiments/군집_검수_동일예산_재학습_20261127.md) · [공개 근거](../baselines/selection_cycle_20261127/README.md)


**27일 판정:** 새f1용28열 GP3는 주 확인MAE0.07979(RFQ0.08382), 기존f0/g0는0.04982다. 사전 허용0.05982를 넘었으므로 새 버전 쌍은 연구 후보로 보존하고 기본f0/g0를 유지한다. 다음 우선순위는 g1의 도로별 편향·과신과 보정 지원을 보완하는 것이다.


## 정답과 해석

주 정답은 패딩을 제외한 전체 white/yellow 차선 클래스 합집합의 IoU Q 하나다. GT의 TP·FP·FN으로 만들며 stop line은 주 Q에서 제외한다. **온라인 GT나 ROI별 IoU 계산은 없다.** 오프라인 보조 정답은 근거리·원거리 영상 띠의 recall이고, 4과제 후보는 near F1을 추가한다. f1은 인지모델 버전 이름이고 near F1은 precision/recall의 지표다.

근거리 recall은 누락을 본다. 근거리 양호를 검수할 때에는 precision도 필요하다. 사후 GT에는 near omission/false-positive issue, near precision·recall retained, far omission을 따로 남긴다. 근거리 recall 분모는 GT≥50, precision 분모는 예측≥50을 사용해 GT가 없는 큰 오검출도 확인한다. 가시성·운행 정상은 별도의 의미다.

MAE0.05는 IoU의 평균 절대 차이0.05, 즉5퍼센트포인트다. 모든 장면이 그 오차 안에 있거나 검수 정확도가95%라는 뜻은 아니다. 전체 평균과 도로별 오차·과신 사례·분모를 함께 본다. Q0.7 경계 판정은 float32 반올림 대신 실제 정수 카운트의 비율로 계산한다.

## GP와 RF 비교

[SpatialQualityGP](../../src/quality_estimation/spatial_gp.py)는 Matérn3/2 입력 커널과 훈련 정답 상관의 축소 행렬 `B=(1−ρ)I+ρ Corr_train(Y)`를 사용하는 separable GP다. Kronecker 고유분해를 사용하며 행 상한2,500 중2,480행을 고정 학습분으로 쓴다. 표준화·상수 열 제거는 훈련 fold에서 적합한다.

| 항목 | 이번 고정 비교 |
|---|---|
| 자료 역할 | fit2,480 / dev937 / cal612 / 확인834; 주 개발361·주 확인366 |
| CV | 지리3fold, held 위치 주변25m 제외 |
| GP 설정 | 길이 배수1.4/2.8/5.6, 잡음 분산0.02/0.05/0.1, ρ0/0.4/0.8 |
| RF 설정 |128트리, 깊이8/12/제한없음, leaf1/2/4, 특징비율0.5/0.75/1 |
| 탐색 | 모델별8회BO·8회무작위, 각4개 공통 초기 관측 |
| 목적함수 | GP는Q MAE+0.25×근/원 recall MAE, RF는주Q MAE |

설정 쿼리 수를 맞췄으며 CPU시간까지 같지는 않다. RF4는 선택한 RF 설정을 재사용한다. 28열과 FP 관련 추가6열은 같은 조건에서 대조한다. 추가열은 개발 Q MAE가0.003 이상 좋아지고 보조 오차 악화가0.005 이하여야 채택한다. near F1은 RF4보다0.005 이상 좋고 Q 악화가0.002 이하여야 별도 채택한다. 선택은 확인 자료를 열기 전에 고정한다.

BO의 GP는 설정 θ에 따른 CV/검수 손실을 예측하는 **실험 대리모델**이다. 프레임 X에서 IoU를 예측하는 품질 GP와 입력·목적이 다르다. EI로 다음 설정을 고르며 같은 초기점·횟수의 무작위 탐색을 비교한다. 탐색의 최선이 초기점이면 그 사실도 기록한다.

## 불확실성과 공간 진단

GP는 원래 IoU/recall 단위의 평균과 관측 공분산 Σ를 반환한다. 잠재함수 σ와 관측 σ를 구분한다. `near−far recall`의 분산은 `Σnn+Σff−2Σnf`다. 결합 정규분포로 근/원거리 사건 확률을 계산하고, 교차 공분산을0으로 둔 같은 평균·주변분산의 대조와 Brier·대비 구간 폭/포함률을 비교한다.

σ만으로 전반 저하와 원거리 저하를 분류한다고 가정하지 않는다. 전체 저품질 확률, 보조 목표의 평균·결합 분포, σ 단독의 실제 성적을 나눠 본다. 3과제 GP의 near 항목은 recall 진단이며 precision 보존을 뜻하지 않는다. 실행 출력의 `band_diagnostic_near_metric`을 함께 읽는다.

별도26R1 보정 자료의 도로 제외 검증으로 잔차 편향·폭·상관 보정을 고른다. 표준편차 배율은1 이상으로 두고, 보정 사용 여부는 개발 Brier로 다시 검사한다. 점 추정은 제한한 원시 평균이고 위험 점수는 선택한 보정 분포를 쓴다. 포함률과 폭을 함께 보고하며, 새로운 환경에서의 확률·포함률을 보장하지 않는다.

## 인지 가중치가 바뀔 때

`refit_quality.py`는 새로운 `--adaptation-run`으로 특징·Q/보조 정답을 다시 만든 팩만 읽는다. GP NPZ에 인지 체크포인트·계보·선택 state dict·ROI·열·목표 순서를 내장한다. 보정·정책도 같은 식별자에 묶는다. f0/g0를 f1과 섞으면 거부한다.

RF 주Q 비교 모델은 [PortableForest](../../src/quality_estimation/portable_forest.py) 배열로 함께 내보내40/50환경에서 pickle 없이 읽을 수 있다. RF의 트리 간 차이를 GP 잠재분산으로 해석하지 않는다. 새 f1/g1의 RGB 재생·GT 연결과40CPU/50GPU 점검은 결과 문서에서 확인한다.

quality-fit과 인지 추가학습은 ID·픽셀이 분리돼 있지만 가까운 위치가 많다. 이2480행이 모두 인지 추가학습과 지리적으로 독립된 자료라는 주장은 하지 않는다. 개발·보정·확인과 추가학습 사이의 예약 위치 분리, 이미 열었던 f0 확인 이력도 따로 기록한다. [자료 원장](데이터_등록과_특징정답.md)

원태는 동결된 새 버전의 평균·관측/잠재 σ·포함률/폭·같은 예산 검수를 재현하고, 재호는 높은 recall과 낮은 precision이 공존하는 실제 사례를 확인한다. 누적 갱신은 [인지 재학습](인지모델_재학습과_갱신판정.md)과 함께 판정한다. 이전28+31 보정·조건부 라벨 획득·오전 성적은 [이력 가이드](../archive/guides_20261126/품질모델_학습과_불확실성.md)에 보존한다.
