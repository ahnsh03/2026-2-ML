# 이력과 원문 이동 대응표

현재 작업은 [팀 목차](../README.md)와 [일정·인계](../guides/일정과_역할.md)에서 시작한다. 이 폴더는 이전 설계·계획·실행 원문과 통합 전 안내를 보존한다. 당시 데이터·모델·담당·주차는 각 원문의 기준으로 읽는다.

## 11월26일 통합 전 가이드

환경·품질·인지 재학습·일정 가이드4개의 원문을 [별도 보존](guides_20261126/README.md)했다. 원문 기준은80cc4a7이며 [원문/보존 해시](guides_20261126/preservation_manifest.json)를 대조했다. 현재 가이드에서 중복 과거 분석을 덜어내고 [27일 실제 통합 결과](../experiments/군집_검수_동일예산_재학습_20261127.md)와 실행/후속 과제를 연결한다.

## 11월 27일 전체 원본 재생 반영 전 가이드

[가이드8개 원문](guides_20261127/README.md)과 [바이트 해시](guides_20261127/preservation_manifest.json)를 보존했다. 현재 가이드는26,001장 원본 재생·Q 단일 회귀·RGB400 환경 분류와 새 확인 절차를 따른다. 직전 실험의 수치와 실패 판정은 날짜별 기록에 남긴다.

## 보존 기준

정리 시점의 작업 트리 원문과 최종 커밋 `6ac9fa6513425c69cf20892fc4993ca05ad9c6a0`을 대조했다. 아래 SHA-256은 **문서 이동 전 원문 바이트**의 해시다. 현재 문서는 로컬 링크를 새 위치로 연결했으며, 보관 원문에는 현행 목차 안내를 덧붙였다. 실험 표·숫자·명령 블록은 원문과 대조했다. 코드 출처 inventory의 ID·내용과 계약의 의미는 보존했다.
