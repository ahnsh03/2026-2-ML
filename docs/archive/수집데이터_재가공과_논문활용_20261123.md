# 수집 데이터 재사용 점검과 참고 논문 적용 순서

2026년 11월 23일 점검. **전방 연구 수집분은 원본 RGB에서 특징을 다시 만들고, 보관한 Semantic에서 정답을 다시 정의할 수 있다.** 주행 중 검수기가 보관하는 점수·선별 영상만으로는 미선별 장면에 새 특징을 적용하거나 전체 검수 성능을 평가할 수 없다. 다음 야간·독립 도로 실험에서는 **선별 전 모집단을 먼저 등록**하고 같은 모집단에 공통 기준과 환경별 기준을 함께 적용한다. ## 1. 무엇을 다시 만들 수 있는가

| 다시 묻고 싶은 질문 | 남겨야 할 입력과 확인된 범위 |
|---|---|
| 보닛 특징이나 원·근거리 경계를 바꾸면 어떤가? | 원해상도 RGB, 카메라 규격, 고정 마스크 버전을 사용한다. X56·10영역 평균만으로 새 영역의 통계를 복원할 수 없다. 보닛 마스크를 다시 학습할 때는 학습 위치만 사용한다. |
| 야간 또는 특정 영역의 누락을 다르게 정의하면 몇 장인가? | 같은 f0·팔레트·마스크에서 기존 영역을 합치거나 IoU 기준만 바꿀 때는 보관한 영역별 TP·FP·FN이면 충분하다. 흰색과 노란색을 분리하거나 영역 경계를 바꾸면 원본 Semantic과 같은 버전의 픽셀 예측부터 다시 집계한다. 빈 합집합과 미라벨은 별도로 센다. |
| 다른 인지모델, 연결성분 특징, logit energy를 시험할 수 있는가? | 원본 RGB와 정확한 체크포인트·전처리·코드로 재추론한다. 연구용 축소 맵은 4개 요약 평면을 320×180, 8비트로 저장한다. argmax에는 클래스별 logit이 없고, 축소 맵에는 원해상도의 성분 경계가 남지 않는다. f1을 평가할 때는 같은 RGB에서 f1용 X와 y를 새로 만든다. |
| 공통 경보와 환경별 경보 중 어느 쪽이 데이터를 잘 선별하는가? | 모집단 전체의 순서·점수·예산·정책 버전, 사후 정답이 필요하다. 연구 수집에서는 보관한 전량을 사용할 수 있다. 운영에서 일부만 라벨링하면 선정 이유·무작위 대조군·포함확률을 남겨 표본 평가 범위를 명시한다. 예측한 날씨와 시뮬레이터가 보고한 날씨의 출처를 분리한다. |
| 어떤 실패 장면을 다음 학습에 넣을 수 있는가? | 원본과 GT가 있고 학습이 허용된 후보만 선별한다. 촬영 위치·물리 세션·근접 프레임·기존 인지모델 노출 이력을 먼저 확인한다. 이전 평가셋은 회귀 점검에 계속 쓸 수 있지만, 그 결과를 보고 설계를 바꾼 뒤에는 새 도로를 최종 확인용으로 남긴다. |

원본 전방 영상, 모델 공간의 padding 없는 640×360 차선 마스크, 추정기의 입력 특징은 해상도와 용도가 다르다. 기록된 Depth 값으로 상대 구간 분석은 가능하다. 미터 단위 거리나 하드웨어 노출 시각이 필요한 연구에는 해당 센서 규격·시각의 추가 증거가 필요하다. [ROI 설정](../../config/roi10_front_v1/profile.json) · [지연 정답과 점수 접합 코드](../../src/quality_estimation/roi10_study.py)

## 2. 보관 자료로 확인한 결과

- 과거 전방 X/y 9,135장과 10월 가공본 16,044장의 전체 RGB·Semantic 경로를 확인했고, 각 목록에서 세 쌍의 파일 해시를 대조했다. 10월 최초 후보 17,846장 중 가공본에 없는 **1,802장**은 확인한 두 저장 루트의 등록 경로와 회차별 경로에서 원본 쌍을 찾지 못했다. 이 ID들은 복구 대기로 구분하며 가용 데이터와 독립 평가 분모에서 제외한다.
- 11월 23일 오후에 새로 촬영한 8개 묶음의 전방 **3,233장**에서 RGB·Semantic·Instance·Depth **12,932파일**의 SHA-256과 PNG 크기를 전수 확인했다. 디코딩한 RGB 3,233개의 식별 해시도 서로 달랐다. 같은 장소 반복 촬영은 같은 통계 단위로 취급한다.
- 별도 도로 2회차의 **273장**은 GT 없이 생성해 둔 점수와 지연 정답을 프레임 ID·RGB 픽셀 해시로 다시 연결했다. 동일한 점수에서 실제 차선 IoU 기준만 0.60, 0.70, 0.80으로 바꾸면 저품질 분모는 각각 **199, 204, 220장**이었다. 두 회차를 합쳐 예측 IoU 하위 28장을 고정하면 세 정의 모두 28장이 검수 목록에 들어온 실제 저품질이었다. 회차별 예산·정책으로 선별한 기존 25/28 결과와는 집계 방식이 다르다. 이 재계산은 새 임계값의 타당성 검증을 뜻하지 않는다.
- 각 회차의 첫째·가운데·마지막 원본 **6장**에서 다시 추출한 10영역 RGB 특징 **480개**의 최대 절대 차이는 **5.96×10⁻⁸**이었다. 같은 6장의 원본 Semantic에서 흰색·노란색 차선 픽셀을 다시 세어 저장된 TP+FN과 비교한 **60개 영역**은 정수 단위로 모두 일치했다.
- 실제 3회 주행 관찰 로그에는 **1,448개 점수·24개 검수 창·147개 대기열 항목**이 남아 있다. 해당 연구에서 미선별 영상을 다시 볼 수 있는 이유는 별도의 원본 수집기가 전량을 보관했기 때문이다. 팀의 온라인 검수기는 전 입력의 점수를 남기고 채택된 RGB를 복사한다. ROS RGB 수집기는 수신 원문과 메시지 시각을 기록한다. 설치별 보존 범위와 GT 짝은 각 세션에서 확인해야 한다. [온라인 검수기](../../src/quality_estimation/stream_review.py) · [ROS RGB 수집기](../../ros/src/data_collection/src/data_collection/compressed_rgb.py)

## 3. 처음 선정한 논문에서 가져올 것

11월 3일 목록은 품질 추정·평가 연구 5편과 기반 인지모델 1편이다. 아래 ‘적용’은 우리 데이터에서 검증할 설계다. 외부 코드 버전, 인지 체크포인트, 품질 회귀모델 버전을 각각 기록한다. [최초 검토와 소스 잠금](../baselines/참고논문_베이스라인.md) · [현재의 출력·RGB 특징](../../src/quality_estimation/features.py)

| 연구 | 원 논문의 단위와 차용할 부분 | 우리 시스템에서의 적용과 판단 기준 |
|---|---|---|
| MetaSeg · Rottmann 등 | 예측 연결성분별 softmax 분산·엔트로피, 확률 상위 두 클래스 차이, 성분의 면적·경계·내부 요약으로 성분 품질을 추정한다. [원문](https://arxiv.org/abs/1811.00648) | 이미 지역 엔트로피·전체 및 격자별 성분 수를 쓴다. 추가 후보는 **예측 차선 경계와 내부의 엔트로피 차이**, 확률 마진이다. 기존 영역별 모델에 하나씩 더해 같은 도로·예산에서 누락 발견과 추론비용을 비교한다. 성분이 아예 없는 누락을 위해 고정 영역의 면적과 누락 정답을 유지한다. 입력 계산에 GT ignore 마스크가 들어가지 않도록 한다. |
| Küchler 등 | 자동차 외장 부품의 예측 성분이 precision > 0.5인지 판별한다. 크기·클래스·불확실성 특징군과 분류기를 단계적으로 비교한다. [원문 §2–3](https://arxiv.org/html/2401.09245v2) | **특징군 제거 후 재학습**을 차용한다. 같은 위치 분할에서 출력만 → RGB 추가 → 연결성분 추가를 비교하고, 원거리 미검출과 보닛 오검출을 나누어 센다. 원문 precision 기준은 차선 누락을 평가할 수 없어 우리 차선 IoU와 함께 쓰는 진단으로 한정한다. gradient·XGBoost는 단순 대조군 이후 후보로 둔다. |
| SEE · Deichsel 등 | 이미지별 분할 품질을 RF로 회귀한다. entropy·energy·NIQE·별도 복원기의 PSNR을 결합하며 SEELIGHT는 복원 단계를 뺀다. [공식 학회 초록](https://epapers2.org/iscas2026/ESR/paper_details.php?paper_id=2485) | 현재 RF·출력 엔트로피·RGB 통계의 비교 근거다. 동일 f0와 동일 분할에서 기존 RF에 평균 logit energy 한 항목을 추가하는 비교가 가능하다. MAE·검수 적중과 지연 시간을 함께 측정한다. NIQE는 RGB에서 별도 계산할 수 있다. PSNR은 논문 방식의 복원기가 있어야 한다. 세부 구현은 공식 초록이 확인해 주는 범위로 한정한다. |
| TCSR-Monitor · Pham 등 | 동일 열화 조건 안에서 정상·실패를 섞어 단순한 열화 감지와 실제 분할 실패 탐지를 구별한다. 본 적 없는 열화에 대한 전이, 분리된 보정 자료, 오경보를 평가한다. [원문 §4](https://arxiv.org/html/2608.16748v1) | **다음 실험의 1순위**다. 같은 야간·날씨·위치의 정상과 저품질을 모두 등록하고 별도 도로에서 공통 기준과 조명별 기준을 비교한다. 야간 정상 위치 수, FP/정상, TP/실패를 함께 낸다. 시간 특징을 추가한다면 과거 프레임·이동량·간격을 기록한다. 정상 차량 이동도 마스크 중첩을 바꾼다. |
| 실패 탐지 벤치마크 · Zenk 등 | 신뢰도 집계와 risk–coverage로 품질 순위 전체를 평가한다. [원문](https://arxiv.org/abs/2406.03323) | **다음 평가표의 보조 지표**다. 예측 IoU 상위 장면을 자동 통과시킬 때 통과 비율별 평균 실제 손실인 1−IoU와 곡선 아래 면적(AURC, 낮을수록 좋음)을 낸다. 같은 분모에서 MAE·검수 예산별 Recall·야간 정상 오경보도 병기한다. 동일 점수 처리, 미정의 정답, 도로별 재표집을 고정한다. [프로젝트 평가 정의](평가_수집_재학습계획.md) |
| TwinLiteNet+ · Huy 등 | 주행가능 영역과 차선을 함께 예측하는 경량 구조를 제공한다. [원문](https://arxiv.org/abs/2403.16958) | 현재 기준은 자체 가중치 **Medium v6 f0**다. 같은 프레임에 같은 가중치와 전처리를 적용해 근거리·원거리 오류를 비교한다. 재학습 효과는 f0/f1을 같은 미사용 평가 장면에서 짝지어 측정하고 기존 성능 유지도 검증한다. [체크포인트·클래스 계약](../baselines/medium_v6_baseline_evidence.json) |

후속 날씨 연구는 **환경을 설명하는 특징**에 이미 반영했다. Roser의 지역 블록 히스토그램과 Cheng의 도로·하늘 밝기 및 색도를 같은 10영역에서 비교하고, Lu의 하늘·대비 단서와 Lin의 영역 간 동시 출현을 참고해 띠별 날씨 확률을 결합했다. 이 연구들은 ‘비를 알아봤다’는 근거가 될 수 있다. ‘비 오는 장면 중 실제 차선 실패를 찾았다’는 주장은 같은 날씨 안의 정상·실패 대조가 필요하다. [Roser 원문](https://www.mrt.kit.edu/z/publ/download/Roser_al2008iv.pdf) · [Cheng 원문](https://scholarworks.indianapolis.iu.edu/items/ffcb6cd1-ceca-4d88-bec9-3ded514a1dcc) · [Lu 원문](https://openaccess.thecvf.com/content_cvpr_2014/papers/Lu_Two-Class_Weather_Classification_2014_CVPR_paper.pdf) · [Lin 원문](https://www.cse.cuhk.edu.hk/~leojia/papers/rscm_pami17.pdf) · [현재 구현과 대조 실험](../experiments/전방_10영역_특징과_품질추정_20261123.md)

## 4. 다음 수집의 인계 조건

| 시점 | 남길 항목 | 수집 후 확인 방법 |
|---|---|---|
| 수집 전 | 수집 목적, 입력 채널과 보존 범위, 카메라 설정, 부모 세션·도로·위치, 학습/보정/평가 역할, 야간 정상과 저품질의 정의 | 미사용 확인 도로를 지정하고 같은 위치 반복 촬영이 서로 다른 분할에 들어가지 않는지 확인한다. 실제 IoU < 0.7, 원거리 가시성 저하, 근거리 차선 누락은 별도 열로 기록할 수 있다. |
| 수집 중 | 프레임 ID·순서, 원본 상대경로·SHA-256, RGB 픽셀 해시, 환경 설정값과 관측 출처, 센서/호스트 시각과 단위, 누락·중단·재시도 | 동일 이름 재촬영을 구분하고 끝나지 않은 시도와 추정·미상 조건을 별도 상태로 보존한다. 선별기는 점수·시드·예산·결정 사유와 원본 ID를 기록한다. |
| 수집 직후 | 수집 목록의 해시, 실제 채널별 장수, 누락·중복, 코드와 체크포인트·ROI·GT 정책 버전, 재가공 산출물이 가리키는 부모 목록 | 원본에서 소수 프레임의 특징·정답을 다시 만들고 다른 IoU 기준으로 분모를 다시 센다. 다른 저장 위치에서 원본과 체크포인트를 읽을 수 있는지도 확인한다. |
| 검증·후속 사용 | 평가 결과를 본 시점, 학습에 사용 가능한 후보, 무작위 대조와 검수 결과, f0/f1 계보 | 같은 모집단·예산에서 기준을 비교하고 도로별 야간 정상 분모와 불확실성을 보고한다. f1 채택 여부는 이 검수 성능과 별도로 판단한다. |

점검 후 공통 세션 기록, 기존 4채널 원장 등록, 복원본 검증과 오프라인 입력 내보내기를 구현했다. 다음 검증은 보관 자료의 역할을 먼저 고정하고, 야간 정상 위치가 부족한 범위를 보강하는 것이다. [수집기 실행법](수집세션_등록과_오프라인_재가공.md) 현재 별도 야간 자료 256장의 정상은 **16장, 3개 위치**에 집중됐다. 위치를 추가한 뒤 TCSR 방식의 조건 내 검증과 Zenk 방식의 순위 평가를 먼저 하고, 부족한 실패 유형이 남을 때 MetaSeg 등의 특징을 추가한다. e-means는 환경 태그, GP는 품질·불확실성 비교, Bayesian optimization은 개발 분할에서의 오프라인 탐색에 배치한다.
