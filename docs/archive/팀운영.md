# 팀 운영과 공통 인계 기준

기계학습과 캡스톤디자인은 개발 결과를 공유한다. 기계학습 팀원은 안승현·손재호·장원태, 캡스톤 팀원은 안승현·장원태다. 날짜별 담당과 완료 기준은 [최종 실험 일정과 3인 작업 분담](데이터플라이휠_통합실험계획_3인분담.md)을 따른다.

## 팀원 인계

| 전달 자료 | 함께 기록할 내용 |
|---|---|
| 입력과 특징표 | 프레임 ID, 도로·세션과 데이터 역할 목록, 입력 목록 해시, 인지 체크포인트, 카메라·ROI 버전, 열 이름·순서·단위와 유효성. 같은 표를 재생할 예시와 실행 명령을 전달한다. |
| 품질 점수와 검수 목록 | 프레임별 모델·특징 버전, 예측 IoU, 해당하는 경우 GP 표준편차와 환경군, 검수 창·예산·중복 규칙·선택 사유·시드를 기록한다. 추론 입력은 영상과 인지 출력에서 계산한다. |
| 평가와 채택 결과 | 선택 목록을 고정한 뒤 프레임 ID·원본 해시로 GT를 연결한다. 독립 평가 도로, 분모·미정의 장수, 기준선, 개선·악화 사례와 채택 또는 보류 사유를 적는다. [입출력 규약](../contracts/품질추정_입출력규약.md) · [평가 계획](평가_수집_재학습계획.md) |

## 저장과 공유

팀 PR에 실행 명령·코드 버전·입력 목록 식별자·결과표를 포함한다. 공개 집계와 그림은 팀 저장소에, 원본·체크포인트·상세 실험 로그는 실험 볼륨에, 과목별 발표 작업 파일은 로컬 워크스페이스에 둔다. 검증한 결과는 [개발 현황](개발현황.md)에서 연결한다. 초기 기술 이식과 당시 담당 구분은 [코드 이식 계획](코드이식_분담계획.md)에 기록돼 있다.
