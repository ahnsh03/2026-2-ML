## ROI 가로 분할 비교

**안승현 · 11월 24일 인계.** 보유한 같은 전방 RGB와 TwinLiteNet+ Medium v6 출력 맵을 7·10영역으로 각각 집계한다. 두 마스크는 상부·원거리·근거리와 보닛 경계를 공유한다. 7영역은 x=640에서 좌우로 나누고, 10영역은 좌·중앙·우를 나눈다. 전역 특징 포함 여부와 추출 해상도를 맞추고, 기존 지역 평균·분위수 대신 원본 픽셀 또는 출력 맵에서 다시 집계한다. [7영역 마스크 정의](../../config/roi7_front_v1/profile.json) · [10영역 마스크 정의](../../config/roi10_front_v1/profile.json)

같은 도로 분할에서 **두 ROI 방식 × RF·GP** 네 조합에 공통 RGB 8개와 출력 4개를 적용해 프레임 전체의 흰색·노란색 차선 IoU 하나를 직접 예측한다. 네 조합의 MAE, Recall@10%, 처리시간, 중앙 분할로 선택이 달라진 실패 사례를 한 표에 적는다. 비교 전 허용 손실을 정하고, 개발 도로에서 성능이 비슷하면 간단한 구성을 고른다. 표본이 부족하면 이번 주기에 사용할 기준과 불확실성을 함께 기록한다. 4영역 및 전역 특징 추가는 해석이 필요할 때의 보조 대조다. [보관 자료·특징 재생 절차](전방_10영역_실험_재현.md)

## 11월 25–27일 · 특징과 알고리즘 첫 결합

### 안승현 · 인지 출력 특징, RF 기준선, 통합 실행

1. 프레임 ID·물리 세션·도로·용도(학습/개발/보정/평가)가 있는 목록과 선택한 ROI를 전달한다. 재호에게 RGB 입력, 원태에게 기준 특징표와 분리된 학습 정답을 제공한다. 실제 날씨·시각·위치·GT는 추론 입력에서 제외한다.
2. 주행가능 면적·차선 면적·차선 확률·마킹 엔트로피를 기준으로 확률 마진, 예측 차선 경계·내부의 엔트로피를 추가한다. 상부와 보닛은 각각 출력 4개, 차선 면적 1개, 출력 0개로 줄여 누락되는 실패를 확인한다. [출력 통계와 예측 맵](../../src/quality_estimation/roi10.py) · [논문별 차용 근거](수집데이터_재가공과_논문활용_20261123.md)
3. 재호의 RGB 열과 프레임 ID로 결합해 RF를 학습한다. 원태의 GP와 같은 행·열을 쓴다. 개발 회차 하나를 끝까지 재생해 ID 중복·누락, 열 순서, 처리시간을 확인하고 첫 결합 명령과 모델·특징 버전을 팀에 넘긴다.

### 손재호 · RGB 특징 추출과 특징 선정 공동 담당

1. 24일 받은 마스크로 모든 영역에서 밝기 평균·색차·밝기 표준편차·다크 채널·국소 대비·선명도·고휘도 비율·중앙값 필터 잔차를 계산한다. 첫 RGB 표를 원태에게 먼저 넘긴다. 각 열의 영역·계산식·단위·해상도와 빈 예측 마스크 처리 규칙을 기록한다. [기존 특징과 제거 실험](../experiments/전방_10영역_특징과_품질추정_20261123.md)
2. 논문에서 차용한 밝기·대비·색상 분포를 특징군 단위로 더한다. 이후 영역별로 줄이고 마지막에 보닛–노면 밝기차, 원–근거리 대비차, 좌우 비대칭을 시험한다. 선택하지 않은 원 측정값도 실험 볼륨에 남겨 관계 특징을 다시 계산할 수 있게 한다.
3. 승현과 같은 개발 분할에서 RGB만, 출력만, 결합 입력을 RF·GP로 비교한다. 27일에는 첫 특징표와 사례 그림을 전달하고, 30일 판정 전에는 특징군별 MAE·검수 성과·추출비용을 근거로 최종 열을 공동 확정한다. 품질 추정용 열과 환경 군집용 RGB 열은 각각 명시한다.

### 장원태 · GP, e-means, Bayesian optimization과 검수 정책

1. 기준 특징표로 GP의 IoU 예측 평균·표준편차를 출력한다. 별도 보정 도로에서 90% 예측구간의 실제 포함률과 폭을 확인한다. BO는 GP의 길이척도·잡음부터 조정하고 같은 평가 횟수의 무작위 탐색과 비교한다. [GP 구현](../../src/quality_estimation/gaussian_process.py) · [기존 BO 실험](../experiments/환경_ROI와_품질추정_20261123.md)
2. 재호의 RGB 표에서 색차·다크 채널·대비로 e-means를 시작한다. 학습 도로에서 표준화와 중심을 적합하고 개발 도로에서 군집 ID·중심 거리·정상/저품질 위치 수를 낸다. 특징 버전이 바뀌면 같은 명령으로 다시 적합한다. [군집 구현](../../src/quality_estimation/environment_clusters.py)
3. 같은 검수 창·예산에서 무작위, 예측 IoU 순위, GP 불확실성을 반영한 순위, 환경 내 상대 순위와 혼합 정책을 비교한다. 27일 인계물은 프레임 ID별 RF/GP 점수, GP 표준편차, 환경군, 선택 여부·이유가 포함된 **같은 회차의 결과표**다. 기존 익명 점수표는 검수 로직 재생에 사용하고 새 군집 적합에는 RGB 특징표를 사용한다. [점수표](../baselines/offline_review_20261123/scores.csv) · [사후 GT 표](../baselines/offline_review_20261123/delayed_gt.csv)

## 11월 28–30일 · 오프라인 판정

- **재호·승현**이 특징 열·순서와 추출기를 확정하고 **원태**가 최종 모델과 군집을 다시 적합한다. 실제 전체 IoU < 0.7을 공통 비교 분모로 두고 공통·환경별 경보값을 보정한다. 정상 위치가 적은 군집에는 공통 보정값을 우선 적용한다. 주 평가 예산은 10%다.
- **원태**가 모델·정책·선택 ID를 고정한 뒤 **승현**이 미사용 도로의 GT를 연결한다. **재호**는 MAE, Recall·Precision@10%, 서로 다른 실패 위치 수, 야간 오경보와 정상 분모를 확인하고 정책 변경으로 추가·누락된 장면을 대조한다. ROI별 오류는 사례 진단에 사용한다. 기존에 분석한 273장은 진단 자료로 표시한다.
- **승현**이 선별과 무작위에 동일한 신규 라벨 수·초기 모델·기존 자료 혼합·업데이트 예산을 적용해 재학습한다. 새 인지모델 출력으로 품질 정답과 추정기를 갱신한다. 신규 차선 IoU 변화 ≥ 0, 기존 IoU 손실 ≤ 0.005, 품질 MAE 증가 ≤ 0.010을 함께 확인한다. **세 사람**이 채택할 모델·정책 또는 보류 사유, 독립 평가 범위와 시연할 버전을 판정표에 실험 식별자와 함께 기록한다.
