# 전체 원본 재생과 동일 예산 재학습

> **11월28일 후속 주기 진행:** 인지 개발 기준을 `m-v6-r1-20261128`로 승격했다. 누적 학습기는 명시한 부모와 전체29,073장 replay를 검증하며 새2,048장 은행을 비교한다. [현행 진행·프로토콜](../../experiments/표시가용성_누적갱신_20261128.md)을 먼저 확인한다. 아래8학습·선별3,072장·판정표는 직전 완료 주기의 재현 기준이다.

현재 단위는 **v6 원본26,001장을 공통 재생 풀로 보존**하고 새 선별3,072장의 효과를 비교했다. [28일 실험 기록](../../experiments/환경검증_전체원본재생_20261128.md)의8학습·새 확인은 완료됐으며 **검수 실패로 통합 교체를 보류**한다. 직전4,096장 재생 결과와 보류 판정은 [27일 기록](../../experiments/군집_검수_동일예산_재학습_20261127.md), 이전 실행 설명은 [원문](../guides_20261127/인지모델_재학습과_갱신판정.md)에 보존했다.

## 원래 학습 구성 보존

체크포인트 내부 train-manifest SHA가 현재26,001장 목록과 일치한다. 전·좌·우8,667장씩, 초기4수집 묶음14,145장과 이후8묶음11,856장이다. 이전4,096장은 수집 묶음×시야별 유사 할당 후 시간순 균등 간격 추출이어서 원래 묶음 비율을 바꾸었다. 이번에는 전체 목록의 순열을 반복한다. 원래 날씨·시각이 비어 있는 곳은 파일명이나 PC 시각으로 추정해 정답으로 넣지 않는다.

전체 원본의 RGB·두 헤드 정답·패딩은 주소형 캐시로 검증하며, 두 헤드 정답과 valid mask는 원래 학습 버전과 전부 비트 단위로 같다. D 원본은 읽기 전용이고 파생 캐시·로그·가중치는 실험 볼륨에 둔다. 기존 캐시를 공유하여 원본을 다시 복사하지 않는다.

## 같은 출발점과 학습 예산

| 방법 | 새 bank | 원본 공통 풀 | optimizer 시드 |
|---|---:|---:|---:|
| RandomFull | 무작위3,072장 |26,001장 |2 |
| RFGlobalFull | RF 보정 위험도+감사3,072장 |26,001장 |1 |
| GPGlobalFull | GP 보정 위험도+감사3,072장 |26,001장 |2 |
| TagBalancedFull | 시뮬 환경 균형 무작위3,072장 |26,001장 |2 |
| ReplayFull |0장 |26,001장 |1, 계속학습 대조 |

모두 **같은 Medium v6 EMA**에서 시작하는8학습이다. 먼저4방법을1시드씩 비교한 뒤, Random과 Dev에서 유지 기준을 통과한 비무작위 상위2방법을 반복한다. 나머지1방법은1시드 진단이며 원본 전용 대조1회를 더한다. 같은 총예산 안에서 균형 선별도 유망하면 반복하는 Dev 기반 적응 배분이다. 새 확인은 이 선택에 쓰지 않는다. 최적화 반복은 선별 bank의 반복이 아니다. 시뮬/RGB 환경별 임계 정책이 GPGlobal과 같은 순서의 목록을 고르면 그 결과를 공유하며 독립 방법의 반복으로 세지 않는다. 원본만 계속 학습하는 대조는 새 자료 없이 최적화한 효과를 분리한다.

매 배치는 신규2+원본14, 대조는 원본16이다. 동결 sampler 재구성에서 원본 각 장은12–13회(대조14–15회), 신규는15–16회 사용되며 원래 수집 묶음 비율과의 총변동은0.00018 미만이다. 이 재구성은 완료 실행의 draw 합계·소스 해시와 대조하고 실제 이미지 읽기 telemetry와는 구분한다.24,000업데이트, AdamW LR1e-5→1e-6 cosine·warmup200·decay1e-4·clip10·BF16 forward/FP32 loss·고정BN moments를 공유한다. affine은 학습하며 원본에는 f0 teacher KL0.25/T2를 적용한다. 신규 bank는 약15.625회, 원본은 약12.923회 제시된다. 신규 비율12.5%는 전체 합집합의10.57%보다 조금 높다. 실제 시간·메모리·손실은 각 실행 영수증으로 보고한다.

직전 실험과 비교하면 재생 풀과 배치 비율을 함께 바꾸었다. 두 변경 중 무엇이 개선의 원인인지를 분리한 실험은 아니다. 이번 방법끼리는 같은 구성과 예산을 쓴다.

## 개발 선택과 독립 확인

같은 alpha0.25/0.5/0.75/1.0에서 `θα=(1−α)θv6+αθtrained`를 평가한다. 추가 gradient 학습 없이 만든 파생 가중치이며 고정 buffer의 일치를 확인한다. 방법 효과는 공통 alpha에서 비교하고, 최종 후보의 alpha·시드는 Dev에서만 선택한다. [WiSE-FT](https://github.com/mlfoundations/wise-ft)의 보간 아이디어를 다른 모델·과제에 적용한 실험이다.

| 판단 | 고정 기준 |
|---|---|
| 신규3도로 | macro IoU 이득≥0.005,2도로 이상 향상, 개별 손실≤0.02 |
| 기존 validation1,404장 | lane/drivable pooled 손실 각각≤0.005 |

| 검수10% | 저IoU 정답20장·2도로 이상 지원, precision·road-macro recall이100회 무작위 평균 이상 |

지표의 지원 조건·정확한 수치는 동결 설계와 결과 JSON을 따른다. 품질 MAE 증가는 달라진 정답 버전 사이의 실용 유지 기준이며 통계적 동등성 증명은 아니다. 새 확인으로 특징·임계·가중치를 다시 고르지 않는다.

## 버전 쌍 완성 절차

[실험 실행 안내](../../../scripts/experiments/environment_cycle_20261127/README.md)는 원본 감사→RGB 환경/GP·RF/검수 기준→GT 없는 고정 선별→공통 캐시→8학습·Dev→f1 고정→X/y 재생성→g1 GP·RF·잔차 보정·검수 정책→새 확인→실제 RGB 재생·GT 재연결 순서다. 후보·원본·품질 역할의 ID/픽셀 혼입을 거부한다.

품질 학습은2,500행이다. 이미 열었던834행을 학습 역할로 명시적으로 승격하고 시험 지위를 폐기했다. 새 확인은 같은 맵의 다른3구간·6날씨·07/08/13/20시에서 별도로 수집한다. 원래 학습 ego 위치와의 이격은 확인하지만 카메라 시야의 완전한 비중복이나 새 도시 일반화까지 뜻하지 않는다.

인지 가중치가 바뀌면 출력 특징과 IoU 정답도 바뀐다. 같은 f1으로 품질 fit/Dev/Cal을 다시 만들고 GP/RF·보정·정책을 재적합한다. [Q·환경 번들 계약](../../contracts/environment_review_bundle_v1.md)은 인지 신원·ROI·열·모델·보정·정책 해시를 묶는다. `deployment/candidate_pair.json`이 채택/보류 인계물이며 기본 v6 파일을 덮어쓰지 않는다.

## 완료 판정과 다음 단위

8회 학습과 새 확인을 완료했다. GP 은행의 두 시드는 인지·기존 성능 유지 기준을 통과했으나, 같은 alpha의 확인 평균은 GP0.23569/무작위0.23831/태그 균형0.23923이었다. **위험 선별이 무작위보다 재학습에 유리하다는 증거는 없다.** GP 후보의 도로평균 이득은0.19877→0.23650이지만 실질적인 개선은 표시가 충분한 한 구간의0.59620→0.70928에 집중됐다. 다른 한 구간의0.00011 이득도 기존의 ‘양수2도로’ 조건에 포함되므로 복수의 유효 표시 도로 개선으로 해석하지 않는다.

검수 기준이 실패했으므로 온라인 전환은 보류다. 다음 프로토콜에서는 표시·무표시·원거리 전용 장면의 지원량과 실제 FP/FN을 분리하고, 복수의 유효 표시 구간과 실질 이득의 최소값을 **새 평가 전에** 정한다. 현재 확인을 삭제하거나 같은 자료에 임계값을 맞춰 통과시키지 않는다.

오프라인 채택을 먼저 판단하고 [ROS shadow 연결](온라인_연결과_최종제출.md)을 진행한다. `retrain_streaming --parent-adaptation-run`은 누적 부모·노출 원장·전체 replay·중복을 검증한다. 비교 실험의 원래v6 출발 경로도 보존한다. 새 인지 버전의 채택은 해당 품질/정책 채택과 따로 판단하며 자동 입학이나 live 갱신을 뜻하지 않는다. [11월30일 판정·12월4일 최종물 일정](일정과_역할.md)은 유지한다.
