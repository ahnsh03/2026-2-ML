# 데이터 등록과 특징·정답 생성

승현이 원본·역할 목록을 준비하고 재호·원태가 같은 ID의 특징표를 사용한다. 최신 역할·추가학습/평가 목록은 [전체 원본 재생 실험](../../experiments/환경검증_전체원본재생_20261128.md), 담당은 [일정과 인계](일정과_역할.md)를 따른다. 아래 날짜별 등록 수는 당시의 자료 규모다.

## 현재 전체 원본 재생 주기의 자료

원래 인지 train26,001·val1,404장의 목록과 checkpoint 내 해시를 대조했다. 신규 후보7,442장에서 방법별3,072장을 고르고 전체26,001장을 공통 원본 풀로 사용한다. 전체 원본 두 헤드 정답·padding을 원래 학습 버전과 비트 단위로 대조했고 주소형 캐시를 공유한다. 원본을 새로 복사하거나 캐시 glob으로 학습 자료를 늘리지 않는다.

품질 fit은 이전2,480행 중1,666행과 **이미 열었던834행 전부**를 합친2,500행이다.834행은 이번부터 학습이며 다시 독립 시험으로 부르지 않는다. Dev937행(이동361+이전576), Cal612행의 역할은 유지한다. union0인 Q는 미정의이며 새 인지 버전에서 fit의 정의된 지원 장수를 다시 기록한다. 근/원거리 정답 미정의를 이유로 정의된 주 Q 행까지 버리지 않는다.

새 확인은 모든 선택과 분리한3구간·6날씨·07/08/13/20시의26R1 저속 주행이다. 실제1815장/4채널7260파일을 해시 검증하고3m XY 기준으로618장을 정답/출력 검사 전에 고정했다. 기존 품질/추가학습 위치와 최소30.83m, 기록된 원래 학습 ego 위치와 최소46.35m 이격했다. 같은 맵의 시야가 완전히 비중복이라는 의미는 아니다. 확인 역할을 학습에 승격하지 않는다.

quality-fit과 인지 추가학습은 ID·픽셀은 다르지만 가까운 위치가 많다. 완전한 지리 독립을 주장하지 않는다. 추가 자료 선별은 후보 y·Semantic을 읽지 않고 재현한 순서와 일치한다. 선별 뒤 실제 GT를 학습 정답으로 연결하는 시점과 선별 정책 자체의 입력을 구분한다.

현재 [실험/자료 역할](../../experiments/환경검증_전체원본재생_20261128.md)과 [실행 안내](../../../scripts/experiments/environment_cycle_20261127/README.md)를 따른다. 직전4,096장 재생·fit2,480/확인834 역할은 [27일 가이드 원문](../guides_20261127/데이터_등록과_특징정답.md)에 보존한다.

## 원본 등록과 내보내기

다음 변수는 자신의 실험 볼륨의 원본·목록·새 출력 경로로 설정한다. `SESSION_CONTEXT`에는 물리 세션, 도로, 학습/개발/보정/평가 역할, 카메라 설정과 관측 출처를 기록한다.

```bash
python3 scripts/capture_sessions.py register-front \
  --manifest "$RAW_MANIFEST" --media-root "$RAW_ROOT" --session-id "$SESSION_ID" \
  --context "$SESSION_CONTEXT" --population all_captured --output "$CAPTURE_STORE/$SESSION_ID"
python3 scripts/capture_sessions.py verify "$CAPTURE_STORE/$SESSION_ID" --media-root "$RAW_ROOT"
python3 scripts/capture_sessions.py export "$CAPTURE_STORE/$SESSION_ID" \
  --media-root "$RAW_ROOT" --output "$EXPORT_DIR"
```

출력의 `rgb.jsonl`은 점수화 입력, `paired.jsonl`은 사후 정답 입력이다. RGB만 수신한 세션은 paired가 0이며 실제 IoU는 미정의다. 원본 미디어는 `RAW_ROOT`에 있고 후속 `--data-root`도 그 루트를 사용한다. 누락 채널·잘린 원장·선별본의 모집단 범위는 그대로 기록한다. [세션 기록 형식과 복원 절차 원문](../수집세션_등록과_오프라인_재가공.md)

## 특징과 정답

- 원해상도 RGB와 같은 버전의 인지 출력에서 특징을 계산한다. 흰색·노란색 차선은 4클래스 argmax 결과의 합집합으로 정의하고 모델 letterbox padding을 제거한다.
- 정답은 `TP / (TP + FP + FN)`으로 계산한 프레임 전체 IoU 하나다. 합집합이 빈 장면은 미정의로 기록한다. 회귀 적합·MAE에는 정의된 정답을 쓰고, 검수 후보와 예산에는 미정의 장면도 남겨 선택 수를 보고한다.
- ROI별 TP/FP/FN은 누락·오검출 사례를 해석하고 전체 IoU를 대조하는 데 사용한다. 이번 직접 회귀의 목표는 전체 IoU다.
- 인지모델을 갱신하면 같은 RGB에서도 출력 특징과 실제 IoU를 다시 계산한다. 인지모델·품질모델의 짝과 학습 이력을 함께 기록한다.

기존 X56을 재현할 때는 아래 명령을 사용한다. `NATIVE_MANIFEST`에는 RGB·Semantic 짝과 출처 역할이 있어야 한다.

```bash
scripts/run_container.sh python3 -m quality_estimation.build_native_dataset \
  --manifest "$NATIVE_MANIFEST" --data-root /data \
  --output-dir /outputs/datasets/native_front --audit-per-run 2
```

기존 10영역 연구 팩은 다음 명령으로 만들 수 있다. `--paired`는 학습·사후 정답용 입력에서 사용한다.

```bash
scripts/run_container.sh python3 -m quality_estimation.roi10_study build \
  --manifest /outputs/manifests/train.jsonl --data-root /data \
  --paired --purpose training --output /outputs/roi10/train
```

새 [공간 추출기](../../../src/quality_estimation/spatial_features.py)는 7·9·10영역을 같은 RGB·출력 맵에서 재집계한다. f0 기준은 RGB10·출력14·원본 softmax1·거리관계3의 **28열 v3**이고 f1 후보는 RGB 요약24개를 더한52열이다. 인지 버전별 번들의 열 순서를 따른다. 120열 공통 대조와27열v2·환경80/160/54열은 이전 연구다. [f0 명세](../../../config/region_feature_recipe_v3.json), [버전별 열과 사용법](ROI와_특징추출.md), [최신 비교 결과](../../experiments/환경검증_전체원본재생_20261128.md)를 따른다.

## 26R1 원본과 재가공 보존

1차 등록 자료는82팩·23,142장으로 ID와 디코딩RGB 픽셀 해시는 모두 고유했다. 1차 신규 수집은 **26R1 336장**이며 설정 전이144·보정96·학습 미사용 링크96으로 역할을 나눴다. 보관22,806장을 신규 수집으로 세지 않는다. [역할·좌표 이격의 한계](../../experiments/ROI9_GP와_26R1_검증_20261126.md#2-자료-역할과-누수-통제)

정지 수집은 전방RGB·Semantic·Depth·Instance 원본과 촬영 전후 자세·날씨·시간·Park/속도·요청 결과를 보관한다. SaveSensorData가 타임아웃되어도 파일이 생성되는26R1 현상 때문에, 고유 접두사·완전한4파일·안정된 크기·디코딩·해시·상태 일치를 통과한 프레임만 등록했다. 실패/고아 파일과 원래 요청은 삭제하지 않는다. 시뮬레이터 timestamp RPC가 인수되지 않은 정지 경로는 timestamp를 null로 남긴다. 호스트 시각을 센서 시각으로 가장하지 않는다. 이후 저속 주행은 아래 별도 절에서 검증했으며 카메라 노출 동기화의 인수와 구분한다.

새 후보 팩은372열, 사후9영역TP/FP/FN, 전체y·ID·픽셀해시·위치/환경/역할을 담는다. 원본RGB·Semantic·f0·전처리·코드를 보존해 다른 집계로 재가공한다. 보관 재생 일부에는 원본확률도 있지만 새 `infer_review_images --save-heads`는 마킹argmax와 축소head맵만 저장한다. 새로운 확률·logit 특징은 원본RGB와 동결모델에서 재계산한다. 모든 프레임의 raw logit이 캐시됐다고 가정하지 않는다.

확대 품질학습은 입력 조건으로2,496장을 먼저 고르고, 근거리 GT 분모가 없는16장을 제외해 RF·GP공통2,480장을 썼다. 미정의 recall을0으로 채우지 않는다. 기존 진단624장은 학습으로 승격했으므로 독립평가 역할을 해제했다. 번들의 `training_membership.json`은 정확한 구성원·원본해시·정답을, `split_roles.json`은 학습/개발/보정/평가ID를 남긴다. 학습 표준화X·적합 가중치를 원본팩에서 재구성해 대조했다. ID 불교집합만으로 지리적 독립이 증명되지는 않으므로 좌표/링크 이격도 별도 기록한다.

원거리 보조 후속 당시 보정96장·다른 평가4링크96장을 추가해 신규26R1은528장, 등록은84팩·23,334장이었다. 이후 [실제 라벨 획득 검증](../../experiments/GP_조건부_라벨획득_20261126.md)에96장을 더 촬영해 **오전 당시 신규26R1 624장·전역85팩·23,430고유ID/픽셀**이다. 모델/보정 또는 선택/갱신 상태 고정 뒤 새 평가를 촬영했고 이미 열어본 자료는 진단으로 구분한다. [원거리 후속 역할](../../experiments/ROI9_원거리보조와_환경전이_20261126.md)

정지 수집의 새 등록은 전체 현행 index를 `register_capture.py --existing-index`에 제공하고, 컬렉션별 `--sample-id-prefix`를 지정한다. 논리 sample/site ID는 전역 고유하게 하고 raw `capture_sample_id`/`capture_site`와 매체 파일명은 보존한다. 등록기는 기존 ID 중복·4채널 누락을 거부한다. 계획기의 site ID도 제외 계획과 겹치지 않도록 인수한다. 이번 raw ID 충돌은 원본 보존/namespace로 수정했고28열/27모델 성적은 바뀌지 않았다. 이전 index/실패/별칭 대응표도 실험 볼륨에 보존한다.

RPC가 멈추면 `remaining_capture.py --plan ... --collections ... --output ... --max-frames 48`로 **원래 전체 계획**에서 승인된 ID만 제외한 작은 묶음을 만든다. 고아 파일을 승인된 것으로 간주하지 않는다. 이 도구는 정지한RPC 서비스를 자동으로 재연결하지 않으며 재개 전 Keyboard/Park·상태·원본 파일을 확인한다.

## 저속 주행 원본·현재 역할 원장

26일 저속 정규 수집은237회·5,541장, 4채널22,164파일 해시를 검증했다. 3m 진행거리 간격 후보1,929장은 원본 전체 목록과 별도다. 63개 확인 낮 프레임의 자기GT 경계가 인접GT보다 RGB 경계에 잘 맞았지만 노출 시각은 미제공이다. 차량 상태의 최초 파일 관측 시각을 센서 노출 시각으로 바꾸지 않는다. [역할·수집·보존 결과](../../experiments/ROI9_저속주행과_검수보정_20261126.md)

실험 볼륨의 `global_registry_v2/index_full.json`·`pack_artifacts.json`은103팩·28,971고유ID/픽셀의 원본/팩 대응표다. `role_ledger_v2/index_with_current_roles.json`·`roles_by_sample.json`은 취득 당시 역할을 보존하면서 현행 노출을 표시한다. 보정으로 전환한 후속도로 전체와 인접 원본을 미사용 평가로 재사용하지 않는다. 실제 보정612행, GP학습2,480행은 별도 구성원 해시로 고정한다. 원본 폴더를 glob해서 학습 목록을 만들지 않는다.

**이미 만든 팩의 정답 연결에는 영수증이 참조한 원래 index를 사용한다.** 현행 역할을 덧붙인 index는 해시가 다르므로 기존 팩의 `--source-index`로 바꿔 끼우지 않는다. 현행 원장을 새 추출의 입력으로 쓰면 별도 팩/영수증을 생성한다. 실패·파일럿·확인 영수증 전 시작한 격리 회차는 원본을 남기고 정규 목록에서 제외했다.

## GT 없는 선별 후 정답 연결

인지모델을 갱신할 때에는 `extract.py --adaptation-run ...`으로 **별도 팩 폴더**에 다시 만든다. f1은 완료 실행·학습 가중치·계보 해시를 검증한다. 팩/명세/GP/보정에 같은 인지 버전을 기록하고 기존 f0 팩을 재사용하지 않는다. 새 추출 영수증에는 배치 크기·float32/TF32 설정도 남긴다. [보관 후보384장 재가공과 버전 연결 검증](../../experiments/9영역_인지버전쌍_연결검증_20261126.md)은 새 물리 프레임 수집이 아니다.

현재 버전 쌍은 `infer_versioned_review`가 RGB·고정 인지모델과 짝 번들만 읽는다. 이전 `infer_review_images`/`review_calibrated`와 `infer_spatial_images`/`review_spatial`도 해당 f0 번들의 재현 경로로 유지한다. 후보ID·해시·선별 사유를 먼저 고정한 뒤 다음 명령으로 같은 인지 버전의 paired 팩을 연결한다.

```bash
PYTHONPATH=src python3 -m quality_estimation.join_spatial_gt \
  --queue-dir "$NEW_QUEUE" --packs "$VERIFIED_PACKS" \
  --source-index "$REGISTERED_INDEX" --all-keys \
  --data-root "$RGB_GT_ROOT" --output-dir "$NEW_GT_REVIEW"
```

여러 도로는 `--all-keys`, 단일 팩은 기존 `--key "$SOURCE_KEY"`를 사용한다. 선택 원본의 RGB/Semantic 바이트도 `--data-root`에서 확인하고 서로 다른 인지 버전의 팩은 거부한다.

index는 팩을 만들 때의 **동일 파일 해시**여야 한다. 검수기에 복사한 RGB의 숫자 파일명 대신 원래RGB/Semantic 출처를 되찾는다. 완료 영수증·후보/팩/스키마/원본RGB/인지체크포인트/ROI 해시·ID순서를 확인한다. 결과는 전체IoU와 근·원거리 recall/GT분모·precision·FP수를 연결하되 `admission_approved=false`로 남긴다. 근·원 recall은 오프라인 누락 진단이며 precision이 낮은 FP 장면을 정상으로 해석하지 않는다. 예측이 없을 때 precision은null로 둔다. 온라인ROI IoU는 없다. .7 비교값만으로 운행 실패·자동 학습허용을 결정하지 않는다.

## 분할과 재가공

11월28일 확인의 사후 감사에서 검수62장 중59장이 근거리 진단 미지원 장면에 몰렸고 실제 근거리 결함114장은 놓쳤다. 전체 Q는 계속 보존하되 **GT/예측 지원량·근거리 FP/FN·예상 표시 유무·검수 가치**를 별도 필드/사유로 다뤄야 한다. 현재 `gt_review_flags`의 지원량과 precision/recall 정의를 재사용하고 버전별 사유를 기록한다. GT 지원량은 오프라인 학습 정답·평가·검수 후 정보이며 온라인 입력에 넣지 않는다.

무표시 구간에도 실제 근거리 FP43장이 있었고, 예측이 없는 장면은 정상 무표시일 수도 전체 누락일 수도 있다. 빈 예측을 일괄 정상/제외로 처리하지 않는다. 다음 Dev/Cal은 표시·무표시·원거리 전용과07시를 층화하고, 최종 확인은 복수의 유효 표시 구간과 음성 구간을 **모델 선택 전에** 등록한다. 이미 개봉한618장은 이번 실패 증거로 보존하며 새로운 방법의 선택·튜닝에는 쓰지 않는다.

학습·개발·보정·미사용 평가 도로는 모델과 정책을 선택하기 전에 정한다. 물리 세션, 인접 위치·프레임, 디코딩 RGB 중복과 인지모델의 과거 노출을 확인한다. 이미 본 273장 도로는 진단 자료다. 미사용 평가 GT는 예측·선택 목록을 고정한 뒤 연결한다.

ROI·분위수·연결성분을 바꿀 수 있도록 원본 RGB, 픽셀 예측을 재생성할 체크포인트·코드·전처리를 보관한다. 원해상도 연결성분이나 logit energy가 필요하면 같은 RGB를 재추론한다. 축소 요약 맵에서 사라진 경계나 raw logit은 원래 의미로 복원할 수 없다. [원본 복원 범위와 누락 1,802장 기록](../수집데이터_재가공과_논문활용_20261123.md)

## 인계와 확인

ID·해시가 같은 작은 샘플에서 RGB 단독 특징과 paired 특징을 대조하고 Semantic에서 실제 차선 수를 다시 센다. 다른 저장 루트에서도 같은 목록이 열리는지 확인한다. 재호·원태에게 목록·특징명·유효성·분할·모델 식별자와 재현 명령을 넘긴다. 보관 자료 3,233장 검증과 273장 재생은 [기존 결과](../../experiments/오프라인_검수와_동일예산_재학습_20261123.md)에 있다.
