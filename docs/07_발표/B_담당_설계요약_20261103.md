## 중간발표에서의 연결

현재 확보한 것은 **정지선을 학습한 M v6**와 GT 평가 기록이다.
train 26,001/val 1,404의 3뷰 학습을 18 epoch 완료했고 best_mean은 epoch 11이다.
도로 2클래스·노면표시 4클래스 출력이며, 과거 validation의 전방 정지선 누적 IoU는 0.873175다.
[검증 근거](../05_구현계획/M_v6_정지선_재확인_20261103.md)를 우선한다.
새 품질 모델은 전방만 사용하며 설계 단계다. 이전 lane 0.165/0.940 그림은 v5 사례다.

## 해결할 질문

**고정된 TwinLiteNet+의 전방 출력에서 계산한 특징으로, 기존 confidence보다 실제 분할 품질을
잘 예측할 수 있는가?** 예상 품질로 검수 우선순위를 만들 수 있도록 한다.

## 입력과 출력

- 입력 X: v6의 도로 2채널·노면표시 4채널 확률에서 계산한 통계·형태·ROI 특징.
- 정답 Y: GT와 비교한 클래스/ROI별 실제 IoU. 정지선 품질은 별도 유지한다.
- 차원·열 순서·target 목록은 A/B 취합 후 동결한다. 기존 14/30/78차원은 v5 초안이다.
- 출력: 예상 IoU와 검수 순위 점수. union=0 정답은 undefined로 구분한다.
- GT·실제 IoU·날씨/시각/장소는 X에 넣지 않는다. 추론 시 GT는 필요 없다.

**발표는 1분 40초:** 선형 회귀의 가중합·최소제곱을 주로 설명하고,
로지스틱 분류는 저품질 여부를 직접 학습하는 비교안으로 약 15초 소개한다.
[슬라이드·수식·대본](./B_담당_슬라이드와대본_20261103.md)을 따른다.

## 비교할 방법

**회귀를 주 과제로 제안한다.** 품질 정도와 ROI별 차이를 보존하고 같은 출력으로 검수 순위를 만들 수 있다.
직접 실패 분류는 회귀가 낮은 품질 선별에 약한 경우의 선택 비교다.

| 방법 | 역할 |
|---|---|
| train IoU 평균 | 학습의 최소 기준선 |
| 단일 confidence/entropy | 기존 자기 확신. MAE 비교에는 1변수 회귀 매핑 |
| 선형 회귀 OLS | Lecture3의 연속 target·최소제곱을 직접 적용한 기준선 |
| StandardScaler + Ridge | 정규화한 선형 관계, 상관된 특징의 계수 제어 |
| Random Forest 회귀 | 출력 통계·형태·ROI 사이의 비선형 결합 관계 비교 |

기말에는 같은 Ridge에서 전역→격자→카메라 ROI 특징을 비교해 정보 추가 효과를 본다.
같은 F_camera_roi에서 Ridge→RF를 비교해 학습기 효과를 본다. 모두 같은 평가 주행을 사용한다.

## 학습과 검증

`meta_train 적합 → meta_dev에서 모델·경고 기준 확정 → 잠근 final_test 평가`.
부모 수집 세션 단위로 분리하고 scaler는 각 학습 데이터에서만 fit한다.
유효 그룹이 충분하면 meta_train 내부 GroupKFold로 작은 튜닝을 한다.
Ridge alpha={0.1,1,10,100}, RF trees=300에서 깊이·leaf 크기 등을 제한 탐색한다.
test 결과로 ROI·feature·threshold를 고치지 않는다.

## 완료를 판단할 결과

- 기준선 대비 MAE·순위 상관, 같은 검수 예산의 실패 발견율을 C와 평가한다.
- 예측값·설정·schema·전처리를 저장한 bundle과 GT 없는 predict 경로를 전달한다.
- 같은 환경 안의 성공/실패와 높은 confidence 오류를 따로 확인한다.
- 개선이 없거나 특정 조건에서 과신하면 그 한계까지 보고한다.
