## 핵심 이야기

**직접 수집한 데이터로 학습한 인지 모델과 GT 평가 기반이 있다. 이제 그 모델을 고정하고,
출력 특징으로 실제 분할 품질을 학습해 GT 없는 품질 추정과 검수 우선순위를 구현·검증한다.**

- 팀 합의: 프로젝트 목표, TwinLiteNet+, 전방 카메라만 사용.
- 데이터: MORAI Capture RGB·Semantic GT. 새 수집에서 시간대·날씨·장소·차량 자세 등을 통제·기록한다.
- A: 확률·형태·ROI 특징 X와 GT 기반 실제 IoU Y.
- B: 별도 품질 모델 학습, GT 없는 예상 품질 출력.
- C: 검수 순위·조건별 평가, 같은 예산의 데이터 선별 비교. 추가학습은 시간 허용 시 확장.
- 입력 X에는 TwinLite 출력에서 계산한 정보만 사용한다. GT·실제 IoU·날씨/시각/장소는 입력하지 않는다.
- GT는 정답 생성·평가에만 사용한다. 조건 정보는 분할 설계·사후 분석에 활용한다.

## 실제로 확보한 중간 결과

M v6는 도로 2클래스와 노면표시 4클래스(배경/흰 차선/노란 차선/정지선)를 출력한다.
train 26,001 / val 1,404의 3뷰 이미지로 18 epoch 학습 완료, best_mean은 epoch 11이다.
새 품질 모델은 전방만 사용한다. 과거 인지 모델도 전방만으로 학습했다고 바꾸어 말하지 않는다.

| 전방 클래스 | 과거 validation 누적 IoU |
|---|---:|
| 도로 | 97.75% |
| 흰 차선 | 77.69% |
| 노란 차선 | 86.19% |
| 정지선 | 87.32% |

이는 선택 checkpoint의 과거 validation 누적 교집합/합집합 점수이며 새 독립 test·프레임 IoU 평균이 아니다.
출처는 [근거 JSON](../05_구현계획/contracts/medium_v6_baseline_evidence.json)이다.
정지선을 출력하려고 새 M 학습이나 L 전환을 해야 한다는 이전 설명은 정정됐다.

기존 lane IoU 0.165/0.940 그림과 89/468 통계는 **v5**다. v6 수치와 같은 모델 결과로 묶지 않는다.
실제 그림은 Git 밖에 있으므로, 발표 제작 시 해당 모델·조건·실제 IoU가 확인된 이미지를 별도로 제공해야 한다.
그림이 없는 단계에서는 자리 표시자를 사용하고 임의의 추론 결과·학습 곡선을 생성하지 않는다.

## B 파트: 1분 40초, 회귀 중심

전체 발표의 4:40–6:20에 배치한다. 입력/정답 연결 15초, 회귀 45초, 검증 20초,
분류 대안 15초, C 인계 5초다. 발표용 수식은 연결된 B 대본 문서에 LaTeX로 있다.

- 주 방식: 실제 IoU를 정답으로 쓰는 선형 회귀, 가중합과 최소제곱 오차.
- 짧은 대안: 실제 IoU가 기준 미만인지 정답을 만들어 로지스틱 회귀로 분류.
- Ridge/RF·튜닝은 기말 비교 계획 또는 부록. 분류 손실 유도까지 본문에 추가하지 않는다.
- Lecture3 PDF p.5: 선형 회귀·최소제곱. p.22–24: 로지스틱 sigmoid.
- main_notes PDF p.9–10: 선형 가설·최소제곱. 쪽수는 PDF 뷰어의 물리 페이지다.

정지선 GT/예측 모두 없으면 union=0이므로 IoU undefined로 관리한다. 완전 누락은 IoU=0이다.
OLS 출력은 범위를 벗어날 수 있어 raw 값과 clip한 표시값을 구분한다.
`1-예상 IoU`는 검수 점수이며 실패 확률이 아니다.

## 기말에 보여줄 구체적 결과

1. 고정 M v6의 출력만 받아 클래스/ROI별 예상 IoU를 출력하는 품질 모델.
2. 기준선 대비 IoU 추정 MAE, 동일 검수 예산의 실패 발견율 비교.
3. 낮은 예상 품질 순으로 정렬한 검수 목록과 GT 기반 실제 실패 확인.
4. 조건별 추정 한계·과대평가 사례 분석. 시간이 허용되면 동일 예산 추가학습의 개선 비교.

새 품질 모델은 아직 학습·검증하지 않았다. 수치 개선을 예측값이나 완료된 결과로 만들어 제시하지 않는다.
기존 binary 정책·14/30/78개 특징 계약은 v5 초안이다. v6 클래스·특징·target 수는 A/B 취합 후 동결한다.
온라인 수집·실차 모니터·fail-safe는 향후 활용 가능성으로 짧게 언급한다.
