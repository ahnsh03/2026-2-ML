## 슬라이드 1 — 출력 특징으로 실제 분할 품질을 학습

**화면의 핵심:** “분할 모델을 고정하고, 출력 특징 → 실제 IoU의 관계를 선형 회귀로 학습한다.”

```text
학습 때: 전방 영상 → M v6 → 확률·형태·ROI 특징 x ─┐
                       예측 + GT → 실제 IoU y ─┴─ 회귀 학습

사용 때: 전방 영상 → 같은 M v6 → 특징 x → 예상 IoU
                                        GT 불필요
```

도로·흰 차선·노란 차선·정지선에서 특징/정답을 만들 수 있다.
설명은 정지선 IoU 하나를 예로 들고, 클래스/ROI별 별도 target으로 확장한다고 덧붙인다.
정지선 GT/예측 모두 없는 union=0 행은 정지선 IoU 회귀에서 제외·별도 집계한다.

**본문 수식 — Lecture3 PDF p.5, main_notes PDF p.9–10**

$$
y_i=\operatorname{IoU}(\hat M_i,M_i^{GT}),\qquad
h_\theta(x_i)=\theta^\top x_i
$$

$$
\theta^*=\arg\min_\theta J(\theta),\qquad
J(\theta)=\frac12\sum_{i=1}^{n}(h_\theta(x_i)-y_i)^2
$$

`x_0=1`로 절편을 포함한다. x는 출력 특징 벡터, y는 GT로 측정한 실제 IoU다.
“여러 특징의 가중합이 실제 IoU에 가까워지도록 오차 제곱합을 줄인다”로 설명한다.
정규방정식·경사하강법 유도와 RF 파라미터는 본문에서 설명하지 않는다.

**발표 대본 약 60초**

> 앞에서 정의한 출력 특징을 입력 x로, GT와 비교한 실제 IoU를 정답 y로 사용합니다.
> 예를 들어 정지선의 확률과 형태 통계를 보고 정지선의 실제 IoU를 추정하는 문제입니다.
> 먼저 수업에서 배운 선형 회귀를 사용하겠습니다.
> 식처럼 여러 특징에 가중치를 곱해 예상 IoU를 만들고, 실제 IoU와의 오차 제곱합을 최소화하도록 학습합니다.
> TwinLiteNet+는 고정하고 이 별도 품질 모델을 학습합니다.
> 학습할 때는 GT로 정답을 만들지만, 새 영상에서는 M의 출력만 있으면 예상 품질을 얻습니다.
> 같은 방식으로 도로와 차선, 정지선의 품질을 따로 추정하도록 확장할 계획입니다.

## 슬라이드 2 — 검증과 짧은 분류 대안

**본문:**

- confidence만 사용한 방법과 비교한다.
- 주행 세션 단위 train/dev/test 분리. MAE와 동일 검수량의 실패 발견율로 평가한다.
- C에 예상 IoU와 검수 순위 점수를 넘긴다.

**보조 상자: 실패 여부만 직접 예측하는 대안 — Lecture3 PDF p.22–24**

$$
z_i=\mathbb{1}[y_i<\tau],\qquad
s(x)=\sigma(w^\top x)=\frac{1}{1+e^{-w^\top x}}
$$

| 주 방식: 회귀 | 비교 방식: 로지스틱 분류 |
|---|---|
| 실제 IoU y를 연속값으로 추정 | 실제 IoU가 기준 미만인지 z로 학습 |
| 출력: 예상 IoU | 출력: 저품질 분류 점수 |
| 추정 오차와 검수 순위 평가 | 실패 발견율·오경보 평가 |

분류의 학습 손실까지 화면에 추가하지 않는다. 필요하면 부록에 cross-entropy를 둔다.
회귀 결과를 threshold로 나누는 것과 별도 로지스틱 분류기를 학습하는 것은 다르다.

**발표 대본 약 40초**

> 주행 세션을 분리해 검증하고, 기존 confidence보다 IoU 추정 오차가 작은지 확인하겠습니다.
> 또 같은 수의 장면을 검수했을 때 실제 실패를 얼마나 찾는지 평가합니다.
> 대안은 실제 IoU가 기준보다 낮은지를 정답으로 만들고, 로지스틱 회귀로 저품질 여부를 직접 분류하는 것입니다.
> 이번 발표는 품질 정도를 보여주는 회귀를 중심으로 설명하고, 분류는 같은 입력의 비교 실험으로 두겠습니다.
> 이렇게 얻은 예상 IoU와 검수 점수를 다음 데이터 선별 단계에 전달합니다.

## 부록·질문 대응

- OLS는 범위 밖 값을 낼 수 있다. raw 추정값을 보존하고 표시·검수용 clip 값을 구분한다.
- `1-예상 IoU`는 검수 점수다. 별도 분류기의 실패 점수나 보정된 확률과 같지 않다.
- 최종 비교 후보는 Ridge·RF 회귀다. 중간발표 본문은 선형 회귀로 설명하고 확장은 한 문장으로 둔다.
- MetaSeg의 별도 품질 모델·회귀/분류 구성을 참고한다. 우리 frame/ROI target과 원 논문 segment target은 다르다.
- 품질 추정은 새 조건의 실패를 모두 보장하지 않는다. 온라인/fail-safe는 후속 검증 대상이다.
- 수식 쪽수는 PDF 뷰어의 물리 페이지 번호다. 실제 발표 속도는 취합 후 리허설로 확인한다.
