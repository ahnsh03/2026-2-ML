### 0. 표지

안녕하세요. 저희 팀은 '차선 인식 모델의 실패 예측'을 주제로 발표하겠습니다.

### 1. 목차

(말 없이 넘김)

### 2. 문제 상황과 목표

저희 팀은 기계학습을 자율주행에 접목하면서, 차선 인식 모델의 실패를 효율적으로 찾는 방법에 초점을 두었습니다.

저희가 학술동아리 연구에서 학습시킨 차선 인식 모델은 대체로 잘 작동하지만, 간혹 차선을 놓치거나 정지선, 노면 표시처럼 차선이 아닌 부분을 차선으로 인식합니다. 이런 실패 장면을 찾아 데이터를 보강하고 다시 학습하는 것이 모델 개선의 기본입니다.

시뮬레이터에서는 정답 차선이 함께 나오기 때문에 이런 장면을 바로 찾을 수 있습니다. 하지만 실제 주행 영상에는 정답이 없기 때문에 모델이 어디서 틀렸는지 자동으로 구분하기 어렵고, 결국 사람이 많은 영상을 직접 확인해야 합니다. 그런데 그 대부분은 이미 맞은 장면입니다.

따라서 저희는 시뮬레이터의 정답으로 학습하고 검증하되, 실제 사용 시에는 정답 없이 각 장면의 실패 확률을 출력해 확인 우선순위를 정하는 머신러닝 모델을 개발하고자 합니다.

> **메모** — 재호 대본 그대로에 세 가지를 더했다. ① 모델의 출처("학술동아리 연구에서 학습시킨") — 뒤의 "이미 준비되어 있다"가 자연스럽게 이어진다 ([확인할 것](#확인할-것) 1번).
> ② 실패 예시(정지선·노면 표시)와 "실패를 찾아야 데이터를 보강해 다시 학습할 수 있다" — 왜 실패를 찾아야 하는지가 비어 있었다 (승현 v1 피드백).
> ③ "그 대부분은 이미 맞은 장면" — 확인 우선순위가 왜 필요한지, 5번의 "상위 10%" 지표와 이어진다.

### 3. 데이터 구축과 실패 정의

데이터는 MORAI 시뮬레이터의 K-City 맵에서 직접 구축합니다. 날씨와 시간대가 차선 인식에 미치는 영향을 분리해서 확인하기 위해, 같은 경로에서 두 요소만 바꾸어 반복 주행합니다.

맑음과 안개 두 가지 날씨와 네 가지 시간대를 조합한 8개 조건의 데이터는 학습과 교차검증에 사용합니다. 여기에 학습에 없던 흐린 날씨 2회로 처음 보는 날씨에서의 성능을, 기존 조건을 반복한 2회로 최종 성능을 평가하며, 이 4회는 끝까지 따로 보관합니다.

정답 차선은 MORAI가 일반 카메라 영상과 함께 저장하는 시맨틱 이미지에서 얻습니다. 차선 모델의 예측과 정답이 얼마나 겹치는지를 IoU로 계산하고, 전면 카메라의 차선 IoU가 0.7보다 낮으면 실패 장면으로 정의합니다.

또한 같은 주행의 연속 장면은 서로 매우 비슷하기 때문에, 학습과 평가 데이터가 섞이지 않도록 주행 단위로 분리하겠습니다.

> **메모** — 첫 두 문장을 한 문장으로 합쳤다. 흐린 날씨 2회와 반복 주행 2회가 각각 무엇을 평가하는지 나눠 말하고, "따로 보관"을 넣어 5번 일정의 "따로 보관한 데이터"와 이었다.

### 4. 입력값과 전처리

다음은 입력값과 전처리입니다. 실패 예측 모델은 카메라 영상을 새로 학습하는 것이 아니라, 기존 차선 모델과 영상에서 얻은 정보를 장면별 숫자로 정리해 입력으로 사용합니다.

입력값은 세 종류입니다. 첫 번째는 차선 확률과 엔트로피처럼 모델이 얼마나 확신하는지를 나타내는 정보입니다. 두 번째는 영상을 좌우로 반전해 다시 추론했을 때 결과가 얼마나 일관적인지입니다. 모델이 제대로 본 장면이라면 뒤집어도 결과가 같아야 하기 때문입니다. 세 번째는 밝기, 안개, 과노출과 저노출, 윤곽선 밀도와 같은 영상 상태입니다.

날씨와 시간대 설정값은 실제 차량에서 항상 알 수 있는 정보가 아니므로 입력에 넣지 않고, 조건별 성능 분석에만 사용합니다.

전처리 과정에서는 정차 중 반복해서 저장된 장면과 정답 차선이 너무 적어 IoU가 불안정한 장면을 제외합니다. 또 IoU와 오류맵은 정답이 있어야 계산할 수 있어 실제 주행에서는 얻을 수 없으므로, 실패 라벨과 실패 유형 분석에만 쓰고 입력에는 넣지 않습니다.

> **메모** — 좌우 반전 일관성이 왜 신호가 되는지 한 문장을 더했다.
> 마지막 문장은 승현 의견대로 고쳤다. 원문의 "결과 분석"은 학습·평가 데이터 분리 이야기로 읽힐 수 있었다. 뜻은 "정답으로 계산한 값은 실제로는 없으므로 입력에 넣지 않는다"이므로 그 이유를 직접 말하고, "결과 분석"은 "실패 유형 분석"(5번의 PCA·GMM)으로 구체화했다. 데이터 분리는 3번 마지막 문장이 맡는다.

### 5. 머신러닝 기법과 평가 방법

다음은 머신러닝 기법과 평가 방법입니다. 가장 단순한 기준은 차선 모델의 확신도 하나만 보고 실패를 판단하는 임계값 방식입니다. 이후 로지스틱 회귀를 적용해 각 입력값이 실패 확률에 미치는 영향을 확인합니다.

주력 모델은 HistGradientBoosting입니다. 작은 결정트리를 순서대로 학습하면서 이전 트리가 틀린 부분을 보완하기 때문에, 여러 입력값이 함께 작용하는 상황을 표현할 수 있습니다. 하이퍼파라미터는 랜덤 서치로 고릅니다.

장소와 날씨, 시간대의 영향은 선형회귀로 분해하고, 가우시안 프로세스를 이용해 경로 위치에 따른 위험도와 불확실성을 표현하겠습니다.

확신도만으로는 모델이 확신하면서 틀리는 경우를 놓칠 수 있습니다. 그래서 확신도에 좌우 반전 일관성, 영상 상태, 경로별 위험도를 차례로 추가하면서 어떤 정보가 실제로 성능을 높이는지 비교하겠습니다. 실패 유형은 오류맵을 작은 격자로 줄인 뒤 PCA로 압축하고, GMM으로 비슷한 오류 형태를 묶어 어떤 유형이 확신도만으로는 잡히지 않는지 분석합니다.

평가는 실패 데이터가 적다는 점을 고려해 PR-AUC를 주 지표로 사용합니다. 또한 모델이 선정한 상위 10%의 장면만 확인했을 때 전체 실패 중 얼마나 많이 찾는지도 평가합니다. 무작위로 고르면 10%입니다.

일정은 차선 인식 모델과 데이터가 이미 있어 그 다음 단계부터 시작합니다. 6주차부터 8주차까지는 시험 기간이라, 기존 데이터로 입력값 추출을 시험하고 주행 조건을 정하는 가벼운 준비를 합니다. 9주차에 데이터를 수집하고, 10주차 중간 발표까지 기준 모델을 구현합니다. 11주차부터 13주차까지는 부스팅, 가우시안 프로세스, GMM을 배우는 주차에 맞춰 각 분석을 진행하고, 14주차에 따로 보관한 데이터로 최종 평가하겠습니다.

> **메모** — "경로별 위험도"가 설명보다 먼저 나왔으므로, 선형회귀·가우시안 프로세스 문장을 앞으로 옮겼다.
> 입력값을 차례로 더하는 이유("확신하면서 틀리는 경우")와 실패 유형 분석의 목적("어떤 유형이 확신도만으로는 잡히지 않는지")을 넣었다. 그래야 PCA·GMM이 따로 떨어진 분석으로 들리지 않는다.
> 랜덤 서치는 교수님이 직접 권한 항목이다 ([요구사항 §4](../01_강의정보/교수님_프로젝트_요구사항.md#-4-하이퍼파라미터-튜닝--lecture-13-gradient-free-optimization)). "무작위로 고르면 10%"는 상위 10% 지표의 비교 기준이다.
> 일정: 모델·데이터·도구가 이미 있다는 점을 먼저 말하고, 6~8주차를 가벼운 준비로 채웠다 (승현). 11~13주차는 강의 주차(11주 앙상블, 12주 가우시안 프로세스, 13주 GMM)와 같다.

### 6. 실현 가능성·예상 결과·기대효과

앞서 말씀드린 것처럼 차선 인식 모델과, 이 모델을 학습할 때 구성한 데이터와 시각화 도구, 그리고 이번 프로젝트에서 달릴 전역 경로까지 준비되어 있어, 남은 핵심 작업은 입력값 추출과 머신러닝 분석입니다.

예상 결과로는 확신도만 사용하는 기준 모델보다 영상 상태와 예측 일관성을 함께 사용한 모델이 실패 장면을 더 잘 선별할 것으로 예상합니다.

이를 통해 모든 영상을 보는 대신 실패 가능성이 높은 장면부터 확인해, 차선 인식 모델 개선에 필요한 데이터를 더 효율적으로 고를 수 있을 것으로 기대합니다.

이번 프로젝트의 범위는 동일한 K-City 경로의 시뮬레이터 데이터에서 개발하고 검증하는 것까지입니다. 더 나아가서는 차선 인식뿐 아니라 다른 인공지능 모델에도, 시뮬레이터뿐 아니라 실제 차량 데이터에도 적용해, 데이터 분류와 라벨링에 드는 수작업을 줄이는 머신러닝 프레임워크를 만드는 것이 목표입니다.

> **메모** — 슬라이드 제목과 겹치는 첫 문장, 5번 평가와 겹치는 "실제 향상 여부는 PR-AUC와 상위 10% 실패 발견률로 검증" 문장은 시간 때문에 뺐다.
> 준비된 것은 승현 의견대로 "차선 인식 모델, 이 모델을 학습할 때 구성한 데이터와 시각화 도구, 전역 경로"로 적었다. 체크포인트는 모델에 포함되므로 뺐다.

장소와 날씨, 시간대의 영향은 선형회귀로 분해하고, 가우시안 프로세스를 이용해 경로 위치에 따른 위험도와 불확실성을 표현하겠습니다.

실패 유형은 오류맵을 작은 격자로 줄인 뒤 PCA로 압축하고, GMM으로 비슷한 오류 형태를 군집화해 분석합니다.

평가는 실패 데이터가 적다는 점을 고려해 PR-AUC를 주 지표로 사용합니다. 또한 모델이 선정한 상위 10%의 장면만 확인했을 때 전체 실패 중 얼마나 많이 찾는지도 평가하겠습니다.

일정은 7주차까지 데이터 수집과 입력값 추출을 완료하고, 10주차 중간 발표까지 기준 모델을 구현합니다. 이후 11주차부터 13주차까지 각 분석을 진행하고, 14주차에 따로 보관한 데이터로 최종 평가하겠습니다.

슬라이드 6. 실현 가능성·예상 결과·기대효과

마지막으로 프로젝트의 실현 가능성과 예상 결과, 기대효과를 말씀드리겠습니다.

현재 차선 인식 모델과 데이터, 체크포인트, 결과 시각화 도구가 준비되어 있어, 남은 핵심 작업은 입력값 추출과 머신러닝 분석입니다.

예상 결과로는 확신도만 사용하는 기준 모델보다 영상 상태와 예측 일관성을 함께 사용한 모델이 실패 장면을 더 잘 선별할 것으로 기대합니다. 실제 향상 여부는 PR-AUC와 상위 10% 실패 발견률로 검증하겠습니다.

이를 통해 사람이 모든 영상을 확인하는 대신 실패 가능성이 높은 장면부터 확인하고, 차선 인식 모델을 개선하는 데 필요한 데이터를 더 효율적으로 선택할 수 있을 것으로 기대합니다.
