# 동일 예산 재학습과 갱신 판정

승현이 주도하고 재호는 데이터·사례, 원태는 정책·품질모델 갱신을 함께 확인한다. 11월 30일에는 신규 조건 성능, 기존 조건 유지, 새 인지모델의 품질 추정 결과로 채택 또는 보류를 기록한다. [일정과 역할](일정과_역할.md)

## 11월26일 현재 범위

[9영역28열·GP실험](../experiments/ROI9_GP와_26R1_검증_20261126.md)에서는 f0 가중치를 유지했고 인지모델을 새로 재학습하지 않았다. 합성 입력의 CUDA 역전파는 GPU호환성 확인이다. 새 검수큐·GT연결은 구현됐지만 학습허용은 false로 남는다. 아래기존 admission/retrain CLI에 새큐JSON을 형식변환 없이 넣지 않는다.

다음단계는 충분한 선별자료와 기존replay, 데이터 노출·모델버전·가시성 검수를 거친 명시적 학습manifest를 만드는 것이다. 몇백장·짧은학습 결과만으로26천여장 수집 기반 f0의 개선 불가능을 단정하지 않는다. 동일 예산/업데이트 수와 충분한자료 대조를 함께 설계한다. 28열 f0/g0와 새 f1/g1의품질 재적합·보정을 짝지어 검증한다. 원거리 확률만으로 자동 입학시키지 않는다.

## 입력과 비교 조건

입력은 GT를 보기 전에 고정한 선택 목록, 학습 허용 후보의 RGB·Semantic·해시·역할, 기존 replay 풀, 같은 초기 v6다. 평가는 새 도로와 기존 조건에 같은 RGB·GT를 사용한다.

| 통제 항목 | 비교 규칙 |
|---|---|
| 신규 자료 | 정책 선별과 무작위에 같은 신규 라벨 장수를 사용한다. 평가 프레임과 인접 묶음은 학습 후보에서 격리한다. |
| 학습 예산 | 같은 초기 f0, optimizer·업데이트 수·replay 수·증강·학습 시드를 사용한다. 선별 시드는 별도로 기록한다. |
| 품질모델 | 각 f1의 출력과 실제 IoU를 다시 만들어 해당 모델용 g1을 학습·보정한다. |
| 평가 | 같은 미사용 도로·기존 조건에서 인지 IoU와 짝지은 품질 MAE를 비교한다. 각 정책의 검수 성과도 별도 표로 남긴다. |

## 기존 CLI로 선별·정답·학습 연결

기존 10영역 점수 팩의 후보는 `offline_review`로 선택하고 `offline_review_admit`로 ID·해시·학습 역할을 대조해 입학 목록을 만들 수 있다. `W`는 완료 점수와 후보 목록을 둔 실험 경로다.

```bash
PYTHONPATH=src python3 -m quality_estimation.offline_review \
  --scores "$W/scores" --budget .10 --seed 20261123 --output "$W/review.json"
PYTHONPATH=src python3 -m quality_estimation.offline_review_admit \
  --scores "$W/scores" --queue "$W/review.json" \
  --candidates "$W/candidate_annotations.jsonl" --output "$W/admitted.jsonl"
```

목록은 RGB·Semantic·픽셀 해시와 물리 세션·candidate 역할을 포함한다. 실제 정책·예산과 학습 프로토콜의 arm을 맞춘다. 새 직접 회귀 점수의 검수 산출물도 같은 프레임·선택 이력을 유지하도록 연결한다. [기존 후보 연결 원문](../archive/전방_10영역_실험_재현.md#동일-예산-검수와-사후-정답-연결)

```bash
scripts/run_container.sh python3 -m quality_estimation.retrain_perception \
  --new-manifest /outputs/manifests/quality_selected_native.jsonl \
  --replay-manifest /outputs/manifests/known_f0_train_replay.jsonl \
  --data-root /data --protocol /ml/config/perception_adaptation_pilot_v1.json \
  --seed 20261116 --arm FrozenQualityRank --output-dir /outputs/adaptations/quality_seed1
```

무작위는 실제 무작위 선택 목록과 `Random` arm을 사용한다. 혼합 검수는 원래 기록된 arm과 프로토콜을 맞춘다. 출력에는 가중치·학습 ID·초기 모델·코드·프로토콜 해시와 완료 표식이 남는다. 학습 설정·고정 평가 명령과 replay 유지 제약의 원문은 [재학습 실행 기록](../archive/선별자료_인지모델_재학습.md)에 있다.

## BO와 인지모델·품질모델 갱신

재학습 설정 탐색은 학습률·replay 양·기존 출력 유지 가중치로 신규 개발 IoU 이득을 높이고 기존 조건 손실을 제한한다. 원태가 BO 실행을 지원하고 승현이 실제 학습·평가를 연결한다. 선별 정책 효과를 주 비교할 때에는 양쪽의 학습 설정을 먼저 같게 고정한다.

기존 실측 격자의 탐색 효율은 GPU 없이 재생할 수 있다.

```bash
PYTHONPATH=src python3 -m quality_estimation.replay_adaptation_search \
  --surface docs/baselines/adaptation_search_surface_20261123.json --grid primary
```

이 명령은 기록된 개발 결과에서 탐색을 재생한다. 새 프레임 재학습·독립 도로 실측은 별도 실행으로 남긴다. [기존 BO와 학습 결과](../experiments/환경_ROI와_품질추정_20261123.md#기존-경로-성능을-보존하는-재학습-설정-탐색)

완료된 f1에 맞춰 특징·정답 생성, 학습·보정·추론·평가에 같은 `--adaptation-run`을 전달한다. 인지 재학습 데이터와 품질 학습·평가 ID, 픽셀·세션 중복을 확인한다. f0/g0와 f1/g1의 체크포인트·특징·정답·군집·경보 이력을 함께 저장한다. [버전 쌍 명령](../archive/버전쌍_경보_갱신판정.md#버전-쌍을-명시한다)

## 평가와 완료 기준

모델과 정책을 고정한 뒤 사후 GT를 연결한다. 전체 프레임 IoU 평균과 품질 MAE, 조건별 유효·미정의 수, 야간 정상 분모와 오경보, 지역별 누락 사례를 기록한다. 도로·위치 단위로 반복 프레임의 의존성을 표시한다.

[채택 기준](../../config/cycle_acceptance_v1.json)은 신규 차선 IoU 변화 ≥ 0, 기존 차선 IoU 손실 ≤ 0.005, 짝 품질 MAE 증가 ≤ 0.010이다. `cycle_gate`는 같은 프레임·GT·모델 이력과 완료 해시를 대조해 항목별 판정을 기록한다. [판정 실행 명령](../archive/버전쌍_경보_갱신판정.md#갱신은-비교한-뒤-판단한다)

30일 인계물은 초기·후보 모델과 품질모델·선택 정책 버전, 같은 조건의 전후표, 학습 예산·실행 식별자, 채택 또는 보류 근거, 시연 모델이다. 현재 재학습 CLI의 출발점은 고정 f0다. f1→f2 누적 갱신은 부모 계보·노출·새 평가를 연결할 후속 구현이다. 과거 조건부 적용 후보의 효과와 제약은 [11월 23일 비교](../experiments/오프라인_검수와_동일예산_재학습_20261123.md)에 있다.
