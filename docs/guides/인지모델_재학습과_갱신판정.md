# 누적 재학습과 버전 승격

현재 개발 인지는 **m-v6-r2-20261128**이다. [등록부](../../config/perception_releases.json)는 원래v6·r1·r2의 체크포인트와 실행 계보를 분리한다. 원래v6를 덮어쓰지 않으며 대조용 시각화 CLI의 기본값도 원래v6다. 현행 실행은 명시 `--adaptation-run` 또는 `ML_ACTIVE_PERCEPTION_RUN`으로 버전을 검사한다.

| 버전 | 학습 구성 | 새 확인 표시3구간 macro IoU |
|---|---|---:|
| 원래v6 | train26,001 /val1,404 |0.58353 |
| r1 | 원래26,001+기편입3,072=29,073 |0.76453 |
| **r2** | 부모29,073 replay+새2,048=31,121 |**0.78415** |

r2는 Dev에서 선택한 Coverage2048/24k 원시 endpoint다. Dev·실제5070Ti의 원래 성능 유지 검사와 사전 고정한 새 확인을 통과했다. 부모 대비 새 구간 이득0.01962, 세 구간 모두 양수이며 조건 블록 bootstrap95% 범위는[0.01175,0.02820]이다. 같은 지도의 고정 구간에 조건부인 결과이며 새 도시/도로 모집단 신뢰구간이나 반복 학습 검증이 아니다.

Risk2048와 환경 수를 맞춘 Random2048은 같은 부모·전체 replay·18,000update·학습 시드를 사용했다. 새 확인 차이는 Risk−Random0.00521, 조건 bootstrap[0.00243,0.00818]이지만 Dev에서는 반대였고 한 optimizer 시드다. Coverage24k와 이 차이를 순수 선별 효과로 비교하지 않는다. 두2,048장 bank의 교집합907장과 후보4,794장 대비42.72% 편입 비율도 기록했다. 이는10% 검수 성능 예산과 다르다.

학습 배치는 신규2+replay14, BF16 forward/FP32 loss, 고정 BN moments, LR3e−6 cosine, 부모 KL0.5/T2다. 원본/이전 편입 전체를 유지하고 D 원본을 복사하지 않는다. 각 실행의 실제 checkpoint·sampler·시드·손실·구성원은 실험 볼륨의 불변 run과 영수증으로 확인한다.

인지 가중치가 바뀌면 X/y→RF/GP→Cal→정책을 모두 새로 만든다. 이번 r2의 품질·오류·환경 번들은 오프라인 기준과 RGB 재생·standalone 검증을 통과했다. 채택 영수증은 동결 번들의 `adopted=False` 연구 메타데이터를 사후 수정하는 대신 별도로 둔다. **자동 학습 편입이나 ROS 연결은 아직 활성화하지 않았다.**

다음 갱신도 새fit/Dev/Cal과 새 확인 역할, 같은 부모와 공정한 학습 예산, 기존 성능 유지 및 정확한 새 품질 버전을 확인한다. 이번에 개봉한590장을 다음 독립 시험으로 다시 사용하지 않는다.
