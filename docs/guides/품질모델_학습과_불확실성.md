# Q 품질모델과 GP/RF 비교

현재 형식은 **전체 화면 차선 IoU Q 하나**를 GP 또는 RF로 예측한다. 근거리·원거리 정답은 오프라인 진단이며 온라인 ROI IoU를 요구하지 않는다. 최신 진행·성적은 [28일 실험](../experiments/환경검증_전체원본재생_20261128.md), 정확한 열과 인지 버전은 번들 manifest를 따른다. 직전3/4과제 GP·공간 결합 확률과 실패 성적은 [보존 원문](../archive/guides_20261127/품질모델_학습과_불확실성.md) 및 [27일 결과](../experiments/군집_검수_동일예산_재학습_20261127.md)에 남긴다.

## 정답과 자료 역할

패딩을 제외한 white/yellow 차선 합집합으로 Q=TP/(TP+FP+FN)를 만든다. stopline은 주 Q에서 제외한다. union0은 미정의이며0이나1로 채우지 않는다. GT가 적더라도 Q가 정의되면 주 학습에서 배제하지 않는다. 근거리 누락/오검출 진단에는 precision·recall을 함께 쓰며 가시성 정상의 정답으로 해석하지 않는다.

품질 fit2,500행은 기존 fit1,666행+이미 열었던 진단834행이다. 이전 진단을 다시 시험이라고 부르지 않는다. Dev937행 중 이동3도로361행이 주 개발, 이전 정지 자료576행은 과거 조건 유지 진단이다. Cal612행은 별도로 보정하고, 새 확인은 모든 선택을 고정한 뒤 연다. 인지 추가학습과 품질 fit은 ID·픽셀은 다르지만 가까운 위치가 많아 완전한 지리 독립은 아니다.

MAE0.04는 평균 절대 IoU 차이0.04, 즉4퍼센트포인트다. 모든 장면의 오차 상한이나 검수 정확도96%를 뜻하지 않는다. 도로·조명별 오차와 지원 장수를 함께 보고한다.

## 특징과 같은 조건의 비교

| view | 입력 차원 | 목적 |
|---|---:|---|
| base28 |28 | 기존 RGB·출력·상위 엔트로피·근−원 관계 |
| fp34 |34 | 근거리·전체의 출력 불일치와 형태 후보 추가 |
| env52 |52 | 별도 RGB 환경 요약 추가 |
| morph49 |49 | 차선 형태21후보 추가 |

두 모델은 같은 정의된 Q 표본·지리3fold·25m 제외·특징 view를 사용한다. GP는 Matérn3/2 길이1.4/2.8/5.6, 잡음 분산0.02/0.05/0.1을 비교하는 **단일 과제** 모델이다. RF는160트리, 깊이12/제한없음, leaf1/3/6, 특징 비율0.5/1을 비교한다. 각 view/모델에서 BO6회와 공통 초기3점의 무작위6회를 사용하고 합집합 중 CV 최저 설정을 적합한다. 쿼리 예산을 맞추며 CPU시간까지 같지는 않다.

추가 view는 base28보다 CV가 좋거나 같고 이동 Dev MAE가0.002 이상 개선되며 이전 Dev 악화가0.005 이하여야 한다. 이 범위에서 Dev 오차·차원으로 고른다. RF는 GP보다 이동 MAE가0.003 이상 낮고 CV가 좋으며2/3도로 이상 우세하고 이전 Dev 악화가0.005 이하여야 일관된 우세로 채택한다. 새 확인 결과로 모델을 교체하지 않는다.

기존 v6용 선택은 GP28/RF49이며 이동 Dev MAE0.04020/0.04160이다. **같은28열** 대조는 GP0.04020/RF0.04587이다. 새 f1에 대해서는 모든 출력·정답을 다시 계산하여 같은 비교를 반복한다.

## 불확실성의 용도와 한계

GP는 Q 평균과 관측 분산을 반환한다. 잡음 분산을 뺀 잠재 표준편차도 진단으로 보관한다. 이번 검수 탐색에는 **관측 표준편차의 전체 버퍼 순위**를 사용한다. 이전 다과제 결합 확률·근원거리 공분산은 이 단일 Q 형식에 포함되지 않는다. σ만으로 전체 저하와 원거리 저하를 구별한다고 주장하지 않는다.

Cal의 부호 잔차 `(y−μ)/scale` 분포를 고정한다. GP scale은 관측 표준편차이고 RF scale은1이다. 이 경험적 CDF로 Q<0.7 검수 확률과 중앙90% 구간을 만든다. RF scale1은 표준편차1이나 GP 불확실성을 뜻하지 않는다. 구간의 포함률·폭·조건별 편향은 새 확인에서 측정하며 조건부 보장을 가정하지 않는다. 새 확인의 MAE도 부모 f0/g0보다0.010 넘게 악화되면 채택하지 않는다. 이 추가 유지 기준은 첫 Random Dev 이후, g1 적합과 새 확인 개봉 전에 더 엄격하게 등록했다.

새 f1 HPO 대리모델에는 GP 길이/잡음의 정규화2차원, RF 깊이/leaf/특징비율의3차원 좌표를 쓴다. 기존 f0 탐색은 당시1차원 설정 인덱스 좌표를 재현하기 위해 보존했다.

BO의 GP는 설정 θ→CV/검수 손실을 예측하는 실험 대리모델이다. 이미지 특징 X→IoU의 품질 GP와 목적이 다르다. HPO/검수 탐색에서 쓰며 배포 후 매 프레임마다 BO를 돌리지 않는다.

## 구현과 인계

[quality_screen.py](../../scripts/experiments/environment_cycle_20261127/quality_screen.py)는 정확한 인지 신원·ROI·열 순서와 정답/입력 영수증을 검증한다. [SpatialQualityGP](../../src/quality_estimation/spatial_gp.py)는 이 단위에서 Q 단일 목표로 사용하며, RF는 [PortableForest](../../src/quality_estimation/portable_forest.py)로 내보낸다. pickle 없이40/50 프로필에서 읽는다.

새 인지 가중치와 예전 품질/보정/정책을 섞으면 [번들 로더](../../src/quality_estimation/environment_review.py)가 거부한다. 오래된 g0를 f1 출력에 수치상 적용한 진단은 버전 재적합 필요성을 보여주는 대조일 뿐 배포하지 않는다. 실제 RGB 재생·GT 연결·40CPU/50GPU 비교는 최종 영수증으로 확인한다. 실제40계열 GPU와 live ROS는 별도다.

원태는 동결된 두 모델·확률/구간·공통/환경별 검수를 독립 재현하고, 승현·재호는 큰 오차·근거리 FP와 야간 정상 라벨 지원을 검수한다. [환경·검수](환경군집과_검수정책.md)와 [재학습 판정](인지모델_재학습과_갱신판정.md)을 함께 읽는다.
