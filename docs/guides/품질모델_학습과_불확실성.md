# 품질모델 학습과 GP 불확실성

원태가 GP·튜닝·불확실성 평가를 맡고 승현이 RF 기준선을 연결한다. 27일에는 첫 결합용 점수표를, 30일에는 최종 입력으로 재학습·보정한 모델과 비교표를 전달한다. [일정과 역할](일정과_역할.md)

11월 24일의 현재 인계 입력은 **RF·GP 공통 24열**이다. [9영역 특징 선정](../experiments/ROI_9영역_특징선정_20261124.md)과 [고정 열·파라미터·해시](../../config/region_feature_recipe_v1.json)를 사용한다. GP는 Matern 1.5·스칼라 길이 배수 2.8·정규화 타깃 공간의 관측 잡음 분산 0.15로 적합했다. 반환 표준편차는 관측 잡음을 포함한 IoU 단위이며 별도 보정이 남아 있다. 새 480장 전체에서 관측 MAE는 RF 0.0616·GP 0.0673이다. 8위치 재표집 구간과 정상 오경보를 함께 보고 정책을 구체화한다.

## 입력과 기존 구현

입력은 같은 프레임의 버전 있는 특징 X와 전체 차선 IoU y다. 학습·개발·보정·평가 그룹, ROI·인지모델·열 순서를 확인한다. RF·GP는 같은 입력 열과 같은 정답을 사용한다.

| 구현 | 현재 기능과 이번 개발의 연결 |
|---|---|
| [모델 학습 CLI](../../src/quality_estimation/train_models.py) | X56 실행 스키마와 데이터 로더를 사용한다. 기존 OLS·Ridge·RF 및 선택적인 GP를 재현한다. |
| [GP 클래스](../../src/quality_estimation/gaussian_process.py) | 유한한 X와 0~1의 y로 학습하고 평균·표준편차를 반환한다. 정확 GP의 현재 행 상한은 2,500이다. |
| [10영역 모델](../../src/quality_estimation/roi10_quality.py) | 영역별 정밀도·누락 면적을 RF로 추정해 합산한다. 과거 성적표의 영역별 모델이다. |
| [공간 특징 직접 회귀](../../scripts/compare_roi_features.py) | 7·10영역 세 특징 구성과 RF·GP를 같은 학습 그룹 CV·개발 자료로 비교한다. 이 경로는 앞선 ROI 비교를 재현한다. 현재 기본 ROI는 9영역이며 선정한 열과 새 실행 방법은 [ROI와 특징 추출](ROI와_특징추출.md)을 따른다. [ROI 선택 결과](../experiments/ROI_7영역_10영역_비교_20261124.md) |

앞선 ROI 비교의 96열은 `(7영역+전체 화면)×12`의 새 스키마다. 과거 `X56+output10`의 96열과는 이름·순서·프로파일이 다르다. 열 수가 같아도 모델 번들에서 이 식별자가 모두 일치해야 재사용한다.

기존 X56의 스키마 검사는 [dataset_io](../../src/quality_estimation/dataset_io.py)에 있다. 새 특징을 56열로 가장해 기존 로더에 전달하면 스키마가 달라진다. 새 공간 특징의 연구용 학습·저장 경로가 추가됐다. 배포용 특징 스키마·모델 번들과 기존 스트림 추론 연결은 승현과 함께 구현하고 버전의 일치를 검증한다.

## 바로 재현할 실행 경로

X56 데이터·분할·프로토콜이 준비된 CPU 환경에서는 다음 명령을 사용한다. 이 명령의 기본 프로토콜은 최초 기준선 재현용이다. 새 공간 특징을 이 X56 명령에 그대로 넣지 않는다.

```bash
PYTHONPATH=src python3 -m quality_estimation.train_models \
  --dataset-dir "$QUALITY_DATASET" --split "$QUALITY_SPLIT" \
  --protocol "$QUALITY_PROTOCOL" --feature-set full \
  --output-dir "$QUALITY_MODEL_RUN"
```

GP를 이 CLI에 넣는 기존 프로토콜 설정과 모델 선택·출력 파일은 [재현 원문](../archive/회귀학습_선별평가.md#gp의-iou-예측과-불확실성-검수)에 있다. 저장 모델은 같은 스키마·의존성·인지모델 이력으로 재로딩해 예측을 대조한다.

새 공간 특징 비교는 해시 영수증이 있는 연구 팩을 준비한 뒤 아래와 같이 재현한다. 팩은 같은 프레임 ID의 `x7_base12`, `x7_base12_global`, `x7_robust17`과 10영역 대응 열, `y`, `group`, `pixel_sha256` 등을 담는다. 스키마 JSON의 열 순서를 함께 전달한다. 원본 팩·모델은 실험 볼륨에서 인계한다.

```bash
PYTHONPATH=src python3 scripts/compare_roi_features.py \
  --packs "$QUALITY_SPATIAL_PACKS" \
  --protocol docs/baselines/roi_selection_20261124/reproduction_protocol.json \
  --output-dir "$QUALITY_SPATIAL_RUN" --jobs 4
```

출력은 후보별 학습 그룹 교차검증, 개발 MAE, joblib 모델과 `frozen_models.json`이다. 출력 디렉토리는 새 경로를 쓴다. 위 프로토콜은 ROI 비교 당시의 세 구성·12개 설정 예산을 보존한다. 이후 팀 실험에서는 9영역에서 선정한 같은 열로 RF·GP를 대조하며, 기존 진단 도로를 최종 미사용 평가 자료로 재지정하지 않는다.

## RF·GP 비교와 튜닝

1. 학습 자료에서만 상수 열 제거·표준화를 적합한다. X56 재현과 새 ROI 결과의 데이터·특징 버전을 표에 표시한다.
2. 선택된 같은 열에서 RF와 GP를 학습한다. GP의 행 예산 때문에 부분집합이 필요하면 위치·환경을 고려해 먼저 고정하고, 같은 부분집합의 RF 결과도 함께 낸다. 별도 전체 학습분 RF는 표본 수를 표시한다.
3. 같은 도로 분할·시드·평가 횟수에서 GP 길이척도와 잡음, 이후 RGB/출력/관계별 가중 커널을 튜닝한다. 가중 커널은 확장 구현 과제다. 개발 도로 MAE와 검수 성과로 선택한다.
4. BO의 입력은 튜닝 설정, 목표는 해당 설정의 그룹 교차검증 MAE다. 같은 초기 관측·평가 횟수의 무작위와 비교한다. 개별 프레임 IoU를 예측하는 GP와 BO 내부의 대리모델은 각각 기록한다.

현재 GP는 Matérn 3/2와 WhiteKernel을 사용하고 내부 optimizer는 꺼져 있다. 길이척도는 표준화 후 유효 차원 수에 맞춰 조절하며 잡음 분산은 정규화된 y 공간의 값이다. 같은 도로 평가 결과에서 모델을 다시 고르면 해당 도로를 개발 자료로 표시한다. [기존 커널·BO 결과](../experiments/전방_10영역_특징과_품질추정_20261123.md#5-군집gp베이지안-최적화의-사용처)

## 불확실성 평가

- 점 예측은 원래 IoU 단위 평균과 [0,1] 제한값을 저장하고 MAE·편향·조건별 오차를 낸다. GP 표준편차는 관측 잡음을 포함한다.
- 명목 90% 구간은 원시 평균 ± 1.645σ로 시작한다. 별도 보정 도로에서 조정하고 미사용 도로에서는 실제 포함률과 평균 폭을 함께 측정한다. 분포 경계에서 구간을 잘랐다면 원시 구간과 표시 구간을 명시한다.
- σ가 큰 장면에 실제 오차가 모이는지, 야간에서 좁은 구간으로 틀리는지 본다. 같은 GP 평균 순위에 σ를 더했을 때 새로 찾거나 놓친 장면을 비교한다.
- 예측 저품질 확률을 쓸 때는 분포·보정 방법을 기록하고 실제 저품질 비율과 대조한다. 실패 확률의 해석은 이 검증 결과와 함께 제시한다.

기존 273장 도로에서 한 GP의 90% 구간 포함률은 98.2%였지만 평균 폭은 0.644였고, σ와 절대오차의 순위상관은 −0.251이었다. 이 모델의 σ 단독 검수는 평균순보다 적은 실패를 찾았다. 새로운 입력에서는 같은 검증을 다시 한다. [불확실성 실측](../experiments/오프라인_검수와_동일예산_재학습_20261123.md#gp의-평균-예측과-불확실성-순위)

추가 수집에서는 차선 GT가 매우 적은 장면을 포함해 GP의 전이 오차를 따로 확인한다. 같은 특징의 ROI 대조와 개발 자료에서 각각 선정한 특징 구성의 대조를 구분한다. 전자는 영역 효과, 후자는 전체 설정의 전이 성능을 보여준다. GT 차선 면적은 사후 진단에만 사용하고 RGB 단독 모델 입력에는 넣지 않는다. [GT 픽셀 수와 전이 결과](../experiments/ROI_7영역_10영역_비교_20261124.md)

## 인계와 완료 기준

프레임 ID별 원시 평균·예상 IoU·σ, 모델·특징·분할 해시, 개발 비교표, 예측구간 보정값과 조건별 포함률·폭, 추출과 추론 p50/p95 시간을 넘긴다. 유효·미정의 y 수, 표본 수와 독립 위치 수도 적는다. 재로딩한 같은 표의 예측이 일치하고 [검수 정책](환경군집과_검수정책.md)이 같은 점수표를 읽으면 첫 결합이 가능하다.
