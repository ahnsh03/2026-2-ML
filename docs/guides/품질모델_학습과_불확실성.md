# 품질모델 학습과 GP 불확실성

**27일 결합 기준선은 9영역·28열·다과제 GP**다. RF는 동일 입력·학습분의 대조군으로 유지한다. 원태는 불확실성·군집·정책을, 승현은 데이터·RF·전체 통합을 맡고 재호는 특징·사례를 검토한다. [최신 결과](../experiments/ROI9_GP와_26R1_검증_20261126.md) · [v3 명세](../../config/region_feature_recipe_v3.json) · [일정](일정과_역할.md)

## 주 정답과 보조 진단

주 정답·온라인 점수는 전체 흰색+노란색 차선 IoU Q 하나다. 추가 학습 정답은 고정 영상 띠의 근거리·원거리 차선 recall이다. `R=TP/(TP+FN)`이며 누락만 본다. 보조 정답은 오프라인 GT로 만들고, 실행 중에는 RGB·인지 출력 특징으로 예측한다. **온라인 GT나 ROI IoU 계산은 없다.** 근거리 recall이 높아도 precision이나 전체 인지 성능을 보장하지 않는다.

보조 정답의 GT 분모가 없는 행은 0으로 채우지 않는다. 세 정답이 유한한 2,480장을 RF·GP 공통 학습분으로 썼다. 공간 진단 집계에는 양쪽 띠 각각 GT 차선 ≥50픽셀을 요구했다. [자료 역할과 정의](데이터_등록과_특징정답.md)

## 구현한 GP

[SpatialQualityGP](../../src/quality_estimation/spatial_gp.py)는 정확한 separable GP다. 입력 Matérn 3/2 커널과 학습 정답 상관의 축소 행렬 `B=(1−ρ)I+ρ Corr_train(Y)`를 곱하고 Kronecker 고유분해로 적합한다. 최종 길이 배수 2.8·정규화 관측 잡음 분산 0.05·ρ=0.4다. 행 상한은 2,500이고 표준화·상수 열 제거는 학습 fold에서만 적합한다. 임의의 자유 B를 주변우도로 최적화한 완전한 다과제 GP 재현은 아니다.

반환은 IoU/recall 원래 단위의 평균·3×3 관측 공분산과 별도 잠재함수 분산이다. `D=R_near−R_far`의 분산은 `Σ_nn+Σ_ff−2Σ_nf`로 계산한다. [spatial_risk](../../src/quality_estimation/spatial_risk.py)는 다음을 계산한다.

- `global_low`: `P(Q<0.7)`.
- `near_good_far_weak`: `P(R_near≥0.8, R_far<0.5)`.
- `normal_far_only`: `P(Q≥0.7, R_near≥0.8, R_far<0.5)`.

숫자 기준은 비교용 사건 정의다. 어둡거나 가시거리가 짧은 상황의 낮은 IoU가 운행 실패인지는 별도 검수 기준이다. 보정은 별도 도로의 중앙 잔차·표준화 잔차 분위수로 평균·구간 폭을 조정하는 경험적 방법이며 OOD 포함률 보장이 없다. Gaussian 근사에는 0~1 밖 질량도 있다.

`predicted_iou`는 제한한 원시 평균이고 `calibrated_iou`와 `posterior_mean`은 위험 점수용 보정값이다. `observation_std`와 `latent_std`를 구분한다. 26R1 보정은 `--simulator-release 26.R1`을 명시해야 읽는다. [FrozenSpatialPredictor](../../src/quality_estimation/spatial_predictor.py)는 체크포인트·열 순서·프로파일·모델·보정 해시와 보조 정답 순서를 검사한다.

## 지금 확인한 성적과 해석

재학습된 인지모델은 해당 실행의 계보·`model_state_dict`를 명시하고 f1용 특징/정답과 g1을 다시 만든다. GP NPZ와 보정 파일에도 같은 계보를 묶으며 기존 g0와 섞으면 거부한다. [9영역 버전 쌍 기능 검증](../experiments/9영역_인지버전쌍_연결검증_20261126.md)까지 확인했지만 충분한 g1 학습분과 최종 성능 유지 판정은 남아 있다.

| 평가군 | GP IoU MAE | 같은 학습분 RF |
|---|---:|---:|
| 반복주행 20세션·7,339장 | 0.05622 | 0.05953 |
| 보관 별도 10링크·99장 | 0.11639 | 0.09618 |
| 26R1 기존 학습 위치 재생성 144장 | 0.03031 | 0.02002 |
| 26R1 품질 학습 미사용 4링크·96장 | 0.06445 | 0.07117 |

도로마다 순위가 다르다. 새 4링크 결과만으로 GP의 보편적 우위를 주장하지 않는다. 28열은 첫 결합 기준선이며 최종 채택은 30일 판정이다.

**σ 단독으로 전반 저하와 원거리만 약한 상황을 구별하는 가설은 확인되지 않았다.** AUC 방향이 자료마다 바뀌었다. 근거리 예측 평균·원근 대비가 유형을 더 잘 구별했지만, 26R1 새 링크의 명목90% 구간 포함률은 새 보정 후 Q91.7%·근거리85.4%·원거리39.6%였다. 원거리 과신이 남아 공간 점수는 진단용이다. 공분산이 같은 주변분포의 독립 가정보다 주는 확률 개선도 작았다. [방향·분모를 명시한 결과](../baselines/roi9_gp_20261126/sigma_hypothesis.json)

## 원거리 전용 후속 후보

새로운31열은 원거리 출력10과 원거리 형태3을 사용해 Far GP를 별도로 적합한 진단 후보다. 원래28열과 합친 고유 특징은41개지만 주 품질 GP는28열 그대로다. 합성 분포는 주 GP의 Q/근거리 주변분포와 전용 원거리 주변분포를 독립 블록으로 둔다. 새 분산에 옛 교차 공분산을 그대로 붙이지 않는다.

다른4링크96장의 원거리 recall MAE는 GP31 0.0546·RF31 0.0591이었다. 보정 지원을 늘려 포함률91.7%를 얻었지만 폭이 커지고 결합 확률 Brier는 나빠졌다. 이미 진단한 앞선 도로에서는 평균 오차도 악화됐다. 따라서 기본 모델을 자동 대체하지 않는다. [후속 설계·동결·성적](../experiments/ROI9_원거리보조와_환경전이_20261126.md)

## 학습·튜닝 재현

이번 팩은 RGB180·출력80·관계88·원본확률3·형태21 후보와 별도 정답/역할을 저장한다. 기존 X56 로더로 전달하지 않는다. 동결된 실험 볼륨에서 역할·프로토콜·스키마를 먼저 검증하고 [실험 스크립트](../../scripts/experiments/roi9_gp_20261125/)를 사용한다.

```bash
PYTHONPATH=src:scripts python3 scripts/experiments/roi9_gp_20261125/study.py --help
PYTHONPATH=src:scripts python3 scripts/experiments/roi9_gp_20261125/coverage.py --help
PYTHONPATH=src:scripts python3 scripts/experiments/roi9_gp_20261125/evaluate.py --help
```

품질 학습은 같은 2,480장·28열에서 RF와 GP를 대조한다. 확대 학습 3지리fold·25m embargo의 최소 이격은 26m 이상이었다. 이 단계의 탐색은 GP36/RF12설정으로 횟수가 다르므로, 동일 튜닝 예산의 우위로 해석하지 않는다. 다만 이전 24열에서 시작해 개발 자료로 축소한 결과이므로 완전히 중첩된 특징 선택 검증은 아니다. 이미 열어본 진단/평가 자료를 학습에 승격하면 이후 독립 평가로 부르지 않는다.

BO는 **오프라인 설정 탐색**이다. [bounded_bo](../../src/quality_estimation/bounded_bo.py)의 EI와 같은 초기 관측·총 횟수의 무작위를 비교한다. 이번 가산 커널 630설정·18회 비교에서는 둘 다 초기점이 최선이었고 기본 GP를 개선하지 못했다. BO를 썼다는 이유로 성능 향상을 주장하지 않는다. 이 GP 대리모델과 프레임 품질 GP는 별개다. OLS·Ridge 신규 실험은 하지 않는다.

가중·가산 커널과 형태 특징은 시도 후 보류한 후보이며 결과를 [공개 근거](../baselines/roi9_gp_20261126/README.md)에 보존한다. 이론과 프로젝트 차용 범위는 [논문 목록](../baselines/참고논문_베이스라인.md#8-9영역-gp와-bo의-근거-20261126)을 따른다.

## 원태의 다음 우선순위와 인계

1. 현재 28열·모델·새 보정으로 팀 재생을 맞추고 원거리 누락 정답의 가시성/GT 분모·오검출 누락 한계를 검토한다.
2. 원거리 정상·저하가 있는 별도 위치를 보강한다. 새 보정96장에는 원거리 recall≥0.5가0장이었지만 새 평가에는25장이었다. 이 구간의 자료 지원을 먼저 확보한다. 보조 정답 전용 형태/거리 특징과 타깃별 커널·변환·이분산·보정은 제한된 후보부터 비교한다. 주 Q 악화와 불확실성 과신을 함께 검사한다.
3. `global_probability` 기준선을 먼저 유지하고 공분산·환경군·혼합 예산의 추가 이득을 별도 정책 실험으로 판단한다. 새 링크를 재튜닝에 쓰면 다시 독립 평가 자료를 확보한다.
4. 모델 NPZ·열·학습 구성원·보정·역할·해시·프레임별 원시/보정 점수·구간 폭/포함률·정상 분모와 같은 예산 표를 전달한다. [검수 가이드](환경군집과_검수정책.md)

## 이전 모델 재현

X56, 7·10영역 모델, 24열v1·27열v2는 과거 비교용이다. 기존 `train_models`, `compare_roi_features.py`, v2 추출/재적합 명령과 당시 성적은 [가이드 원문](../archive/가이드_20261124_원문.md#품질모델_학습과_불확실성), [24일 결과](../experiments/ROI_9영역_특징선정_20261124.md)에 보존한다. 현재 모델에 옛 27열·joblib·보정값을 섞지 않는다.

후속31열은 새4링크에서 원거리 recall MAE0.0546·보강한192장 보정의90% 포함률91.7%였지만, 이전 도로의 악화와 결합 확률 Brier 증가가 남았다. 원태는 다음 비교에서 보정 잔차의 과제 간 상관·과제별 커널을 검토하되, 같은 보정 위치의 분리 검증으로 선택하고 이미 열어본 평가를 다시 미사용으로 부르지 않는다. 점 오차·주변 포함률·결합 확률·동일 예산 선택을 각각 판정한다.
