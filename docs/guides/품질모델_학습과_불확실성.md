# RF·GP와 불확실성의 현재 사용

현재 동결 번들은 **GP52로 전체 IoU Q**, **RF74로 지원 오류3개**를 추정한다. 전체 이미지의 실제 IoU는 GT가 있을 때만 계산한다. 온라인은 RGB·인지 출력에서 추정값을 내며 실제 ROI별 IoU를 요구하지 않는다.

| 비교 | Dev segment-macro MAE | 새 확인590장 MAE |
|---|---:|---:|
| GP52 |0.04654 |0.03136 |
| RF52 |0.05169 |0.02421 |

새 확인에서 RF가 더 정확했다. GP를 모든 조건의 최선이라고 결론 내리지 않는다. 이번 주기는 Dev로 선택한 GP 주 번들을 사전에 고정하고 확인 기준을 통과했으며, 시험에서 더 좋은 RF 대조로 사후 교체하지 않는다. 다음 버전의 점 추정 비교는 RF를 강한 기준으로 유지한다. Q와 검수 순위의 최선 패밀리는 각각 판단한다.

GP는 Matérn 계열 커널과 예측 scale을 사용한다. 오류 GP 대조는 근거리 오류·원거리 오류·비도로 FP와 공분산을 내며, 가중치 w=(1,0.25,0.5)의 평균/분산은 `wᵀμ`, `wᵀΣw`로 전파할 수 있다. 이 Gaussian 점수나 SD가 검증된 실패 확률·오류 위치의 정답은 아니다.

평균+SD, 점별 정보량과 조건부 정보 검수를 비교했지만 Dev 이득 기준을 넘지 못해 **기본 β=0, 정보 슬롯0**으로 고정했다. 새 확인에서도 GP 정보 대조의 근거리 오류 recall0.45794는 GP-only0.49533보다 낮았다. 큰 σ=전반 실패, 작은 σ=원거리만 실패라는 규칙은 채택하지 않는다. 분산은 로그·보정 점검에 보존한다.

Cal의 도로별 잔차 외피를 적용한90% 구간은 새 확인 전체590장 포함률0.95297, 평균 폭0.27049다. 고정 GT≥50 모집단441장의 MAE0.03716·포함률0.93730도 함께 보고한다. 이 구간을 GP의 베이지안 credible interval이나 안전 보장으로 부르지 않는다. RF의 같은 모집단 MAE0.03156·포함률0.88538도 숨기지 않는다.

BO는 온라인 추론이 아니라 오프라인 HPO 대조다. 공식 BoTorch SingleTaskGP+LogEI와 고정 Matérn-EI를 무작위8쿼리·공통 초기4점·3탐색 시드로 비교했으나 채택 기준을 넘지 못했다. 후속 새 인지 재적합은 무작위12쿼리×3시드를 사용했다. 탐색 시드3개는 인지 재학습을3번 했다는 뜻이 아니다. [논문/구현 출처](../baselines/참고논문_베이스라인.md)

## 추가 진단: GP의 근−원 오류 대비

새 확인의 근·원 동시 오류99장 대 근거리 유지·원거리 오류342장에서 Q GP σ의 AUC는0.46813, GP 오류 가치 σ는0.63518이었다. GP/RF 평균 차이는0.87790/0.87731이었지만, GP의 `μd=μnear−μfar`, `σd²=Σnn+Σff−2Σnf`를 함께 쓴 `z=μd/σd`는0.92808이었다. σ 크기만의 실패 판정보다 **근/원 오류 관계의 사후 대비**가 유망한 단서다.

이 z는 별도로 동결한 **GP-only 오류GP74**의 값이다. 현재 RF74 오류 head는 GP 잠재 SD를 제공하지 않으므로 기본 Q GP의 σ와 섞거나0으로 나누지 않는다. 오류GP74와 주 RF74의74개 순서 있는 입력은 실제 manifest에서 같음을 확인했다. 같은 GP74의 평균 대비→자기 SD 정규화 비교와 RF/GP 패밀리 대조를 구분한다.

이는 확인 개봉 후 추가한 설명용 진단이다. 확률 보정·임계 선택·새 selector 채택은 하지 않았다. 두 조건부 오류 집단 밖으로 일반화하지 않으며, Gaussian z를 실제 실패 확률로 읽지 않는다. 새 Dev/Cal과 새 확인에서 데이터 선별 이득을 검증할 과제다. 기본 RF74 평균 가치·감사10%·GP 정보 슬롯0과 r2 채택은 바꾸지 않았다. ## 후속 선별·입력 활용 비교

11월29일 작업에서는 부모 GP 적합2,500장과 픽셀/ID가 겹치지 않는 Cal835장으로 정규화/메타학습 후보를 구성하고 Dev334장에서 비교했다. GP z 단독 선별은 기존 RF보다 낮았다. RF 검수 가치의 Cal 순위75%와 GP z의 Cal 순위25%를 결합한 후보는 근거리 오류 회수율을 유지하며 도로 평균 가중 검수 회수율이 좋아 별도 확인 대상으로 동결했다. 입력 추가 메타모델은 현재 RF 기준을 넘지 못했다. 새534장 확인 전 결과이므로 아직 기본 정책을 바꾸지 않는다. [진행·채택 근거](../experiments/대비특징_검수와_shadow_20261129.md)

RF/GP는 앞으로도 같은 모집단·예산·인지 버전으로 유지한다. 최종 패밀리 선택은 온라인 연결, 추가 수집과 대용량 선별/재학습 결과 이후다. 사후 z AUC가 좋다는 이유만으로 GP를 선택하지 않는다.
