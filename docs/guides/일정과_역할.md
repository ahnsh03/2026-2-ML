## 팀원이 이어받을 작업

| 담당 | 우선 작업과 산출물 | 연결 이후 |
|---|---|---|
| **안승현** | 현행 release/계보와 데이터 역할 총괄.작동하는 ROS shadow를 긴 주행·후보 GT 연결·대용량 RF/GP 선별/동일 부모 재학습으로 확장하고 버전/rollback을 기록한다. | 차기 재학습은 새 역할/확인으로 수행한다. 최종 수치·시연 영상·영어 대본·리허설을 총괄한다. |
| **손재호** |앞선590장과 새534장의05/06/07시 미회수 사례를 중심으로 근거리 FN/FP·헤드라이트 가시성·GT 표시 적합성을 표본 검수한다. GT 오류와 물리 가시성 정상은 별도 태그로 제안하며 현재 확인 라벨/기준을 바꾸지 않는다. | 영어 웹페이지를 병행한다. 실제 GT가 검증된16:9 그림, 분모·버전·한계·영문 캡션, 영상·코드 링크와 모바일 표시를 확인한다. |
| **장원태** |48장 standalone과590장 결과를 독립 재현한다. 가능하면40계열 실제 GPU에서 같은 선택 ID·Q 차이·군집을 확인한다. 모집단별 RF/GP 우열 역전과 GP 구간/정보 검수 한계를 재현한다. | 기존 ROS shadow의40실기·재연결·버전 전환을 검증하고 재현 로그를 인계한다. 새 패밀리/보정 변경이 필요하면 새 Dev와 새 확인 프로토콜로 진행한다. |

GP/e-means/BO와 수집기·오프라인 연결은 이미 구현·비교했다. 같은 기능을 처음부터 다시 만드는 일을 배정하지 않는다. BO는 이번 탐색 범위에서 이득이 없어 기본에서 제외했고, e-means는 맥락 로그이며 환경별 임계를 강제하지 않는다.

근−원 GP 대비의 실제 선별/입력 활용은 이미 시험했다. 새534장에서 기준을 넘지 못해 제외했으므로 같은 후보를 다시 최우선으로 개발하지 않는다. 원태는40실기 재현·큰 pool의 동일 조건 RF/GP 대조를 우선한다. 재호는 GT 표시와 물리 가시성을 분리한 사례 검수·영어 페이지를 병행한다. [최신 결과](../experiments/대비특징_검수와_shadow_20261129.md)

인계에는 인지/ROI/목표/모델/Cal/정책 해시, 목록·분모·시드·명령·결과·한계, 재생 가능한 입출력과 다음 질문을 남긴다. 새 결과는 dated experiment, 현재 사용법은 guide, 실제 파일 경로는 로컬 자산 기록에 둔다.
