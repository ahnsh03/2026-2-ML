# 최종 일정과 담당별 인계

내부 완료일은 **2026년 12월 4일**이다. **상부를 반반 나눈 9영역을 기본 ROI로 결정했으며** 안승현·손재호가 특징을 공동 선정하고 장원태가 GP·e-means·Bayesian optimization(BO)과 검수 정책을 구현한다. 세 사람이 오프라인 판정을 마친 뒤 온라인 시연과 영어 발표·사이트를 병행한다.

| 날짜 | 책임과 완료 기준 |
|---|---|
| **11월 24일** | **9영역 기본값 결정.** 상부를 반반 나누는 후속 결정을 반영하고 같은 원본·고정 v6와 RF·GP 비교, 추가 수집 결과와 한계를 [결과 문서](../experiments/ROI_9영역_특징선정_20261124.md)에 남긴다. 승현이 마스크·프레임 목록·120열 공통 대조와 당시27열v2·환경80/160/54열의 특징표를 재호·원태에게 인계한다. |
| **11월 27일** | 재호·승현의 첫 특징표와 원태의 알고리즘을 결합한다. 같은 개발 주행에서 RGB → v6 출력·특징 → RF·GP 점수·환경군 → 검수 목록 → 사후 GT 비교표를 한 번 재생하고 실행 명령을 공유한다. |
| **11월 30일** | 최종 입력·모델·정책을 고정하고 미사용 도로 평가와 동일 예산 재학습을 수행한다. 신규·기존 인지 성능과 품질 오차를 근거로 채택 또는 보류, 시연할 버전을 기록한다. |

| **12월 9일** | 기존 발표 장소에서 영어 8분 최종 발표. |
| **12월 13일** | 보고서를 대체하는 영어 프로젝트 페이지의 공식 제출 마감. 제출용 공개 URL은 4일에 확보한다. |

## 11월26일 인계와 남은 우선순위

**9영역·주28열 GP를27일 결합 기준으로 유지한다.** 저속 주행·보정 v2·검수·사후GT 연결은 [최신 결과](../experiments/ROI9_저속주행과_검수보정_20261126.md)와 [실행 구성/그림](../baselines/roi9_drive_20261126/README.md)을 따른다. 원거리31열은 기본 대체를 보류했고 보정된28+31은 진단용이다. 공통IoU0.7 확률순을 유지하며 인지 재학습 효과·가시성 기준의 정상/실패·ROS 완료와 구분한다.

| 담당 | 27일까지 바로 할 일 | 30일까지 판단할 일 |
|---|---|---|
| **안승현** | 현재 역할 원장·학습 구성원·동결 모델과 RGB→검수→다구간 GT CLI를 팀 환경에서 재생하고 합친다. 이미 열린 도로/보정 전환을 표시한다. | 충분한 실패환경 자료와 기존 replay를 구성해 같은 수량/학습 예산의 인지 재학습·유지성을 비교한다. f1용 X/y·g1/보정도 다시 만들고 최종 채택을 총괄한다. |
| **손재호** | 고정28열·9영역의 실제 RGB/GT/추출값을 검수한다. Q0.428을0.763으로 본 낮 장면, 높은recall/낮은precision·무표시/야간 가시성 사례를 우선 확인한다. | 무제한 특징 탐색을 재시작하지 않고 사례별 개선 가설/소수 대조를 제안한다. 공개 그림의 영문 설명과 웹페이지 골격·영상 배치를 병행한다. |
| **장원태** | `review_bundle_v2_final`과 원시/v2의 포함률/폭·Brier/NLL·동일예산 점수를 재생한다. σ 단독 규칙과31열 기본 대체가 채택되지 않았음을 확인한다. | ‘근거리 정상’이 필요하면precision까지 포함한 보조 정답의 새 버전·별도 적합/검증을 설계한다. 환경 정상 참조가 부족한 기준은 공통값으로 되돌리고, 불확실성/공간 선별의 이득을 평균만 쓰는 RF/GP 대조와 분리한다. BO는 오프라인 탐색/무작위 대조다. |

오프라인의 기계학습 기법·검수 정책·GT 평가·충분한 인지 재학습/유지성 판정을 먼저 완성한다. 12월1–4일 온라인 연결과 공개 영문 웹사이트·8분 영어 발표/시연을 분담한다. 웹 골격은 지금 병행할 수 있다. 12월4일 내부 완료,9일 발표·13일 공식 페이지 제출 일정은 유지한다.

오전의 [f1/g1 기능 연결](../experiments/9영역_인지버전쌍_연결검증_20261126.md), [실제 라벨 획득·조건부 GP 갱신](../experiments/GP_조건부_라벨획득_20261126.md), [40/50 RF 호환 번들](../baselines/roi9_gp_20261126/portable/README.md)은 보존 인계물이다. 오늘 새 인지 학습의 성과로 합치지 않는다.

## 담당별 시작점

| 담당 | 처음 받을 입력 | 맡을 작업과 인계 |
|---|---|---|
| **안승현** | 보유 원본·v6 가중치·데이터 역할 목록 | [ROI 결정과 출력 특징](ROI와_특징추출.md), [데이터 등록](데이터_등록과_특징정답.md)을 맡는다. 재호와 최종 열을 선정하고 원태에게 버전 있는 특징표를 전달한다. RF 기준선·전체 결합·[재학습 판정](인지모델_재학습과_갱신판정.md)을 총괄한다. |
| **손재호** | 선택한 ROI, 같은 RGB와 프레임 목록 | [RGB 특징과 관계 실험](ROI와_특징추출.md)을 맡는다. 첫 RGB 표는 원태에게 조기 전달한다. 승현과 특징을 선정하고 실제 실패 사례·분모를 검증한다. 온라인에서 특징값을 대조하고 영문 웹페이지를 구현한다. |
| **장원태** | 기준 특징표와 분리된 학습 정답, 첫 RGB 표 | [품질모델](품질모델_학습과_불확실성.md), [군집·검수 정책](환경군집과_검수정책.md)을 맡는다. 27일에 평균·표준편차·군집·선택 이유를 같은 회차 표로 전달한다. 특징 확정 후 모델·보정을 다시 적합한다. 온라인 추정·검수와 결과 그림을 맡는다. |

기계학습 팀은 세 명, 캡스톤 발표·제출 팀은 안승현·장원태다. 공통 개발은 팀 저장소에서 진행한다.

## 공통 인계 규칙

- 입력에는 프레임 ID, RGB 해시, 물리 세션·도로와 학습/개발/보정/평가 역할을 남긴다. 특징은 ROI·인지모델·열 이름·순서·단위·계산 해상도·유효성 규칙으로 버전 관리한다. 같은 의미의 열끼리 결합한다.
- 예측에는 모델·특징 버전, 예상 IoU, 해당하는 경우 GP 표준편차·군집 ID를 기록한다. 선택에는 모집단·창·예산·동점·중복 규칙·선택 이유와 시드를 남긴다.
- PR에는 질문, 실행 명령, 코드·입력 식별자, 비교 조건·분모, 개선·악화 사례와 다음 판정을 적는다. 학습 시드와 선별 시드를 각각 기록한다.
- 원본·가중치·상세 로그는 실험 볼륨에서 공유하고, 공개 집계·방법·그림은 팀 저장소에 둔다. 과목별 발표 작업 파일은 로컬 워크스페이스에 둔다.

## 함께 판정할 기준

회귀 정답과 출력은 전방 프레임 전체의 흰색·노란색 차선 IoU 하나다. 실제 IoU < 0.7을 공통 벤치마크로 쓰되 운행 실패 기준으로 확정하지 않고, 환경별 상대 저하와 근거리 오류도 사후 분석한다. 모델·특징을 개발 도로에서 정하고 별도 보정 자료로 정책을 고정한 뒤 미사용 도로에서 평가한다. 이미 분석한 273장은 진단에 사용한다.

주 검수 예산은 10%다. 품질 MAE, 같은 예산의 Recall·Precision, 고유 실패 위치, 야간 오경보와 정상 분모, 처리비용을 함께 보고한다. 갱신 채택은 신규 인지 IoU 변화 ≥ 0, 기존 IoU 손실 ≤ 0.005, 짝 품질 MAE 증가 ≤ 0.010을 함께 확인한다. [정책 파일](../../config/cycle_acceptance_v1.json)

최종 발표·페이지와 ROS 연결의 완료 기준은 [온라인 연결과 최종 제출](온라인_연결과_최종제출.md)을 따른다.
