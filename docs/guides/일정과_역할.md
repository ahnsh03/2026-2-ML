## 통합 구현 이후의 담당

이번 자율 실험에서 원태의 GP·e-means·BO 구현도 통합했다. [28일 새 확인](../experiments/환경검증_전체원본재생_20261128.md)은 인지/품질 유지 기준을 통과했으나 검수에서 실패했다. 현재 f1/GP52는 연구 후보이며 온라인으로 이행하지 않는다. GP는 Dev 우세, RF는 새 확인 우세이므로 다음 독립 검증에서도 둘을 비교한다. 팀원은 같은 구현을 다시 만들기보다 아래 보완과 독립 재현을 나눠 맡는다.

## 우선순위와 종료 조건

1. **지원량·검수 정답과 장면 표현 보완.** 원본 Q는 유지하고 예상 표시 유무·근거리 FP/FN·검수 가치 목표를 분리한다. 무출력 장면은 일괄 제외하지 않는다. 새 Dev/Cal에서07시 라벨과 표시/무표시 지원을 확보한다. 보완 전 임계 BO를 확대하지 않는다.
2. **모델·정책 동결과 새로운 독립 확인.** GP/RF와 공통/상황 기준을 같은 자료·예산으로 비교한다. 원태는 BO history만 고르던 정책 선택을 BO/무작위 합집합 선택으로 바꾸는 규칙을 먼저 고정하고 균형 예약·상대 임계의 효과를 분리한다. 복수의 유효 표시 구간과 음성 구간, 지원량·실질 이득 기준을 먼저 고정한다. 이번에 개봉한618장에 다시 맞추지 않는다. 통과 전 ROS 연결·자동 갱신을 보류한다.
3. **조건 통과 후 다음 수천장 주기.** 현재8학습은 모두 같은 v6에서 시작했다. f1→f2 부모/누적 노출·중복·전체 replay 구성을 구현한 뒤 다음 bank를 연결한다. 아직 위험 선별의 무작위 대비 재학습 우세는 확인되지 않았다.
4. **온라인과 공개물.** 오프라인 기준을 먼저 판정한 뒤 ROS shadow 연결을 인수한다. 실시간 추론/검수와 자동 재학습 승인을 구분한다. 일정이 부족하면 검증된 오프라인 재생 영상의 범위를 명시한다.

## 공통 판정과 인계 규칙

주 정답은 전방 전체 white/yellow 차선 IoU 하나다. Q<0.7은 공통 검색 벤치마크이며 가시성 정상·운행 실패의 정답이 아니다. 보조 근/원거리 목표는 이미지 띠의 사후 진단이다. 주 검수 예산10%와 실제 반올림 장수, 동일3,072장 학습 예산을 함께 보고한다.

이번 재학습 판정은 [현재 가이드](인지모델_재학습과_갱신판정.md#데이터-역할과-판정)의 신규 macro 이득≥0.005·2/3도로 향상·기존 pooled 손실≤0.005·클래스/시야 손실≤0.01·두 optimizer 시드 통과다. 과거 cycle_acceptance_v1의 신규 이득≥0과 구분한다. 품질·검수도 각각 고정 기준을 통과해야 한다. 확인 결과로 계수·특징·임계값을 다시 선택하지 않는다.

- 입력: 프레임ID·RGB/GT 해시·물리 세션·도로·역할·인지 과거 노출, ROI·열 순서·단위·전처리 버전.
- 예측/선택: 정확한 인지/품질 신원·평균/σ·군집·모집단·창·예산·동점 규칙·시드·선택 사유·포함 확률.
- 결과: 질문·명령·코드/입력 해시·비교 분모·좋고 나쁜 사례·한계·다음 판정. 학습 시드와 선별 시드를 구분한다.
- 보관: 원본·가중치·상세 로그는 실험 볼륨, 공개 집계·방법·그림은 팀 저장소, 과목별 발표 작업 파일은 로컬 워크스페이스.
