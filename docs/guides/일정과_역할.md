## 통합 구현 이후의 담당

이번 자율 실험에서 원태의 GP·e-means·BO 구현도 통합했다. 직전 후보의 g1 유지성 실패를 보완하기 위해 [전체 원본 재생·RGB 환경 구분·새 확인](../experiments/환경검증_전체원본재생_20261128.md)을 진행한다. 현재 Q 단일 GP/RF와 버전별 검수 번들의 최종 채택은 새 확인 결과를 따른다. 팀원은 같은 구현을 다시 만들기보다 동결 결과를 독립 재현하고 남은 대조·연결을 나눠 맡는다. 실제 채택 모델·점수·기준은 위 통합 결과와 번들 manifest가 정한다.

## 우선순위와 종료 조건

1. **g1 품질 유지성 보완·재현과 데이터 역할 확인.** 새 버전 번들·정확한 인지 가중치·고정 목록·영수증을 함께 받는다. 새GP의 도로별 과신과 별도도로 MAE를 먼저 진단하고 보완 후보를 개발 역할에서 정한다. 이미 열었던 f0 확인은 처음 보는 최종 시험으로 쓰지 않는다. 예약 역할의 GT 연결은 학습 승격을 뜻하지 않는다.
2. **한 번의 동결된 새 경로 확인.** 특징·정책·가중치를 먼저 고정하고 새로운 물리 구간/위치를 평가한다. 반복 시드와 같은 지도 안의 도로 수를 별도로 센다. 결과가 나쁘면 공개하고 정책을 다시 맞춘 자료는 개발 역할로 전환한다.
3. **다음 수천장 주기.** 현재 trainer는 f0에서 시작한다. f1→f2 부모/누적 노출·중복·공통 replay 구성을 구현한 뒤 다음 bank를 연결한다. 두 번째 주기를 첫 주기의 독립 검증처럼 세지 않는다.
4. **온라인과 공개물.** 오프라인 기준을 먼저 판정한 뒤 ROS shadow 연결을 인수한다. 실시간 추론/검수와 자동 재학습 승인을 구분한다. 일정이 부족하면 검증된 오프라인 재생 영상의 범위를 명시한다.

## 공통 판정과 인계 규칙

주 정답은 전방 전체 white/yellow 차선 IoU 하나다. Q<0.7은 공통 검색 벤치마크이며 가시성 정상·운행 실패의 정답이 아니다. 보조 근/원거리 목표는 이미지 띠의 사후 진단이다. 주 검수 예산10%와 실제 반올림 장수, 동일3,072장 학습 예산을 함께 보고한다.

이번 재학습 판정은 [현재 가이드](인지모델_재학습과_갱신판정.md#데이터-역할과-판정)의 신규 macro 이득≥0.005·2/3도로 향상·기존 pooled 손실≤0.005·클래스/시야 손실≤0.01·두 optimizer 시드 통과다. 과거 cycle_acceptance_v1의 신규 이득≥0과 구분한다. 품질·검수도 각각 고정 기준을 통과해야 한다. 확인 결과로 계수·특징·임계값을 다시 선택하지 않는다.

- 입력: 프레임ID·RGB/GT 해시·물리 세션·도로·역할·인지 과거 노출, ROI·열 순서·단위·전처리 버전.
- 예측/선택: 정확한 인지/품질 신원·평균/σ·군집·모집단·창·예산·동점 규칙·시드·선택 사유·포함 확률.
- 결과: 질문·명령·코드/입력 해시·비교 분모·좋고 나쁜 사례·한계·다음 판정. 학습 시드와 선별 시드를 구분한다.
- 보관: 원본·가중치·상세 로그는 실험 볼륨, 공개 집계·방법·그림은 팀 저장소, 과목별 발표 작업 파일은 로컬 워크스페이스.
