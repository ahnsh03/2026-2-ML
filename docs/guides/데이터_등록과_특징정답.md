# 데이터 역할과 버전별 X/y

원본은 읽기 전용으로 보존하고 파생 캐시·가중치·실행 증거는 실험 볼륨에 둔다. 주소형 캐시와 manifest를 공유하며 원본을 다시 복사하거나 캐시 glob으로 학습 목록을 정하지 않는다.

| 역할 | 현재 구성과 경계 |
|---|---|
| 원래 인지 train/val |26,001 /1,404. 체크포인트 내 목록 해시와 대조했다.4,096장은 과거 replay 부분집합이다. |
| 부모 인지 replay | 원래26,001+기편입3,072=29,073. 후속 후보에 전체 보존한다. |
| 추가학습 후보 | 미노출4,370+신규424=4,794. GT 없는 목록에서2,048장을 고정한 뒤 GT를 연결한다. |
| 품질·오류 fit |2,500. 이전 fit1,882+이미 개봉한 확인618이며,618장의 시험 지위는 폐기했다. |
| 환경 fit |3,118. 기존2,500+개봉한618이며 새 확인590장은 포함하지 않는다. |
| 새 Dev / Cal |334 /835(기존612+신규223). 같은 인지 버전으로 X/y를 재계산한다. |
| 인지 Dev·유지 비교 |2,675=기존Dev937+원래val1,404+새Dev334. 품질 학습 행 수와 다르다. |
| 새 확인 |96조건·원본1,674프레임·4채널6,696파일. 모델/정책 고정 뒤 수집했고3m thinning으로590장을 정했다. |

새 확인의 품질 fit 이격은 최소46.25m다. **원래 인지학습 ego와는 최소0.10m**이므로 완전히 새 도로나 새 도시 일반화를 주장하지 않는다. 같은 지도에서 품질 fit과 역할을 분리한 새 수집·환경 전이 확인이다. 감사 보고서의 `quality_fit_all`은 환경 fit을 포함한 전체3,118행 풀 이름이며, 실제 Q/오류 적합은 위2,500행이다. 원본 전체의 ID·디코딩 픽셀과 학습 노출도는 [역할 감사](../baselines/scene_cycle_20261128/confirmation/reports/reserved_role_audit.json)를 따른다.

전체 Q는 흰색/노란색 차선 합집합 IoU다. union0은 미정의이며0이나1로 채우지 않는다. 검수용 근/원 FN은 GT≥50픽셀이고 recall<0.8, FP는 예측≥50픽셀이고 precision<0.8인 경우다. 비도로 FP는 상부·보닛의 합집합에서 계산한다. [목표 코드](../../src/quality_estimation/review_targets.py)

<a id="gt-없는-선별-후-정답-연결"></a>

목록·원본 RGB/GT 해시·픽셀 해시·인지 가중치/계보·ROI·정답 정책·특징 순서를 함께 저장한다. 수집은 [현행 재현 순서](../../scripts/experiments/scene_cycle_20261128/README.md)를 따른다. 선별된 RGB ID를 먼저 고정하고 `join_spatial_gt`로 원본 바이트·픽셀·버전을 확인한 뒤 GT를 연결한다. 확인·Dev·Cal의 원본 전체를 현재 재학습에 편입하지 않는다.
