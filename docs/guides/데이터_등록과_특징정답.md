# 데이터 등록과 특징·정답 생성

승현이 원본·역할 목록을 준비하고 재호·원태가 같은 ID의 특징표를 사용한다. 11월 24일에는 ROI 비교용 입력을, 27일에는 첫 결합용 회차를 전달한다. [일정과 인계](일정과_역할.md)

## 기존 구현과 추가 개발

| 경로 | 현재 가능한 것 | 이번 작업에서 이어갈 것 |
|---|---|---|
| `capture_sessions.py` | 기존 4채널 원장을 해시 검증해 등록하고 RGB 단독·paired 입력을 내보낸다. | 역할과 물리 세션·도로를 확정하고 팀원이 읽을 입력 목록을 만든다. |
| `build_native_dataset` | X56과 단일 전체 IoU를 생성한다. 실행 스키마는 `ml-quality-xy-2.0.0`이다. | X56 재현 입력으로 사용한다. [원래 스키마](../contracts/quality_xy_v2.json) |
| `roi10_study build` | 10영역 RGB 8개·출력 4개·예측 면적·사후 TP/FP/FN을 저장한다. | 같은 원본에서 7영역을 재집계하고 선택 가능한 특징표·직접 회귀 학습 경로를 구현한다. [기존 10영역 팩](../archive/전방_10영역_실험_재현.md) |

새 특징표에는 프레임 ID, 입력 해시, 인지모델·ROI·추출기 버전, 순서 있는 특징명과 값이 필요하다. 실제 IoU와 평가용 날씨·시각·위치는 별도 정답·메타데이터로 연결한다. [입출력 규약과 기존 구현](../contracts/품질추정_입출력규약.md)

## 원본 등록과 내보내기

다음 변수는 자신의 실험 볼륨의 원본·목록·새 출력 경로로 설정한다. `SESSION_CONTEXT`에는 물리 세션, 도로, 학습/개발/보정/평가 역할, 카메라 설정과 관측 출처를 기록한다.

```bash
python3 scripts/capture_sessions.py register-front \
  --manifest "$RAW_MANIFEST" --media-root "$RAW_ROOT" --session-id "$SESSION_ID" \
  --context "$SESSION_CONTEXT" --population all_captured --output "$CAPTURE_STORE/$SESSION_ID"
python3 scripts/capture_sessions.py verify "$CAPTURE_STORE/$SESSION_ID" --media-root "$RAW_ROOT"
python3 scripts/capture_sessions.py export "$CAPTURE_STORE/$SESSION_ID" \
  --media-root "$RAW_ROOT" --output "$EXPORT_DIR"
```

출력의 `rgb.jsonl`은 점수화 입력, `paired.jsonl`은 사후 정답 입력이다. RGB만 수신한 세션은 paired가 0이며 실제 IoU는 미정의다. 원본 미디어는 `RAW_ROOT`에 있고 후속 `--data-root`도 그 루트를 사용한다. 누락 채널·잘린 원장·선별본의 모집단 범위는 그대로 기록한다. [세션 기록 형식과 복원 절차 원문](../archive/수집세션_등록과_오프라인_재가공.md)

## 특징과 정답

- 원해상도 RGB와 같은 버전의 인지 출력에서 특징을 계산한다. 흰색·노란색 차선은 4클래스 argmax 결과의 합집합으로 정의하고 모델 letterbox padding을 제거한다.
- 정답은 `TP / (TP + FP + FN)`으로 계산한 프레임 전체 IoU 하나다. 합집합이 빈 장면은 미정의로 기록한다. 회귀 적합·MAE에는 정의된 정답을 쓰고, 검수 후보와 예산에는 미정의 장면도 남겨 선택 수를 보고한다.
- ROI별 TP/FP/FN은 누락·오검출 사례를 해석하고 전체 IoU를 대조하는 데 사용한다. 이번 직접 회귀의 목표는 전체 IoU다.
- 인지모델을 갱신하면 같은 RGB에서도 출력 특징과 실제 IoU를 다시 계산한다. 인지모델·품질모델의 짝과 학습 이력을 함께 기록한다.

기존 X56을 재현할 때는 아래 명령을 사용한다. `NATIVE_MANIFEST`에는 RGB·Semantic 짝과 출처 역할이 있어야 한다.

```bash
scripts/run_container.sh python3 -m quality_estimation.build_native_dataset \
  --manifest "$NATIVE_MANIFEST" --data-root /data \
  --output-dir /outputs/datasets/native_front --audit-per-run 2
```

기존 10영역 연구 팩은 다음 명령으로 만들 수 있다. `--paired`는 학습·사후 정답용 입력에서 사용한다.

```bash
scripts/run_container.sh python3 -m quality_estimation.roi10_study build \
  --manifest /outputs/manifests/train.jsonl --data-root /data \
  --paired --purpose training --output /outputs/roi10/train
```

## 분할과 재가공

학습·개발·보정·미사용 평가 도로는 모델과 정책을 선택하기 전에 정한다. 물리 세션, 인접 위치·프레임, 디코딩 RGB 중복과 인지모델의 과거 노출을 확인한다. 이미 본 273장 도로는 진단 자료다. 미사용 평가 GT는 예측·선택 목록을 고정한 뒤 연결한다.

ROI·분위수·연결성분을 바꿀 수 있도록 원본 RGB, 픽셀 예측을 재생성할 체크포인트·코드·전처리를 보관한다. 원해상도 연결성분이나 logit energy가 필요하면 같은 RGB를 재추론한다. 축소 요약 맵에서 사라진 경계나 raw logit은 원래 의미로 복원할 수 없다. [원본 복원 범위와 누락 1,802장 기록](../archive/수집데이터_재가공과_논문활용_20261123.md)

## 인계와 확인

ID·해시가 같은 작은 샘플에서 RGB 단독 특징과 paired 특징을 대조하고 Semantic에서 실제 차선 수를 다시 센다. 다른 저장 루트에서도 같은 목록이 열리는지 확인한다. 재호·원태에게 목록·특징명·유효성·분할·모델 식별자와 재현 명령을 넘긴다. 보관 자료 3,233장 검증과 273장 재생은 [기존 결과](../experiments/오프라인_검수와_동일예산_재학습_20261123.md)에 있다.
