# ROI 결정과 특징 추출 실험

승현이 11월 24일 ROI를 정하고, 재호와 승현이 선택된 마스크에서 특징을 공동 선정한다. 27일 첫 결합, 30일 오프라인 판정에 사용할 열과 추출기를 인계한다. 원태는 같은 특징표로 RF·GP와 군집·정책을 비교한다. [일정과 역할](일정과_역할.md)

## ROI 정의와 의도

| 구성 | 픽셀 배정과 의도 |
|---|---|
| **10영역** | 상부·원거리·근거리를 좌·중앙·우로 나누고 보닛 하나를 더한다. 중앙 주행로와 양옆 배경, 편측 가림을 따로 본다. [프로파일](../../config/roi10_front_v1/profile.json) |
| **7영역** | 같은 세 띠를 x=640에서 좌·우로 나누고 보닛 하나를 더한다. 상부·원거리·근거리·보닛 경계는 10영역과 픽셀 단위로 같다. [프로파일](../../config/roi7_front_v1/profile.json) |
| **전체 화면 옵션** | 보닛을 포함한 유효 화면에서 같은 특징을 추가한다. 측정 범위 수는 각각 11개 또는 8개다. |

고정 전방은 1280×720, 수평 화각 90°, 피치 2°이며 수평선은 y=338이다. 수평선과 보닛 사이를 1대2로 나눈다. 원·근거리는 영상의 띠를 뜻한다. 7영역 경계는 10영역의 중앙 칸 내부를 지나므로 같은 RGB·v6 출력 맵에서 통계를 다시 집계한다. 평균·분산·중앙값의 재집계 의미를 확인하고 영역 순서를 기록한다.

11월 24일에는 같은 공통 특징과 데이터·학습 시드·튜닝 예산으로 7·10영역 × RF·GP 네 조합을 비교한다. 전체 화면 옵션은 두 분할에 같게 적용한다. 개발 도로별 MAE, Recall@10%, 처리시간, 중앙 분할로 선택이 달라진 실제 실패를 확인한다. 선택 전에 허용할 성능 손실을 정하고 선택 근거를 팀에 전달한다. 4영역은 가로 분할 효과를 해석할 필요가 있을 때의 보조 대조다.

## 현재 공통 특징

| 특징군 | 열 이름과 정의 |
|---|---|
| RGB 8개 | `intensity` 회색조 평균, `chroma` RGB 최댓값−최솟값 평균, `intensity_std` 밝기 표준편차, `dark_channel` 다크 채널 중앙값, `local_contrast` 국소 대비 평균, `sharpness` Sobel 선명도, `glare_fraction` 245/255 이상 밝기 비율, `median_residual` 중앙값 필터 잔차 평균 |
| 출력 4개 | `drivable_fraction` 주행가능 면적, `lane_fraction` 차선 면적, `lane_probability` 흰·노란 확률 합의 **영역 전체 평균**, `marking_entropy` 마킹 엔트로피 평균 |

실제 수치 정의와 축소·양자화 방식은 [현재 추출 코드](../../src/quality_estimation/roi10.py)에 있다. 최초 X56의 영역당 8개는 RGB 4개와 출력 4개였으며 물리 ROI의 12개와 다르다. [X56 정의 원문](../archive/X_y_데이터셋.md)

10영역 RGB 추출은 지금 다음 명령으로 확인할 수 있다.

```bash
PYTHONPATH=src python3 -m quality_estimation.roi10 \
  --image front.png --output scene.json
```

`nodes`는 10×8이고 `--head-maps`로 4×180×320 바이트 맵을 주면 출력 40개를 얻는다. 기존 `FrontProfile`과 연구 CLI는 10영역 전용이다. 7영역은 ID 마스크·프로파일까지 준비됐다. 같은 통계의 7영역 추출과 선택 가능한 직접 회귀용 특징표 연결은 승현·재호가 구현한다. [기존 팩·실행 원문](../archive/전방_10영역_실험_재현.md)

## 후보와 담당

| 담당 | 추가할 후보 | 참고와 측정 목적 |
|---|---|---|
| **재호** | 밝기 분위수·어두운 비율, 색상·채도·대비·선명도의 블록 분포, 다크 채널 | Roser·Cheng·Lu에서 차용한 환경 단서. 같은 조건의 다른 도로에서도 안정적인지 본다. |
| **승현** | 예측 차선 확률 마진, 성분 크기·연결성분, 경계·내부 엔트로피, 필요 시 raw logit energy | MetaSeg·SEE의 품질 단서. 같은 환경 내 정상·실패를 구분하는지 본다. |
| **공동** | 보닛–노면 밝기차, 원–근거리 대비차, 좌우 비대칭 | 영역의 단독 값으로 설명되지 않는 실패를 추가로 찾는지 본다. |

논문별 원래 과제·사용한 정의와 재현 범위는 [논문 목록](../baselines/참고논문_베이스라인.md), [적용 분석 원문](../archive/수집데이터_재가공과_논문활용_20261123.md)에 있다. RGB 환경군과 품질 회귀의 열은 각각 선정한다. 필터 잔차에는 재질·반사·압축 효과도 섞인다.

## 실험 순서

1. **일괄 추출과 추가**를 한다. 모든 ROI에 같은 후보를 계산하고 공통 12개에서 특징군 하나씩 추가한다. RGB만·출력만·결합 입력을 RF·GP의 같은 조건에서 비교한다.
2. **영역별 축소**를 한다. 상부와 보닛에서 출력 4개 → 차선 면적 1개 → 0개를 각각 비교한다. 도로의 RGB·출력도 묶음별 제거 후 다시 학습한다. RF 중요도와 제거 전후 실제 성능을 함께 본다.
3. **관계 특징**을 추가한다. 독립 열로 선택되지 않은 보닛 밝기도 관계 계산의 재료로 남긴다. 관계마다 추가 발견·누락 장면과 비용을 비교한다.
4. 개발 도로에서 최종 열을 정하고 추출기·열 목록·단위·유효성·버전을 고정한다. 회귀 정답과 최종 출력은 전체 차선 IoU 하나다.

한 프레임은 한 행이고 열은 `영역.특징`이다. 선택한 열만 연결하면 차원이 줄어든다. 예측 차선 위 통계는 예측 픽셀 0개에서 대체값과 예측 면적·유효 여부를 함께 기록한다. 필터·경계는 먼저 영상에서 계산한 뒤 마스크로 집계해 ROI 테두리가 특징이 되는 것을 막는다.

## 인계와 완료 기준

첫 RGB 표는 최종 선정 전 원태에게 제공한다. 인계물은 추출 코드, 순서 있는 열 목록, 동일 ID 샘플, 데이터·인지모델·ROI 버전, RF·GP의 MAE와 검수 결과, 특징 계산시간이다. 같은 RGB 재실행 일치, 상수 영상의 대비·경계, 빈 예측, 7·10영역의 전체 픽셀 배정을 확인한다. [품질모델 연결](품질모델_학습과_불확실성.md)
