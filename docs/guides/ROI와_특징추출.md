# 고정9영역과 현재 특징

기본 ROI는 **roi9-front-v1**이다. 상부 높이를 반분한 위/아래층×좌우4개, 원거리 좌우2개, 근거리 좌우2개, 보닛1개로 전 화면을 나눈다. 전체 화면 통계는 추가 마스크가 아니다. [정의](../../config/roi9_front_v1/profile.json) · [예시](../../config/roi9_front_v1/regions.png)

| 영역 | 의도와 현재 활용 |
|---|---|
| 상부 위층 좌우 | 조명·색·명암·포화/눈부심. 현재 Q52와 RGB 환경 표현에 사용한다. |
| 상부 아래층 좌우 | 건물·표지판·수직 구조와 비도로 오검출 맥락. 모든 후보를 무조건 Q에 넣지는 않는다. |
| 원거리 좌우 | 먼 차선·작은 구조. 근−원 차이와 오류 진단에 기여한다. |
| 근거리 좌우 | 노면 RGB, 주행가능/차선 비율·확률·엔트로피, 검수 가치의 중심이다. |
| 보닛 | 고정 물체의 반사·색·밝기·잔차. 차체 그림자를 날씨 정답으로 단정하지 않는다. |
| 전체 집계·관계 | 전역 출력과 근−원 대비, 비도로 출력까지 남겨 FP를 관찰한다. |

현재 인지 버전은 **m-v6-r2-20261128**, Q는 GP52열, 오류는 RF74열이다. 두 head의 입력 합집합은74열이며 환경 RGB 히스토그램400열은 별도다. 영역마다 다른 특징을 쓰므로9×고정 특징 수가 아니며, 사용하지 않는 조합을 결측값으로 채우지 않는다. 순서와 정확한 이름은 [현재 manifest](../baselines/scene_cycle_20261128/confirmation/reports/active_review_manifest.json)의 `evidence.quality_columns/error_columns`가 정본이다.

환경 확률·히스토그램과 출력 관계를 무조건 전부 넣는 방식은 채택하지 않았다. 새 가중치에서는 Q52 GP의 Dev MAE0.04654가 GP74의0.05568보다 작았다. 다만 새 확인에서는 같은52열 RF의0.02421이 GP0.03136보다 작았다. 특징 수와 GP 우세를 같은 것으로 해석하지 않는다.
