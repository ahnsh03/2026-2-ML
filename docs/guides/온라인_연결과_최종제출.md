# 온라인 연결과 영어 최종 제출

오프라인 기준을 통과한 현재 쌍은 **r2 인지 + GP52 Q + RF74 검수 + e-means 맥락**이다. 실제 RGB590장→59장 검수→사후 GT 연결을40프로필 CPU와50실기 GPU에서 재현했다. 원래 작업공간/데이터 없이 release+새 출력 폴더만 마운트한48장 standalone도 통과했다. 실행 성공과 실시간 ROS 완료는 구분한다.

## 다음 구현 순서

1. **26R1 ROS shadow 수신:** RGB·프레임 ID·시각·카메라 규격을 연결하고 현행 인지/품질/ROI 해시를 기록한다. UDP 실험에서 확인한26R1 조향 부호·wheel 설정을 ROS와 같다고 가정하지 않는다.
2. **동일 영상 재생 대조:** 실시간 출력 특징과 오프라인 팩의 열·순서·값, Q·검수 점수를 비교한다. GT는 이 단계 입력으로 쓰지 않는다.
3. **검수 버퍼·저장:** 닫힌 버퍼 전체에서 예산을 배분하고 중복·순서·감사 슬롯을 유지한다. 프레임마다 독립 선별하거나 ROI별 실제 IoU를 온라인에서 계산하지 않는다. 지연·드롭·저장량을 측정한다.
4. **사후 GT·갱신:** 선별 ID를 먼저 고정하고 GT를 연결한다. 다음 인지/품질 버전은 새로운 검증과 승인된 채택 영수증으로 전환한다. 이전 버전으로 rollback할 수 있어야 한다.

48장 묶음의 실행 안내와 manifest가 인계 시작점이다. 개인 경로는 로컬 자산 대응표에 있으며 공개 문서에 쓰지 않는다.40계열 실제 GPU는 팀원 장비에서 추가 확인한다. 두 의존성 이미지의 CPU331검사는 통과했다.

## 발표·페이지 완료 기준

내부 완료일 **12월4일**, 공식 영어8분 발표 **12월9일**, 영어 프로젝트 페이지 공식 제출 **12월13일**이다. 사전지식 없이 목표·방법·결과·한계를 이해할 수 있도록 구성한다.

페이지에는 개요·파이프라인·동일 조건 결과표·실제 RGB/GT/예측/FP-FN 사례·시연 영상·코드/재현 링크를 둔다. 원래v6/부모/r2, 검수59/590, 근거리 오류53/107, RF/GP 대조와 GP 불확실성의 한계를 구분한다. 같은 지도·한 학습 시드·원래 인지학습 위치 근접을 공개하며 안전 성능이나 새 도시 일반화를 주장하지 않는다. 공개 원본 데이터·가중치 업로드를 이 작업의 완료 조건으로 삼지 않는다.
