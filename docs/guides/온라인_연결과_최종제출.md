# 온라인 연결과 영어 발표·프로젝트 페이지

11월 30일 오프라인 모델·정책을 판정한 뒤 12월 1–4일에 온라인 시연과 최종 발표물을 병행한다. 12월 4일까지 영문 슬라이드·대본·8분 리허설, 확정 수치·영상, 영어 공개 사이트와 제출 URL을 준비한다. 공식 발표는 12월 9일 기존 장소, 페이지 제출 마감은 12월 13일이다. [전체 일정](일정과_역할.md)

## 시작 입력과 담당

| 담당 | 온라인 작업 | 발표·사이트 인계 |
|---|---|---|
| 승현 | RGB 수신·프레임 ID·시각과 v6 추론을 연결하고 한 세션을 녹화한다. | 단일 확정 결과표, 주장·분모·모델 버전, 최종 영상·영어 대본과 리허설을 총괄한다. |
| 재호 | 라이브 RGB·출력에서 특징을 계산하고 같은 영상의 오프라인 열·값과 대조한다. | 영어 웹페이지 제작을 맡고 ROI·대표 사례, 자막 영상, 코드·재현 링크를 배치한다. |
| 원태 | 채택 추정기·군집·보정·검수 정책을 연결한다. 같은 입력의 점수·선택 ID, 지연·드롭·저장량을 측정한다. | RF·GP, 검수, 재학습 결과 그림에 분모·단위·영문 캡션을 붙이고 공개 수치를 대조한다. |

입력은 오프라인 판정에서 정한 모델·특징·ROI·중심·보정값과 회차 재생 예제다. 원본과 점수·선택을 같은 프레임 ID로 연결한다. ROS 센서 시각과 호스트 수신·추론·선택 시각은 단위·출처를 기록한다.

## 기존 스트림 연결과 추가 구현

기존 `stream_front_rgb.py`는 ROS 압축 전방 RGB를 원래 바이트·헤더 시각·수신 시각과 함께 저장하고 RGB 경로 행을 내보낸다. `stream_review`는 이 경로 행을 순서대로 읽어 기존 품질모델로 채점하고 창별 선택 원본을 저장한다. 기존 X56 모델·환경 중심과 새 ROI 직접 회귀의 번들 연결은 원태·재호가 구현할 대상이다. 실제 26R1 토픽·압축 설정·수신률은 시뮬레이터에서 확인한다. [ROS 입력·수신기 원문](../archive/회귀학습_선별평가.md#ros-1-전방-압축-영상-입력)

기존 저장 RGB로 일괄·스트림 출력을 대조할 때는 다음 명령을 사용한다. 변수는 같은 프레임과 완료 모델의 실제 경로로 설정한다.

```bash
PYTHONPATH=src python3 -m quality_estimation.stream_review \
  --data-root "$RGB_ROOT" --model-run "$QUALITY_RUN" --alarm-calibration "$ALARM_RUN" \
  --window-frames 64 --budget-percent 10 --audit-fraction 0.2 \
  --output-dir "$LIVE_RESULT" < "$RGB_MANIFEST"
```

`stream_review`는 표준 입력의 JSON 행마다 RGB를 읽는다. `scores.jsonl`, `windows.jsonl`, `queue.jsonl`, `selected_rgb/`와 `_SUCCESS`를 확인한다. 창이 닫힐 때까지 원본이 같은 경로에서 읽혀야 한다. 스트림 공급·관측 예제는 [기존 실행 기록](../archive/회귀학습_선별평가.md#들어오는-rgb를-바로-채점하고-검수-이미지를-저장하기)에 있다.

같은 입력 순서에서 선택 ID·특징값·점수를 오프라인과 대조한다. 프레임 수·수신률·p50/p95 추출/추론/전체 지연·드롭·기록 용량과 종료 후 재처리 가능 여부를 남긴다. 원본 수집의 보존 범위는 [데이터 등록](데이터_등록과_특징정답.md)에서 확인한다.

## 영어 발표와 보고서 대체 페이지

8분 구성은 문제·목표 1분, 방법·비교 조건 2분, 정량 결과·실패 사례 3분, 시연 1분, 한계·결론 1분이다. 첫 장면으로 RGB·차선 예측·정답을 설명하고, 처음 듣는 청중이 검수와 IoU를 이해할 수 있게 한다. 핵심 결과는 ROI·특징 선택, RF·GP와 검수 비교, 실제 재학습 전후를 같은 데이터 범위와 함께 제시한다.

영어 페이지는 저장소의 `site/`에 구현한다. 첫 화면의 제목·한 문장 성과·대표 영상에서 방법 그림·결과·한계·코드·재현 절차·팀·참고문헌으로 이어지게 한다. 최신 연구 페이지의 영상·코드 접근 방식을 참고한다. [CVPR 2026 LFG 페이지](https://lfg-ai.github.io/)

공개할 표와 그림은 `docs/baselines/`의 공개 집계 또는 문서와 함께 검토한 자산에서 사용한다. 원본 영상의 공개 범위를 확인하고, 영상에는 실제 촬영·재생 방식과 영문 자막을 붙인다. 공개 페이지에서는 개인 경로 대신 코드·결과·영상의 실제 링크를 사용한다.

## 12월 4일 완료 점검

- 세 사람이 슬라이드·영상·페이지의 수치, 분모·모델·예산·독립 평가 범위를 같은 확정표와 대조한다. ROS 실측과 오프라인 재생의 관측 범위를 영상에 표시한다.
- 영어 8분 전체 리허설을 마치고 최종 슬라이드·대본·영상을 보관한다. 검증된 재생 영상은 발표 환경에서도 열어 본다.
- 공개 URL에서 모바일·데스크톱의 그림·영상·자막·코드·재현 링크를 확인한다. 재호가 페이지를 완성하고 승현이 제출용 URL과 최종 파일 버전을 보관한다.
