# 온라인 연결과 영어 최종 제출

오프라인 기준을 통과한 현재 쌍은 **r2 인지 + GP52 Q + RF74 검수 + e-means 맥락**이다. 실제 RGB590장→59장 검수→사후 GT 연결을40프로필 CPU와50실기 GPU에서 재현했다. 원래 작업공간/데이터 없이 release+새 출력 폴더만 마운트한48장 standalone도 통과했다. 실행 성공과 실시간 ROS 완료는 구분한다.

## 실제 연결 명령

[shadow 실행](shadow_실행.md)의 demo/start/stop/status/replay를 쓴다.26R1 ROS 전방 약20Hz, native 주행300초의293장 저장/추론과6구간88.45m 저속 주행을 확인했다. 원래 배치로 재생한 특징·모든 예측 차이0, 선택 ID/순서/사유가 같았다. 최종 소스의 추가146장도 같은 결과다. [측정·한계·영수증](../baselines/shadow_cycle_20261129/README.md)

주행 제어 자체는 UDP와 SDK를 썼다. 카메라 ROS 연결과 차량 제어 ROS 이식을 구분한다. 온라인 검수는 GT·실제 ROI별 IoU·차량 제어·자동 학습 편입을 요구하지 않는다.40/50 CPU353검사는 통과했고 실제 GPU는5070Ti에서 실행했다.40실기 GPU는 팀원 장비 확인이 남았다.

## 남은 연결·갱신 작업

1. **긴 연속 주행/재연결:** 현재 짧은 구간 검증을 넘겨 날씨 전환·센서 중단/재연결·자원/저장 상한을 확인한다. 노출 시각과 수신 시각을 혼동하지 않는다.
2. **선별 후 GT:** 온라인 후보 ID를 먼저 고정하고 지원량·FP/FN·가시성을 사후 검수한다. 시간/거리 중복과 자료 역할을 보존한다.
3. **대용량 비교와 재학습:** RF/GP·무작위를 같은 예산/부모/replay로 비교하고 독립 유지/개선 결과로 인지를 갱신한다. 새 인지에는 새 X/y·품질/Cal·정책이 필요하다.
4. **버전 전환/rollback:** 현재 해시 불일치 거부를 유지하며 승인된 새 쌍을 전환·복구하는 실행 절차를 검증한다. 최종 패밀리는 위 비교 이후 결정한다.

검증된 가중치·번들은 [models](../../models/README.md)에 있다. 원본 자료와 전체 학습 원장은 로컬에 보존한다. 접속 기능이 작동한다는 사실만으로 대용량 플라이휠의 성능 이득이 모두 확정된 것은 아니다.

## 발표·페이지 완료 기준

내부 완료일 **12월4일**, 공식 영어8분 발표 **12월9일**, 영어 프로젝트 페이지 공식 제출 **12월13일**이다. 사전지식 없이 목표·방법·결과·한계를 이해할 수 있도록 구성한다.

페이지에는 개요·파이프라인·동일 조건 결과표·실제 RGB/GT/예측/FP-FN 사례·시연 영상·코드/재현 링크를 둔다. 원래v6/부모/r2, 검수59/590, 근거리 오류53/107, RF/GP 대조와 GP 불확실성의 한계를 구분한다. 같은 지도·한 학습 시드·원래 인지학습 위치 근접을 공개하며 안전 성능이나 새 도시 일반화를 주장하지 않는다. 원본 데이터·optimizer·전체 학습 원장은 공개하지 않는다. 사용자가11월28일 명시한 검증 배포 가중치는 [models](../../models/README.md)에 포함해 팀원이 pull 후 사용하도록 한다.
