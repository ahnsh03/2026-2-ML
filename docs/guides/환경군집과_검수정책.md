# 환경 표현·e-means와 검수 정책

RGB 환경 모델은9영역+전체의400열 히스토그램과 광도/색 요약을 사용한다. 환경 fit3,118장에서 적합하고 SDK 날씨·시각과 GT 표시 맥락은 학습/평가 정답으로만 사용한다. RGB 단독 재생에는 SDK 태그나 GT가 없다.

현재 군집은 **photo12·공식 e-means·20pass·K16·시드281128**이다.3시드 ARI0.74959로 안정성 기준을 통과했다. 실제 레시피의 batch64·alpha0.1893369·pass당49step과 버전/해시는 [재현 영수증](../baselines/scene_cycle_20261128/confirmation/reports/emeans_recipe.json)을 따른다. pass 수를 바꾸면 유도되는 batch/alpha까지 다시 기록한다.

| 새 확인590장 balanced accuracy | 직접 RGB 분류 | e-means 고정 의미표 | 같은 표현/K/시드 Lloyd |
|---|---:|---:|---:|
| SDK 날씨 |0.97565 |0.90674 |0.97214 |
| SDK 조명 구간 |0.98434 |0.62156 |0.57885 |
| 표시 맥락 |0.91153 |0.84889 |0.77811 |

군집은 환경 맥락·다양성 로그에 사용한다. K16개가 날씨16종이나 정확한 시각 분류라는 뜻은 아니다. e-means가 날씨 분류 전부에서 우월하지 않으며 임의 군집 ID 사이에 임계값을 복사하지 않는다. 의미표는 fit에서 고정하고 새 확인에서 다시 맞추지 않았다.

기본 검수는 RF의 근거리 오류·원거리 오류·비도로 FP 점수에 각각1/0.25/0.5를 적용한 공통 평균 가치 순위다. **검수 예산 ceil(0.1N)** 중10%를 무작위 감사로 남긴다. 환경별 임계·균형 강제·불확실성 가산을 강제하지 않았다. 공통 IoU0.7은 별도 대조이며 현재 주 정책이 아니다.

590장 중59장을 골라 근거리 오류107장 중53장(49.53%)을 회수했다. 같은 예산 무작위100회 평균은9.91%, Q0.7 대조는40.19%다. 유용한 오류 회수와 환경 분류 성적, 실제 재학습 이득은 서로 다른 결과다.

SDK05시는50장 중18장(36%),07시는4장 중0장을 회수했다. 원본의 `dawn_near_error_recall`은 과거07시 전용 이름이다. [명시 시각 감사](../baselines/scene_cycle_20261128/confirmation/reports/explicit_sdk_clock_audit.json)를 사용한다. 시계나 GT가 실제 가시성 정상의 정답은 아니며, 야간을 무조건 정상/실패로 제외하지 않는다.
