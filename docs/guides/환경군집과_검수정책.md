# 환경 군집과 동일 예산 검수

현재 품질 기준선은 **9영역·28열 GP**이며 검수 기본 대조는 `global_probability`다. 원태가 환경 표현·불확실성·검수 정책을 맡고, 승현은 같은 입력·자료 역할·재학습 연결, 재호는 원본 사례·정상 분모를 확인한다. 환경군별 기준을 최종 채택한 상태는 아니다. [최신 결과](../experiments/ROI9_GP와_26R1_검증_20261126.md) · [일정](일정과_역할.md)

## 입력의 분리

| 입력 | 용도와 현재 상태 |
|---|---|
| 품질28열 | RGB10·출력14·원본확률1·거리관계3, v3 GP/RF 입력 |
| 환경 RGB54 | 상부 위층 좌우·보닛 각18개, v2 공식 e-means 적합·고정 중심 배정 연구 |
| 날씨80·시각160 | v2 RGB 히스토그램 분류 연구. 시뮬레이터 GT 설정은 검증 라벨이며 실행 입력이 아님 |
| 위치·실제 IoU·근/원 GT recall | 학습/분할·사후 평가용. 온라인 품질·군집 입력에 넣지 않음 |

환경 표현은 [v2 명세](../../config/region_feature_recipe_v2.json)와 당시 모델·표준화·중심을 함께 사용한다. 품질은 [v3 명세](../../config/region_feature_recipe_v3.json)를 쓴다. 날씨를 잘 분류하는 것과 같은 날씨 안에서 인지 저하를 찾는 것은 다르다. 보관 주행의 GT 날씨/시각 중앙값 대조군 MAE0.12419에 비해 품질 GP0.05622였고 조건 안의 순위도 따로 검사했다. [조건 통제](../baselines/roi9_gp_20261126/condition_control.json)

## e-means의 인계와 남은 검증

v2의 RGB54는 공식 Faiss e-means K=8·16·32/3시드 비교에서 K=16을 첫 후보로 인계했다. 온라인 배정은 저장된 상수 열 제거·표준화·최근접 중심으로 수행한다. 현재 CLI는 `region_inference --recipe ...v2.json --task environment --model .../environment.npz`다. `weather`, `hour`도 v2 모델로 실행한다. [당시 선정 결과](../experiments/ROI_9영역_특징선정_20261124.md)

이번 연구에서 새 환경 특징·중심을 26R1로 재학습·검증한 것은 아니다. 다음은 원태의 과제다.

1. 같은 환경의 다른 장소가 함께 묶이는지, 같은 장소의 다른 조건이 구분되는지 확인한다. 군집 크기·위치 수·시드 ARI·배정 전환을 남긴다.
2. 새 시뮬레이터 RGB의 중심 거리·분류 성적·야간 정상 분모를 검사한다. 형상/주행상황 태그는 날씨 태그와 별도 정의한다.
3. 정상 자료가 부족하거나 중심에서 먼 군집은 공통 기준으로 되돌린다. 기본 대조군과 같은 창·예산에서 검수 이득이 있어야 채택한다.

기존 10영역 haze30 `fit-centers`는 이전 재현용이다. 현재 9영역 RGB54와 섞지 않는다. [기존 군집 코드](../../src/quality_estimation/environment_clusters.py) · [24일 명령·세부 인계 원문](../archive/가이드_20261124_원문.md#환경군집과_검수정책)

## 현재 GT 없는 검수 재생

먼저 [RGB 단독 GP 재생](ROI와_특징추출.md#gt-없는-현재-실행)을 완료한다. 아래 명령은 GT 없이 창별 후보를 만든다. 출력은 원본 경로·해시·예측·사유·모델/ROI 식별자가 있는 `candidates.jsonl`과 `run.json`, `_SUCCESS`다.

```bash
PYTHONPATH=src python3 -m quality_estimation.review_spatial \
  --replay-dir "$NEW_REPLAY" --policy global_probability \
  --window-size 64 --budget-fraction 0.1 --output-dir "$NEW_QUEUE"
```

세션을 넘어서 창을 합치지 않는다. 창마다 `ceil(비율×행수)`를 쓰므로 전체 예산은 정확히10%보다 클 수 있다. 기본은 전체 저품질 확률순이다. `global_mean`은 낮은 원시 평균 대조다. `dual_probability`, `dual_conditional`은 전체 저품질에 70% 올림, 나머지를 근거리 recall 유지/원거리 약화 진단에 배분한다. 후자는 `--model`로 같은 GP를 제공해 조건부 분산을 갱신한다. 라벨을 아직 받지 않은 후보의 평균을 가짜로 갱신하지 않는다.

모든 후보의 `admission_approved`는 false다. 원거리 확률은 **진단용**이며 자동 제외·재학습 승인에 쓰지 않는다. 별도 [GT 연결](데이터_등록과_특징정답.md#gt-없는-선별-후-정답-연결)을 거친 뒤 운행 목적·가시성 기준과 자료 노출을 검토한다.

## 실험 근거와 한계

7,339장·20반복세션의64프레임 창에서 실제805슬롯(10.97%)이었다. GP 낮은 평균638, 저품질 확률640, RF620개의 실제 IoU<0.7을 찾았다. 두 목적 확률은532개와 정상Q/원거리약화256개, 두 목적 조건부는482개와305개를 찾았다. 후자는 공간 진단을 늘리지만 전체 저품질 발견이 줄어드는 절충이다. 원거리 약화를 실패로 합쳐 높은 precision을 주장하지 않는다. [고유 위치·무작위·전체 분모](../baselines/roi9_gp_20261126/review_tradeoff.json)

새26R1 품질 학습 미사용 링크96장의 원거리 recall 명목90%구간 포함률은39.6%였다. 단순 σ로 전반/원거리 저하를 구분하는 가설도 자료마다 방향이 달랐다. 위험 순위와 확률의 보정은 다른 문제다. 근거리 recall이 높다고 오검출까지 적다는 뜻도 아니다. [GP의 범위와 다음 과제](품질모델_학습과_불확실성.md)

## 임계값·BO와 채택 기준

전체 IoU<0.7은 공통 벤치마크다. 야간·짧은 가시거리의 원거리 GT를 놓치는 현상이 운행 실패인지 별도 판단해야 한다. 환경별 정상 수준을 낮추면서 실제 근거리 누락이나 오검출을 숨기지 않도록 공통·환경 기준을 함께 보고한다.

- 절대 품질, 환경 내 상대 저하, GP 평균/확률, 무작위 감사를 같은 모집단·창·예산·중복/동점 규칙으로 비교한다.
- 별도 보정 자료에서 임계·예산 비율을 고정하고 미사용 도로에서는 조정하지 않는다. 정상 수·야간 오경보·실제 저품질 분모·누락·고유 위치를 함께 보고한다.
- 작은 임계 후보는 직접 sweep한다. 군집 보정 강도·혼합 비율 등 여러 설정이면 BO를 오프라인에서 사용하되 같은 초기 관측·횟수의 무작위와 비교한다. BO가 온라인 프레임 판단을 대체하지 않는다.
- 이번 가산 커널18회 BO는 무작위보다 좋아지지 않았다. 정책 BO의 이득까지 검증된 것은 아니다.

과거 경보 구현의 정상20장·2자세 최소조건/fallback, 849행 재생표·X56 선별은 [보존 원문](../archive/가이드_20261124_원문.md#환경군집과_검수정책), [기존23일 결과](../experiments/오프라인_검수와_동일예산_재학습_20261123.md)에 있다. 새 정책 채택에는 26R1 적용 범위를 다시 검증한다. 30일에 정책·같은 예산 표·불확실성 보정과 제한·선택 사유를 [재학습 판정](인지모델_재학습과_갱신판정.md)에 인계한다.
