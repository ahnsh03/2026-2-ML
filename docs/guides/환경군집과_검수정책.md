# 환경 군집과 동일 예산 검수

원태가 RGB 기반 환경 군집과 검수 기준을 구현한다. 27일에는 같은 개발 회차의 선택 표를 만들고, 30일에는 별도 보정 자료로 최종 정책을 고정한다. 승현은 모델·입력을 제공하고 재호는 실제 장면과 분모를 확인한다. [일정과 역할](일정과_역할.md)

## 입력과 출발점

입력은 프레임 ID·시간 순서·예상 IoU·모델 버전, GP 사용 시 σ, RGB 환경 특징이다. 실제 IoU와 시뮬레이터 날씨·시각은 사후 검증용으로 연결한다. 온라인 추출값과 실제 설정 라벨의 출처를 구별한다.

GPU 없이 먼저 시작할 때는 [849행 점수표](../baselines/offline_review_20261123/scores.csv)와 [사후 GT](../baselines/offline_review_20261123/delayed_gt.csv)를 `id`로 연결한다. `candidate` 576장과 `road` 273장은 각각 별도 모집단으로 계산한다. `roi10`은 과거 영역별 합산 모델, `gp_raw_mean`과 `gp_std`는 기존 GP의 값이다. 두 모델은 학습 조건도 다르므로 이 표는 기존 검수 재생에 사용한다. 새 RF·GP의 주 비교에는 같은 특징·학습분으로 만든 점수표를 사용한다. [전체 열 정의](../archive/전방_10영역_실험_재현.md#팀원이-cpu로-재생할-표)

## e-means 환경 표현

1. 학습 도로 RGB의 색차·다크 채널·국소 대비에서 시작하고 재호의 밝기·색상·대비 분포를 추가한다. 품질 회귀용 열과 환경 군집용 RGB 열을 각각 선정한다.
2. 상수 열 제거·표준화·중심 적합은 학습 도로에서만 수행한다. K=2·4·8, 시드 0·1·2는 기존 계획의 첫 후보다. 유망한 표현부터 비교하고 같은 표현·K·초기조건에서 KMeans 대조를 남긴다.
3. 다른 장소의 같은 조명이 함께 묶이는지, 같은 장소의 다른 조건이 구분되는지, 군집이 한곳에 몰리는지 본다. 시드 간 ARI, 군집별 프레임·장소 수, 일정 조건 주행 중 배정 전환도 기록한다.
4. 군집은 환경 태그와 검수 예산 배분·보정에 적용한다. 정상 위치가 적거나 배정 신뢰가 낮은 군집에는 공통 보정값을 적용한다. 중심 거리와 관측 조건은 서로 다른 열로 남긴다.

기존 10영역 학습 팩에서는 다음 명령으로 공식 e-means 중심을 만들 수 있다. 학습에는 Faiss의 e-means 구현이 필요하다. 고정 중심의 배정은 저장된 평균·표준편차·중심으로 실행한다.

```bash
PYTHONPATH=src python3 -m quality_estimation.roi10_study fit-centers \
  --data "$TRAIN_PACK" --method emeans --clusters 8 --seed 0 \
  --output "$ENVIRONMENT_RUN"
```

현재 명령은 고정 10영역의 haze30 표현을 사용한다. 선택한 ROI·RGB 열에 맞는 군집 입력과 직렬화 연결은 원태가 확장한다. [기존 군집 코드](../../src/quality_estimation/environment_clusters.py) · [공간·시드 평가 원문](../archive/작업단위1_주행환경_특징과_군집화.md)

## 정책 비교와 보정

| 정책 | 고정 예산에서 고르는 순서 |
|---|---|
| 무작위·기존 신뢰도 | 같은 후보와 창에서 대조군을 만든다. |
| 절대 품질 | 예상 IoU가 낮은 장면부터 고른다. |
| GP 불확실성 활용 | 동일 GP의 평균순을 기준으로, 불확실성에 배분한 장면 또는 보정한 저품질 확률의 이득을 본다. |
| 환경 내 상대 품질 | 비슷한 환경에서 통상 얻는 품질보다 낮은 장면을 우선한다. |
| 혼합 | 절대 품질·환경 내 상대 품질과 무작위 점검에 예산을 배분한다. |

실제 전체 IoU < 0.7은 공통 비교 분모다. 환경별 예상 IoU 경보값은 별도 보정 자료에서 고른다. 환경 내 이례적인 저하·근거리 누락도 보조 집계한다. 모델·정책에 같은 모집단, 시간 창, 중복 규칙·동점·무작위 시드를 적용하고 GT를 보기 전에 선택 ID를 고정한다. 미정의 정답을 고른 장면도 검수 예산에 포함한다.

기존 RGB 단독 추론에서 검수 목록을 재생하는 명령은 다음과 같다. 역할이 평가·시연인 입력은 `demonstration_only`로 구분한다.

```bash
PYTHONPATH=src python3 -m quality_estimation.review_queue \
  --inference-run "$RGB_INFERENCE" --rgb-manifest "$RGB_MANIFEST" \
  --window-frames 64 --budget-percent 10 --audit-fraction 0.2 --seed 20261116 \
  --purpose demonstration_only --output-dir "$QUEUE_RUN"
```

현재 `quality_uncertainty`는 무작위 감사 몫을 확보한 뒤 우선 선별 몫의 3/4를 낮은 GP 평균, 나머지를 큰 σ로 채운다. `environment_relative`는 군집 학습 IoU 하위 20% 기준과 현재 예상값의 차이를 쓴다. 정책 이름·정렬·기존 보정 실행은 [재생 원문](../archive/회귀학습_선별평가.md), [경보 원문](../archive/버전쌍_경보_갱신판정.md)에 있다. 새 혼합 비율과 보정한 실패 확률은 후속 비교 항목이다.

군집별 경보의 기존 구현은 정상 20장·정상 자세 그룹 2개 이상을 요구하고 부족하면 전체 cutoff를 쓴다. 공통·군집 기준을 결합한 정상 오경보 예산도 검사한다. 원태는 다른 도로에서 실제 오경보·누락을 함께 보고 이 기준의 적용 범위를 기록한다. 기존 273장에서는 공통 보정의 오경보/누락이 1/5, 조명 보정은 8/1이었다. [기존 실측](../experiments/오프라인_검수와_동일예산_재학습_20261123.md#야간-오경보를-평가할-수-있는-범위)

## BO와 결과표

저장 점수표의 소수 임계값은 직접 비교한다. 절대/상대 예산 비율과 군집 보정 강도 등 여러 변수를 함께 고를 때 BO를 적용하고 동일 초기 관측·횟수의 무작위 탐색과 대조한다. 개발 자료 안에서 정책 보정과 검증 그룹을 나눈다. 목표는 고정 예산의 실패 발견·고유 위치, 함께 확인할 제약은 정상 오경보와 근거리 누락이다. 설정과 허용 손실은 평가 전에 고정한다. [GP 커널 튜닝](품질모델_학습과_불확실성.md)

주 예산 10%, 보조 5%·20%에서 Recall·Precision, 실제 저품질 분모, 고유 실패 위치, 야간 정상 수와 오경보, 원·근거리 누락을 보고한다. risk–coverage와 AURC는 같은 정의된 전체 후보에서 계산한다. 프레임 간 의존성은 도로·위치별 재표집으로 확인한다. 전체 GT가 없을 때의 무작위 감사 모집단 추정과 그 넓은 변동 범위는 [원문](../archive/버전쌍_경보_갱신판정.md#검수한-장면만-라벨링했을-때의-모집단-추정)을 따른다.

모델·중심·보정값·입력 목록 해시, 선택 ID와 사유, 평가표·실패 사례·지연표를 넘기고 [동일 예산 재학습](인지모델_재학습과_갱신판정.md)에 연결한다.
