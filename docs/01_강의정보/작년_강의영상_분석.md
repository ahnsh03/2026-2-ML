## Lecture 11 — 불확실성 정량화·GP `[확정]` ★

이 과목에서 **가장 교수님 전공(확률 기반 추정)에 가까운 주차**다.

| 다룬 내용 | 비고 |
|---|---|
| 불확실성의 개념, 왜 중요한가 | "모델로 예측을 하는데 그것을 얼마나 믿을 수 있냐" |
| **Aleatoric vs Epistemic** | *"데이터를 100개, 1000개, 만 개를 모으더라도 이 데이터 자체가 가지고 있는 불확실성은 줄여질 수가 없습니다"* |
| Bayesian Linear Regression → **Gaussian Process** | BLR의 확장으로 GP를 도입 |
| 커널 함수 (31회 언급) | 매핑 함수를 몰라도 커널만 계산하면 예측 가능 |
| **Bayesian Optimization** | acquisition으로 **confidence bound**, **Thompson sampling** 설명 |
| Calibration | 언급됨 |
| 구현 규모 | *"GPyTorch (…) 한 100만 개 정도 데이터까지는 커버를 할 수 있는 걸로 알고 있어요"* |

> *"이 가우시안 프로세스나 베이지안 옵티마이제이션 같은 경우는 **현재 리서치 토픽에서도 연구되고 있는 분야**긴 해요."*

**시사점**: GP/UQ를 주력으로 쓰는 프로젝트는 교수님의 관심 영역 정중앙이다.
또한 GP의 데이터 규모 한계를 교수님이 이미 알고 있으므로, 서브샘플링 근거를 밝히면 자연스럽다.

## Lecture 13 — Gradient-free Optimization `[확정]`

| 다룬 알고리즘 | 비고 |
|---|---|
| Local search, random restart, simulated annealing | local optima 탈출 |
| **Genetic Algorithm** | *"지금은 제네틱 알고리즘 아무도 로봇에 사용하려는 사람이 없습니다. 이미 RL이 다 대체를 해 버렸지만"* |
| **PSO** | 교수님이 이번에 준비하며 처음 공부했다고 언급 |
| **CMA-ES** | 엘리트셋 기반 분포 갱신 |
| **MPPI** | ★ *"**자율주행에서 많이 사용되는 알고리즘**"* — 코스트 기반 softmax 가중평균으로 설명 |
| Grid search vs **Random search** | random이 나은 이유를 길게 설명 |

**시사점**: 교수님이 자율주행 맥락(MPPI)을 강의에서 직접 사용한다. 우리 주제의 언어가 통한다.
