## 2. MetaSeg — IJCNN 2020, preprint 2018

[논문](https://arxiv.org/abs/1811.00648): Prediction Error Meta Classification in Semantic Segmentation.

- 확률 분포의 entropy/확률 차이, 예측 segment의 크기·경계·내부 특징을 사용한다.
- 예측 segment의 adjusted IoU가 0인지 분류하고 IoU를 회귀한다. 프레임 IoU<0.7과는 다른 정답이다.
- 확인 파일: `metrics.pyx`의 `entropy`, `probdist`, `compute_metrics`;
  `metaseg_eval.py`의 `fit_model_run`, `metrics_to_dataset`; `metaseg_io.py`.
- **중요:** 원본 `compute_metrics(probs,gt)`는 특징과 정답을 함께 만들고
  `prediction(...,ignore=True)`에서 `gt==255`를 사용한다. 우리 배포용 특징은 GT 없이
  component를 만들고 기하 마스크만 적용하도록 분리한다. IoU/GT 유래 열은 입력에서 제외한다.
- 원본 Python 3.4/오래된 sklearn/Cython 환경의 정확 재현을 첫 목표로 삼지 않는다.
- 우리의 global/ROI 요약 특징은 MetaSeg-inspired adaptation이다. 원본 component의 adjusted IoU와
  일반 frame IoU를 같은 숫자로 비교하거나 원 논문을 재현했다고 부르지 않는다.
- 완전히 누락된 객체는 예측 segment가 없으므로 빈 예측·고정 ROI 특징으로 보완하되 검출 보장은 없다.

## 3. Küchler 등 — 2024

[논문](https://arxiv.org/abs/2401.09245): Uncertainty estimates for semantic segmentation:
providing enhanced reliability for automated motor claims handling.

차용: 크기·클래스·불확실성 특징의 단계적 비교, 간단한 분류기와 XGBoost의 비교.
원래 자동차 외장 부품 segment의 **precision>0.5** 분류이며 차선 ROI IoU가 아니다.
원 논문의 gradient 특징은 내부 activation/gradient가 필요하므로 출력+RGB 통계 기반 핵심 실험에서 제외한다.
낮은 품질 segment 삭제는 precision을 높여도 recall을 떨어뜨릴 수 있어 우리 방법에 바로 적용하지 않는다.
공식 논문 전용 공개 저장소는 이번 검색에서 **확인하지 못했다**. 존재하지 않는다고 단정하지 않으며
임의의 GitHub를 공식 코드로 표기하지 않는다. MetaSeg 코드와 논문을 참고해 필요한 비교를 구현한다.

## 4. SEE — ISCAS 2026

[공식 초록](https://epapers2.org/iscas2026/ESR/paper_details.php?paper_id=2485),
[DOI](https://doi.org/10.1109/ISCAS66217.2026.11562804).

차용: 이미지별 mIoU를 Random Forest로 회귀하는 문제 설정과 출력 불확실성 결합.
원래 energy/entropy 외에 NIQE, 별도 autoencoder 재구성 PSNR을 쓴다.
SEELIGHT는 재구성 branch를 제외한다. 우리는 출력 특징에 원본 RGB 밝기·대비·경계 통계를 더한다.
NIQE·별도 autoencoder를 그대로 쓰는 계획은 아니므로 SEE/SEELIGHT 정확 재현이라고 부르지 않는다. Energy는 raw logits가 있어야 하며 argmax/확률 PNG에서 역산하지 않는다.
공식 공개 레포와 재현 가능한 세부 파라미터는 이번 검색에서 **확인하지 못했다**.
초록·기관 publication 기록을 확인했으며 논문 전체 구현을 확인한 것처럼 설명하지 않는다.

## 5. TCSR-Monitor — UNSURE @ MICCAI 2026 워크숍

[논문](https://arxiv.org/abs/2608.16748), [원문](https://arxiv.org/html/2608.16748v1).

차용 우선순위는 검증 protocol이다. 학습하지 않은 열화 조건, 같은 열화 조건 안의 성공/실패 구분,
점수 학습과 경고 임계값 설정의 분리를 참고한다.
확인 코드: `src/tcsr/features/{confidence,shape,temporal,build}.py`,
`src/tcsr/monitor/{classifiers,train}.py`. 출력 형태·과거 마스크 변화는 선택 실험으로 차용한다.
원본 RGB의 밝기·어두운 픽셀·대비·경계 통계는 최신 발표의 기본 입력이다.
TCSR의 RGB branch 전체·foundation embedding·GRU·conformal calibration을 재현하는 것은 필수 범위가 아니다.
움직이는 차량의 단순 이전 mask IoU는 정상 ego-motion에도 바뀌므로 그대로 실패 정답으로 쓰지 않는다.

의료 영상·합성 열화의 워크숍 연구다. 원문의 오경보·모델 전이 한계와 시간 의존성에 따른 보장 한계를
함께 기록한다. README의 coverage/transfer 문구를 우리 주행 안전 보장으로 인용하지 않는다.
코드를 클론했다는 사실은 해당 결과를 재현했다는 뜻이 아니다.

## 7. 이번 프로젝트의 결합 방식

11월 16일의 X56 기준선은 `출력 불확실성·형태 + RGB 통계 → 전체/3행×2열 ROI 특징 → IoU 회귀 → 조건 평가 → 검수 순위`다. 11월 23일부터 전방 고정 10영역으로 정밀도·누락 면적을 추정하는 모델을 병행한다. [10영역 근거와 결과](../project/전방_10영역_특징과_품질추정_20261123.md)
공식 코드 4종과 논문 2종을 모두 같은 방식으로 재현하는 과제가 아니다.
기본 모델 비교는 Least Squares(OLS)/Ridge/Random Forest, 데이터는 MORAI, 입력은 M v6 출력+원본 RGB 특징이다.
[최신 설계](../project/프로젝트_확정설계_20261103.md)의 단일 통합 Lane IoU·MAE·예산별 Recall을 우선한다.
최신 논문 차용의 의미는 더 큰 모델을 쓰는 것이 아니라 **어떤 정보를 더할지와 어떤 일반화 주장을 검증할지**다.
