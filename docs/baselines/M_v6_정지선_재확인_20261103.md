# TwinLiteNet+ M v6 — 정지선 학습 이력 재확인

> 모델 검증: 2026-11-03 · 원본 config·18행 history·result·checkpoint SHA를 직접 대조했다.
> 프로젝트 적용 계획: 2026-11-16에 최신 ML 발표 기준으로 갱신. 검증 수치·해시는 보존한다.
> **M v6는 정지선을 포함해 본학습을 완료했다.** 이전에 v5 binary 모델만 확인해 M 전체가
> 정지선을 출력하지 않는다고 설명한 것은 잘못이다. 이 문서가 이전 M 클래스 설명보다 우선한다.

| 항목 | 확인 결과 |
|---|---|
| 크기 | Medium, 479,060 parameters |

| drivable 클래스 | background / drivable |
| road_marking 클래스 | background / white_lane / yellow_lane / stopline |
| 과거 학습 데이터 | train 26,001 / val 1,404 이미지, front·left·right |

| 초기화 | v5 M의 EMA에서 공통 가중치 이전, 노면표시 head 초기화, optimizer/scheduler reset |
| 최신 계획의 고정 대상 | best_mean, 선택 epoch **11**. 18은 완료한 학습 epoch 수 |
| checkpoint SHA256 | `a26311b3af4e92880f632509eff3c81defc1b95135f5b463c7a08e5b6e23d24b` |

정지선을 추가하기 위해 새 M을 처음부터 학습해야 하는 상황은 아니다.
11/4 ML 발표의 최신 계획은 이 가중치를 품질 추정 대상 f0로 고정한다. 새 품질 추정기는 전방만 사용한다.
과거 인지 모델이 전방만으로 학습됐다고 설명하지 않는다.

**best_mean epoch 11의 과거 validation 누적 교집합/합집합 IoU**다.
frame별 IoU의 평균이나 새 독립 test 성능이 아니다.

| 클래스 | 3뷰 전체 | 전방만 |
|---|---:|---:|
| drivable | 98.34% | 97.75% |
| white_lane | 87.86% | 77.69% |
| yellow_lane | 93.28% | 86.19% |

원본 validation의 노면표시 3개 foreground class 평균은 89.56%다.
발표에서는 이번 과제 범위에 맞게 전방 수치를 우선 보여준다.
클래스별 평균만으로 장면별 실패의 빈도·환경 원인을 주장하지 않는다.
숫자는 [근거 JSON](medium_v6_baseline_evidence.json)에 별도로 보존했다.

10월의 다른 해상도·데이터 버전 재평가도 존재한다. 그 수치를 위 학습 validation 수치와 섞지 않는다.
기존 v5 그림의 lane IoU 0.165/0.940, 89/468 사례를 v6 결과로 재표기하지 않는다.

## 품질 모델 입출력에 반영할 점

최신 기준은 `5_IsTrue_v2.pptx` 슬라이드 9~14와 발표자 노트다.

```text
전방 RGB → 고정 M v6 → 확률·형태 특징 ─┐
원본 RGB → 밝기·대비·경계 특징 ────────┤ 전체 + 3행×2열 ROI → X
학습·평가 때: white/yellow argmax 합집합 + Semantic GT → 프레임 Lane IoU y
X/y → Least Squares·Ridge·Random Forest 비교 → GT 없는 예상 Lane IoU → 검수 순위
```

- 노면표시 예측은 multiclass argmax를 기준으로 정의한다. 각 클래스를 독립 이진 threshold로 겹쳐 만들지 않는다.
- 흰·노란 차선 합집합을 회귀 정답으로 사용한다. argmax class가 white 또는 yellow인 마스크와
  `p_white+p_yellow≥0.5` 마스크는 같다고 가정하지 않는다.
- background와 stopline은 통합 Lane 마스크에서 0이다. 기본 회귀 정답은 프레임 Lane IoU 하나다.
- 인지 모델의 정지선 출력·과거 평가 근거는 유지한다. 도로·정지선·ROI별 IoU 회귀는 이번 필수 범위가 아니다.
- union=0은 undefined, union>0의 완전 누락은 IoU=0이다. 품질 추정치를 주행 안전도나 정지 위치 정확도로 해석하지 않는다.

기존 `quality_contract_v1.json`과 14/30/78개 특징·의미 영역 ROI·binary 정책은 **v5 초안 이력**이다.
[최신 입출력 계획](../contracts/품질추정_입출력규약.md)과 [비실행 계획 JSON v2](../contracts/quality_plan_v2.json)를 따른다.
11/16 후속 작업에서 ML 기본 로더·시각화를 M v6로 연결하고 56차원 특징·IoU 정답 정의를 고정했다.
회귀 학습·선별·제한된 인지모델 갱신과 예약한 주 최종 평가를 실행했다.
RGB 단독/paired 특징과 ML 내부의 정답 생성/평가 일치는 확인했지만, 과거 외부 학습 runtime 전체와의 동일성을 인증한 것은 아니다.
현재 결과와 기존 조건 성능 감소는 [실험 결과](../experiments/품질추정_실험결과_20261116.md)를 따른다.
근거 JSON의 학습 미실행·스키마 미확정 상태는 11/3 검증 당시 기록이며 현재 완료 상태를 뜻하지 않는다.
실제 원본 경로는 공개 저장소 밖의 로컬 자산 대응표에 기록한다.
