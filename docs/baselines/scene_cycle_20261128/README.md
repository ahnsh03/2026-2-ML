# 표시 가용성·누적 갱신 공개 근거

[개발·선별 중간 근거](development/README.md)는 새 Dev/Cal과 동결 은행의 사후 GT 감사다. 새 독립 확인과 장시간 인지 재학습의 최종 결과로 읽지 않는다. 현재 진행과 최종 판정은 [실험 기록](../../experiments/표시가용성_누적갱신_20261128.md)을 따른다.

원본·학습 가중치·전체 특징 팩은 실험 볼륨에 보존한다. 공개 집계에서는 개인 경로를 별칭으로 치환하며 원본 보고서 SHA와 공개 사본 SHA를 함께 기록한다. 그림과 사진은 실제 새 개발 수집 자료로 만들었으며 GT는 source target에서 검증했다.
