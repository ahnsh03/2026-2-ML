## 추가 진단: GP의 근−원 오류 대비

새 확인의 근·원 동시 오류99장 대 근거리 유지·원거리 오류342장에서 Q GP σ의 AUC는0.46813, GP 오류 가치 σ는0.63518이었다. GP/RF 평균 차이는0.87790/0.87731이었지만, GP의 `μd=μnear−μfar`, `σd²=Σnn+Σff−2Σnf`를 함께 쓴 `z=μd/σd`는0.92808이었다. σ 크기만의 실패 판정보다 **근/원 오류 관계의 사후 대비**가 유망한 단서다.

이 z는 별도로 동결한 **GP-only 오류GP74**의 값이다. 현재 RF74 오류 head는 GP 잠재 SD를 제공하지 않으므로 기본 Q GP의 σ와 섞거나0으로 나누지 않는다. 오류GP74와 주 RF74의74개 순서 있는 입력은 실제 manifest에서 같음을 확인했다. 같은 GP74의 평균 대비→자기 SD 정규화 비교와 RF/GP 패밀리 대조를 구분한다.

이는 확인 개봉 후 추가한 설명용 진단이다. 확률 보정·임계 선택·새 selector 채택은 하지 않았다. 두 조건부 오류 집단 밖으로 일반화하지 않으며, Gaussian z를 실제 실패 확률로 읽지 않는다. 새 Dev/Cal과 새 확인에서 데이터 선별 이득을 검증할 과제다. 기본 RF74 평균 가치·감사10%·GP 정보 슬롯0과 r2 채택은 바꾸지 않았다. ## 이번 비교의 순서

1. **자료와 검수 목표:** Q와 표시 가용성·근거리 FN/FP·미지원 사유를 분리한다. 무출력을 일괄 제외하지 않는다. 기존 자료에서 새벽·무표시 지원을 확인하고, 학습에 편입한 과거 진단/확인은 시험 지위를 명시적으로 폐기한다.
2. **누적 학습:** 새 후보2,048장을 먼저 환경별로 선별한다. 원본26,001장과 부모가 이미 학습한3,072장을 모두 replay에 보존한다. 부모에서 출발하고 새 은행에 과거 노출 프레임이 섞이지 않도록 [누적 계보 검사](../../src/quality_estimation/adaptation_lineage.py)를 적용한다.
3. **방법 결정:** 고정9영역에서 RF·GP와 검수 가치 목표를 같은 역할·예산으로 비교한다. GP SD는 실패 자체로 해석하지 않고 잔차 보정·보류/감사 예산에서의 이득을 검증한다. 환경 분류·군집 해석·데이터 선별 이득을 따로 판단한다.
4. **BO·군집:** 공식 구현·논문 기준 BO를 동일 예산 무작위와 비교하고 합집합에서 후보를 고른다. BO와 e-means는 실제 이득이 있을 때만 채택한다. 시뮬 환경 태그는 오프라인 대조/정답이며 RGB 없는 온라인 입력으로 사용하지 않는다.
5. **새 확인과 갱신:** 모델·특징·기준을 먼저 고정하고 새 장면/날씨의 독립 확인을 연다. 인지모델의 채택과 검수 정책 채택을 따로 기록한다. 가중치가 바뀌면 X/y·품질모델·보정·정책도 새 버전으로 만든다.

## 재현과 현재 구현

[누적 학습기](../../src/quality_estimation/retrain_streaming.py)의 `--parent-adaptation-run`은 프로토콜에 고정한 부모 신원과 전체 부모 학습 구성원을 검증한다. 새로운 은행의 기존 ID/픽셀 재사용, 부모 replay 누락/변조, resume 시 부모 변경을 거부한다. 기존의 같은v6 출발 비교 경로는 유지한다. 현재40/50 두 의존성 이미지에서 CPU312검사가 통과했다. 실제5070Ti에서 부모 신원을 연결한8-step 역전파를 확인했고, 이 smoke 가중치는 채택 후보에서 제외했다. 장시간 학습·새 독립 확인 결과는 실행 뒤 추가한다.

## 검수 목표와 GP의 역할

[지원 오류 목표](../../src/quality_estimation/review_targets.py)는 전체 white/yellow 차선 IoU와 분리한다. 패딩을 제외한 평가 격자640×360 기준 GT50픽셀 이상에서 recall0.8 미만이면 FN, 예측50픽셀 이상에서 precision0.8 미만이면 FP로 정의한다. 근거리 오류·원거리 오류·도로 밖 FP를 각각 학습하고 검수 가치 가중치는1/0.25/0.5로 사전 고정했다. 이는 이번 실험의 공학적 정의이며 안전/정상 판정 기준이나 논문의 권장 수치가 아니다. 오류0은 이 정의에서 지원되는 오류 근거가 없다는 뜻이다. 무출력의 실제 FN과 무표시 구간의 FP는 제외하지 않는다.

[RGB 장면 모델](../../src/quality_estimation/scene_environment.py)은 표시 가용성의 **추정치**와 환경 맥락을 제공한다. GT 표시 유무를 온라인 입력으로 넣지 않는다. 가용성 분류가 틀릴 수 있으므로 이를 이유로 근거리 FN 후보를 일괄 제거하지 않는다. SDK시각 분류와 관측 밝기 구간도 구분한다. 개발/보정은07시/13시/20시를 반복 수집했고, 최종 확인에는05시도 사전 추가했다. 시각 자체를 실제 어두움의 정답으로 간주하지 않는다.

GP 오류 출력의 선형 결합은 `mu_u=w^T mu`, `var_u=w^T Sigma w`로 전파하고, 근거리−원거리 오류 점수의 공분산도 보존한다. 이 점수는 Gaussian 회귀 근사이며 보정된 이항 실패 확률이 아니다. [검수 선택기](../../src/quality_estimation/support_review_selection.py)는 예측 오류 우선·불확실성 검수·무작위 감사를 구분한다. 조건부 분산 방식은 먼저 고른 프레임을 조건으로 놓고 중복도가 낮은 추가 프레임을 선택한다. 실제 라벨을 보지 않고 계산하며, 이것만으로 추가 모델 갱신을 수행한 것은 아니다. [GP 정보 선택 원논문](https://www.jmlr.org/papers/v9/krause08a.html)에서 동기를 얻었으나 센서 배치 목적과 이 실험의 검수 목적이 다르므로 논문의 근사 보장을 주장하지 않는다.

[버전별 실행 번들](../../src/quality_estimation/support_aware_review.py)은 Q/오류/환경/보정/정책과 인지 가중치의 해시를 검증한다. 실제40프로파일 CPU에서 RGB48장→특징→품질·오류 추정→24장 검수까지 GT 없이 완료했다. 여기에는 우선20장·조건부 정보 검수2장·무작위 감사2장이 포함된다. 시험용 번들이며 자동 학습 편입이나 라이브 ROS 완료를 의미하지 않는다.

## BO와 군집의 중간 판단

[공식 BoTorch 기본 구성](https://botorch.org/docs/getting_started)의 `SingleTaskGP`·LogEI와 기존 고정 Matern EI를 무작위와 비교했다. 각 모델8쿼리·공통 초기4점·3시드를 맞추고, 최종 모델은 실제 평가한 방법들의 합집합에서 선택했다. [실용 BO 원논문](https://papers.nips.cc/paper/2012/hash/05311655a15b75fab86956663e1819cd-Abstract.html), [LogEI 수치 안정화 원논문](https://papers.nips.cc/paper_files/paper/2023/file/419f72cbd568ad62183f8132a3605a2a-Paper-Conference.pdf)을 참고했다. 두 BO 모두 이번8모델에서 평균 개선0.001·3시드 중2회 우세라는 채택 기준을 만족하지 못했다. 이 작은 탐색 공간/예산에서 이득이 없다는 결과이며 BO 일반의 무효를 뜻하지 않는다. 후속 갱신의 기본 탐색에는 넣지 않는다.

[공식 e-means](https://github.com/facebookresearch/faiss/blob/main/contrib/e_means/README.md)는 RGB400열 PCA16, 교차적합 환경/표시확률11열, 환경/표시확률+관측 광도12열에서 Lloyd와 비교한다. 환경 분류 성능·군집의 시드 안정성·동일 예산 검수 효과를 따로 기록한다. 같은 표현의 Lloyd보다 불리한데도 e-means를 강제 채택하지 않는다. 최종 표현·군집·검수 기준은 새 개발 자료 결과 뒤에 추가한다.

## 자료 역할과 실행 중 제한

이미 개봉한 이전 확인618장은 이번 fit으로 전환하고 새 시험으로 재사용하지 않는다. 표시/무표시 구간은 모델 예측 전 scout의 GT지원량으로 사전 확인했으며 scout 프레임은 fit/Dev/Cal/test에서 제외한다. 새 프레임의 멤버십은3m XY thinning만 사용한다. 같은 지도 내 구간 분리이며 새 도시나 시야 완전 독립은 주장하지 않는다.

새 Dev54조건994원본 중334장을 동결했다. fit좌표 최소거리29.28m, 원래 인지학습 좌표에 대한 최소거리28.99m이며 파일3,976개를 해시 검사했다. 유효 주행의 최대속도1.565m/s·최대CTE0.281m였다. Cal36조건637원본 중223장과 새 학습 후보24조건424원본의 수집·등록도 완료했다. 새 확인96조건은 최종 후보 동결 뒤 실행한다. 원본 alpha 채널은 기존 입력 로더와 동일하게 제거하고 RGB 픽셀 해시는 별도로 계산한다.

GPU 학습과 시뮬 주행을 동시에 실행하면 UDP상태가 stale해지는 경우가 반복되어 각 실패를 중단/복원했다. 같은 조건에서 학습을 일시 정지한 주행은 정상 완료되어 수집→학습 순서로 자원을 분리했다. 학습 wall time에 정지 시간이 포함되므로 실제 update 수와 일시정지 구간을 함께 보고한다. 실패한 부분 등록과 로그도 보존한다.

## 새 개발 자료의 중간 결과 — 독립 확인 전

같은 부모 인지 버전에서 새 Dev334장·Cal835장(이전612+새223)을 사용했다. Q와 오류 선별은 다른 목표이므로 각 head를 따로 비교했다. 아래 결과는 개발 선택이며 새 확인 성적이 아니다.

| Q 입력 | GP road-macro MAE | RF road-macro MAE |
|---|---:|---:|
| 기존 env52 |0.04559 |0.05236 |
| 도로 밖·원거리 출력 보강74열 |**0.04245** |0.05148 |

검수10%는34장이다. 공통 지원 오류 가치의 RF74 head가 근거리 오류45장 중31장(68.89%)을 회수했고 도로별 recall은0.74134였다.100회 무작위는 평균10.44%·도로별0.10289였다. FN회수73.53%와 FP회수61.54%를 따로 집계했다. 세 구간 모두에서 지원 오류가 있었다. 07시에는 이번 정의의 근거리 오류 양성이 없어 새벽 recall은 미정의로 둔다. 이를0이나1로 채우지 않는다.

Q는 GP74, 오류 선별은 RF74가 개발 후보가 됐다. GP 오류 head의 최고 도로별 검수 가치 회수는0.2920, RF는0.3958이다. GPσ를 더한 정책은 최고 공통 평균 점수를 개선하지 못했다. 두 GP의 σ로 근/원 동시 오류를 구분하는 AUC는 약0.45–0.46이어서 ‘σ가 높으면 전반적 오류, 낮으면 원거리만 오류’ 가정은 지지되지 않았다. Q-GP의 경험 구간은 제공하되, 오류σ를 직접 우선순위에 넣는 선택은 보류한다. 근−원 평균 대비는 별도 진단이며 낮은 σ만으로 정상 판정하지 않는다.

환경만으로 만든 평균 검수 가치 대조도 수행했다. RGB군집 평균 대조의 도로별 회수0.2354와 시뮬 날씨×조명 평균 대조의 최고0.2163보다 개별 RGB/인지 출력 RF head가 높았다. 같은 Dev에서 고른 연구 비교이며 새 도시 일반화나 재학습 이득의 증명은 아니다.

실제40프로파일 CPU에서 새 RGB334장을 GT 없이 재생해 같은34장 **선택 순서까지** 재현했고, 이후 원본바이트·디코딩픽셀·버전 검증을 통과한 GT를 연결했다. 실제 RGB 재생 Q MAE는0.04255였다. 원본 Semantic을 온라인 입력으로 사용하거나 자동 입학시키지 않는다.

환경 직접 분류의 Dev balanced accuracy는 날씨0.9576·SDK조명0.9357·표시맥락0.8257이다. 5-pass e-means photo12/K16의 ARI0.6923이 안정성 기준0.7에 못 미쳐, 같은 fit에10/20-pass를 별도 실험했다.20-pass/K16의 ARI0.7496, 대표 시드의 날씨·표시·관측광도 평균 점수0.8286으로 Lloyd/K16의0.8257보다 근소하게 높았다. 날씨 자체는 e-means0.8859/Lloyd0.9424로 trade-off가 있으며, e-means가 모든 환경 분류에서 우월하다는 결과가 아니다. 시드는 결과를 보고 교체하지 않았다. 이 맥락 표현으로 검수도 다시 비교했지만 공통 오류 우선 정책이 그대로 선택돼 환경별 임계를 강제하지 않았다.

추가 학습 후보 수집24조건424장을 마쳤다. 기존 미노출4,370장과 합친 풀에서 GT 없는 특징만으로2,048장을 고르고 환경/출처 수를 맞춘 Random과 비교한다. 이 은행의 비율은 검수 성능 평가의10%와 다르며 실제 값은 동결 선별 영수증에 남긴다. 원본26,001+기편입3,072의 전체 replay는 보존한다. 수집 완료 후 일시 정지한 GPU 학습을 재개했다.

## 새 확인의 사전 고정

인지 후보는 원래v6에 대한 유지 기준과 부모r1에 대한 새 Dev 개선 기준을 함께 통과해야 한다. CPU FP32 선택 뒤 실제5070Ti의 같은 자료 FP32로 다시 확인한다. 선택된 인지 가중치로 X/y·RF/GP·Cal·정책을 다시 만들고, 그 뒤 새 확인96조건을 수집한다.

11월28일14:00KST, 확인용 모델/정책 동결과 어떤 확인 수집도 하기 전에 원래72조건 계획을96조건으로 확장했다. 개발 사진의07시가 상당히 밝아, 네 유효 구간·6날씨 모두에05시를 더해 실제 새벽 범위를 보완하기 위해서다. 원래 계획/설계의 바이트·해시는 별도로 보존했다. 학습/Dev/Cal 멤버십, 경로 기하, 인지·검수 채택 기준은 그대로다. 최종 설계와 수집 계획 SHA의 일치도 번들 동결 전에 검사한다.

확인 전7개 번들을 고정한다. 주 정책, RF-only, GP-only, GP 조건부 정보 검수, Q0.7 공통 기준, 부모r1 정책과 같은 표현/K/시드의 Lloyd 환경 대조다. 가족/불확실성/군집 대조가 시험에서 더 좋더라도 주 정책을 사후 교체하지 않는다. 인지모델과 검수 정책의 채택은 별도로 판정한다.

인지 확인에는 미리 선택한 채택 후보 외에도, 같은 부모·환경 수·전체 replay·18,000update의 Risk/Random 원시 endpoint를 동결해 함께 평가한다. 이는 새 구간에서 데이터 선별 효과를 추정하기 위한 대조이며, 확인 결과를 보고 더 좋은 모델을 사후 채택하는 후보 풀이 아니다. 한 학습 시드의 결과와 조건 블록 bootstrap을 반복 학습 검증으로 확대 해석하지 않는다.

`assess_environment_context.py`는 fit에서 정한 군집 의미표를 그대로 사용한다. 직접 RGB 분류와 군집의 날씨·SDK시각·표시 맥락·관측광도 성적을 나눠 보고한다. 관측 밝기 구간은 이미지 측정값이며 시각 예측 정답이 아니다. 군집에 대한 의미 설명과 같은 예산 검수 이득도 별개의 결과로 남긴다. 이 절차 보완은 최종 모델/정책 동결·새 확인 수집 전에 기록했다.

## 첫 누적 후보의 개발 점검 — 최종 선택 전

Coverage24k 원시 후보는 새 표시 구간2개 평균 IoU0.79315로 부모0.78979보다0.00336 개선됐고 원래v6 유지 기준도 통과했다. 보간0.95/0.9/0.8은 개발 개선 기준에 미달했다. 이는 개발 비교이며 새 확인 통과나 채택을 뜻하지 않는다. 같은334장의 근거리 FN/FP 프레임은 원래v6가84/7, 부모r1이34/13, Coverage가34/15였다. Coverage의 pooled 근거리 precision/recall은0.98673/0.86721로 부모0.98599/0.86404보다 조금 높았다. 픽셀 지표와 임계 기반 프레임 수는 다른 지표이므로 하나만으로 일률적인 개선을 주장하지 않는다.

Coverage의 X/y·Cal·8개 RF/GP head를 다시 적합하니 Q는GP52(MAE0.04654), 오류는RF74가 선택됐다. 같은52열의 RF MAE는0.05169였다.74열은 GP0.05568/RF0.05248로 오히려GP가 불리했다. 부모의GP74 우세를 새 가중치에 그대로 적용할 수 없다는 개발 근거다. 오류σ의 선별 이득은 여전히0으로, 기본 정책은 평균 오류 가치+10% 무작위 감사다. 새 오류47장 중31장을 회수했으며, 양성 분모도 인지 버전과 함께 바뀌었음을 기록한다.

이 후보는 CPU로 미리 계산한 별도 산출물이다. 최종 인지 선택이 정확히 같은 가중치일 때만 모든35개 모델/입력/소스 해시를 확인해 재사용하고, 다른 가중치가 선택되면 새로 적합한다. 실제40프로필 CPU의 RGB334장 재생에서 동일34장·순서를 재현했고 최대 Q 예측 차이는2.30e−6이었다. 이후34장의 원본 GT 바이트·픽셀·버전을 확인했다. Q52/오류74처럼 서로 다른 부분집합도 입력 합집합74열에서 올바르게 분리됐다.

07시114장 중 근거리 GT지원77장의 FN은 v6에서10장, 부모/Coverage에서0장이었다.07시 자체를 어두운 새벽이나 정상의 정답으로 부르지 않는다. 원거리 FN 지시값은 세 모델 모두225장이지만 pooled recall은0.30838→0.39356→0.39652로 개선됐다. 고정0.8 지시값에 변화가 없다고 원거리 픽셀 성능이 같다고 설명하지 않는다. 이 개발 자료의 원거리 정상/오류 변동이 제한적이므로 σ로 오류 유형을 나눈 결과도 다른 상황 전체에 일반화하지 않는다.
