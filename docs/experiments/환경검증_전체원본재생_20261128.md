## 보류의 핵심: 낮은 IoU와 검수 가치가 달랐다

**온라인 이행·버전 쌍 교체를 보류한다.** 3개 확인 구간 중 Road1/2는 근거리 GT가 전혀 없는 무표시 구간이었다. 전체 GT 중앙값도75/43픽셀로 원거리의 작은 표시가 대부분이었다. Road3는 전체2,169.5/근거리1,906픽셀 중앙값의 노면표시 구간이다. 수집 실패로 영상을 버리지 않고, 이 장면들이 기존 검수 정책의 약점을 드러내는 음성 사례임을 보존한다.

고정한62장 검수는 Road1/2/3에22/37/3장을 썼다. **59장은 근거리 precision/recall 진단을 지원하지 않았고, 실제 근거리 결함114장은 한 장도 회수하지 못했다.** 무표시 구간에도 근거리 오검출43장(36+7)이 있었지만 모두 놓쳤다. 낮은 IoU precision95.16%만으로 선별에 성공했다고 말할 수 없다. 도로 평균 recall9.54%는 무작위 평균10.15%보다 낮아 사전 검수 기준도 실패했다. ## 기존 데이터는 어떻게 포함했는가

v6 체크포인트 내부 train-manifest SHA와 실제 **26,001장** 목록이 일치한다. 전·좌·우8,667장씩이며 초기4묶음14,145장+후속8묶음11,856장이다. 이전4,096장은 완전 무작위가 아니라 묶음×시야별 비슷한 할당과 시간순 균등 간격 추출이어서, 원본에서 약32%인 큰 묶음을 약8.3%로 줄였다. 원본 날씨·시각의 직접 기록이 모두 복구되지는 않아 파일명이나 PC 시각으로 환경 정답을 만들지 않았다.

이번에는 **원본 전체를 공통 풀로 보존**하고 순열을 반복했다. 원본 각 장은12–13회, 신규3,072장은15–16회 제시되며 묶음 구성 총변동은0.00018 미만이다. 원본 전용 대조는14–15회다. 이는 동결 sampler와 실행 draw 영수증의 재구성이며 실제 이미지 읽기 telemetry는 별도 검사다. 두 헤드 정답·패딩은 원래 학습 버전과 모든 캐시를 비트 단위 대조했다. 원본 복사 없이 공통 캐시를 공유했다. ## 같은 v6에서 시작한8회 비교

모든 학습은 같은 Medium v6 EMA,24,000업데이트, 신규2+원본14의 배치16을 사용했다. 원본 전용 대조는0+16이다. AdamW LR1e−5→1e−6, warmup200, 고정BN moments, 원본 teacher KL0.25/T2, BF16 forward/FP32 loss를 공유했다. affine은 학습했다. 원본 풀과 배치 비율을 함께 바꿨으므로 직전 실험과의 차이를 어느 한 변경의 효과로 단정하지 않는다.

환경 균형 bank는 가용 날씨×조명18그룹의 균등 할당이다. 장수가 적은3그룹은50/79/81장에서 포화되어 남는 슬롯을 재분배했고, 나머지는190–191장이다. 따라서 날씨·조명 주변분포를 완전히 균일하게 만들었다는 뜻은 아니다. 신규 목록은 중복 없는3,072장이며 원본 풀은 별도로 그대로 보존했다.

4방법1차를 비교한 뒤 Random과 유망 비무작위 상위2방법을 반복했다. 실제 반복은 RandomFull, GPGlobalFull, TagBalancedFull다. 이 적응 배분은 Random/균형 첫 Dev 이후, RF/GP 첫 Dev와 모든 새 확인 개봉 전에 기록했다. 같은 신규 은행을 두 최적화 시드로 반복했으며 은행 자체를 다시 추출한 반복은 아니다. 원본 전용 대조는1시드다.

## 환경이 잘 분류되었는가

지역 RGB 블록의 최소 밝기·대비·hue·채도10-bin을9영역+전체 화면에서 추출한400열이다. [Roser·Moosmann2008](https://www.mrt.kit.edu/z/publ/download/Roser_al2008iv.pdf)의 측정량에서 출발한 적용 변형이며 원 논문의13ROI·5측정량·SVM을 그대로 재현한 것은 아니다. [Cheng 등2018](https://doi.org/10.1109/IVS.2018.8500385), [Lu 등2014](https://openaccess.thecvf.com/content_cvpr_2014/papers/Lu_Two-Class_Weather_Classification_2014_CVPR_paper.pdf)의 환경 문맥·하늘/반사/색 단서도 후보 설계 근거다.

기존 RGB27+e-means의 이동 Dev 날씨/조명 balanced accuracy는0.7316/0.8992였다. 개선한 RGB400 감독 분류 확률의 제곱근9차원을 [공식 Faiss e-means](https://github.com/facebookresearch/faiss/blob/main/contrib/e_means/README.md)로16군집화했다. 이동 Dev1.0/1.0, 시드 ARI약0.946이었다. 같은 표현의 Lloyd도 Dev1.0/1.0, 시험한 대각 GMM 한 설정은0.714/0.689였다. 표현 개선과 군집 알고리즘의 우세는 구분한다.

새 확인의 직접 RGB 날씨/조명 balanced accuracy는 **0.91212/0.69858**, 군집 매핑은 **0.90109/0.67920**다. 직접 태그 기준=미통과, 군집 해석 기준=미통과다. **감독 RGB 표현+비지도 양자화**이며 label-free 날씨 발견이나 e-means의 Lloyd 대비 정확도·속도 우세를 주장하지 않는다.

## 환경별 임계와 BO가 선별을 개선했는가

Cal에서 최소30행·2도로·10공간 셀의 지원을 검사하고, 분위수와 축소·균형 예약·SD 탐색·근거리 양호 표본 참조 여부를 조절했다. 부족한 그룹은0.7로 돌아간다. 정확한 시뮬 날씨×조명/조명과 RGB 날씨/조명/태그/e-means를 Dev BO16회와 같은 예산 무작위16회로 비교했다.10%/25%/41.3% 검수 목적의 대리 최적화이며 딥러닝 재학습 성능을 직접 BO 최적화한 것은 아니다.

## 환경 정보만으로 충분한지 확인하는 대조

[고정한 환경 평균 대조](../baselines/environment_cycle_20261128/reports/fresh_context_controls.json)는 각 버전의 GP/RF와 **같은 품질 fit 정답**을 사용한다. RGB 조명·태그·군집별 평균에50행의 전체 평균 사전을 더하고30행·2도로 미지원 그룹은 전체 평균으로 돌아간다. 시뮬 태그 평균은 오프라인 대조다. 이 고정 대조는 채택 기준이나 모델 선택에 쓰지 않았다. Dev에서는 조명 평균만으로도10% precision이GP와 같았으므로, Dev의 높은 검수 precision만으로 인지 출력 특징의 추가 가치를 입증하지 않는다. 새 확인에서는 회귀 오차와 검수 성적을 함께 비교한다. 단순 그룹 평균이 모든 RGB 전용 회귀 모델을 대표하는 것은 아니다.

## 불확실성·동점과 야간 해석

f0 Dev에서 GP SD 단독 저IoU AUC0.1552, SD/오차 Spearman−0.2889여서 큰 SD를 곧 저품질로 읽지 않는다. 유한 Cal CDF의 최댓값 동점은 후보의 GP38.03%/RF44.01%였으며 ID 순서와 표준화 margin을 비교했다. f0는 대안이 개선되지 않아 은행을 유지했고, g1도 독립적으로 Dev 대조했다. 현재 동점 처리는 `standardized_margin`다.

## 새 확인과 실제 인계물

26R1에서 미리 정한 같은 맵의3새 구간×6날씨×07/08/13/20시를 저속 주행했다.72조건, 원본1,815프레임·4채널7,260파일 해시를 보존했고3m 간격으로618장을 등록했다. 원 학습 ego 위치에서 최소46.35m, 이번 튜닝/추가학습에서30.83m 이격했다. 같은 맵·기존 링크의 다른 구간으로, 시야의 완전한 비중복이나 새 도시 검증을 뜻하지 않는다. RGB/GT는 실제 노출 시각이 없어 경계 대조로 등록 상태를 검증했다. 차량 위치·날씨·시각·제어 상태의 원복 영수증을 남겼다.

RGB48장→GT 없는 검수→사후 GT 연결에서 예약 역할을 유지했다. standalone 배포 묶음은 코드·독립 upstream Git·인지 가중치/학습 계보·품질/환경/보정·RGB8예제를 포함하며 원본 GT는 포함하지 않는다. 이 묶음만 마운트한40프로필 CPU와50프로필 실제5070Ti GPU에서 재생했다. 실제40GPU·실시간 ROS 성능 검증은 후속이다. 두 의존성 이미지에서 당시 CPU275검사가 통과했고, 개발 전용 탐색 감사의7검사를 더한 [최종282검사](../baselines/environment_cycle_20261128/reports/final_code_validation.json)도 각각 통과했다.

전체 표·그림·동결 JSON은 [공개 근거 시작점](../baselines/environment_cycle_20261128/README.md), 실행은 [코드 안내](../../scripts/experiments/environment_cycle_20261127/README.md), 팀원 재현은 [개발 환경](../guides/개발환경.md)을 따른다. 사례 그림은 평가 종료 후 큰 야간/새벽 개선과 최악 변화를 골랐으며 대표 평균으로 해석하지 않는다. 원본 경로·정확한 위치·가중치는 로컬 실험 볼륨에 남긴다.

## 남은 작업

1. 같은 원본에서 Q·GT/예측 지원량·근거리 FP/FN 사유를 분리해 재가공한다. 무표시 장면과 표시를 전부 놓친 장면을 구분할 RGB/상황 기반 가용성·검수 가치 목표를 먼저 확정한다. 무출력을 일괄 제외하지 않는다.
2. 표시·무표시·원거리 전용 장면과07시를 포함한 새 Dev/Cal에서 특징·상황 군집·GP/RF·검수 목적을 비교한다. 정책 선택은 BO/동일 예산 무작위 탐색의 합집합에서 고르도록 사전 명시하고, 균형 예약과 상대 임계 효과를 분리한다. 이번 확인은 실패 이력으로 보존하며 새 방법 선택에 사용하지 않는다.
3. 복수의 유효 표시 구간과 무표시 음성 구간을 동결한 새 독립 확인에서 통과한 뒤26R1 ROS shadow로 연결한다. 실제40GPU·버퍼 지연·역할 보존도 인수한다.
4. f1→f2는 부모 신원·전체 노출 원장·중복/보류·품질 재적합을 구현한 별도 비교다. 이번8학습은 모두 같은 v6 출발이며, 품질 선별이 무작위보다 재학습에 유리하다는 증거는 아직 없다.
5. 내부12월4일까지 수치·시연 영상·영어8분 발표·공개 프로젝트 페이지를 마무리한다. 공식 발표12월9일, 페이지 마감12월13일이다.
