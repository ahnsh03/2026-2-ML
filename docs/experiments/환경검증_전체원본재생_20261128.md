# 환경 검증과 전체 원본 재생을 통한 오프라인 갱신

**진행 중 — 완료 수치와 채택 여부는 아직 확정하지 않았다.** 목표는 군집의 환경 구분 능력, 환경별 검수 기준, 기존 데이터 구성 보존, 선별 후 인지 재학습과 새 품질모델의 연결을 한 단위로 확인하는 것이다. 이전 [4,096장 재생 실험](군집_검수_동일예산_재학습_20261127.md)의 결과는 별도로 보존한다.

## 원본 학습 데이터와 재생 구성

v6 체크포인트 내부의 train-manifest 해시와 현재 **26,001장** 목록이 일치한다. 전방·좌측·우측은 각각8,667장이다. 초기 네 수집 묶음14,145장과 이후 여덟 묶음11,856장으로 구성된다. 원본의 날씨·시각이 모두 직접 기록된 것은 아니므로 파일명이나 촬영 PC 시각으로 비어 있는 환경 정답을 만들지 않는다.

이전4,096장은 완전 무작위 추출이 아니라 **수집 묶음×카메라별 유사 장수와 시간 순서 균등 간격 추출**이었다. 원본에서 약32%인 큰 묶음도 재생에서는 약8.3%가 되었다. 이번에는 전체26,001장을 공통 재생 풀로 두고 순열을 반복한다. 캐시의 두 인지 정답과 패딩 마스크를 원래 학습 버전과 전부 비트 단위로 대조했다. 원본 이미지를 새로 복사하지 않는다.

## 같은 v6에서 시작하는 비교

| 방법 | 신규 데이터 | 기존 데이터 | 학습 시드 |
|---|---:|---:|---:|
| Random | 고정 무작위3,072장 | 전체26,001장 | 2 |
| RF global | 보정한 저IoU 검수 확률과 무작위 감사 | 전체26,001장 | 2 |
| GP global | 보정한 저IoU 검수 확률과 무작위 감사 | 전체26,001장 | 2 |
| Tag balanced | 시뮬 환경 태그별 균형 무작위3,072장 | 전체26,001장 | 1, 탐색 대조 |
| Full replay only | 신규0장 | 전체26,001장만 계속 학습 | 1, 계속학습 대조 |

추가 자료가 있는 방법은 매 배치 신규2+원본14, 대조군은 원본16이다. 모두 같은 Medium v6 EMA에서24,000업데이트를 수행하고 학습률·BN 통계 고정·원본 teacher 정규화를 공유한다. 기존 풀의 상대 빈도를 유지하면서 신규 자료를 명시적으로 조금 더 노출하는 비율이다. 원본만 계속 학습한 효과와 데이터 선별의 효과를 구분한다. 한 시드 대조의 한계는 최종 보고에 남긴다.

같은 alpha0.25/0.5/0.75/1.0의 가중치 보간을 모든 방법에서 대칭적으로 평가한다. **같은 alpha에서의 방법 비교**와 **개발 자료에서 고른 최종 파이프라인**을 구분한다. 새 확인 자료는 가중치·특징·임계값을 선택하는 데 쓰지 않는다.

## 특징과 환경 분류의 첫 검증

품질 회귀는9영역의 기존28열, 오검출 관련34열, 환경 요약52열, 구조 특징49열을 GP/RF에 각각 같은 품질학습 자료로 비교했다. 현재 v6용 선택은 GP28열과 RF49열이다. 이동 개발3도로의 도로별 평균 MAE는 각각**0.04020/0.04160**이다. 같은28열 비교에서는 GP0.04020/RF0.04587이다. 이 숫자는 아직 새 확인 주행의 성적이 아니다.

환경 분류는 품질 입력과 별도로 원본 RGB의 지역 블록 분포를 사용한다. 최소 밝기·대비·hue·채도10-bin을9영역+전체 화면에서 계산한400열, 이전 선택 히스토그램, 상부·보닛만의 표현을 비교했다. RGB 분류기 확률에 제곱근 변환을 적용한 뒤 공식 Faiss e-means로 양자화한16개 군집이 개발 자료의 환경 태그와 잘 대응했다. **시뮬 태그로 감독한 RGB 표현+e-means이며 순수 비지도 환경 발견이 아니다.** 개발 이동 자료에는6날씨 중5개만 있어 새 확인에는 폭풍과 새벽도 넣는다.

지역 블록 히스토그램은 [Roser·Moosmann, IV2008](https://www.mrt.kit.edu/z/publ/download/Roser_al2008iv.pdf)의 측정량에서 출발한 적용 변형이다. 이번 실험은 선명도를 제외한4종, 고정9영역과 전체 화면을 사용한다. 원 논문의 ROI·SVM 전체 재현은 아니다. [Cheng 등, IV2018](https://doi.org/10.1109/IVS.2018.8500385)의 환경 문맥과 [Lu 등, CVPR2014](https://openaccess.thecvf.com/content_cvpr_2014/papers/Lu_Two-Class_Weather_Classification_2014_CVPR_paper.pdf)의 하늘·반사·색 단서는 지역별 후보를 설계하는 근거다. 실제 선택은 현재 자료의 지리 분리 검증으로 판단한다.

## 환경별 기준과 검수

공통 **IoU<0.7**은 방법 비교용 정답 정의로 유지한다. 환경별 참조는 검수 순위만 바꾼다. Cal에서 환경별 분포를 만들고, 지원 장수·도로·5m 공간 셀을 확인하며, 지원이 부족하면 공통 기준으로 돌아간다. 환경별 할당을 일부만 예약하고 나머지를 전체 위험 순위로 채워, 임계값이 실제 환경 간 선택 비중을 바꿀 수 있게 했다.

시뮬레이터 태그와 RGB 군집 기준 모두 Dev에서 BO16회와 동일 예산 무작위 탐색16회를 비교했다. 현재 v6에서는 환경별 기준이 공통 정책을 개선하지 못했고, 선택된 학습 목록도 GP global과 정확히 같았다. 같은 목록을 별도 독립 학습으로 세지 않는다. **분류가 잘 된다는 사실이 환경별 IoU 임계값의 이득을 보장하지 않는다.** 인지 버전이 바뀌면 새 Cal/Dev 출력으로 기준을 다시 검토한다.

중요한 자료 편향도 확인했다. 현재 이동 Dev는 낮242장이 모두 근거리 precision/recall 양호, 밤119장이 모두 근거리 결함이다. Cal에도 지원되는 야간 근거리 양호 장면이 없다. 따라서 정상 야간과 실제 결함을 구별했다고 주장할 수 없다. 근거리 지표 양호와 가시성에 따른 운행 정상도 다른 의미다.

## 새 확인과 오프라인 실행

기존 등록 자료에서25m 이상 이격한 같은 맵의 새 세 구간을 영상·정답 검사 전에 정했다. 이는 추가학습·튜닝 자료와의 이격이며, v6 원 학습 경로에 없던 위치까지 증명하지는 않는다. 26R1에서6날씨와07/08/13/20시를 저속 주행하며4채널 원본과 요청·파일 관측·차량 상태를 보존한다. 프레임에는 실제 카메라 노출 시각이 없으므로 RGB/GT 경계 정합 검사를 별도로 수행한다.

현재 RGB만의48장 재생은40프로필 CPU와50프로필 GPU에서 동작했다. IoU 예측의 프로필 간 최대 차이는 약2.16×10^-7이고, 다른 인지 버전 쌍은 거부한다. 40계열 실제 GPU 하드웨어 시험은 아니다. 재학습 후에는 새 인지 가중치로 X·y·GP/RF·보정·검수 정책을 다시 만들고, 동결한 뒤 새 확인 자료를 연다. GT 연결 후에도 예약된 개발·확인 역할은 유지한다.

실행 단계와 해석 범위는 [이번 실험 코드 안내](../../scripts/experiments/environment_cycle_20261127/README.md)를 따른다. 온라인 ROS 연결·자동 학습 편입은 이 단위의 완료 조건에 포함하지 않는다.
