# 9영역 경로의 인지·품질 버전 쌍 연결 검증

**재학습된 인지모델 f1에 맞춰 특징·정답을 다시 만들고 품질 GP g1을 학습·보정·재생하는 기능을 연결했다.** 기존에 보관한 재학습 후보를 사용했으며 새 인지 재학습이나 채택 성과는 아니다. 주 기준선은 v6 EMA f0와 28열 g0다.

## 바꾼 이유와 계약

새 9영역 추출기·RGB 재생기는 f0 해시와 EMA 가중치만 사용하도록 고정돼 있었다. 재학습 체크포인트는 `model_state_dict`를 저장하므로, 경로만 바꾸면 읽을 수 없었다. 이전 버전의 GP·정답·보정값이 섞이는 것도 막아야 했다.

[버전 검증](../../src/quality_estimation/spatial_identity.py)은 완료된 재학습 실행의 `_SUCCESS`, 체크포인트·프로토콜·학습 구성원·원래 v6·타깃 정책 해시를 검증한다. f0는 EMA, f1은 명시한 학습 가중치를 사용한다. f1 명세·GP NPZ·보정 파일에는 같은 인지 계보와 가중치 키를 기록한다. 임의의 체크포인트 경로만으로 f1을 선언할 수 없다.

추출 팩은 인지 체크포인트·계보·가중치·스키마·원래 index를 확인한다. 다른 버전 팩이 이미 있으면 덮어쓰거나 재사용하지 않는다. RGB 재생 → 검수큐 → GT 연결에도 같은 식별자를 전달한다.

## 기능 검증에 쓴 자료

이전에 촬영·검토한 같은 지도 26R1 **384장**을 f1으로 재처리했다. 새로 수집한 사진 수에 더하지 않는다. 192장 학습·96장 보정·96장 진단으로 나누고 ID·디코딩 픽셀·기존 f1 학습 노출의 중복을 검사했다. 역할 간 최소 위치 이격은 학습/보정395.7m, 학습/진단355.1m, 보정/진단54.4m였다.

ROI9·28열 순서·GP 설정은 현재 기준선에서 가져왔고 특징/하이퍼파라미터 탐색은 하지 않았다. **192장 g1과 2,480장 g0를 성능 향상 비교로 사용하지 않는다.** 이미 확인한 자료이므로 독립 평가 주장도 하지 않는다. [프로토콜](../baselines/roi9_gp_20261126/version_pair/protocol.json)

## 확인 결과

| 검사 | 결과 |
|---|---|
| GT 파일을 마운트하지 않은 f1 RGB 재생96장, 추출과 같은 batch16 | 28열 차이0, GP 평균 최대 차이2.6e−14 |
| 재생 softmax와 원본 Semantic의9영역 카운트 재집계 | 다른 프레임0, 전체 IoU float32 저장 차이≤3.0e−8 |
| batch16과 batch8 대조 | 특징 차이2.42e−5·GP 평균 차이1.37e−5, 차선 마스크 변경0 |
| f0 기존16장 회귀 대조 | 특징 차이0 |
| 조건부 검수12장 → 사후 GT 연결 | 계보 유지, 학습 허용false |
| f1+g0, f0+g1, f1큐+f0정답 | 모두 거부 |

처음의 batch8 대조는 1e−5 검증 허용치를 넘었다. 차이를 숨기지 않고 batch16으로 맞춰 재검증했고, 서로 다른 배치의 수치 차이도 보존했다. 향후 추출 영수증에는 배치 크기·가중치·float32/TF32 설정을 기록한다. [실측·거부 사유](../baselines/roi9_gp_20261126/version_pair/verification.json)

소규모 g1의 진단 전체 IoU MAE는0.11695였다. Q/근거리90% 구간 포함률은71.9%/60.4%로 낮았다. 기능 연결이 성공해도 품질모델 채택 기준을 충족하는 것은 아니다. 추가 학습분과 보정 지원이 필요하다. [40 CPU GP 대조](../baselines/roi9_gp_20261126/version_pair/g1_rtx40_cpu.json)는 저장된96개 X의 평균/공분산을 검증하며 실제40 GPU 측정은 아니다.

## 재현과 다음 단계

[extract.py](../../scripts/experiments/roi9_gp_20261125/extract.py)의 `--adaptation-run`으로 기존 f0 팩과 **다른 출력 폴더**에 재생성한다. [fit_versioned_spatial.py](../../scripts/experiments/roi9_gp_20261125/fit_versioned_spatial.py)는 학습·보정·진단 역할과 최소 이격을 명시한 프로토콜을 받고 같은 계보를 GP 번들에 묶는다.

```bash
PYTHONPATH=src python3 -m quality_estimation.infer_spatial_images \
  --manifest "$RGB_MANIFEST" --data-root "$RGB_ROOT" \
  --recipe "$G1_BUNDLE/feature_recipe.json" --model "$G1_BUNDLE/quality_spatial_gp.npz" \
  --calibration "$G1_BUNDLE/calibration_26r1.json" --adaptation-run "$F1_RUN" \
  --simulator-release 26.R1 --batch-size 16 --output-dir "$NEW_REPLAY"
```

실제 갱신 채택에는 충분한 선별/replay 자료의 동일 예산 인지 재학습, 각 f1의 품질 학습·보정 재생성, 같은 미사용 도로와 기존 조건의 성능 유지 대조가 남는다. 새 검수큐의 승인·학습 manifest 연결도 별도 인수 대상이다. 기능용 g1을 배포 기준선으로 교체하거나 이 자료만으로 데이터 플라이휠의 개선을 주장하지 않는다.
