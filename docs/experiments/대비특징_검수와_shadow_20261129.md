## 변경 감사와 경계

시작 시 fetch한 원격 `main`은 `266d5c6`으로 현재 검증 인계와 같다. 별도 `roi7-final-quality-features` 브랜치는11월24일의 과거7영역 안이며 현행9영역에 자동 병합하지 않는다. 작업 중 새 팀 변경이 생기면 별도 비교·검증 후 반영한다.

사용자가 이번 요청에서 인지 가중치의 레포 포함을 명시했다. 기존 원본/모든 체크포인트 제외 원칙에서 **검증·버전 고정한 배포용 가중치만** 예외로 관리한다. 전체 원본 데이터·optimizer·개인 경로·상세 학습 원장은 포함하지 않는다. 이전r2 원본 해시·계보를 유지하고 모델과 다른 품질 번들의 혼합을 거부해야 한다.

이미 개봉한 확인590장은 새 검수 기준의 독립 시험으로 재사용하지 않는다. GP 대비 z의 기존 AUC0.928은 사후 진단이며 채택된 selector가 아니다. 새 후보는 별도 개발/보정과 확인이 필요하다. 새벽 SDK시각과 물리 가시성 정상은 별도 개념으로 유지한다.

shadow는 인지·추정·선별·로깅을 실행하며 조향/가감속에 품질 점수를 연결하지 않는다. 원본·재가공 근거를 E에 보존하고 D는 읽기 전용으로 사용한다. 개발 명령은 start/stop/status/replay가 명확해야 하며, 종료 후 마지막 UDP 패킷 뒤 SDK Keyboard/Park 복원까지 확인한다.

## 21시대 첫 점검

r2 원본 체크포인트2,032,633바이트와 기존 검증된 품질/검수/환경 번들50,094,073바이트를 공개 배포 폴더에 그대로 복사했다. 가장 큰 파일은48,737,377바이트로 일반 Git 범위다. JSON·NPZ 문자열과 체크포인트pickle 메타데이터에 개인 경로/비공개 식별자가 없는지 점검했다.

새 `--perception-release` 경로로40CPU/5070GPU 각각48장을 재생하니 기존 source run 대비 Q 차이0·선택 ID와 순서가 같았다. 한 장짜리 demo는 마지막 짧은 버퍼에서 기존 selector의0/0을 발견해 수정했고, 실제 repo 모델/예제만으로 실행했다. 두 프로필CPU337검사를 통과했다. 추론/Xy용 공개 모델과 재학습용 전체 ledger는 구분한다.

전방 UDP9291에는 아직 패킷이 없고9293/9295는 좌/우640×480,9297은 별도 상부 뷰였다. 이를 전방으로 잘못 연결하지 않는다. 실제 전방1280×720의 통신 설정을 확인한 뒤 shadow 기본 입력을 정한다.
