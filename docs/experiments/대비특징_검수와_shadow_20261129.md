## 26R1 ROS shadow·실제 주행

기본 경로는 **ROS1 카메라→분리된 얇은 bridge→GPU worker**다. UDP 대체 경로를 유지한다. 온라인은 GT 없이 RGB·인지 출력으로 Q와 검수 후보를 기록하며 품질 점수를 조향·가감속이나 자동 학습 편입에 연결하지 않는다.

|---|---|
| native ROS 정지180초 |176장 저장/추론·추론 생략0 |
| native ROS 주행300초 |293장 저장/추론·생략0,20Hz 수신5,995건·sequence gap0 |
| 저속 주행 |6개 짧은 구간 총88.45m, 목표4km/h·관측 최대5.57km/h·최대 CTE0.186m |

주행 제어는 ML 자체 UDP 저속 제어와 SDK 배치/복원을 사용해26R1 조향 부호를 한 번 반전했다. **카메라 ROS 연결이 차량 제어 ROS 이식을 뜻하지 않는다.** 동기 GT가 없는 주행은 정확도·인지 개선 근거가 아니다. 마지막 UDP 송신 뒤 Keyboard/Park·위치·날씨·시각을 복원했다. 이후 실행을 위해 전방 ROS 연결과 bridge는 유지했다.

초기45초에는 모델 준비 중3장을 생략해 이후 명령은 수신 전 예열하도록 바꿨다.4장 배치 재생에서는 RF Q 최대0.000595 차이가 나 `--processed-only`가 원래 프레임·창·**추론 배치**까지 보존하도록 개선했다. 원래293장과 배치 제어를 추가한 재생은 worker 소스 해시가 다르지만 핵심 scorer 해시는 같다. 추가146장에서는 worker 소스까지 동일하게 재확인했다.

통제 ROS 시험은 잘못된 카메라·해상도·깨진 JPEG 각12건을 거부했다. 과부하594장 중170장 추론/424장 생략을 원본 보존과 집계했다. Windows UDP detached40장 수신·추론·종료·CPU 재생도 일치했다. **프로토콜 재생 시험은 새 시뮬 정확도/학습 자료에서 제외**했다. 입력 없음은 no_input/exit3으로 종료하고 성공 표식을 남기지 않는다. 기존 bridge의 드라이브/checkout이 새 설정과 다르면 시작 전에 거부한다.

40/50 의존성 이미지에서 각각 **353개 CPU 검사**가 통과했다. 실제 GPU는5070Ti/CUDA12.8/capability12.0에서 실행했다. **실제40계열 GPU 재현은 미완료**이며 CPU 호환성으로 대신했다고 쓰지 않는다.
