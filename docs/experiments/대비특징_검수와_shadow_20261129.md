## 변경 감사와 경계

시작 시 fetch한 원격 `main`은 `266d5c6`으로 현재 검증 인계와 같다. 별도 `roi7-final-quality-features` 브랜치는11월24일의 과거7영역 안이며 현행9영역에 자동 병합하지 않는다. 작업 중 새 팀 변경이 생기면 별도 비교·검증 후 반영한다.

사용자가 이번 요청에서 인지 가중치의 레포 포함을 명시했다. 기존 원본/모든 체크포인트 제외 원칙에서 **검증·버전 고정한 배포용 가중치만** 예외로 관리한다. 전체 원본 데이터·optimizer·개인 경로·상세 학습 원장은 포함하지 않는다. 이전r2 원본 해시·계보를 유지하고 모델과 다른 품질 번들의 혼합을 거부해야 한다.

이미 개봉한 확인590장은 새 검수 기준의 독립 시험으로 재사용하지 않는다. GP 대비 z의 기존 AUC0.928은 사후 진단이며 채택된 selector가 아니다. 새 후보는 별도 개발/보정과 확인이 필요하다. 새벽 SDK시각과 물리 가시성 정상은 별도 개념으로 유지한다.

shadow는 인지·추정·선별·로깅을 실행하며 조향/가감속에 품질 점수를 연결하지 않는다. 원본·재가공 근거를 E에 보존하고 D는 읽기 전용으로 사용한다. 개발 명령은 start/stop/status/replay가 명확해야 하며, 종료 후 마지막 UDP 패킷 뒤 SDK Keyboard/Park 복원까지 확인한다.

## 21시대 첫 점검

r2 원본 체크포인트2,032,633바이트와 기존 검증된 품질/검수/환경 번들50,094,073바이트를 공개 배포 폴더에 그대로 복사했다. 가장 큰 파일은48,737,377바이트로 일반 Git 범위다. JSON·NPZ 문자열과 체크포인트pickle 메타데이터에 개인 경로/비공개 식별자가 없는지 점검했다.

새 `--perception-release` 경로로40CPU/5070GPU 각각48장을 재생하니 기존 source run 대비 Q 차이0·선택 ID와 순서가 같았다. 한 장짜리 demo는 마지막 짧은 버퍼에서 기존 selector의0/0을 발견해 수정했고, 실제 repo 모델/예제만으로 실행했다. 두 프로필CPU337검사를 통과했다. 추론/Xy용 공개 모델과 재학습용 전체 ledger는 구분한다.

전방 UDP9291에는 아직 패킷이 없고9293/9295는 좌/우640×480,9297은 별도 상부 뷰였다. 이를 전방으로 잘못 연결하지 않는다. 실제 전방1280×720의 통신 설정을 확인한 뒤 shadow 기본 입력을 정한다.

## 22시 초기 연결·개발 비교

- ROS 전방 `/image_jpeg/compressed` 약20Hz 수신과 native UDP 전방 조각 복원을 실제26R1에서 확인했다. 전방 Capture Mode와 스트리밍은 전환해서 사용했다. 카메라1의1280×720·위치/화각을 유지했다.
- ROS45초 표본23장 중20장을 상주 처리했다. 초기 모델 준비 중3장은 원본을 보존하고 추론 생략으로 집계했다. 현재 시작 명령은 모델/GP를 예열한 뒤 수신한다. 같은 처리20장의 오프라인 Q와 최대 차이1.384×10⁻⁶, 선택 ID/순서 일치다.
- `scripts/shadow.sh`로 demo/start/stop/status/replay/bridge를 제공한다. 기본은ROS, Windows UDP는 대체 경로다. 입력 없는 세션은 `no_input`·exit3으로 종료하고 성공 표식을 남기지 않는다. [실행 안내](../guides/shadow_실행.md)
-40CPU 의존성·5070Ti GPU에서 repo 모델/예제 demo를 실행했다.40실기 GPU는 연결된 장비가 없어 미검증이다. 두 CPU 이미지345검사 통과와 실제GPU 검증을 구분한다.

부모 적합2,500장·서로 다른 Cal835장·Dev334장을 사용해 GP 대비를 검수와 학습 입력으로 시험했다. Meta Cal은 부모 GP에 적합되지 않았음을 ID/픽셀 해시로 확인했다. 같은 적합 표본에서 만든 posterior를 그대로 학습 입력에 넣지 않았다.

| 개발 선별 후보 | 근거리 오류 recall | 도로 평균 가중 검수 recall |
|---|---:|---:|
| 기존 RF 오류 가치 |0.65957 |0.34732 |
| 기존 GP 오류 가치 |0.55319 |0.28668 |
| GP 근−원 z 단독 |0.38298 |0.22488 |

RF/GP 메타모델의 공통74열, GP 평균 추가, GP 평균+z/SD 추가를 같은 Meta Cal에서 비교했다. 어떤 입력 추가안도 기존 RF를 넘지 못했다. 작은 표본·고정한 메타모델 설정의 범위로 한정하며, 이 단계에서 입력 특징을 늘리지 않는다.25% 순위 결합만 별도 확인 후보로 고정했다. Gaussian z나 결합 순위는 실제 실패 확률이 아니다.

후보 고정 이후 새로운 같은 지도6구간·3정지 위치·6날씨·05/06/07/13/20시534장 확인 수집을 시작했다. Sunny13 중앙 위치의 사전 GT 검수6장은 확인에서 제외한다. 전체6구간은 GT 표시 지원이 있었으며 이전590장을 새 시험으로 재사용하지 않는다. **수집·독립 확인은 진행 중이며 채택 결과가 아니다.**
