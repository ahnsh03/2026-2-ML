# 고정 ROI 7영역의 최종 피처 판정

**보관 자료 기준 최종 품질 회귀 입력은 99열로 확정한다.** 고정 전방 카메라의 7개 ROI와 전체 화면에서 RGB 8개·인지 출력 4개를 반복한 96열에 전체 화면 불확실성 3개를 더한다. 모델은 한 프레임의 흰색·노란색 차선 IoU 하나를 예측한다. 이 결정은 오프라인 품질 추정과 검토 우선순위 산출에 적용한다.

[정확한 99개 열의 순서와 모델 해시](../baselines/roi7_final_20261124/selected_features.json) · [평가 수치와 판정 결과](../baselines/roi7_final_20261124/summary.json) · [도로 하나씩 제외한 검산](../baselines/roi7_final_20261124/sensitivity.json) · [앞 단계의 21개 피처 비교](ROI7_피처_검증_20261124.md)

### 최종 입력

| 계산 범위 | 입력 |
|---|---|
| 상단 좌우, 원거리 좌우, 근거리 좌우, 후드, 전체 화면에서 각각 RGB 통계 8개 | 평균 밝기, 평균 색차, 밝기 표준편차, 다크 채널 중앙값, 국소 대비, Sobel 선명도, 아주 밝은 픽셀 비율, 중앙값 필터 잔차 평균 |
| 같은 8곳에서 각각 인지 출력 통계 4개 | 주행 가능 영역 비율, 예측 차선 면적 비율, 흰색·노란색 차선 확률 합의 평균, 마킹 클래스 엔트로피 평균 |
| 전체 화면에서 추가로 3개 | 엔트로피 상위 10% 픽셀의 평균, 32×32 창 평균 엔트로피의 최댓값, 예측 차선 픽셀의 1·2순위 클래스 확률 차이 평균 |

기본 96열은 320×180에서 집계한다. 추가 3열은 패딩을 뺀 640×360 마킹 확률에서 계산한다. 엔트로피는 4클래스 기준으로 정규화한다. 32×32 창의 이동 간격은 16픽셀이며 가장자리 창을 포함한다. 예측 차선 픽셀이 없으면 확률 차이 평균에 0을 쓴다.

## 99개로 결정한 수치

표는 세 시드의 평균 MAE다. 낮을수록 실제 IoU에 가깝다. 별도 링크 열은 각 링크, 반복주행 열은 각 세션의 평균에 동일한 가중치를 준다.

| 열 수·구성 | 별도 도로 16개 링크 | 반복주행 20회 | 64프레임 창별 실패 적중 / 검토 805장¹ |
|---|---:|---:|---:|
| 96 · 기존 기준 | 0.12263 | 0.07785 | 565 |
| 97 · 차선 확률 차이 | 0.11237 | 0.06896 | 607 |
| 98 · 확률 차이와 상위 엔트로피 | 0.11275 | 0.06911 | 600 |
| 98 · 확률 차이와 최대 구간 엔트로피 | 0.11313 | 0.06833 | 608 |
| **99 · 불확실성 3개** | 0.11000 | 0.06776 | 610 |
| 102 · 불확실성 3개와 누락 단서 3개 | 0.10795 | 0.06689 | 612 |

¹ 적중 수는 미리 정한 대표 시드 23411이다. 실제 IoU가 0.70 미만이면 실패다.

- **96→99열**로 바꾸면 별도 링크의 오차가 0.01263, 반복주행의 오차가 0.01009 감소했다. 대표 시드에서 96열 대비 오차 감소의 짝지은 95% 구간은 별도 링크 [0.00455, 0.01708], 반복주행 [0.00711, 0.01278]이었다. 세 시드에서 링크 또는 주행을 하나씩 빼도 감소폭은 각각 0.00870~0.01577, 0.00876~0.01091이었다. 링크 표본의 10% 검토에서는 여섯 모델 모두 17장 중 17장이 실패였다.
- **97·98열**은 원래 개발 자료에서 유망했다. 가장 작은 97열과 개발에서 선택된 98열(확률 차이+최대 구간 엔트로피)은 독립 보관 평가에서 사전에 정한 오차 증가 허용폭 0.001과 검토 적중 유지 조건을 충족하지 못했다. 진단용으로 함께 계산한 나머지 98열도 두 평가의 평균 오차가 99열보다 컸다.
- **102열**의 MAE가 가장 낮았다. 99열 대비 세 시드 평균 이득은 별도 링크 0.00205, 반복주행 0.00087로 사전 교체 기준 0.003에 미달했다. 세 시드의 창별 적중 수는 99열이 610·609·613건, 102열이 612·605·607건이었다. 따라서 차선 검출 행 비율, 내부 공백 길이, 차선 밖의 약한 확률 지지까지 추가하는 구성은 이번 최종 입력에서 제외한다.

## IoU 0.7 경계에서의 실패와 오경보

아래는 대표 시드의 고정 경보다. 예상 IoU < 0.70이면 경보를 낸다. 분모는 미탐의 경우 실제 실패 수, 오경보의 경우 실제 정상 수다.

| 실제 IoU 범위와 자료 | 96열 미탐 | 99열 미탐 | 96열 오경보 | 99열 오경보 |
|---|---:|---:|---:|---:|
| 별도 링크 전체 164장 | 7/140 | 5/140 | 13/24 | 11/24 |
| 별도 링크 경계 15장 | 2/5 | 1/5 | 7/10 | 6/10 |
| 반복주행 전체 7,339장 | 630/3,144 | 440/3,144 | 570/4,195 | 363/4,195 |
| 반복주행 경계 1,097장 | 236/410 | 188/410 | 170/687 | 172/687 |

경계는 0.65 이상 0.75 미만이다. 반복주행 경계에서 99열은 미탐을 48장 줄였고 정상 오경보는 2장 늘었다. 공간 격자 단위 95% 재표집 구간에서 미탐률 감소는 6.8~18.1%p, 오경보율 변화(99−96)는 −2.2~+2.7%p였다. 별도 링크 경계는 8개 링크의 15장뿐이다. 이 자료가 지지하는 결론은 **99열 품질 추정 입력을 고정한다는 것**이다. 0.70을 자동 선별 경보에 쓰면 경계 부근의 놓침과 오경보가 위와 같이 남는다.

## 보정 자료에서 경보 기준을 바꾼 추가 검증

정상 175장을 포함한 기존 보정 자료 576장에서 96열과 99열 각각의 경보 점수를 정했다. 목표 오경보율 5%·10%·20%에 해당하는 보정 자료 점수를 동결한 뒤, 실제 IoU가 0.65 이상 0.75 미만인 반복주행 1,097장에 적용했다. 표는 대표 시드의 결과다. 경계 실패는 410장, 경계 정상은 687장이다.

| 보정 자료의 오경보율 목표 | 96열 미탐 | 99열 미탐 | 96열 오경보 | 99열 오경보 |
|---|---:|---:|---:|---:|
| 5% | 262 | 243 | 135 | 140 |
| 10% | 245 | 188 | 158 | 174 |
| 20% | 201 | 109 | 228 | 344 |

보정에서 10%를 목표로 잡았을 때 두 모델 모두 정상 175장 중 17장에 경보했다. 반복주행 경계에서는 99열이 실패를 57장 더 찾아냈고 정상 경보는 16장 늘었다. 세 시드 모두 같은 방향이었다. 별도 16개 링크의 경계 표본은 15장이다. 이 비교는 보정 자료에서 맞춘 경보율이 다른 주행의 경계 사례에서 달라질 수 있음을 보여준다. 실제 도로의 경보를 확정할 때는 링크·주행 단위로 정상과 실패를 함께 확보하고 허용할 오경보율을 먼저 정해야 한다. ### 추가 촬영 A·B 공간 중복을 확인하는 방법

공개 기록에 A(192장)와 B(288장)의 원본 매니페스트 해시와 세션 ID가 남아 있다. 프로젝트 로컬 데이터에서 해당 매니페스트는 확인되지 않았다. 원본 매니페스트나 8개·12개 촬영 지점의 실제 좌표와 링크 ID를 확보하면, 동일 KATRI 좌표계에서 이번 16개 링크와의 최단거리를 다시 계산할 수 있다. 전체 매니페스트를 받으면 공개 해시와 대조한 뒤 기존 등록 스크립트의 선분 거리 방식으로 25m 미만인 링크를 표시하고, 제외 전후 96·99열 오차를 재집계한다. 같은 장소에서 다른 날 찍을 수 있으므로 사진 해시 일치 여부만으로는 공간 중복을 판정할 수 없다. [A·B 공개 수집 기록](../baselines/roi_selection_20261124/verification.json)

## 추출 비용

99열 구성은 96열의 축소 인지 맵과 같은 프레임의 원해상도 마킹 확률을 함께 사용한다. 로컬 WSL에서 합성 입력 80회, OpenCV 단일 스레드로 측정한 특징 계산 시간 중앙값은 96열 5.94ms, 99열 19.06ms였다. 이 시간은 모델 추론, 파일 읽기, 경보 발행을 제외한 벡터 계산 시간이다.

## 수치 검산

원본 RGB·Semantic 파일 해시, 디코딩 RGB 해시, 모델·마스크·피처 순서를 확인했다. 추가 평가 7,851장 모두 IoU가 정의됐다. 기존 보관 IoU와 다시 계산한 IoU 차이가 0.000001을 넘는 프레임은 10장이고 최대 차이는 0.00071735였다. 실패·정상 분류가 바뀐 프레임은 0장이었다. 보관 IoU로 다시 평가해도 96열 대비 99열의 오차 감소량 차이는 두 주 평가 모두 0.00000008 이내였다.

## 자료와 판정 방법

- 기존 99열 선정에 사용한 14,331장과 이전 전체 화면 실험의 추가 프레임을 합친 14,907개 고유 프레임을 기준으로 중복을 검사했다. 새 평가 7,851장의 샘플 ID와 디코딩 픽셀 해시는 기존 자료와 겹치지 않았고 평가 내부 중복도 없었다.
- 정지 자료는 같은 KATRI 지도에서 서로 다른 위치를 찍은 세 보관 묶음 512장이다. 생성 당시의 MGeo 파일 해시, 계획한 좌표와 실제 좌표를 대조했다. 지도 링크의 모든 선분에서 기존 촬영점까지의 최소 거리를 구해 가장 가까운 지점도 25m 이상 떨어진 **16개 링크·164장**을 주 평가에 넣었다. 이 16개는 시뮬레이터가 기록한 실제 링크 ID도 모두 일치했다. 최소 촬영점 거리는 33.63m, 최소 링크 거리는 25.29m였다. 촬영점 거리를 50m 이상으로 높인 94장과 전체 512장은 별도로 분석했다.
- 시간대와 날씨가 다른 보관 주행 20회, 7,339장을 전부 사용했다. 이 자료는 기존 촬영 경로 근처를 다시 달린 영상이다. 별도 링크의 성능은 링크당 같은 가중치, 반복주행은 주행당 같은 가중치로 MAE를 집계했다. 같은 위치에서 여러 장을 찍었다고 위치를 여러 개로 세지 않았다.
- 훈련과 선별에 쓰지 않은 이번 보관 자료에서는 새 모델을 학습하거나 경보 기준을 조정하지 않았다. 96·97·99·102열 RF 12개의 해시를 사전에 고정했다. 98열 후보 두 개만 기존 학습 구역에서 동일한 RF 설정, 3-fold, 세 시드로 학습했다. 98열 후보 선정도 원래 개발 자료만 사용했다.
- 유지·교체의 판단 기준을 [주 실험 계획](../../scripts/experiments/roi7_final_20261124/protocol.json)에 기록했다. 경쟁 구성이 99열을 교체하려면 세 시드 모두에서 두 주 평가 묶음의 MAE를 각각 0.003 이상 줄이고 같은 검토 예산에서 적중수를 유지해야 했다. 별도로 작은 구성이 같은 성능인지 시험했다. 같은 조건에서 오차 증가 허용폭은 0.001이었고, 대표 시드에서는 두 후보 검토를 고려한 짝지은 재표집 구간의 상한도 이 허용폭 이내여야 했다. 이 수치는 이번 연구의 실무적 허용폭이다. [축소 계획](../../scripts/experiments/roi7_final_20261124/minimality.json) · [98열 판정 순서](../../scripts/experiments/roi7_final_20261124/size_fallback.json)
- 실패는 실제 전체 차선 IoU < 0.70, 경계 사례는 0.65 ≤ 실제 IoU < 0.75로 고정했다. 예측 IoU < 0.70 경보와 기존 보정 구역 정상 프레임 점수의 하위 10% 경보를 각각 평가했다. 주행 검토는 세션 내 촬영 순서로 64장씩 나누고 각 창에서 10%를 올림해 선택했다. 짝지은 2,000회 재표집은 도로 링크·주행 세션을 단위로 했고, 반복 경로의 50m 공간 격자로도 민감도를 확인했다.
- 모든 평가는 고정된 전방 카메라, 같은 KATRI 지도와 v6 EMA 인지 모델을 사용했다. 별도 도로 평가는 그 도로에서 여러 환경의 정지 프레임을 찍은 자료다. 별도 지도에서 연속 주행한 시험으로 해석할 수 없다. 과거 7영역 대 10영역 선정에 사용한 추가 A·B 480장의 전체 좌표가 이번 로컬 자료에는 없어 그 두 묶음과의 공간 중복은 확인 범위 밖이다. 사용자가 선택한 보관 자료 범위에서 판정을 마쳤다.

## 재현

저장소 루트에서 실행한다. `DATA`는 `ml_quality_study_20261123` 등을 포함하는 데이터 폴더, `MAP`은 실험 지도 원본 `src/asmc_planner/config/behavior/link_set.json`, `CHECKPOINT`는 고정 v6 `best_mean.pt` 경로다. 이전 실험 모델 및 해시 기록이 필요하다.

```bash
export PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
s=scripts/experiments/roi7_final_20261124
old=outputs/roi7_features_20261124
out=outputs/roi7_final_reproduction
python3 "$s/prepare.py" "$DATA" "$old" outputs/feature_ablation_20261124 "$MAP" "$out"
python3 "$s/pairs.py" "$old" "$out"
python3 "$s/infer.py" "$DATA" "$CHECKPOINT" "$out"
python3 "$s/score.py" "$DATA" "$old" "$out"
python3 "$s/publish.py" "$out" "$out/portable"
python3 "$s/sensitivity.py" "$DATA" "$out" "$out/portable"
python3 "$s/boundary.py" "$old" "$out" "$out/portable/boundary_alarm.json"
```
