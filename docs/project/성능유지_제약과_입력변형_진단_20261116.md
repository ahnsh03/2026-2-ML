# 기존 성능 유지 제약과 입력 변형 개발 진단

2026-11-16 오후. 이미 사용한 개발576행과 기존 조건1,997행으로 진단했다. 새 독립 평가의 성공 수치로 제시하지 않는다.
[통합 주기 검증](통합주기_검증결과_20261116.md)에서 확인한 기존 성능 하락과 품질 추정기의 분포 변화 대응을 구체화한다.

## Replay에서 초기 인지모델의 출력을 유지하는 제약

원래의 Random30·Quality30을 같은 두 시드·240updates로 다시 실행했다.
원래와 같은 신규/기존 manifest와 **매 step의8개 sample ID 전체 추출 순서**를 확인했다.
고정 f0의 replay 출력을 교사로 사용하고, 신규 행에는 제약을 적용하지 않았다.
두 head의 유효 영역에서 KL을 평균하며 weight1.0·temperature1.0을 결과 확인 전에 고정했다.

| 선별 | 원래 개발 IoU | 제약 추가 개발 IoU | 원래 기존 조건 IoU | 제약 추가 기존 조건 IoU |
|---|---:|---:|---:|---:|
| Random30 | 0.6144 | 0.6172 | 0.7791 | 0.7827 |
| Quality30 | 0.6137 | 0.6181 | 0.7734 | 0.7779 |

표는 두 시드 평균이고 네 개의 개별 비교 모두 개발·기존 조건 값이 소폭 높아졌다.
Quality의 기존 조건은0.7734→0.7779로 회복됐지만 f0의0.8006에는 못 미친다.
**이 제약 하나로 기존 성능 유지 문제가 해결된 것은 아니다.**
교사 cache 준비 비용이 추가되므로 같은 업데이트 수를 같은 GPU시간으로 해석하지 않는다.
모든 교사 cache 해시가 같고 첫 step의 제약 loss는 약8e-9였다. 유한 loss/gradient와 loss 합산도 확인했다.

후속 새 조건에는 가장 좋은 시드가 아니라 사전 지정한 첫 Quality 시드를 사용한다.
해당 모델의 X/y로 g1을 다시 적합하고 새 주행 전에 인지·품질·경보를 고정한다.
새 자료에서의 결과와 개발 진단을 구분하며 운영 기본 f0/g0는 유지한다.

## 품질 추정기 입력 변형에 대한 민감도

이미 노출된 개발 자료에서8조건별 sample ID순 첫4장, 총32개 원본 장면을 정했다.
원본·Gaussian blur(31×31,σ5)·contrast20%의96개 파생 입력을 만들었다.
같은 장면 GT·기하를 유지한 **합성 센서 입력 진단**이며 MORAI의 새 날씨 실험과 구분한다.
f0/g0와 개발 경보 cutoff0.6911은 바꾸지 않았다.

| 입력 | 실제 평균 IoU | 예상 평균 IoU | MAE | 저품질 recall | 정상 FPR |
|---|---:|---:|---:|---:|---:|
| 원본 | 0.5540 | 0.6022 | 0.0999 | 80.0% | 8.3% |
| Blur | 0.2286 | 0.3279 | 0.1097 | 100.0% | NA |
| Contrast20% | 0.0478 | 0.4356 | 0.3920 | 100.0% | NA |

Blur·Contrast의32행은 모두 실제 저품질이므로 정상 FPR은 정의되지 않는다.
저대비 장면은 저품질 경보가 나왔지만 실제 IoU0.0478에 예상0.4356으로 크게 과대 추정했다.
**경보를 냈다는 것과 IoU 수치를 정확히 추정했다는 것은 별도다.**
32개 장면의 파생본을96개 독립 표본으로 세지 않는다. 원본 행의 X/y는 기존 처리 결과와 대조했다.

## 프로젝트에 반영할 과제

- 기존 성능 유지는 소폭 회복에 그쳤다. 대표성 있는 replay·유지 제약과 학습량을 새 평가와 분리해 검토한다.
- 경보 임계값 조정만으로 낯선 입력의 IoU 추정 오차가 해결되지 않는다. 추정기의 자료 범위·실패 사례와 오경보를 함께 기록한다.
- 우선 선별 외에 무작위 감사 샘플을 남기고, 새로 확보한 검수 자료의 역할·사용 이력을 다음 주기에도 추적한다.
- [구현과 실행법](../development/선별자료_인지모델_재학습.md)과 [버전 쌍·검수·채택 판정](../development/버전쌍_경보_갱신판정.md)을 함께 유지한다.

## 학습 특징 범위의 사후 진단

원래 품질 학습824행의 특징별 최소/최대와1e-6의 수치 허용값만 사용해 범위 밖 특징 수를 셌다.
저대비 입력은56개 중 평균24.8개가 범위 밖이었다. 그러나 눈 조건에서는 모든 특징이 각 범위 안인83행도 MAE0.118이었다.
범위 밖 특징 수와 절대 오차의 순위 상관은 새 조건별로 약-0.16~0.26으로 일정하지 않았다.
이는 이미 본 자료의 기술 통계이며 새로운 OOD 탐지기 성과가 아니다. 범위 경고를 운영 규칙으로 추가하지 않았다.
