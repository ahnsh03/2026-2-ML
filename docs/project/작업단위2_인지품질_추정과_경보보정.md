## 2. 데이터 역할과 단위 1 인계

1. 기존 824개 학습 행의 X(출력 28열+RGB 28열)와 y로 시작한다. 정의된 y와 사용 가능한 행만 적합에 쓴다. 같은 자세를 여러 조건에서 찍은 영상은 같은 그룹에 둔다. 부모 세션·인접 경로·원본 픽셀 중복을 확인한다. 전처리·GP 파라미터 추정은 학습 쪽에서만 수행한다.
2. **모델 선택 → 경보 보정 → 잠금 평가**에 서로 다른 그룹을 배정한다. 기존 개발 576행과 이미 본 최종·주행 수치는 기준선 재현과 오류 진단에 쓴다. 기존 RF는 과거 개발 자료로 설정을 선택했으므로 새 모델과의 주 비교에는 양쪽 모두 보지 않은 보정·평가 그룹이 필요하다. 기존 학습 안의 그룹 교차검증으로 GP 커널 후보를 좁힐 수 있다. 기존 자료 역할은 보존하고, 부족한 보정 그룹은 별도 수집한다. 새 평가 그룹은 수집 전에 지정하고 모델·환경 프로필·경보 정책을 고정한 뒤 GT를 연다.
3. 날씨·시간·위치·실제 IoU는 사후 분석용으로 분리한다. 단위 1에서 **행 ID, RGB 해시 대응, 프로필·군집 모델 버전, 군집 ID와 배정 상태**를 받아 RGB 추론 결과에 결합한다. 데이터 분할을 양쪽에서 대조해 보정·평가 그룹이 환경 특징 선택이나 군집 학습에 들어간 경우를 제외한다. 군집 결과가 준비되기 전에는 전역 모델 비교와 밝기 그룹 대조부터 진행한다. [단위 1 인계 규격](작업단위1_주행환경_특징과_군집화.md)

## 3. 회귀와 불확실성 실험

2026-11-23 CPU 점검에서 scikit-learn 1.3.2로 기존 학습 X56의 상수 열을 제거하고 표준화한 뒤 824개 y에 GP를 적합했다. 고정 RBF+WhiteKernel, 목표 표준화, 커널 최적화 해제 조건에서 학습 행 8개에 대한 평균과 표준편차 출력을 확인했다. 이 점검은 라이브러리와 입력 형상의 호환성에 관한 근거다. RF와의 우열·구간 포함률은 아래의 분리된 자료로 평가한다. 기존 경보 CLI는 보정 행으로 `meta_dev`를 사용한다. 재현 시 기존 분할을 유지하고, 새 실험에서는 선택·보정용 부모 그룹 목록을 별도 보관해 서로 겹치지 않는지 모델 고정 단계에서 검사한다.

| 단계 | 비교와 고정 조건 | 결과표에 남길 값 |
|---|---|---|
| A. 품질 회귀 | 고정 f0, 같은 X56·y와 같은 평가 행에서 기존 RF와 전체 환경에 학습한 GP 하나를 비교한다. OLS·Ridge는 기존 참조값을 둔다. | 0~1로 제한한 예측의 MAE, 원시 MAE, 평균 편향(예측−실제), 조건별·최악 구간 MAE, 유효·미정의 수 |
| B. GP 예측구간 | 상수 열 제거·표준화 후 등방성 RBF 또는 Matérn(ν=1.5) 커널과 WhiteKernel을 비교한다. 목표값 표준화는 학습 행만 사용한다. 작은 대각 보정은 수치 안정화에 쓴다. 커널·잡음 설정과 수렴 여부를 저장한다. | 관측 잡음을 포함해 **새 프레임의 y**를 예측한 표준편차 σ, 90% 구간의 실측 포함률과 평균 폭, σ 분위별 실제 절대오차, 학습 시간·메모리와 단일 프레임 p50/p95 추론 시간 |
| C. ROI 추가 가치 | A·B 이후 단위 1에서 고른 소수의 RGB 영역 특징을 추가한다. 동일 모델·분할에서 X56만 쓴 경우와 짝비교한다. 군집별 cutoff가 주는 효과는 이 비교에서 제외한다. | 모델별 MAE 변화, 야간·가림 구간 편향, 특징 계산을 포함한 추가 지연 |

첫 GP 구간은 원시 평균 μ와 관측 표준편차로 계산한 **μ ± 1.645σ**를 사용한다. σ와 구간은 원래 IoU 단위로 되돌려 계산한다. 구간 평가에서는 양 끝을 자르기 전의 폭·포함률을 보고하고, 점 예측의 clipping과 구분한다. 보정 그룹의 RF 절대 잔차 90백분위로 만든 고정 폭 구간도 함께 평가하면 모든 장면에 넓은 구간을 주는 대조군과 비교할 수 있다. σ가 큰 구간에 실제 큰 오차가 모이는지, 야간에 좁은 구간으로 틀리는지 확인한다. σ를 실패 확률로 사용하려면 별도 검증이 필요하다. [scikit-learn 1.3 GP 회귀와 커널](https://scikit-learn.org/1.3/modules/gaussian_process.html)

GP의 점 예측 채택 후보는 같은 평가 행에서 RF 대비 MAE가 줄고, 분리된 위치·세션에서도 개선 방향이 반복되는 경우다. 지연과 메모리를 함께 보고하고, 구간을 출력하는 추가 비용도 평균만 계산할 때와 비교한다. 점 예측은 RF가 우세하지만 σ가 큰 장면에서 오차가 일관되게 커지면, GP는 단위 3의 오프라인 선별 후보로 별도 인계한다.

## 4. 환경별 경보 보정 실험

**먼저 RF 예측값을 한 번 저장한 뒤 같은 행에 아래 네 정책을 적용한다.** 이후 GP 평균에도 같은 절차로 각 cutoff를 새로 보정한다. 동일 모델 안에서 열을 비교하면 환경 보정의 효과를, 같은 정책에서 모델을 비교하면 품질 추정기 변경의 효과를 볼 수 있다.

| 정책 | 보정·적용 규칙 | 확인할 질문 |
|---|---|---|
| 고정 0.7 | 예상 IoU가 0.7 미만이면 경보 | 과거 고정 경보 결과를 재현하는가? |
| 전역 보정 | 모든 보정 정상 장면에 하나의 cutoff | 환경 정보 없이 오경보 예산을 적용한 효과는 얼마인가? |
| 밝기 그룹 보정 | 단위 1의 학습 자료에서 고정한 밝기 구간별 cutoff | 주야 밝기만으로도 개선되는가? |
| 환경 군집 보정 | 단위 1의 고정 군집별 cutoff. 밝기 대조와 같은 그룹 수로 비교 | 보닛·하늘·도로 특징으로 구분한 환경이 밝기를 넘어 추가로 도움이 되는가? |

- 시작값은 기존 구현의 **보정 정상 FPR 예산 10%**다. 정상 점수 n개를 정렬해 0부터 센 `floor(0.1 × n)`번째 값을 cutoff로 정하고 동점은 함께 처리한다. 저장된 자료형 기준의 엄격한 `<` 연산을 재사용한다. 보정 자료에서의 제약이며 새 환경에서도 10%를 보장하는 수치는 아니다. [기존 보정 함수](../../src/quality_estimation/alarm.py)
- 기존 함수의 최소 정상 표본은 20행이다. 군집별 1차 계획은 **정상 20행 이상이며 서로 다른 주행 구간 또는 자세 그룹이 2개 이상**일 때만 개별 기준을 시도한다. 표본 수와 그룹 수는 검증표에 함께 표시한다. 그 외에는 같은 모델의 전역 기준을 적용한다. 미배정·낮은 배정 신뢰도도 전역으로 보내고 이유를 기록한다. 모델·프로필 버전 불일치는 입력 오류로 처리한다.
- 같은 평가 행에서 TP·FP·FN·TN, FPR, Recall, 정밀도와 전체 경보 비율을 전역·날씨/시간·군집별로 집계한다. 정상 또는 저품질이 없는 조건의 해당 비율은 NA로 둔다. 전역 보정 대비 **오경보→정상 통과 / 정상 통과→오경보 / 탐지→누락 / 누락→탐지** 네 전환 수를 함께 제시한다. 조건별 표에는 분모·고유 구간 수도 싣는다. 불확실성 범위는 독립 세션 또는 주행 구간을 묶어서 추정하고, 그룹 수가 적으면 구간별 원수를 제시한다.
- **1차 인계 판단**은 미리 지정한 야간 조건에서 전역 보정보다 FPR이 낮아지고, 같은 평가 행에서 야간과 전체 Recall이 모두 유지되는지다. 야간 정상 장면만 줄여 얻은 결론을 피하도록 주간 최악 조건의 FPR·누락 수도 함께 검토한다. FPR과 Recall이 함께 하락하면 감소한 오경보와 늘어난 누락의 교환관계로 보고한다. 지표가 미정의이거나 세션별 결론이 엇갈리면 후보로 보류한다. 이 판단은 연구 인계용이며 서로 다른 환경의 허용 주행 위험을 정하는 기준과는 구분한다.

## 5. 근거리·원거리 오류 진단

단위 1의 검토된 도로 ROI를 원본 좌표에서 인지 출력 좌표로 옮길 때 기존 리사이즈·letterbox 변환을 사용한다. 같은 f0 예측과 Semantic GT에 대해 각 마스크와 기하·주석 유효 영역의 교집합에서 흰색·노란색 차선 TP·FP·FN, GT 픽셀 수와 IoU를 계산한다. 빈 union은 NA로 남기고 얇은 원거리 차선 몇 픽셀의 영향도 표시한다. 조건별로 프레임 평균과 픽셀 합산 IoU를 구분한다. [기존 라벨 계산](../../src/quality_estimation/labels.py)

같은 자세의 주간·야간 RGB, 예측, GT, 근·원거리 오류를 나란히 본다. **전방 전체 GT 품질은 정상인데 추정기가 낮게 본 경우**와 **실제로 원거리 차선을 놓친 경우**를 따로 집계한다. 가시거리의 정답 정의를 바꾸려면 독립 가시성 주석이나 검토 기준을 마련해 별도의 정답 버전으로 평가한다. 이 분석에서 현재 y와 0.7 기준은 고정한다.

## 6. 개발 순서와 인계물

1. **기준선부터 재현한다.** 기존 f0/g0 RGB 추론 행과 GT를 행 ID와 RGB 해시로 대조한다. 맑음 20시 표와 동일 자료·동일 cutoff에서 정상 61장 중 FP 41장, 저품질 291장 중 TP 284장이 나오는지 확인한다. 경보 이진 판정과 프레임 순위는 별개로 저장한다.
2. **GP·그룹별 경보를 선택 기능으로 추가한다.** 학습 프로토콜, 모델 로더와 선택 가능 모델 목록, 예측 결과, 보정 산출물의 단일 cutoff 구조를 확장한다. 단위 1 특징을 붙일 때는 별도 특징 버전에 열 순서를 기록한다. 기존 RF 산출물로 같은 예측을 재현하고, GP 재로딩 후 평균·표준편차 일치, 구간 폭, 0.7 경계·동점·빈 GT·저표본·미배정, 입력 버전 불일치를 검사한다. [모델 학습](../../src/quality_estimation/train_models.py) · [모델 로더](../../src/quality_estimation/model_io.py) · [GT 없는 추론](../../src/quality_estimation/infer_images.py)
3. **결정과 근거를 넘긴다.** 산출물은 ① 같은 행의 RF·GP 회귀 및 구간 비교표, ② 모델별 네 경보 정책의 짝비교표, ③ 근·원거리 GT 오류 그림, ④ 버전을 고정한 품질모델·경보 설정과 RGB 단독 추론 예시다. RF를 유지하면서 환경별 경보만 넘기는 결론도 가능하다. GP의 σ는 포함률·폭과 오차별 진단 결과를 함께 제시할 수 있을 때 단위 3의 검수 후보 신호로 넘긴다.
4. **단위 3에는 GT 없는 행별 결과를 제공한다.** 행 ID, 예상 IoU, 선택 모델이 제공하는 예측 표준편차, 군집 ID·배정 상태, 적용 cutoff·전역 대체 이유, 경보 여부, 인지·품질·군집·보정 버전을 기록한다. 실제 IoU는 평가 표에만 둔다. 이후 단위 4에서 인지모델을 f1로 바꾸면 그 버전의 X/y로 품질모델과 cutoff를 다시 적합·검증한다.
