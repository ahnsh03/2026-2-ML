> 2026-11-22 문서 검토. 아래 일정의 출처는 `5_IsTrue_v2.pptx` 슬라이드 17과 발표자 노트다.

## 발표의 주차별 계획

| 주차 | 발표의 과제 | 필요한 작업·인수물 |
|---|---|---|
| W10 | 모델 학습 | v6 연결과 X/y 구성 후 Least Squares(OLS)·Ridge·Random Forest 학습 |
| W11 | 모델 비교·선택 | 동일 검증 데이터의 clipped MAE 비교, 선택 모델·전처리·특징 규약 동결 |
| W12 | 성능 검증 | 예상–실제 IoU 산점도, 독립 평가, 날씨·시간대·과신 오류 분석 |
| W13 | 데이터 선별 및 인지 모델 재학습 | 동일 중복 제거 후보에서 5/10/20% 선별 Recall 비교. 여건이 되면 같은 예산의 재학습·독립 평가 |
| W14 | 결과 분석 | MAE·예산별 Recall·조건별 분석, 수행한 경우 재학습 효과, 한계·재현 자료·최종발표 |

슬라이드 17은 재학습 개선 지표를 최종 목표로 적고, 슬라이드 16 노트는 추가학습을 “여건이 된다면” 수행한다고 설명한다.
품질 추정·선별 검증을 우선하며 실제 재학습을 수행하지 않았다면 개선 수치를 제시하지 않는다.
실시간 감지·대응은 지연시간을 확인한 후의 확장이다.

현재의 통합 개발 순서는 [데이터 플라이휠 개발 현황](통합_데이터플라이휠_개발현황_20261116.md)을 따른다.
아래 발표 당시 범위 조정 문구로 이후 사용자 요청에 따른 통합 개발을 제한하지 않는다.

## 현재 구현과 남은 검증

2026-11-16 후속 개발에서 X/y 구성·독립 재계산 검증, 부모 그룹·중복·인지 모델 노출을 반영한 split,
OLS/Ridge/RF 비교, GT 없는 품질 추론과 5/10/20% 선별을 실행했다.
같은 정답 수·업데이트 수의 인지 모델 재학습과 replay-only 대조군을 개발·예약 평가에서 비교했고, f1/g1 새 주행 검증도 완료했다. 갱신 후보는 기존 성능 유지 기준 미달로 채택을 보류했다.
[현재 개발 현황](개발현황.md)의 완료 범위와 남은 과제를 우선한다.
이는 위 주차 계획을 날짜만 보고 완료 처리한 것이 아니라 실제 실행한 범위다.
[X/y 검증](../development/X_y_데이터셋.md) · [회귀·선별](../development/회귀학습_선별평가.md) · [재학습](../development/선별자료_인지모델_재학습.md)

1. **A:** 기존 잠금 평가의 역할·원본 해시·중복 감사를 보존하고 다른 지도·날짜의 신규 평가 역할을 수집 전에 배정한다.
2. **B:** 선택한 품질 모델과 비교할 인지 checkpoint를 평가 전에 고정하고 재현 가능한 bundle을 인계한다.
3. **C:** 잠금 평가에서 MAE·선별 효율·재학습 개선량·기존 조건 성능 유지를 각각 보고한다.
4. **A/B/C:** 동일 지도·세션의 반복이라는 한계를 유지하고, 다른 지도·날짜와 조건으로 검증을 확대한다.
5. **A/B/C:** f1/g1 연결·개발 경보 보정의 완료 기록을 바탕으로 새 분포의 오경보를 줄인다. 26R1 ROS·전체 지연·f2 누적 갱신은 후속 작업이다.

A/B/C는 기술 역할이며 실명은 임의로 배정하지 않는다. GPU가 없는 팀원도 작은 X/y 표로 학습·평가 작업을 진행할 수 있게 인계한다.

## 범위 조정 기준

- 기본 X/y·회귀·선별 검증에 앞서 의미 영역 ROI·다중 target·시간 특징을 필수로 늘리지 않는다.
- 신규 독립 세션이 부족하면 수집을 보강하고, 과거 validation은 탐색 자료임을 표시한다.
- RGB/ROI 특징이나 회귀 선별이 기준선보다 낫지 않으면 그 결과와 과신·배경 집계·누수 가능성을 분석한다.
- 당시 재학습은 시간에 따른 선택 과제였으나 현재는 이미 실험했다. 개선된 조건과 기존 성능 감소를 함께 보고하고, 과거 범위 조정 문구로 통합 개발을 제한하지 않는다.
- final_test 결과를 본 뒤 특징·임계값·모델을 다시 선택하지 않는다.
